# บรีฟเว็บEA BULL (แนวเดียวกับ EA WING)

เอกสารนี้เขียนจากงาน eawing.co (1 ถึง 29 ต.ค. 2026) ให้แชทใหม่ที่จะสร้างเว็บขาย EA อีกแบรนด์อ่านก่อนเริ่มงาน
แชทใหม่ไม่มีความจำของแชท EA WING เลย ทุกอย่างที่เจ้าของเคยสั่งไว้จึงรวมอยู่ในไฟล์นี้

## 0) ภาพรวม

- เว็บใหม่มีโครงหน้าและระบบเหมือน eawing.co ทุกหน้า **ยกเว้นบทความ (โพสต์)** ซึ่งยังไม่ต้องเขียน
- หน้าตาเป็นของแบรนด์ใหม่เอง สี อารมณ์ และลวดลายดึงจากโลโก้ของแบรนด์ใหม่ ห้ามหน้าตาเหมือน EA WING, ea2000, FALCON หรือ FENIX
- ข้อความเขียนใหม่ทั้งหมด ห้ามคัดลอกจากเว็บในเครือ เพราะเจ้าของเดียวกัน ถ้าข้อความซ้ำข้ามโดเมนจะโดน duplicate content
- **ลำดับงาน: ออกแบบก่อน แล้วค่อยทำของจริง**
  - **เฟส 1 ต้นแบบ:** ทำต้นแบบ HTML ของทุกหน้า แล้วให้เจ้าของดูจนอนุมัติ
  - **เฟส 2 ธีมจริง:** ทำธีม WordPress จริงโดย fork จากโค้ด EA WING
  - **เฟส 3 ขึ้นเว็บ:** ใส่เนื้อหาเพจและขึ้นเว็บ
  - **เฟส 4 บทความ:** ทำทีหลัง ไม่อยู่ในงานนี้

## 3) สิ่งที่เจ้าของชอบและไม่ชอบ (เรียนรู้จากงาน EA WING · ใช้กับแบรนด์ใหม่ด้วย)

**ดีไซน์**
- **ไม่มีเงา (box-shadow) ทั้งเว็บ:** แยกบล็อกด้วยขอบและสีพื้นแทน
- **ไม่มีคำเล็กเหนือหัวข้อ (kicker)**
- **ปุ่มหลัก:**
  - สีแฟลทสีเดียว ห้ามไล่สี เจ้าของว่าไล่สีดูโบราณ
  - ต้องเด่น · ทองตุ่น ๆ เจ้าของว่าไม่เด่น จึงเปลี่ยนเป็นเหลืองสด
  - ตอนเอาเมาส์ชี้ให้เข้มขึ้นเล็กน้อย
- **ปุ่มรองและปุ่มเส้น:** ปุ่มรองเป็นสีเข้มทึบ · ปุ่มเส้นพื้นใส มีขอบ · ห้ามปุ่มพื้นขาวบนพื้นสีอ่อน
- **ปุ่มช่องทางติดต่อใช้สีแบรนด์จริงเสมอ:**
  - LINE `#06C755` ตัวขาว (ทุกปุ่มที่ลิงก์ LINE ห้ามเป็นสีธีม)
  - OpenChat พื้นขาว ขอบเขียว
  - Facebook `#1877F2`
- **แถบล่างมือถือ:**
  - พื้นทึบสีเข้มของแบรนด์ 5 ช่องเท่ากัน ตัวขาว ทรงแคปซูล
  - ช่องหน้าปัจจุบันเป็นแคปซูลขาว
  - ช่อง LINE หน้าตาเหมือนช่องอื่น
  - แถบไม่ย่อตอนเลื่อน
- **สีตามความหมาย:** ✓ เขียว · ✗ แดง · คำเตือน อำพัน · เคล็ดลับ เขียว · ข้อมูลทั่วไป ฟ้า · ห้ามใช้สีแบรนด์กับเครื่องหมายถูกผิด
- **ตัวอักษรภาษาอังกฤษ:** เป็นพิมพ์ใหญ่ทั้งเว็บ (ทำด้วย CSS) · ยกเว้นอีเมล ลิงก์ @LINE ID ชื่อไฟล์ XAUUSD.c และ iPhone/iOS
- **ไม่มีโหมดมืด**
- **ไม่มีกรอบนอกสุดรอบทั้งเว็บ**
- **การ์ด:**
  - ไม่มีพื้นที่ว่างโหว่ใต้เนื้อหา
  - การ์ดในแถวเดียวกันสูงเท่ากัน
  - ไอคอนอยู่กึ่งกลางกระเบื้อง
- **ฟอนต์ไทย self-host:** EA WING ใช้ Kanit (หัวข้อ) กับ Noto Sans Thai (เนื้อความ) · แบรนด์ใหม่เลือกคู่ใหม่ให้เข้ากับโลโก้ได้
- **ตัวอักษรต้องผ่าน contrast 4.5:1**

**ข้อความ**
- ภาษาไทยทั้งเว็บ · ห้ามใช้ em dash และ en dash ให้ใช้ `·` หรือ `:` แทน
- ห้ามแต่งรีวิว
- ห้ามตัวเลขผลเทรดสมมติ
- ห้ามระบุข้อเท็จจริงของธุรกิจหรือของ EA ที่เจ้าของยังไม่ได้ให้ เช่น เวลาทำการ เงื่อนไขคืนเงิน หรือค่าตั้งภายใน
  - ในต้นแบบให้ใช้ช่องว่าง หรือข้อความที่บอกชัดว่า "รอข้อมูลจากเจ้าของ"
- ภาพที่มีตัวเลขต้องมีคำบรรยายว่าเป็นภาพประกอบหรือตัวอย่าง
- ห้ามลดคำเตือนความเสี่ยง
  - กฎ "ต้องบอก / พูดได้ / ห้าม" ของแต่ละ EA มาจากเอกสารของเจ้าของในโฟลเดอร์สินค้า
  - ต้องอ่านเอกสารทุกไฟล์ในชุดให้ครบก่อนเขียน
- คำต้องห้ามในงานขาย: รับประกัน กำไรแน่นอน ไม่มีขาดทุน ปลอดภัย 100% รวยเร็ว % ต่อเดือนหรือต่อปี
- ระบุความเป็นพันธมิตรกับโบรกเกอร์ตรงที่กล่าวถึงครั้งแรก · ลิงก์สมัครโบรกเกอร์ติด `rel="sponsored"` เสมอ
- ปิดการขายทาง LINE · ไม่มีฟอร์มอีเมล

## 4) วิธีทำงานกับเจ้าของ

- **ตอบเป็นภาษาไทยเท่านั้นทุกข้อความ** รวมถึงข้อความแจ้งความคืบหน้าสั้น ๆ (เจ้าของย้ำหลายรอบ)
- **ตัดสินใจเรื่องดีไซน์ สี ฟอนต์ และข้อความเองแล้วลงมือ:**
  - ไม่ต้องถามทีละข้อ
  - ถ้ามีตัวเลือกให้ทำมาให้ดู 3 ถึง 4 แบบ แล้วให้เจ้าของเลือก (เช่น ตอนเลือกเฉดเหลืองของ EA WING)
- **หยุดถามเฉพาะสิ่งที่ทำแทนไม่ได้:** ล็อกอิน รหัสผ่าน และข้อมูลจริงของธุรกิจ
- **ตรวจสถานะจริงเองก่อนบอกว่าเจ้าของต้องทำอะไร**
- **รุ่นใหม่ของ EA มาเมื่อไหร่:** อ่านทุกเอกสารในชุดและแก้ให้ครบทั้งเว็บ ก่อนรายงานว่าเสร็จ
- **Claude ไม่พิมพ์รหัสผ่าน และไม่คัดลอก token:**
  - เจ้าของล็อกอิน wp-admin เองในแท็บเบราว์เซอร์ของ Claude
  - ไม่ลบข้อมูลถาวรแทนเจ้าของ

## 5) บทเรียนด้านเทคนิค (ใช้ในเฟส 2 ขึ้นไป)

**fork โค้ด**
- fork `eawing/` แล้วเปลี่ยนชื่อภายในทั้งหมดในครั้งเดียว:
  - prefix `eaw_` / `eaw-` / `eawCamel`
  - text domain
  - REST namespace
  - shortcode `[eawing_*]`
  - ชื่อคุกกี้
- ต้องไม่มีชื่อ EA WING หลงอยู่ใน source · ทำ `check-brand.php` ของแบรนด์ใหม่ไว้สแกน
- ลบของเฉพาะ EA WING ออก: สินค้า 3 ตัว ภาพ banner ปก ภาพหน้าจอ และ zip

**Customizer-driven**
- ข้อความ รูป และลิงก์ทุกจุดเป็น setting (default + control)
- เนื้อหายาวอยู่ใน `inc/content/pages/*.html` แล้วนำเข้าด้วยหน้า Setup ใน wp-admin
- ไฟล์เนื้อหามี `rev` · เลข rev สูงขึ้นจึงแทนของบนเว็บได้
- ก่อนแทนเนื้อหาบนเว็บ ให้เทียบ hash ว่าของบนเว็บยังตรงกับ seed เดิม

**เลขรุ่นของ EA**
- ตั้งที่เดียวเป็น setting แล้วใช้ shortcode แสดงชื่อไฟล์และเลขรุ่น
- ห้ามพิมพ์เลขรุ่นหรือชื่อไฟล์ลงในเนื้อหาตรง ๆ

**เมนู**
- ชื่อรายการเมนูเป็นข้อความที่บันทึกตอนสร้างเมนู
- เปลี่ยนรุ่นแล้วต้องแก้ชื่อรายการเมนูด้วย

**รูปกับ Cloudflare**
- Cloudflare แคชรูปตาม URL · เปลี่ยนรูปเมื่อไหร่ต้องเปลี่ยนชื่อไฟล์ (เช่น ขึ้นเลข v)

**Deploy**
- GitHub, WP Pusher (Push-to-Deploy + webhook) แล้วใช้ `dev/deploy.sh`
- `deploy.sh` push แล้วรอ 20 วินาที ส่ง webhook ซ้ำ แล้วเทียบไฟล์บนเว็บ

**ก่อน commit**
- `php -l` ทุกไฟล์ที่แก้
- `check-settings` ต้องได้ (none)
- `check-content` ต้อง all good
- `check-brand` ต้อง no brand leaks
- ตรวจ 3 ขนาดจอ · ต้องไม่มี PHP Warning หรือ Notice ในหน้าที่เรนเดอร์

**สิ่งแวดล้อมของเครื่อง**
- Windows ใช้ PHP พร้อม extension mbstring และ gd
- Python ใช้ `py -3 -I` และต้องตั้ง `sys.stdout.reconfigure(encoding='utf-8')` ไม่งั้นพิมพ์ภาษาไทยไม่ได้

**git**
- ถ้าบัญชี git ของเครื่องไม่มีสิทธิ์ push ให้ตั้ง credential helper ระดับ repo เป็น `gh auth git-credential` (แบบเดียวกับ EA WING)

**PDPA และ GA4**
- การ์ดคุกกี้พูดถึงเฉพาะบริการที่ใส่รหัสไว้จริง · โหลดแท็ก GA4 หลังผู้ใช้ยินยอมเท่านั้น
- ห้ามเชื่อม Analytics ผ่าน Site Kit เพราะแท็กจะซ้ำและข้ามขั้น PDPA

**SEO**
- ทุกหน้าต้องมี title, description, H1 เดียว และ og:image
- รูปต้องมี alt และขนาด
- ลิงก์ภายนอกต้องมี noopener

**เอกสารของโปรเจกต์**
- ตั้งแต่วันแรกให้สร้าง `CLAUDE.md` ของ repo ใหม่
- จดกติกา คำสั่งของเจ้าของ (พร้อมวันที่) และสถานะเว็บไว้ เพื่อให้แชทถัดไปทำงานต่อได้

## 6) ข้อมูลที่ต้องขอจากเจ้าของ

**ต้องมีก่อนเริ่มเฟส 1**
1. ชื่อแบรนด์ และโดเมน
2. ไฟล์โลโก้ความละเอียดสูง: SVG หรือ PNG พื้นใส · ถ้ามีแบบพื้นเข้ม พื้นสว่าง และไอคอนเดี่ยว ให้ส่งมาด้วย
3. สีแบรนด์ (ถ้ามี) · ถ้าไม่มี Claude ดึงจากโลโก้เอง
4. ภาพโฆษณาหรือภาพแบรนด์ที่มีอยู่ (ใช้เป็นอารมณ์ของแบรนด์ · ภาพที่มีตัวเลขกำไรเว็บจะไม่ใช้)
5. รายชื่อสินค้า EA ของแบรนด์ (ชื่อและเลขรุ่น) · ถ้ายังไม่มีเอกสาร ต้นแบบจะใช้ช่องว่างไปก่อน
6. เว็บหรือภาพอ้างอิงที่ชอบ (ถ้ามี) · EA WING ใช้ภาพเว็บแนวกระจกฝ้าเป็นจุดตั้งต้น

**มีทีหลังได้ (ก่อนเฟส 2 และ 3)**
