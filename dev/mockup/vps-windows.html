รัน EA บน Windows VPS ด้วย Remote Desktop

VPS คือคอมพิวเตอร์เช่าที่เปิดอยู่ตลอดในศูนย์ข้อมูล ย้าย MT5 ไปไว้ที่นั่น EA ก็ทำงานต่อได้แม้คอมที่บ้านปิดหรือไฟดับ คู่มือนี้พาเชื่อมต่อครั้งแรกจนถึงปล่อย MT5 ทิ้งไว้

ใช้เวลาราว 15 นาที สำหรับคอม Windows 6 ขั้นตอน

สรุปแบบสั้น

เปิด Remote Desktop ใส่ IP ใส่ชื่อผู้ใช้ ยืนยันเครื่อง ลง MT5 ปล่อยทำงาน

ก่อนเริ่ม

ข้อมูลเข้า VPS มาจากผู้ให้บริการ VPS ที่คุณเช่า เก็บไว้ในที่ปลอดภัย อย่าส่งรหัสผ่านให้ใครในแชต

ถ้ายังไม่มี VPS ทักทีมงานเพื่อถามสเปกที่เหมาะกับ MT5 ได้ ส่วนผู้ให้บริการที่แนะนำ รอข้อมูลจากเจ้าของ

ขั้นตอนเชื่อมต่อ Windows VPS

  1. 01

    เปิดโปรแกรม Remote Desktop Connection

    กดปุ่ม Windows แล้วพิมพ์ Remote Desktop เลือกโปรแกรม Remote Desktop Connection ที่ขึ้นมา หรือกด Windows + R แล้วพิมพ์ mstsc

    ภาพ 01 · ค้นหา Remote Desktop ในเมนู Startภาพหน้าจอ รอจากเจ้าของ
  2. 02

    ใส่ IP ของ VPS ในช่อง Computer

    พิมพ์ IP ที่ได้จากผู้ให้บริการลงในช่อง Computer แล้วกด Show Options ถ้าอยากบันทึกชื่อผู้ใช้ไว้ใช้ครั้งหน้า

    ภาพ 02 · ช่อง Computerภาพหน้าจอ รอจากเจ้าของ
  3. 03

    ใส่ชื่อผู้ใช้และรหัสผ่าน

    กด Connect หน้าต่างขอรหัสจะขึ้นมา ถ้าชื่อผู้ใช้ที่แสดงไม่ใช่ของ VPS ให้กด More choices แล้วเลือก Use a different account จากนั้นใส่ชื่อผู้ใช้และรหัสผ่านของ VPS

    ติ๊ก Remember me เฉพาะคอมส่วนตัวที่ไม่มีคนอื่นใช้

  4. 04

    ยืนยันเครื่องในการเชื่อมต่อครั้งแรก

    ครั้งแรกจะมีหน้าต่างเตือนเรื่องใบรับรองของเครื่องปลายทาง ตรวจว่าเป็น IP ของ VPS ที่คุณเช่าแล้วกด Yes หน้าจอ Windows ของ VPS จะเปิดขึ้นมาในหน้าต่างใหม่

    ภาพ 04 · หน้าต่างยืนยันใบรับรองภาพหน้าจอ รอจากเจ้าของ
  5. 05

    ติดตั้ง MT5 บน VPS แล้วติดตั้ง EA

    เปิดเบราว์เซอร์ในหน้าจอ VPS ดาวน์โหลด MT5 จากเว็บทางการ ล็อกอินบัญชีเทรด แล้วติดตั้ง EA ตามคู่มือเดียวกับบนคอม

    • คู่มือติดตั้งและล็อกอิน MT5
    • คู่มือติดตั้ง EA บน MT5
  6. 06

    ปิดหน้าต่าง Remote Desktop ให้ถูกวิธี

    กดกากบาทที่แถบด้านบนของหน้าต่าง Remote Desktop เพื่อตัดการเชื่อมต่อ VPS ยังเปิดอยู่และ MT5 ทำงานต่อ

    ห้ามกด Sign out หรือ Shut down ใน VPS MT5 จะปิดตามและ EA หยุดทำงาน

    ล็อกอินบัญชีเดียวกันในแอป MT5 บนมือถือ ไว้ดูว่า EA ยังทำงานอยู่โดยไม่ต้องเข้า VPS ทุกครั้ง

ในหน้านี้
  1. เช็กหลังตั้งค่าเสร็จ
  2. เชื่อมต่อไม่ได้ ทำอย่างไร
  3. คำถามที่พบบ่อย

เช็กหลังตั้งค่าเสร็จ

  • MT5 บน VPS ล็อกอินบัญชีเทรดแล้ว มุมขวาล่างไม่ขึ้น No connection
  • ปุ่ม Algo Trading บนแถบเครื่องมือเป็นสีเขียว
  • มุมขวาบนของกราฟที่ติดตั้ง EA ไม่มีเครื่องหมายหยุดทำงาน
  • ปิดหน้าต่าง Remote Desktop ด้วยกากบาท ไม่ได้กด Sign out
