ติดตั้ง EA BULL บน MT5 ทีละขั้น

EA คือไฟล์โปรแกรมที่ทำงานอยู่ใน MetaTrader 5 คู่มือนี้พาวางไฟล์ให้ถูกโฟลเดอร์ ลาก EA ลงกราฟ และเปิดสิทธิ์ให้ EA ส่งคำสั่งได้ ทำบนคอม Windows หรือบน VPS ก็ใช้ขั้นตอนเดียวกัน

ขั้นตอนติดตั้ง EA บน MT5

  1. 01

    เปิดโฟลเดอร์ข้อมูลของ MT5

    ใน MT5 กดเมนู File > Open Data Folder หน้าต่างโฟลเดอร์ของ MT5 ตัวที่เปิดอยู่จะขึ้นมา ใช้วิธีนี้แทนการค้นหาเองในเครื่อง เพราะ MT5 แต่ละตัวที่ลงไว้มีโฟลเดอร์ข้อมูลแยกกัน

    {{i:folder}}ภาพ 01 · เมนู File > Open Data Folderภาพหน้าจอ รอจากเจ้าของ
  2. 02

    วางไฟล์ในโฟลเดอร์ MQL5 > Experts

    ดับเบิลคลิกเข้าโฟลเดอร์ MQL5 แล้วเข้า Experts คัดลอกไฟล์ EA ที่ได้จากทีมงานมาวางไว้ที่นี่ ถ้าได้มาเป็นไฟล์ .zip ให้แตกไฟล์ก่อน แล้ววางเฉพาะไฟล์ตัว EA

    • ไฟล์อื่นที่อาจมาพร้อมกัน เช่นไฟล์ตั้งค่า และตำแหน่งที่ต้องวาง: {{wait}}
    {{i:folder}}ภาพ 02 · โฟลเดอร์ MQL5 > Experts ที่มีไฟล์ EAภาพหน้าจอ รอจากเจ้าของ
  3. 03

    รีเฟรชรายการใน Navigator

    กลับมาที่ MT5 เปิดหน้าต่าง Navigator (กด Ctrl + N ถ้ายังไม่เห็น) คลิกขวาที่หัวข้อ Expert Advisors แล้วเลือก Refresh ชื่อ EA จะขึ้นในรายการ ถ้ายังไม่ขึ้น ปิด MT5 แล้วเปิดใหม่หนึ่งครั้ง

    {{i:refresh}}ภาพ 03 · คลิกขวาที่ Expert Advisors แล้วเลือก Refreshภาพหน้าจอ รอจากเจ้าของ
  4. 04

    เปิดกราฟที่ถูกต้อง แล้วลาก EA ลงไป

    เปิดกราฟของสินทรัพย์ที่ EA ใช้ ตั้งกรอบเวลาให้ตรงกับคู่มือสินค้า จากนั้นลากชื่อ EA จาก Navigator ไปวางบนกราฟ หรือดับเบิลคลิกที่ชื่อ EA ขณะที่กราฟนั้นเปิดอยู่

    • สินทรัพย์ (Symbol): {{wait}}
    • กรอบเวลา (Timeframe): {{wait}}

    {{i:info}}ชื่อสินทรัพย์ของแต่ละโบรกเกอร์อาจมีตัวอักษรต่อท้าย ให้เลือกชื่อที่ตรงกับคู่มือสินค้า และกราฟหนึ่งกราฟติด EA ได้ทีละตัว ถ้าลากตัวใหม่ลงไป ตัวเดิมจะถูกแทนที่

    {{i:candles}}ภาพ 04 · ลาก EA จาก Navigator ลงกราฟภาพหน้าจอ รอจากเจ้าของ
  5. 05

    ติ๊ก Allow Algo Trading ในหน้าต่าง EA

    เมื่อวาง EA ลงกราฟ หน้าต่างตั้งค่าของ EA จะเปิดขึ้น ไปที่แท็บ Common แล้วติ๊ก Allow Algo Trading ส่วนแท็บ Inputs คือค่าตั้งของ EA ใช้ตามที่ทีมงานแนะนำ แล้วกด OK

    • ตัวเลือกอื่นในแท็บ Common ที่ต้องติ๊ก: {{wait}}
    • ค่าที่แนะนำในแท็บ Inputs: {{wait}}

    {{i:alert}}อย่าเปลี่ยนค่าใน Inputs เองถ้ายังไม่แน่ใจว่าแต่ละค่าทำอะไร ค่าบางตัวเปลี่ยนขนาดไม้และความเสี่ยงของบัญชีได้มาก

    {{i:sliders}}ภาพ 05 · แท็บ Common และช่อง Allow Algo Tradingภาพหน้าจอ รอจากเจ้าของ
  6. 06

    เปิดปุ่ม Algo Trading แล้วเช็กมุมกราฟ

    กดปุ่ม Algo Trading บนแถบเครื่องมือด้านบนให้เป็นสีเขียว แล้วดูมุมขวาบนของกราฟ ชื่อ EA ต้องขึ้นอยู่ และไอคอนข้างชื่อไม่เป็นสีเทา ถ้ายังเป็นสีเทา กลับไปดูขั้นที่ 5

    • การเปิดใช้งานหรือใส่สิทธิ์ใช้งาน (license): {{wait}}

    {{i:bulb}}เปิดหน้าต่าง Toolbox (กด Ctrl + T) แล้วดูแท็บ Experts จะเห็นข้อความว่า EA โหลดสำเร็จ หรือมีข้อผิดพลาดอะไรขึ้นมา

    {{i:power}}ภาพ 06 · ปุ่ม Algo Trading สีเขียวและชื่อ EA มุมขวาบนของกราฟภาพหน้าจอ รอจากเจ้าของ

เช็กหลังติดตั้งเสร็จ

  • {{i:check}}ชื่อ EA ขึ้นใน Navigator ใต้หัวข้อ Expert Advisors
  • {{i:check}}ติด EA บนกราฟสินทรัพย์และกรอบเวลาตามคู่มือสินค้า
  • {{i:check}}ปุ่ม Algo Trading บนแถบเครื่องมือเป็นสีเขียว
  • {{i:check}}มุมขวาบนของกราฟแสดงชื่อ EA และไอคอนไม่เป็นสีเทา
  • {{i:check}}แท็บ Experts ไม่มีข้อความแจ้งข้อผิดพลาด
  • {{i:check}}MT5 ล็อกอินบัญชีที่จะใช้จริง มุมขวาล่างไม่ขึ้น No connection

ติดตั้งแล้วไม่ทำงาน แก้อย่างไร

อาการสาเหตุที่พบบ่อยวิธีแก้
ไม่เห็นชื่อ EA ใน Navigatorวางไฟล์ผิดโฟลเดอร์ หรือวางไว้ใน MT5 อีกตัวที่ลงไว้ในเครื่องเปิด File > Open Data Folder จาก MT5 ตัวที่ใช้อยู่ วางไฟล์ใน MQL5 > Experts แล้วกด Refresh
ไอคอน EA มุมกราฟเป็นสีเทายังไม่ได้ติ๊ก Allow Algo Trading ในหน้าต่าง EA หรือปุ่ม Algo Trading ปิดอยู่ลาก EA ลงกราฟเดิมอีกครั้ง ติ๊กในแท็บ Common แล้วเช็กปุ่ม Algo Trading
ปุ่ม Algo Trading ไม่เป็นสีเขียวกดปิดไว้ หรือ MT5 ปิดให้เองหลังเปลี่ยนบัญชีตามที่ตั้งใน Optionsกดปุ่มให้เป็นสีเขียว และเช็กใน Tools > Options > Expert Advisors ว่าติ๊ก Allow algorithmic trading ไว้
มีข้อความผิดพลาดในแท็บ Experts หรือ Journalขึ้นกับข้อความ เช่นตลาดปิด เงินในบัญชีไม่พอ หรือค่าตั้งไม่ตรงถ่ายภาพข้อความบรรทัดล่าสุดทั้งบรรทัดส่งให้ทีมงานทาง LINE · ความหมายของข้อความเฉพาะของ EA BULL {{wait}}
EA ขึ้นที่กราฟแต่ยังไม่เปิดออเดอร์ยังไม่ครบเงื่อนไขของระบบ หรืออยู่นอกเวลาทำงานของ EAถ้าแท็บ Experts ไม่มีข้อผิดพลาด ให้รอตามเงื่อนไขของ EA · ช่วงเวลาทำงานของ EA {{wait}}

อัปเดตเป็นเวอร์ชันใหม่

เมื่อทีมงานแจ้งว่ามีเวอร์ชันใหม่ ทำตามลำดับนี้บน MT5 ตัวที่รัน EA อยู่ ถ้ารันบน VPS ต้องทำในหน้าจอของ VPS

  1. เช็กว่ามีออเดอร์ที่ EA เปิดค้างอยู่ไหม และอัปเดตระหว่างมีออเดอร์ได้หรือไม่ {{wait}}
  2. คลิกขวาบนกราฟ เลือก Expert Advisors > Remove เพื่อถอด EA ตัวเดิมออก
  3. เปิด File > Open Data Folder > MQL5 > Experts ย้ายไฟล์เดิมไปเก็บที่อื่น แล้ววางไฟล์ใหม่แทน
  4. กลับไปที่ Navigator กด Refresh แล้วลาก EA ลงกราฟใหม่ ตั้งค่าตามคู่มือของเวอร์ชันใหม่
  5. เช็กมุมกราฟและแท็บ Experts อีกครั้งตามเช็กลิสต์ด้านบน

{{i:info}}ค่าที่ตั้งไว้ในเวอร์ชันเดิมใช้ต่อได้หรือไม่ และสิ่งที่เปลี่ยนในแต่ละเวอร์ชัน {{wait}}
