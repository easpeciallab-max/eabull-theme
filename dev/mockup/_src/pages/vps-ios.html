ขั้นตอนเข้า VPS จาก iPhone และ iPad

  1. 01

    ติดตั้งแอป Windows App

    เปิด App Store ค้นหา Windows App ที่ผู้พัฒนาเป็น Microsoft Corporation แล้วกดรับแอป แอปเดียวกันใช้ได้ทั้งบน iPhone และ iPad

    {{i:tablet}}Windows AppMicrosoft Corporation · App Store

    แอปทางการของ Microsoft สำหรับเชื่อมต่อเครื่อง Windows จากระยะไกล ใช้กับ VPS ได้

    เปิด App Store {{i:external}}
    {{i:download}}ภาพ 01 · หน้า Windows App ใน App Storeภาพหน้าจอ รอจากเจ้าของ
  2. 02

    เปิดแอปแล้วแตะปุ่ม +

    เปิด Windows App ครั้งแรกอาจมีหน้าแนะนำหรือขออนุญาตเข้าถึงเครือข่าย อ่านแล้วกดผ่านไป จากนั้นแตะปุ่ม + เพื่อเพิ่มเครื่องที่จะเชื่อมต่อ

    {{i:plus}}ภาพ 02 · ปุ่ม + ในหน้าแรกของแอปภาพหน้าจอ รอจากเจ้าของ
  3. 03

    เลือกเพิ่ม PC

    จากเมนูที่ขึ้นมา เลือก Add PC เพื่อเพิ่มเครื่อง VPS ด้วย IP หน้าตั้งค่าเครื่องใหม่จะเปิดขึ้น

    {{i:monitor}}ภาพ 03 · เมนู Add PCภาพหน้าจอ รอจากเจ้าของ
  4. 04

    ใส่ IP ของ VPS

    แตะช่อง PC Name แล้วพิมพ์ IP ของ VPS ถ้าผู้ให้บริการให้หมายเลขพอร์ตมาด้วย ให้พิมพ์ต่อท้ายแบบ IP:พอร์ต

    {{i:globe}}ภาพ 04 · ช่อง PC Nameภาพหน้าจอ รอจากเจ้าของ
  5. 05

    ตั้งบัญชีผู้ใช้และชื่อเครื่อง

    ที่ช่อง Credentials หรือ User Account แตะเพิ่มบัญชีผู้ใช้ ใส่ชื่อผู้ใช้และรหัสผ่านของ VPS แล้วบันทึก จากนั้นตั้ง Friendly Name เป็นชื่อที่จำง่าย เช่น VPS EA BULL

    {{i:alert}}บันทึกรหัสผ่านไว้ในแอปเฉพาะเครื่องส่วนตัวที่ตั้งรหัสหรือ Face ID ไว้แล้ว

    {{i:user}}ภาพ 05 · ช่อง Credentials และ Friendly Nameภาพหน้าจอ รอจากเจ้าของ
  6. 06

    บันทึกแล้วแตะเครื่องเพื่อเชื่อมต่อ

    แตะ Save เครื่อง VPS จะขึ้นเป็นการ์ดในหน้าแรกของแอป แตะการ์ดนั้นเพื่อเชื่อมต่อ ครั้งแรกจะมีหน้าต่างเตือนเรื่องใบรับรองของเครื่องปลายทาง ตรวจว่าเป็น IP ของ VPS ที่คุณเช่าแล้วแตะยอมรับเพื่อไปต่อ

    เมื่อเข้าได้จะเห็นหน้าจอ Windows ของ VPS เปิด MT5 แล้วดูว่าปุ่ม Algo Trading ยังเป็นสีเขียว

    {{i:x}}ห้ามกด Sign out หรือ Shut down ใน VPS MT5 จะปิดตามและ EA หยุดทำงาน ออกด้วยการตัดการเชื่อมต่อจากแถบเมนูของแอปแทน

    {{i:server}}ภาพ 06 · การ์ดเครื่อง VPS ในหน้าแรกของแอปภาพหน้าจอ รอจากเจ้าของ

เคล็ดลับใช้งานบน iPhone และ iPad

  • บน iPhone หมุนจอเป็นแนวนอน หน้าจอ VPS จะใหญ่ขึ้นและกดปุ่มใน MT5 ได้ง่ายกว่า
  • บน iPad ต่อเมาส์หรือคีย์บอร์ดบลูทูธได้ ใช้งาน MT5 บน VPS ได้ใกล้เคียงกับคอม
  • ปุ่มใน MT5 เล็กจนแตะยาก ให้ใช้สองนิ้วถ่างเพื่อซูม หรือสลับเป็นโหมดเมาส์จากแถบเมนูของแอป
  • ออกจาก VPS ด้วยการตัดการเชื่อมต่อ (Disconnect) จากแถบเมนูของแอป ไม่ใช่กด Sign out ใน Windows
  • ถ้าสลับไปแอปอื่นนาน ๆ iOS อาจตัดการเชื่อมต่อเอง ไม่เป็นไร MT5 บน VPS ยังทำงานต่อ แค่แตะการ์ดเครื่องเพื่อเข้าใหม่

เช็กก่อนออกจากแอป

  • {{i:check}}MT5 บน VPS ยังเปิดอยู่ มุมขวาล่างไม่ขึ้น No connection
  • {{i:check}}ปุ่ม Algo Trading บนแถบเครื่องมือเป็นสีเขียว
  • {{i:check}}มุมขวาบนของกราฟที่ติด EA แสดงชื่อ EA และไอคอนไม่เป็นสีเทา
  • {{i:check}}ออกด้วยการตัดการเชื่อมต่อ ไม่ได้กด Sign out

เชื่อมต่อไม่ได้ ทำอย่างไร

อาการสาเหตุที่พบบ่อยวิธีแก้
เชื่อมต่อไม่ได้หรือหมดเวลาIP หรือพอร์ตผิด VPS ปิดอยู่ หรืออินเทอร์เน็ตไม่เสถียรตรวจ IP อีกครั้ง เปลี่ยนไปใช้ Wi-Fi แล้วลองใหม่ ถ้ายังไม่ได้ ถามผู้ให้บริการ VPS
รหัสผ่านไม่ถูกต้องแป้นพิมพ์ขึ้นต้นด้วยตัวพิมพ์ใหญ่เอง หรือมีเว้นวรรคเกินมาแก้ไขบัญชีผู้ใช้ในการ์ดเครื่อง แล้วพิมพ์ชื่อผู้ใช้และรหัสผ่านใหม่อย่างระวัง
หน้าจอเล็กมาก กดไม่โดนความละเอียดจอของ VPS สูงกว่าจอมือถือหมุนจอเป็นแนวนอน ซูมด้วยสองนิ้ว หรือใช้ iPad กับเมาส์
EA หยุดหลังออกจากแอปกด Sign out ใน VPSเชื่อมต่อใหม่ เปิด MT5 เช็กปุ่ม Algo Trading แล้วออกด้วยการตัดการเชื่อมต่อ
