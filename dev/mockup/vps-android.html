เข้า VPS จากมือถือ Android

ใช้แอป Windows App ของ Microsoft เชื่อมต่อ Windows VPS จากมือถือหรือแท็บเล็ต Android เปิดดู MT5 เช็กว่า EA ยังทำงาน หรือแก้ปัญหาเร่งด่วนได้โดยไม่ต้องเปิดคอม

ใช้เวลาราว 10 นาที สำหรับมือถือและแท็บเล็ต Android 6 ขั้นตอน

สรุปแบบสั้น

ติดตั้ง Windows App แตะ + เลือก PC ใส่ IP ตั้งบัญชีผู้ใช้ บันทึกแล้วเชื่อมต่อ

ก่อนเริ่ม

ใช้ข้อมูลเข้า VPS ชุดเดียวกับที่ใช้บนคอม และ MT5 กับ EA ควรติดตั้งบน VPS ไว้แล้ว ถ้ายังไม่ได้ทำ เริ่มจากคู่มือ VPS บน Windows ก่อน

ขั้นตอนเข้า VPS จาก Android

  1. 01

    ติดตั้งแอป Windows App

    เปิด Google Play ค้นหา Windows App ที่ผู้พัฒนาเป็น Microsoft Corporation แล้วกดติดตั้ง แอปนี้คือแอป Remote Desktop เดิมของ Microsoft ที่เปลี่ยนชื่อแล้ว

    Windows AppMicrosoft Corporation · Google Play

    แอปทางการของ Microsoft สำหรับเชื่อมต่อเครื่อง Windows จากระยะไกล ใช้กับ VPS ได้

    เปิด Google Play
    ภาพ 01 · หน้า Windows App ใน Google Playภาพหน้าจอ รอจากเจ้าของ
  2. 02

    เปิดแอปแล้วแตะปุ่ม +

    เปิด Windows App ครั้งแรกอาจมีหน้าแนะนำหรือขอสิทธิ์ อ่านแล้วกดผ่านไป จากนั้นแตะปุ่ม + เพื่อเพิ่มเครื่องที่จะเชื่อมต่อ

    ภาพ 02 · ปุ่ม + ในหน้าแรกของแอปภาพหน้าจอ รอจากเจ้าของ
  3. 03

    เลือกเพิ่ม PC

    จากเมนูที่ขึ้นมา เลือก Add PC เพื่อเพิ่มเครื่อง VPS ด้วย IP

    ถ้าแอปเสนอให้ค้นหาเครื่องในเครือข่าย ให้เลือกเพิ่มเอง (Add manually) เพราะ VPS ไม่ได้อยู่ในเครือข่ายบ้านของคุณ

    ภาพ 03 · เมนู Add PCภาพหน้าจอ รอจากเจ้าของ
  4. 04

    ใส่ IP ของ VPS

    พิมพ์ IP ของ VPS ลงในช่อง PC name ถ้าผู้ให้บริการให้หมายเลขพอร์ตมาด้วย ให้พิมพ์ต่อท้ายแบบ IP:พอร์ต

    ภาพ 04 · ช่อง PC nameภาพหน้าจอ รอจากเจ้าของ
  5. 05

    ตั้งบัญชีผู้ใช้และชื่อเครื่อง

    ที่ช่อง User account แตะเพิ่มบัญชีผู้ใช้ ใส่ชื่อผู้ใช้และรหัสผ่านของ VPS แล้วบันทึก จากนั้นเปิดตัวเลือกเพิ่มเติม (Show additional options) ตั้ง Friendly name เป็นชื่อที่จำง่าย เช่น VPS EA BULL

    บันทึกรหัสผ่านไว้ในแอปเฉพาะมือถือส่วนตัวที่ตั้งรหัสล็อกหน้าจอไว้แล้ว

    ภาพ 05 · ช่อง User account และ Friendly nameภาพหน้าจอ รอจากเจ้าของ
  6. 06

    บันทึกแล้วแตะเครื่องเพื่อเชื่อมต่อ

    แตะ Save เครื่อง VPS จะขึ้นเป็นการ์ดในหน้าแรกของแอป แตะการ์ดนั้นเพื่อเชื่อมต่อ ครั้งแรกจะมีหน้าต่างถามเรื่องใบรับรองของเครื่องปลายทาง ตรวจว่าเป็น IP ของ VPS ที่คุณเช่าแล้วกด Connect

    เมื่อเข้าได้จะเห็นหน้าจอ Windows ของ VPS เปิด MT5 แล้วดูว่าปุ่ม Algo Trading ยังเป็นสีเขียว

    ห้ามกด Sign out หรือ Shut down ใน VPS MT5 จะปิดตามและ EA หยุดทำงาน ออกด้วยการตัดการเชื่อมต่อจากแถบเมนูของแอปแทน

    ภาพ 06 · การ์ดเครื่อง VPS ในหน้าแรกของแอปภาพหน้าจอ รอจากเจ้าของ

  2. เช็กก่อนออกจากแอป
  3. เชื่อมต่อไม่ได้ ทำอย่างไร

เคล็ดลับใช้งานบนมือถือ

  • หมุนจอเป็นแนวนอน หน้าจอ VPS จะใหญ่ขึ้นและกดปุ่มใน MT5 ได้ง่ายกว่า
  • ปุ่มใน MT5 เล็กจนแตะยาก ให้ใช้สองนิ้วถ่างเพื่อซูม หรือสลับเป็นโหมดเมาส์จากแถบเมนูของแอป
  • ออกจาก VPS ด้วยการตัดการเชื่อมต่อ (Disconnect) จากแถบเมนูของแอป ไม่ใช่กด Sign out ใน Windows
  • ดูยอดและออเดอร์ทั่วไปจากแอป MT5 บนมือถือ เข้า VPS เฉพาะตอนต้องเช็กตัว MT5 บน VPS อัปเดต EA หรือแก้ปัญหา
  • ใช้ Wi-Fi หรือสัญญาณมือถือที่เสถียร การเชื่อมต่อจะลื่นกว่าและหลุดน้อยกว่า

เช็กก่อนออกจากแอป

  • MT5 บน VPS ยังเปิดอยู่ มุมขวาล่างไม่ขึ้น No connection
  • ปุ่ม Algo Trading บนแถบเครื่องมือเป็นสีเขียว
  • มุมขวาบนของกราฟที่ติด EA แสดงชื่อ EA และไอคอนไม่เป็นสีเทา
  • ออกด้วยการตัดการเชื่อมต่อ ไม่ได้กด Sign out

เชื่อมต่อไม่ได้ ทำอย่างไร

อาการสาเหตุที่พบบ่อยวิธีแก้
เชื่อมต่อไม่ได้หรือหมดเวลาIP หรือพอร์ตผิด VPS ปิดอยู่ หรืออินเทอร์เน็ตมือถือไม่เสถียรตรวจ IP อีกครั้ง เปลี่ยนไปใช้ Wi-Fi แล้วลองใหม่ ถ้ายังไม่ได้ ถามผู้ให้บริการ VPS
รหัสผ่านไม่ถูกต้องพิมพ์ชื่อผู้ใช้ผิด หรือแป้นพิมพ์ใส่ตัวพิมพ์ใหญ่หรือเว้นวรรคเกินมาเองแก้ไขบัญชีผู้ใช้ในการ์ดเครื่อง แล้วพิมพ์ชื่อผู้ใช้และรหัสผ่านใหม่อย่างระวัง
หน้าจอเล็กมาก กดไม่โดนความละเอียดจอของ VPS สูงกว่าจอมือถือหมุนจอเป็นแนวนอน ซูมด้วยสองนิ้ว หรือสลับเป็นโหมดเมาส์
EA หยุดหลังออกจากแอปกด Sign out ใน VPSเชื่อมต่อใหม่ เปิด MT5 เช็กปุ่ม Algo Trading แล้วออกด้วยการตัดการเชื่อมต่อ

คำถามที่พบบ่อย

ปิดแอปแล้ว EA ยังทำงานไหม

ทำงาน ถ้าออกด้วยการตัดการเชื่อมต่อ เพราะ MT5 รันอยู่บน VPS ไม่ได้รันบนมือถือของคุณ

ใช้แท็บเล็ต Android ได้ไหม

ได้ ใช้แอปและขั้นตอนเดียวกัน จอใหญ่กว่าทำให้ใช้งาน MT5 บน VPS ได้สะดวกกว่า

เข้า VPS จากมือถือขณะที่คอมเชื่อมต่ออยู่ได้ไหม

ได้ แต่ส่วนใหญ่ใช้ชื่อผู้ใช้เดียวกันได้ทีละเครื่อง เมื่อมือถือเชื่อมต่อ หน้าต่าง Remote Desktop บนคอมจะหลุด MT5 บน VPS ยังทำงานต่อ

ใช้แค่แอป MT5 บนมือถือแทน VPS ได้ไหม

ไม่ได้ แอป MT5 บนมือถือรัน EA ไม่ได้ ใช้ได้แค่ดูบัญชี ดูคู่มือติดตั้งและล็อกอิน MT5
