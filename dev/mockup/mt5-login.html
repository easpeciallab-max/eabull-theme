ติดตั้ง MT5 และล็อกอิน บนคอมและมือถือ

MetaTrader 5 หรือ MT5 คือโปรแกรมเทรดที่ EA ทำงานอยู่ข้างใน ลงบนคอม Windows หรือ VPS เพื่อรัน EA และลงบนมือถือไว้ติดตามบัญชี ทั้งสองที่ใช้ข้อมูลล็อกอินชุดเดียวกัน

ใช้เวลาราว 10 นาที Windows · Android · iPhone / iPad 6 ขั้นตอน
ไปที่ลิงก์ดาวน์โหลด ดูขั้นตอน

สรุปแบบสั้น

ดาวน์โหลด ติดตั้งและเปิด ค้นหาโบรกเกอร์ ใส่ Login และ Server เช็กการเชื่อมต่อ ล็อกอินบนมือถือ

ก่อนเริ่ม

คู่มือนี้ใช้กับบัญชีเทรดที่เปิดกับ Zaurix โบรกเกอร์พันธมิตรของ EA BULL (เราอาจได้รับค่าตอบแทนเมื่อคุณสมัครผ่านลิงก์ของเรา) ข้อมูลล็อกอินได้มาตอนสร้างบัญชีเทรด MT5 ใน Portal

ยังไม่มีบัญชีเทรด ทำตามคู่มือเปิดบัญชีให้เสร็จก่อน แล้วค่อยกลับมาที่หน้านี้

  2. 02

    ติดตั้งแล้วเปิดหน้าล็อกอิน

    เปิดไฟล์ติดตั้งที่โหลดมา กด Next จนเสร็จ แล้วเปิด MT5 ถ้าหน้าต่างเปิดบัญชีไม่ขึ้นมาเอง ไปที่เมนู File แล้วเลือก Open an Account (ค้นหาโบรกเกอร์ก่อน) หรือ Login to Trade Account (ถ้าเคยเพิ่มเซิร์ฟเวอร์ไว้แล้ว)

    จะรัน EA บน VPS ให้ทำขั้นนี้ในหน้าจอของ VPS ส่วนคอมที่บ้านลงไว้ดูบัญชีได้ แต่ไม่ต้องติด EA ซ้ำ

    ภาพ 02 · เมนู File ของ MT5ภาพหน้าจอ รอจากเจ้าของ
  3. 03

    ค้นหาโบรกเกอร์ Zaurix

    ในหน้าต่าง Open an Account พิมพ์ Zaurix ในช่องค้นหา เลือกชื่อบริษัทที่ขึ้นมาแล้วกด Next จากนั้นเลือก Connect with an existing trade account เพื่อใช้บัญชีที่สร้างไว้ใน Portal

    • ชื่อบริษัทที่แสดงในรายการ: รอข้อมูลจากเจ้าของ

    ค้นหาไม่เจอ ให้พิมพ์ชื่อเซิร์ฟเวอร์เต็มลงในช่องค้นหาแล้วกด Enter

    ภาพ 03 · ค้นหาโบรกเกอร์ในหน้าต่าง Open an Accountภาพหน้าจอ รอจากเจ้าของ
  4. 04

    ใส่ Login รหัสผ่าน และ Server

    ใส่เลขบัญชีในช่อง Login รหัสผ่านบัญชีเทรดในช่อง Password และเลือก Server ให้ตรงกับที่โบรกเกอร์แจ้ง ติ๊ก Save password เฉพาะเครื่องส่วนตัว แล้วกด Finish

    • ชื่อเซิร์ฟเวอร์ (Server): รอข้อมูลจากเจ้าของ

    ถ้าใช้รหัสผ่านแบบดูอย่างเดียว (Investor password) จะเห็นบัญชีแต่ส่งคำสั่งไม่ได้ EA ก็เทรดไม่ได้เช่นกัน ใช้รหัสผ่านหลักของบัญชีเทรด

    ภาพ 04 · ช่อง Login, Password และ Serverภาพหน้าจอ รอจากเจ้าของ
  5. 05

    เช็กสถานะการเชื่อมต่อมุมขวาล่าง

    ดูมุมขวาล่างของ MT5 ถ้าเชื่อมต่อสำเร็จจะเห็นแถบสัญญาณพร้อมตัวเลขความเร็วหน่วย ms เลขบัญชีจะขึ้นใต้หัวข้อ Accounts ใน Navigator และแท็บ Trade ในหน้าต่าง Toolbox จะแสดงยอด Balance

    • Invalid account: Login หรือรหัสผ่านไม่ถูก
    • No connection: เลือก Server ผิด หรืออินเทอร์เน็ตมีปัญหา
    ภาพ 05 · ตัวอย่างสถานะการเชื่อมต่อมุมขวาล่างภาพหน้าจอ รอจากเจ้าของ
  6. 06

    ล็อกอินบัญชีเดียวกันบนมือถือ

    เปิดแอป MT5 บนมือถือ ไปที่หน้าจัดการบัญชีแล้วกดเพิ่มบัญชี ค้นหาโบรกเกอร์ เลือกเข้าสู่ระบบด้วยบัญชีที่มีอยู่ แล้วใส่ Login รหัสผ่าน และ Server ชุดเดียวกับบนคอม ชื่อเมนูอาจต่างกันเล็กน้อยระหว่าง Android กับ iOS

    MT5 บนมือถือรัน EA ไม่ได้ ใช้ดูยอดเงิน ออเดอร์ และประวัติได้ ตัว EA ต้องรันบน MT5 ของ Windows หรือบน VPS เท่านั้น

    ล็อกอินบนมือถือพร้อมกับคอมหรือ VPS ได้ EA ไม่หยุด แต่อย่าปิดหรือแก้ออเดอร์ที่ EA เปิดไว้จากมือถือ ถ้าทีมงานไม่ได้แนะนำ

    ภาพ 06 · หน้าล็อกอินในแอป MT5 บนมือถือภาพหน้าจอ รอจากเจ้าของ

เช็กหลังล็อกอิน

  • มุมขวาล่างของ MT5 บนคอมหรือ VPS แสดงความเร็วการเชื่อมต่อ ไม่ขึ้น No connection
  • เลขบัญชีใน Navigator ตรงกับบัญชีที่จะใช้กับ EA
  • ยอด Balance ในแท็บ Trade ตรงกับยอดใน Portal
  • แอป MT5 บนมือถือล็อกอินบัญชีเดียวกันแล้ว
  • เก็บ Login รหัสผ่าน และ Server ไว้ในที่ที่มีแต่คุณเข้าถึงได้

ล็อกอินไม่ได้ ทำอย่างไร

อาการสาเหตุที่พบบ่อยวิธีแก้
ขึ้น Invalid accountLogin หรือรหัสผ่านผิด หรือใช้รหัส Portal แทนรหัสบัญชีเทรดตรวจเลขบัญชีและรหัสผ่านจากอีเมลของโบรกเกอร์ หรือเปลี่ยนรหัสผ่านบัญชีเทรดใน Portal
ขึ้น No connectionเลือก Server ผิด หรืออินเทอร์เน็ตมีปัญหาเลือก Server ให้ตรงกับที่โบรกเกอร์แจ้ง เช็กอินเทอร์เน็ต แล้วล็อกอินใหม่
ค้นหาโบรกเกอร์ไม่เจอชื่อในรายการต่างจากที่พิมพ์พิมพ์ชื่อเซิร์ฟเวอร์เต็มในช่องค้นหาแล้วกด Enter · ชื่อเซิร์ฟเวอร์ รอข้อมูลจากเจ้าของ
ล็อกอินได้แต่ส่งคำสั่งไม่ได้ใช้รหัสผ่านแบบดูอย่างเดียว (Investor password)ล็อกอินใหม่ด้วยรหัสผ่านหลักของบัญชีเทรด
ยอดเงินไม่ตรงกับ Portalล็อกอินผิดบัญชี เช่นบัญชีเดโมเช็กเลขบัญชีใน Navigator แล้วดับเบิลคลิกบัญชีที่ถูกต้อง

คำถามที่พบบ่อย

ทำไมมือถือรัน EA ไม่ได้

แอป MT5 บน Android และ iOS ไม่รองรับ EA ใช้ได้แค่ดูบัญชีและส่งคำสั่งด้วยมือ ถ้าต้องการให้ EA ทำงานตลอดโดยไม่เปิดคอม ใช้ VPS บน Windows

ล็อกอินบนคอมและมือถือพร้อมกันได้ไหม

ได้ บัญชีเดียวกันล็อกอินได้หลายเครื่องพร้อมกัน EA บนคอมหรือ VPS ทำงานต่อตามปกติ

รหัสผ่านบัญชีเทรดกับรหัส Portal ใช้ตัวเดียวกันไหม

อาจเป็นคนละชุด ดูจากอีเมลที่โบรกเกอร์ส่งตอนสร้างบัญชีเทรด หรือในหน้ารายละเอียดบัญชีใน Portal

ลืมรหัสผ่านบัญชีเทรดทำอย่างไร

เปลี่ยนรหัสผ่านบัญชีเทรดใน Portal ตามที่หน้าเว็บโบรกเกอร์แจ้ง แล้วล็อกอินใหม่ทุกเครื่อง รวมถึงบน VPS

ใช้ MT5 บน Mac ได้ไหม

การรัน EA BULL บน Mac รอข้อมูลจากเจ้าของ ถ้าต้องการให้ EA ทำงานต่อเนื่อง ทางที่ตรงที่สุดคือรันบน Windows VPS

คู่มือที่เกี่ยวข้อง

ติดตั้ง EA บน MT5วางไฟล์ เปิดสวิตช์ ลากลงกราฟ VPS บน Windowsให้ EA ทำงานต่อแม้ปิดคอม ฝากเงินเข้าบัญชีเทรดฝากผ่าน Portal แล้วเช็กยอดใน MT5
