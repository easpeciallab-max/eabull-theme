เพจปลอมคือเพจ Facebook หรือบัญชี LINE ที่ลอกชื่อ โลโก้ และโพสต์ของแบรนด์หรือทีมเทรดที่มีอยู่จริง แล้วรอตอบแชตคนที่หลงทักเข้าไป วิธีเช็กที่ได้ผลที่สุดคือเริ่มจากเว็บไซต์ทางการของแบรนด์ แล้วกดไปที่เพจหรือบัญชีแชตจากลิงก์บนเว็บ แทนการค้นชื่อแล้วกดผลแรกที่เจอ

สรุปสั้น

  • เพจแอบอ้างมักใช้ชื่อและรูปเหมือนตัวจริงทุกอย่าง จุดที่ต่างคือวันที่สร้างเพจ ประวัติการเปลี่ยนชื่อ และชื่อผู้ใช้ที่สะกดต่างไปเล็กน้อย
  • กลโกงที่เจอบ่อยคือบัญชีปลอมไปตอบคอมเมนต์ใต้โพสต์ของเพจจริง แล้วชวนให้ทักแชตส่วนตัว
  • บัญชี LINE ปลอมใช้ ID ที่หน้าตาคล้ายของจริง ให้เทียบทีละตัวอักษร หรือเปิดจากปุ่มบนเว็บทางการเท่านั้น
  • เจอแล้วให้รายงานในแอป ถ้าเสียเงินไปแล้วให้ติดต่อธนาคาร โทร 1441 และแจ้งความ

รูปแบบทำงานยังไงจุดสังเกต
เพจโคลนทั้งเพจก๊อปรูปโปรไฟล์ ภาพปก และโพสต์ของเพจจริงไปลงใหม่เพจเพิ่งสร้าง โพสต์เก่าถูกลงพร้อมกันในวันเดียว
บัญชีตอบคอมเมนต์บัญชีส่วนตัวตั้งชื่อและรูปเหมือนแบรนด์ ไปตอบใต้โพสต์ของเพจจริงว่า "ทักแชตมาได้เลย"กดเข้าไปแล้วเป็นโปรไฟล์บุคคล ไม่ใช่เพจเดียวกับที่โพสต์
บัญชี LINE ชื่อเหมือนตั้งชื่อเหมือนแบรนด์ ใช้ ID ที่ต่างไปหนึ่งหรือสองตัวอักษรID ไม่ตรงกับที่ลิงก์จากเว็บทางการ
โฆษณาแอบอ้างลงโฆษณาด้วยชื่อหรือภาพของแบรนด์ แต่ลิงก์ไปเว็บหรือแชตของตัวเองลิงก์ในโฆษณาไปโดเมนอื่นที่ไม่ใช่เว็บของแบรนด์
เพจคนดังปลอมใช้ภาพหรือคลิปของคนมีชื่อเสียงมาชวนลงทุนตัวจริงไม่เคยพูดเรื่องนี้ในช่องทางของตัวเอง
เพจอ้างหน่วยงานหรือทนายอ้างว่ารับเรื่องคนโดนโกงและช่วยตามเงินคืน แล้วเก็บค่าดำเนินการให้โอนเงินก่อนเริ่มงาน

แบบที่สองเป็นแบบที่คนพลาดง่ายที่สุด เพราะคุณเห็นข้อความอยู่ใต้โพสต์ของเพจจริง จึงเชื่อว่ามาจากแบรนด์เดียวกัน ก่อนตอบใคร ให้กดเข้าไปดูที่ชื่อผู้ตอบทุกครั้ง ส่วนแบบที่ห้ามีวิธีจับผิดคลิปแยกไว้ในบท AI หลอกลงทุนด้วยคลิปคนดังปลอม

เพจปลอมดูยังไง: 6 จุดที่เช็กได้ในไม่กี่นาที

ถ้าสงสัยว่าเพจตรงหน้าเป็นตัวจริงหรือเปล่า ไล่เช็กตามลำดับนี้ เมนูของแอป Facebook อาจย้ายตำแหน่งไปตามรุ่น แต่ข้อมูลเหล่านี้ยังหาได้จากหน้าข้อมูลของเพจ

[eabull_photo file="fake-pages/magnifying-glass-check-fake-page.webp" alt="แว่นขยายวางบนโต๊ะไม้ สื่อถึงการไล่เช็กเพจทีละจุดก่อนเชื่อว่าเป็นตัวจริง" caption="ใช้เวลาไม่กี่นาทีเช็กวันที่สร้างเพจและประวัติเปลี่ยนชื่อ ก่อนทักแชตไป" w="1200" h="675" credit="ภาพ: Jon Tyson / Unsplash"]

  1. เปิดเพจจากเว็บไซต์ทางการ

    พิมพ์ชื่อเว็บของแบรนด์เองในเบราว์เซอร์ แล้วกดไอคอน Facebook หรือ LINE ที่อยู่บนเว็บ ถ้าเพจที่เปิดได้ไม่ใช่เพจเดียวกับที่คุณคุยอยู่ ให้หยุดคุยกับเพจนั้น

  2. ดูความโปร่งใสของเพจ

    Facebook แสดงวันที่สร้างเพจและประวัติการเปลี่ยนชื่อไว้ในส่วนความโปร่งใสของเพจ (Page transparency) เพจปลอมมักเพิ่งสร้างไม่นาน หรือเคยใช้ชื่ออื่นที่ไม่เกี่ยวกันมาก่อน

  3. ดูโฆษณาที่เพจลงอยู่

    ในส่วนเดียวกันมักมีลิงก์ไปดูโฆษณาที่เพจกำลังลง ถ้าเพจที่อ้างเป็นแบรนด์เทรดลงโฆษณาหลายภาษาหลายสินค้าพร้อมกัน ให้ระวัง

  4. เทียบชื่อผู้ใช้และลิงก์ของเพจ

    ชื่อที่แสดงตั้งซ้ำกันได้ แต่ชื่อผู้ใช้ในลิงก์ของเพจซ้ำกันไม่ได้ เพจปลอมจึงมักเติมจุด ขีดล่าง ตัวเลข หรือคำว่า official ต่อท้าย

  5. อ่านคอมเมนต์ ไม่ใช่แค่ดูยอดผู้ติดตาม

    ยอดผู้ติดตามและยอดไลก์ซื้อได้ ให้ดูว่าคอมเมนต์มาจากคนจริงที่ถามเรื่องสินค้า หรือเป็นข้อความชมสั้น ๆ ซ้ำกันจากบัญชีที่ไม่มีรูป

  6. ดูว่าใครทักใครก่อน

    ถ้ามีบัญชีทักแชตมาหาคุณหลังคุณคอมเมนต์ในเพจจริง ให้กลับไปเช็กว่าเป็นบัญชีเดียวกับเพจที่โพสต์หรือเปล่า เครื่องหมายยืนยันหน้าชื่อช่วยได้ระดับหนึ่ง แต่อย่าใช้เป็นหลักฐานเดียว

บัญชี LINE ปลอม เช็กยังไง

ธุรกิจจำนวนมากปิดการขายทาง LINE บัญชีปลอมจึงเป็นทางที่มิจฉาชีพชอบใช้ไม่แพ้เพจ ID ของบัญชีทางการธุรกิจ (LINE Official Account) ขึ้นต้นด้วยเครื่องหมาย @ และตัวอักษรที่ตามมาเป็นสิ่งที่ต้องเทียบให้ตรง

  • เปิดบัญชีจากปุ่มหรือคิวอาร์โค้ดบนเว็บไซต์ทางการ ไม่ใช่จาก ID ที่มีคนพิมพ์ส่งมาให้
  • เทียบ ID ทีละตัวอักษร ระวังตัวที่หน้าตาคล้ายกัน เช่น ตัว l กับเลข 1 หรือตัว o กับเลข 0
  • ดูโล่หรือเครื่องหมายหน้าชื่อบัญชีประกอบ แต่จำไว้ว่าบัญชีที่ไม่มีเครื่องหมายก็ทักหาคุณได้เหมือนกัน
  • ถ้าคุยในกลุ่ม OpenChat ให้รู้ว่าใครเป็นแอดมินตัวจริง คนที่ทักส่วนตัวมาจากในกลุ่มอาจตั้งชื่อเลียนแบบแอดมิน

เรื่องกลุ่มแชตมีกลโกงเฉพาะของมันอีกหลายแบบ เช่น ห้องที่เต็มไปด้วยหน้าม้า เราสรุปไว้ในบท เข้ากลุ่มเทรดทองยังไงให้ไม่โดนหลอก

เพจทองปลอม: ระวังเพจขายทองและเพจออมทองที่แอบอ้าง

นอกจากทีมเทรดแล้ว เพจทองปลอมก็เจอบ่อยไม่แพ้กัน มิจฉาชีพลอกชื่อร้านทองที่มีหน้าร้านจริง แล้วประกาศขายทองแท่งถูกกว่าราคาประกาศ เปิดผ่อนทองหรือออมทองรายวัน หรือรับจำนำทองออนไลน์ เมื่อคุณโอนเงินมัดจำหรือค่างวด ก็ไม่มีทองส่งมา

วิธีกันง่ายที่สุดคือติดต่อร้านผ่านเบอร์โทรหรือเว็บไซต์ที่ร้านใช้มาตลอด แล้วถามตรง ๆ ว่าเพจที่คุณเจอเป็นของร้านหรือเปล่า ราคาที่ถูกกว่าตลาดมากเป็นสัญญาณเตือนในตัว เพราะร้านจริงไม่มีเหตุผลที่จะขายทองต่ำกว่าราคาที่ตัวเองรับซื้อคืน

ค้นหาเพจปลอม ที่ใช้ชื่อแบรนด์ที่คุณติดตาม

ถ้าคุณติดตามแบรนด์ไหนอยู่ ลองค้นหาเพจปลอมที่ใช้ชื่อเดียวกันดูสักครั้ง จะได้รู้ว่ามีตัวปลอมหน้าตาแบบไหนบ้าง วิธีทำมีดังนี้

  • พิมพ์ชื่อแบรนด์ในช่องค้นหาของ Facebook แล้วเลือกดูเฉพาะผลที่เป็นเพจ เทียบรูปโปรไฟล์ ชื่อผู้ใช้ และวันที่สร้างของแต่ละเพจ
  • ค้นชื่อแบรนด์คู่กับคำว่า "ปลอม" หรือ "แอบอ้าง" เพราะแบรนด์ที่โดนลอกมักโพสต์เตือนลูกค้าไว้
  • เปิด รายชื่อเตือนภัยของ ก.ล.ต. ซึ่งรวมชื่อ เว็บไซต์ เพจ Facebook และบัญชี LINE ของผู้ที่ไม่ได้เป็นผู้ประกอบธุรกิจภายใต้การกำกับของ ก.ล.ต. แล้วค้นชื่อที่คุณสงสัย

ถ้าไม่เจอชื่อในที่ไหนเลย ก็ยังไม่ได้แปลว่าเพจนั้นเป็นของจริง เพจแอบอ้างเกิดใหม่ทุกวัน และหลายเพจถูกลบก่อนมีใครรายงาน หลักที่ใช้ได้เสมอคือเริ่มจากเว็บทางการ

เพจที่มีผู้ติดตามเป็นแสนคน เป็นเพจปลอมได้ไหม?

ได้ ยอดผู้ติดตามซื้อได้ และบางเพจถูกขโมยมาจากเจ้าของเดิมแล้วเปลี่ยนชื่อ ประวัติการเปลี่ยนชื่อของเพจจึงสำคัญกว่ายอดผู้ติดตาม

มีบัญชีชื่อเหมือนแบรนด์ทักมาหลังคอมเมนต์ ควรทำยังไง?
