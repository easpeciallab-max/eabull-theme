โปรแกรมเทรดทองที่คนไทยใช้กันมากที่สุดคือ MetaTrader 5 (MT5) ซึ่งเป็นแพลตฟอร์มสำหรับดูราคาและส่งคำสั่งซื้อขายไปยังโบรกเกอร์ ส่วนโปรแกรมที่เทรดแทนคุณได้จริงมีแบบเดียว คือ EA ที่รันอยู่ใน MT5 บนคอมหรือ VPS โปรแกรมวิเคราะห์กราฟ แอปสัญญาณ และเครื่องมือ AI ส่วนใหญ่ช่วยดูหรือช่วยคิด แต่ไม่ได้กดซื้อขายให้

สรุปสั้น

  • เทรดทองต้องมีสองอย่างคู่กัน คือบัญชีกับโบรกเกอร์ และแพลตฟอร์มอย่าง MT5 ที่ใช้ส่งคำสั่ง
  • MT5 มีทั้งบนคอม มือถือ และเว็บ แต่บอทรันได้บนโปรแกรมในคอม Windows หรือ VPS
  • ไฟล์บอทของ MT4 (.ex4) ใช้กับ MT5 ไม่ได้ ต้องเลือกให้ตรงแพลตฟอร์ม
  • โปรแกรมวิเคราะห์และแอปสัญญาณช่วยตัดสินใจ แต่คนยังต้องเป็นคนกด
  • แอปที่ให้โอนเงินเข้าระบบของเขาเองแล้วโชว์ตัวเลขกำไร ไม่ใช่โปรแกรมเทรด ให้ระวัง

ถ้าคุณกำลังหาโปรแกรมเพราะอยากให้มีอะไรสักอย่างเทรดทองแทน อ่าน บอทเทรดทองทำงานบน MT5 อย่างไร ควบคู่ไปด้วย บทนี้จะแยกให้เห็นก่อนว่าคำว่า "โปรแกรม" ที่คนพูดถึงกันมีกี่แบบ และแต่ละแบบทำอะไรได้จริง

เทรดทองใช้โปรแกรมอะไร: คำตอบสั้นที่สุด

การเทรดทองออนไลน์มีสองฝั่งที่ทำงานคู่กัน ฝั่งแรกคือโบรกเกอร์ ซึ่งดูแลบัญชีเงินของคุณและรับคำสั่งซื้อขาย ฝั่งที่สองคือแพลตฟอร์ม ซึ่งเป็นโปรแกรมที่คุณใช้ดูราคาและส่งคำสั่งไปยังโบรกเกอร์นั้น MT5 อยู่ฝั่งที่สอง ผู้พัฒนาคือ MetaQuotes ซึ่งระบุบนเว็บของตัวเองว่าเป็นบริษัทซอฟต์แวร์ ไม่ได้ให้บริการเป็นโบรกเกอร์หรือรับลงทุน

เพราะอย่างนี้ การโหลด MT5 มาอย่างเดียวยังเทรดเงินจริงไม่ได้ คุณต้องมีบัญชีกับโบรกเกอร์ที่ให้บริการบน MT5 แล้วใช้เลขบัญชี รหัสผ่าน และชื่อ Server ที่โบรกเกอร์ให้มาเพื่อเข้าระบบ เมื่อเข้าได้แล้ว ราคาทองที่เห็นในโปรแกรมคือราคาจากโบรกเกอร์ของคุณ ไม่ใช่ราคากลางจากที่เดียวทั่วโลก ชื่อสัญลักษณ์ Spread และขนาดสัญญาจึงต่างกันได้ในแต่ละที่

โปรแกรมเทรดทองแบ่งได้ 4 กลุ่ม

ทุกอย่างที่ถูกเรียกว่าโปรแกรมเทรด จัดได้เป็นสี่กลุ่มตามหน้าที่ สิ่งที่ควรดูคือคอลัมน์ขวาสุด ว่ามันเทรดแทนคุณได้หรือไม่

กลุ่มตัวอย่างส่งคำสั่งซื้อขายได้ไหมเทรดแทนคุณได้ไหม
แพลตฟอร์มเทรดMT5 และ MT4ได้ เมื่อเชื่อมกับบัญชีโบรกเกอร์ไม่ได้ด้วยตัวเอง ต้องมีคนกดหรือมี EA
โปรแกรมเสริมใน MT5EA Indicator ScriptEA กับ Script ส่งได้ Indicator ส่งไม่ได้EA ตัวเดียวที่ทำต่อเนื่อง
โปรแกรมวิเคราะห์และข้อมูลเว็บกราฟ ปฏิทินเศรษฐกิจ เครื่องคำนวณส่วนใหญ่ไม่ได้ไม่ได้
แอปสัญญาณและเครื่องมือ AIกลุ่มแจ้งจุดเข้า แชตบอตวิเคราะห์ตลาดไม่ได้ ส่งแค่ความเห็นหรือสัญญาณไม่ได้ ถ้าไม่ได้ทำงานผ่าน MT5 ในบัญชีของคุณ

กลุ่มที่สองคือจุดที่คนสับสนบ่อยที่สุด เพราะไฟล์สามแบบหน้าตาคล้ายกัน แต่มีแค่ EA ที่เปิด ปิด และดูแลออเดอร์ได้ตลอดเวลา ส่วน Script ทำงานครั้งเดียวแล้วจบ และ Indicator แค่คำนวณแล้ววาดบนกราฟ ดูวิธีแยกไฟล์ให้ออกในบท EA ต่างจาก Indicator และ Script ยังไง

โปรแกรมเทรดทอง MT5 มีกี่แบบ: คอม มือถือ และเว็บ

หน้าดาวน์โหลดของ MetaQuotes มี MT5 ให้เลือกหลายแบบ ทั้งสำหรับ Windows macOS Linux แอปบน iPhone iPad และ Android รวมถึง WebTerminal ที่เปิดผ่านเบราว์เซอร์ได้โดยไม่ต้องติดตั้ง (ดู หน้าดาวน์โหลด MetaTrader 5 ทางการ ตรวจเมื่อ พ.ย. 2569) ทุกแบบเปิดกราฟและเทรดเองได้ แต่ไม่ใช่ทุกแบบที่รันบอทได้

MT5 แบบเทรดเองได้ไหมรัน EA ได้ไหมเหมาะกับ
Windows บนคอมหรือ VPSได้ได้คนที่ใช้บอท และคนที่ต้องการเครื่องมือครบ
macOS และ Linuxได้ควรถามผู้พัฒนาบอทก่อนว่าทดสอบไว้หรือยังคนที่ไม่มีเครื่อง Windows
แอปบน iPhone iPad และ Androidได้ไม่ได้ดูออเดอร์และผลของบอทระหว่างวัน
WebTerminal บนเบราว์เซอร์ได้ไม่ได้ใช้คอมคนอื่นหรือคอมที่ทำงานซึ่งติดตั้งอะไรเพิ่มไม่ได้

คนที่เห็นว่าเว็บและแอปเทรดได้เหมือนกัน มักคิดว่าวางบอทได้เหมือนกันด้วย ซึ่งไม่ใช่ บอทต้องอาศัยโปรแกรมที่ติดตั้งบนเครื่องและเปิดค้างไว้ ส่วนเวอร์ชันเว็บทำอะไรได้และไม่ได้บ้าง เราแยกไว้ในบท MT5 Web Terminal ใช้ทำอะไรได้บ้าง

โปรแกรมเทรดทองในคอม: ทำไมคนใช้บอทยังต้องใช้ Windows

MT5 บนคอม Windows เป็นแบบที่ทำได้มากที่สุด และเป็นแบบที่ผู้พัฒนาบอทส่วนใหญ่ทดสอบไว้ สิ่งที่มีเฉพาะในโปรแกรมบนคอม ได้แก่

  • ติดตั้ง EA และ Indicator ที่ซื้อมาหรือเขียนเองได้ในโฟลเดอร์ MQL5
  • มี Strategy Tester สำหรับทดสอบบอทกับข้อมูลย้อนหลัง เปิดด้วย Ctrl+R
  • เปิดหลายกราฟพร้อมกัน วางบอทคนละตัวบนคนละกราฟได้
  • เข้าร้าน Market และคลังโค้ดฟรี Code Base ได้จากในโปรแกรม

ข้อแลกเปลี่ยนคือโปรแกรมต้องเปิดค้างไว้ตลอดเวลาที่อยากให้บอททำงาน คนที่ไม่อยากเปิดคอมที่บ้านทิ้งไว้จึงเช่า Windows VPS แทน ซึ่งก็คือคอม Windows บนคลาวด์ที่รัน MT5 ได้เหมือนกันทุกอย่าง ขั้นตอนเปิดให้บอทเริ่มทำงานบนเครื่องแบบนี้อยู่ในบท ใช้บอทเทรดบน MT5 ครั้งแรกทีละขั้น

MT4 กับ MT5: โปรแกรมเทรดทองคำตัวไหนเข้ากับบอทของคุณ

บางโบรกเกอร์ยังมี MT4 ให้ใช้คู่กับ MT5 ทั้งสองตัวมาจากผู้พัฒนาเดียวกันและหน้าตาคล้ายกัน แต่ภาษาที่ใช้เขียนบอทต่างกัน ไฟล์ของฝั่งหนึ่งจึงเปิดในอีกฝั่งไม่ได้ และถ้ามีแค่ไฟล์ที่คอมไพล์แล้ว ก็แปลงข้ามกันเองไม่ได้ ต้องให้ผู้พัฒนาเขียนรุ่นใหม่จากโค้ดต้นฉบับ

ก่อนซื้อบอทหรือเปิดบัญชี ให้เช็กว่าสามอย่างนี้ตรงกัน คือบัญชี แพลตฟอร์ม และไฟล์บอท ถ้าบอทเป็นไฟล์ .ex5 บัญชีของคุณต้องล็อกอินใน MT5 ได้ ถ้าโบรกเกอร์ให้บัญชีมาเป็น MT4 ก็ต้องขอเปิดบัญชีใหม่ฝั่ง MT5

โปรแกรมวิเคราะห์เทรดทอง: ช่วยดู แต่ไม่ได้กดให้

โปรแกรมวิเคราะห์เทรดทองมีทั้งที่อยู่ใน MT5 และที่อยู่ข้างนอก ในตัว MT5 มี Indicator มาตรฐานให้ใช้ เช่น เส้นค่าเฉลี่ย RSI และ MACD มีปฏิทินเศรษฐกิจอยู่ในแท็บ Calendar ของหน้าต่าง Toolbox ส่วนนอก MT5 ก็มีเว็บกราฟ เว็บข่าว และเครื่องคำนวณขนาดไม้ เช่น เครื่องคำนวณ Lot ของเรา

ข้อดีของเครื่องมือกลุ่มนี้คือช่วยให้คุณเห็นภาพชัดขึ้นก่อนตัดสินใจ ข้อจำกัดคือคุณยังต้องนั่งดูและกดเอง ถ้าเป้าหมายคือไม่ต้องเฝ้าจอ เครื่องมือวิเคราะห์อย่างเดียวไม่ตอบโจทย์ ทางที่คนใช้กันคือเปลี่ยนกฎที่ใช้ดู Indicator ให้กลายเป็นเงื่อนไขในโปรแกรม ซึ่งก็คือแนวคิดของ Algo Trading บน MT5 นั่นเอง

โปรแกรม AI เทรดทอง: แยกของจริงกับคำโฆษณา

คำว่าโปรแกรม AI เทรดทองถูกใช้กับของหลายแบบที่ต่างกันมาก ถ้าแยกไม่ออก อาจจ่ายเงินให้ของที่ไม่ได้ทำอย่างที่โฆษณา

ที่เรียกว่า AIจริง ๆ คืออะไรควรถามหรือเช็กอะไร
บอทที่โฆษณาว่าใช้ AIส่วนใหญ่คือ EA ที่รันใน MT5 เหมือนบอททั่วไปกฎหลักคืออะไร และขอดูผลทดสอบเหมือนบอทตัวอื่น
แชตบอต AI ที่ถามเรื่องตลาดได้ให้ความเห็นหรือสรุปข้อมูลความเห็นของ AI ผิดได้ ใช้ประกอบการคิด ไม่ใช่คำสั่งให้เทรด
AI Assistant ใน MT5 รุ่นใหม่ผู้ช่วยในโปรแกรมที่ช่วยวิเคราะห์ตลาด อธิบายออเดอร์ และดูประวัติการเทรดตั้งค่าความปลอดภัยว่าจะอนุญาต ห้าม หรือให้ยืนยันเองก่อนทุกครั้งที่ AI จะทำรายการเทรด
แอปหรือเว็บที่ให้ฝากเงินแล้ว AI เทรดให้มักไม่ใช่บัญชีเทรดในชื่อคุณ ตัวเลขกำไรแสดงในแอปของเขาเองถ้าตรวจออเดอร์ใน MT5 ไม่ได้และถอนเงินยาก ให้สงสัยว่าเป็นกลโกง

ข้อมูลเรื่อง AI Assistant ใน MT5 มาจาก บันทึกการอัปเดตของ MetaTrader 5 (ตรวจเมื่อ พ.ย. 2569) ซึ่งบอกว่าเริ่มใช้ได้ด้วยการเข้าระบบบัญชี MQL5.community ในโปรแกรม ถ้าจะลอง ให้ตั้งเป็นแบบต้องยืนยันเองก่อนทุกครั้งที่มีการเทรด ส่วนคำถามว่าให้ AI ช่วยเขียนบอทได้แค่ไหน อ่านต่อในบท ใช้ AI เขียนบอทเทรดได้จริงแค่ไหน

เริ่มใช้ครั้งแรก: ลำดับที่ไม่หลงทาง

  1. โหลด MT5 จากแหล่งทางการ

    ใช้ตัวติดตั้งจากเว็บ MetaQuotes จาก App Store หรือ Google Play หรือจากเว็บโบรกเกอร์ของคุณ อย่าใช้ไฟล์ติดตั้งที่มีคนส่งมาให้ทางแชต

  2. เข้าระบบด้วยบัญชีเทรด

    ใช้บัญชีทดลองก่อนก็ได้ ขั้นตอนการเข้าระบบอยู่ในหน้า ล็อกอิน MT5

  3. ลองเปิดออเดอร์ทองด้วยมือสักครั้ง

    จะได้เข้าใจหน้าต่างคำสั่ง ขนาดไม้ และ Stop Loss ก่อนให้โปรแกรมทำแทน ดูขั้นตอนในบท เปิดออเดอร์ทองครั้งแรกใน MT5

  4. ลองเครื่องมือวิเคราะห์ในตัว

    ใส่ Indicator บนกราฟ และเปิดแท็บ Calendar ดูว่าข่าวสำคัญออกวันไหน

  5. ถ้าจะใช้บอท ให้รันบนคอม Windows หรือ VPS

    วางไฟล์ .ex5 ในโฟลเดอร์ Experts เปิดสิทธิ์ Algo Trading แล้วเฝ้าดูกับบัญชีทดลองก่อน

คำถามที่พบบ่อยเรื่อง MT5 และโปรแกรมเทรด

MT5 ต้องเสียเงินไหม?

ตัวโปรแกรมดาวน์โหลดได้จากเว็บ MetaQuotes และร้านแอปโดยไม่มีค่าใช้จ่าย เงินที่จ่ายจริงในการเทรดคือต้นทุนของบัญชี เช่น Spread และค่าธรรมเนียมตามที่โบรกเกอร์กำหนด ส่วนที่อาจต้องซื้อเพิ่มคือ EA หรือ Indicator จากผู้พัฒนา

ใช้ MT5 บน Mac เทรดทองได้ไหม?

เทรดเองได้ เพราะมีเวอร์ชัน macOS ให้ดาวน์โหลด แต่ถ้าจะใช้บอท ควรถามผู้พัฒนาก่อนว่าทดสอบบอทบน Mac แล้วหรือยัง ทางที่ตรงไปตรงมากว่าคือรันบอทบน Windows VPS แล้วใช้ Mac หรือมือถือเข้าไปดูแล

แอปเทรดทองบนมือถือ ตั้งให้เทรดอัตโนมัติได้ไหม?

แอป MT5 บนมือถือรัน EA ไม่ได้ ใช้ดูราคา เปิดปิดออเดอร์เอง และติดตามผลของบอทที่รันอยู่บนคอมหรือ VPS ได้ ถ้ามีแอปไหนอ้างว่าเทรดอัตโนมัติได้บนมือถือ ให้ดูให้ดีว่าออเดอร์ไปเกิดที่บัญชีไหน

เลือกตามบอทและบัญชีที่จะใช้ ถ้าบอทเป็นไฟล์ .ex5 ต้องใช้ MT5 และบัญชีต้องเป็นของเซิร์ฟเวอร์ MT5 ด้วย สองอย่างนี้ต้องตรงกันตั้งแต่แรก จะสลับไฟล์ข้ามแพลตฟอร์มภายหลังไม่ได้

ลงโปรแกรมแล้วเทรดได้เลยไหม?

ได้เฉพาะบัญชีทดลอง ถ้าจะเทรดเงินจริงต้องเปิดบัญชีกับโบรกเกอร์ ฝากเงิน แล้วเข้าระบบด้วยเลขบัญชีและชื่อ Server ที่ได้มา ขั้นตอนเปิดบัญชีอยู่ในหน้า เปิดบัญชีเทรด MT5

สรุป: โปรแกรมเทรดทองที่เทรดแทนคุณได้ ต้องเป็น EA บน MT5

ถ้าคุณอยากเทรดทองเอง MT5 แบบไหนก็ใช้ได้ ทั้งคอม มือถือ และเว็บ แต่ถ้าอยากให้โปรแกรมเทรดแทน ต้องเป็น EA ที่รันใน MT5 บนเครื่อง Windows หรือ VPS ที่เปิดค้างไว้ เครื่องมืออื่นทั้งหมดเป็นตัวช่วยคิด ไม่ใช่ตัวทำแทน

EA BULL ทำ EA สำหรับ MT5 และมีคู่มือบนเว็บให้ใช้ฟรี ขั้นตอนลงบอทบนคอมหรือ VPS ทีละขั้นพร้อมภาพ อยู่ในหน้า วิธีติดตั้งบอทลง MT5 ถ้าเลือกแพ็กเกจ Pro คุณติดตั้งเองตามคู่มือนี้ ถ้าเลือก VIP ทีมงานลงให้และตรวจค่าก่อนเปิดใช้งาน ถ้ายังไม่แน่ใจว่าเครื่องที่มีอยู่ใช้ได้ไหม ถามทีมงานก่อนได้
