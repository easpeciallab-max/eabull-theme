ไม่ต้อง หน้าดาวน์โหลดทางการระบุว่าโปรแกรมใช้ได้ฟรี ทั้งบนคอมและมือถือ ค่าใช้จ่ายที่มีคือค่าใช้จ่ายของบัญชีเทรดกับโบรกเกอร์ ถ้ามีคนเรียกเก็บเงินค่าโปรแกรม MT5 ให้ระวัง

โหลด MT5 จากเว็บโบรกเกอร์ ต่างจากโหลดจาก metatrader5.com ยังไง?

ตัวโปรแกรมเป็นของผู้พัฒนาเดียวกัน ตัวติดตั้งจากเว็บโบรกเกอร์มักตั้งชื่อโปรแกรมและรายชื่อเซิร์ฟเวอร์ของโบรกเกอร์ไว้ให้ ส่วนตัวจาก metatrader5.com ต้องค้นชื่อเซิร์ฟเวอร์เองตอนล็อกอิน ทั้งสองทางใช้ได้ ขอแค่เข้าเว็บด้วยชื่อที่คุณพิมพ์เอง

ลง MT5 หลายตัวในคอมเครื่องเดียวได้ไหม?

ได้ คู่มือของผู้พัฒนาแนะนำให้ติดตั้งแต่ละตัวในโฟลเดอร์แยกกัน เมื่อต้องการเปิดหลายบัญชีพร้อมกัน ตอนติดตั้งให้กด Settings แล้วเปลี่ยน Installation folder เป็นชื่อใหม่ทุกครั้ง

มีคนส่งไฟล์ MT5 มาให้ทางแชต ควรทำยังไง?

อย่าเปิดไฟล์นั้น ลบทิ้ง แล้วโหลดโปรแกรมใหม่จากเว็บทางการหรือเว็บโบรกเกอร์ที่คุณพิมพ์ชื่อเอง ถ้าเปิดไปแล้วและเคยกรอกรหัสผ่านลงไป ให้เปลี่ยนรหัสผ่านบัญชีเทรดทันทีจากเครื่องอื่นที่ไว้ใจได้ และดูประวัติออเดอร์ว่ามีไม้ที่คุณไม่ได้เปิดหรือเปล่า

ใช้ MT5 บนมือถืออย่างเดียว โดยไม่ลงคอมได้ไหม?

ถ้าเทรดเองด้วยมือ ใช้มือถืออย่างเดียวได้ แต่ถ้าจะใช้ EA ต้องมีโปรแกรมบนคอม Windows หรือ VPS ด้วย เพราะแอปมือถือรัน EA ไม่ได้ คนใช้ EA ส่วนใหญ่จึงใช้มือถือไว้ติดตามผล และให้ EA ทำงานบนเครื่องที่เปิดไว้ตลอด

ล็อกอินให้ถูกบัญชี แล้วค่อยติดตั้ง EA

เมื่อโปรแกรมมาจากแหล่งที่ถูกต้องแล้ว ขั้นต่อไปคือการล็อกอินด้วยเลขบัญชี รหัสผ่าน และชื่อ Server ให้ถูกตัว หน้า วิธีติดตั้งและล็อกอิน MT5 แบบมีภาพประกอบ พาทำครบทั้งบนคอมและมือถือ พร้อมวิธีแก้เมื่อขึ้น Invalid account หรือ No connection

สำหรับคนที่ใช้ EA BULL เรื่องนี้สำคัญเป็นพิเศษ เพราะสิทธิ์ใช้งาน EA ผูกกับเลขบัญชี MT5 คู่กับชื่อ Server ที่คุณล็อกอิน แพ็กเกจ Pro ติดตั้งเองได้ตามคู่มือบนเว็บ ส่วนแพ็กเกจ VIP ทีมงานลงให้บนคอมหรือ VPS ของคุณและเช็กค่าก่อนเริ่มรัน ถ้ายังไม่แน่ใจว่าควรลงโปรแกรมบนเครื่องไหน ถามทีมงานได้

อ่านต่อ

  • ติดตั้ง MT5 และล็อกอิน บนคอมและมือถือ
  • รัน EA คืออะไร: วิธีรัน EA บน MT5 ให้ทำงานต่อเนื่อง 24 ชั่วโมง
  • อัปเดต MT5: วิธีอัปเดตในคอมและ VPS โดยที่ EA ไม่สะดุด
  • เทรดทองมีจริงไหม: แยกการเทรดจริงออกจากแอปหลอกลงทุน
