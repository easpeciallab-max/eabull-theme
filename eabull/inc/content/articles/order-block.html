Order Block คือโซนราคาที่เทรดเดอร์สาย SMC (Smart Money Concepts) เชื่อว่าเป็นจุดที่ผู้เล่นรายใหญ่เคยวางคำสั่งก้อนใหญ่ไว้ นิยามที่ใช้กันมากคือแท่งเทียนสีตรงข้ามแท่งสุดท้าย ก่อนที่ราคาจะวิ่งแรงจนทำลายยอดหรือก้นเดิม เมื่อราคากลับมาที่โซนนี้ คนกลุ่มนี้จะรอดูว่ามีแรงซื้อหรือแรงขายรออยู่อีกหรือไม่ แนวคิดนี้ไม่ใช่ Indicator ของ MT5 และยังไม่มีใครพิสูจน์ได้ว่าโซนบนกราฟเป็นคำสั่งของสถาบันจริง

สรุปสั้น

  • Order Block เป็นศัพท์จากการวิเคราะห์สาย SMC ไม่ใช่เครื่องมือมาตรฐานใน MT5
  • Bullish OB คือแท่งขาลงแท่งสุดท้ายก่อนราคาพุ่งขึ้นแรง Bearish OB คือแท่งขาขึ้นแท่งสุดท้ายก่อนราคาดิ่งลง
  • คนสายนี้ใช้คู่กับคำว่า BOS CHoCH สภาพคล่อง และ FVG ซึ่งแต่ละสำนักนิยามไม่ตรงกันทั้งหมด
  • ใน MT5 ตีโซนด้วย Rectangle ครอบราคาสูงถึงต่ำของแท่งนั้น แล้วลากยาวไปทางขวา
  • กราฟทอง CFD ไม่มีข้อมูลคำสั่งจริงของทั้งตลาด โซนจึงเป็นการตีความ ต้องทดสอบก่อนเชื่อ

Order Block ใช้พื้นฐานเดียวกับการอ่านโครงสร้างราคาและแนวรับแนวต้าน ถ้ายังไม่คุ้นกับสองเรื่องนี้ แนะนำให้ดู ภาพรวมวิเคราะห์กราฟทองแบบเรียงขั้น ก่อน แล้วค่อยกลับมาที่บทนี้ ซึ่งอธิบายทั้งวิธีหาโซนและข้อถกเถียงของแนวคิดนี้

Order Block คืออะไร

เรื่องเล่าเบื้องหลังคือ ผู้เล่นรายใหญ่ซื้อขายจำนวนมากเกินกว่าจะได้ครบในราคาเดียว จึงทยอยส่งคำสั่งในโซนหนึ่ง เมื่อคำสั่งก้อนนั้นทำงาน ราคาจะพุ่งออกจากโซนแรง และอาจมีคำสั่งส่วนที่เหลือค้างอยู่ รอทำงานเมื่อราคากลับมา โซนต้นทางของการพุ่งนี้คือสิ่งที่คนสาย SMC เรียกว่า Order Block

สิ่งที่ควรแยกให้ออกคือ เรื่องเล่านี้เป็นคำอธิบาย ไม่ใช่ข้อมูลที่คุณตรวจสอบได้จากกราฟ ราคาทองใน MT5 เป็นราคาเสนอซื้อขายของโบรกเกอร์ที่คุณใช้ คู่มือ MT5 อธิบายว่าตัวเลข Volumes ในตลาด Forex คือจำนวนครั้งที่ราคาเปลี่ยนในแต่ละแท่ง ไม่ใช่ปริมาณที่ซื้อขายกันจริง ทองแบบ CFD ส่วนใหญ่ก็เห็นข้อมูลลักษณะนี้ คุณจึงไม่เห็นว่าใครวางคำสั่งไว้ที่ไหน ในทางปฏิบัติ Order Block จึงทำงานคล้ายโซนแนวรับแนวต้านที่มีวิธีเลือกเฉพาะตัว

SMC คือ Forex สายไหน: ศัพท์ที่มากับ Order Block

ถ้าค้นว่า SMC คือ Forex สายไหน คำตอบสั้นคือเป็นแนววิเคราะห์ที่แพร่หลายในกลุ่มเทรดเดอร์ออนไลน์ ใช้ได้ทั้งกับคู่เงินและทอง แนวคิดหลักคือพยายามอ่านว่าผู้เล่นรายใหญ่น่าจะทำอะไร จากร่องรอยบนกราฟราคา หลายคนมองว่ามันต่อยอดจากแนวคิดเก่าอย่างแนวรับแนวต้านและโซน Supply Demand แล้วตั้งชื่อเรียกใหม่ ศัพท์ที่ต้องรู้มีดังนี้

ศัพท์ความหมายที่ใช้กันทั่วไป
BOS (Break of Structure)ราคาปิดผ่านยอดหรือก้นเดิมไปทางเดียวกับเทรนด์ ยืนยันว่าเทรนด์ยังไปต่อ
CHoCH (Change of Character)ราคาปิดผ่านยอดหรือก้นล่าสุดสวนเทรนด์เดิมเป็นครั้งแรก มองว่าทิศอาจเปลี่ยน
Liquidity (สภาพคล่อง)ระดับที่เชื่อว่ามีคำสั่งตัดขาดทุนกองอยู่ เช่น เหนือยอดที่สูงเท่ากันสองครั้ง
Liquidity Sweepไส้เทียนแทงผ่านระดับเหล่านั้นแล้วปิดกลับ มองว่าเป็นการเก็บคำสั่งก่อนกลับตัว
FVG (Fair Value Gap)ช่องว่างในชุดแท่งสามแท่งที่ไส้ของแท่งแรกกับแท่งที่สามไม่ทับกัน
Premium และ Discountครึ่งบนและครึ่งล่างของช่วงราคาล่าสุด ใช้แบ่งว่าราคาแพงหรือถูกเมื่อเทียบกับช่วงนั้น

การแบ่งครึ่งช่วงราคาแบบ Premium กับ Discount ใช้หลักเดียวกับระดับ 50 ของเครื่องมือ Fibonacci ถ้าอยากเห็นวิธีวัดช่วงและระดับย่อตัวบน MT5 ดูบท กางระดับ Fibonacci บนกราฟทอง

Order Block มีกี่แบบ

ถ้าถามว่า Order Block มีกี่แบบ แบบหลักมีสองแบบตามทิศ และมีชื่อแยกย่อยที่ใช้กันในกลุ่มผู้สอน ซึ่งนิยามต่างกันไปตามแต่ละคน ตารางนี้สรุปแบบที่เจอบ่อย

แบบหน้าตาคนสายนี้มองว่า
Bullish Order Blockแท่งขาลงแท่งสุดท้ายก่อนราคาพุ่งขึ้นแรงจนผ่านยอดเดิมโซนที่อาจมีแรงซื้อรอ เมื่อราคาย่อกลับมา
Bearish Order Blockแท่งขาขึ้นแท่งสุดท้ายก่อนราคาดิ่งแรงจนหลุดก้นเดิมโซนที่อาจมีแรงขายรอ เมื่อราคาเด้งกลับมา
Breaker BlockOB ที่ถูกราคาทะลุผ่านไปแล้วโซนเดิมเปลี่ยนบทบาทเป็นฝั่งตรงข้าม คล้ายแนวรับกลายเป็นแนวต้าน
Mitigation Blockโซนที่ราคาเคยกลับมาแตะแล้วคำสั่งที่ค้างถูกใช้ไปบางส่วน น้ำหนักลดลง

Order Block ดูยังไง: หาโซนบนกราฟทองทีละขั้น

คลิปที่ใช้ชื่อแนว เทรดทอง เทคนิค ดูกราฟ OB ส่วนใหญ่สอนขั้นตอนคล้ายกัน คือเริ่มจากโครงสร้าง แล้วไล่ย้อนกลับไปหาแท่งต้นทางของการวิ่ง

  1. ดูโครงสร้างบนกรอบใหญ่

    เปิด H4 หรือ H1 แล้วตอบให้ได้ก่อนว่าตอนนี้ราคาทำยอดและก้นยกขึ้น หรือกดลง วิธีอ่านโครงสร้างแบบนี้อธิบายไว้ในบท Price Action และลำดับยอดก้น

  2. หาการวิ่งที่ทำลายโครงสร้าง

    มองหาช่วงที่ราคาวิ่งแรงจนปิดผ่านยอดหรือก้นล่าสุด แท่งช่วงนี้มักตัวยาวกว่าแท่งรอบข้างชัด ถ้าไม่ผ่านระดับเดิม ส่วนใหญ่จะไม่นับ

  3. ย้อนกลับไปหาแท่งสีตรงข้ามแท่งสุดท้าย

    ถ้าราคาพุ่งขึ้น ให้หาแท่งขาลงแท่งสุดท้ายก่อนการพุ่ง ถ้าราคาดิ่งลง ให้หาแท่งขาขึ้นแท่งสุดท้ายก่อนการดิ่ง แท่งนี้คือ Order Block

  4. กำหนดขอบเขตโซน

    ส่วนใหญ่ใช้ราคาสูงสุดถึงต่ำสุดของแท่งนั้น บางคนใช้แค่ตัวแท่งกับไส้ด้านเดียว เพื่อให้โซนแคบลง เลือกแบบหนึ่งแล้วใช้แบบเดิมทุกครั้ง

  5. เช็กว่าโซนยังไม่ถูกใช้

    ถ้าราคาเคยกลับมาแตะโซนแล้ว หลายคนถือว่าน้ำหนักลดลง และถ้าราคาปิดทะลุโซนออกไปฝั่งตรงข้าม ถือว่าโซนนั้นเสียแล้ว

ตัวอย่างสมมติ: บนกราฟ H1 ยอดล่าสุดของทองอยู่ที่ 2,395.00 แท่งขาลงแท่งหนึ่งเปิดที่ 2,384.20 ขึ้นไปสูงสุด 2,386.00 ลงไปต่ำสุด 2,379.50 แล้วปิดที่ 2,380.10 จากนั้นมีแท่งขาขึ้นตัวยาวสามแท่งติดกัน พาราคาไปปิดที่ 2,402.00 ซึ่งผ่านยอด 2,395.00 คนสาย SMC จะมองแท่งขาลงนั้นเป็น Bullish Order Block โซน 2,379.50 ถึง 2,386.00 และรอดูว่าเมื่อราคาย่อกลับมาจะมีแรงซื้อหรือไม่ ตัวเลขทั้งหมดแต่งขึ้นเพื่ออธิบายวิธีหา ไม่ใช่สัญญาณซื้อขาย

ตีโซน Order Block ใน MT5

MT5 ไม่มีเครื่องมือชื่อ Order Block แต่ใช้วัตถุ Rectangle ตีโซนได้ คู่มือ MT5 อธิบายว่าให้เลือกวัตถุ คลิกจุดเริ่ม แล้วลากไปจนได้ขนาดที่ต้องการ (ดู คู่มือ Rectangle ของ MT5 ตรวจเมื่อ พ.ย. 2569)

  1. วาดกรอบครอบแท่ง

    เลือก Insert → Objects → Shapes → Rectangle คลิกที่ราคาสูงสุดของแท่ง OB แล้วลากลงไปที่ราคาต่ำสุด ลากยาวไปทางขวาหลายสิบแท่ง เพื่อให้เห็นตอนราคากลับมา

  2. ใส่ราคาให้ตรง

    ดับเบิลคลิกที่กรอบเพื่อเปิด Properties แท็บ Parameters ให้พิมพ์วันเวลาและราคาของสองจุดเองได้

  3. ทำให้กรอบไม่บังแท่งเทียน

    ติ๊ก Fill เพื่อเติมสีในกรอบ และในแท็บ Common เปิด Draw object as background กรอบจะอยู่ด้านหลังแท่งเทียน ใช้สีต่างกันสำหรับโซนฝั่งซื้อและฝั่งขาย

  4. ติดป้ายและจำกัดกรอบเวลา

    ใช้วัตถุ Text เขียนกำกับ เช่น OB H1 และใช้แท็บ Visualization เลือกให้แสดงเฉพาะกรอบเวลาที่เกี่ยวข้อง

Order Block กับ FVG ต่างกันยังไง

FVG หรือ Fair Value Gap คือช่วงราคาที่ถูกวิ่งผ่านเร็วจนแทบไม่มีการซื้อขายสวนทาง ดูจากชุดแท่งสามแท่ง ในขาขึ้น ถ้าราคาสูงสุดของแท่งแรกยังต่ำกว่าราคาต่ำสุดของแท่งที่สาม ช่องว่างระหว่างสองราคานี้ในตัวแท่งที่สองคือ FVG ตัวอย่างสมมติ: แท่งแรกสูงสุด 2,388.40 แท่งที่สามต่ำสุด 2,391.10 FVG คือโซน 2,388.40 ถึง 2,391.10 กว้าง 2.70 ดอลลาร์ ตัวเลขสมมติขึ้นเพื่ออธิบายนิยาม

หาจากอะไรแท่งสีตรงข้ามแท่งสุดท้ายก่อนการวิ่งช่องว่างระหว่างไส้แท่งที่หนึ่งกับแท่งที่สามช่วงพักตัวก่อนราคาวิ่งออกแรง
ขนาดโซนหนึ่งแท่งมักแคบมักกว้าง เพราะรวมหลายแท่ง
คนมองว่าต้นทางของคำสั่งก้อนใหญ่ราคาที่ถูกข้ามไป มักถูกกลับมาเติมโซนที่แรงซื้อหรือแรงขายเคยชนะขาด

คนที่ใช้สองอย่างคู่กันมักให้น้ำหนักกับ OB ที่มี FVG ตามมาทันที แต่ทั้งคู่ตีความจากภาพเดียวกัน คือราคาวิ่งแรงจากจุดหนึ่ง จึงไม่ใช่หลักฐานสองชิ้นที่แยกกัน

Supply Demand Zone คือ อะไร ต่างจาก Order Block ไหม

Supply Demand Zone คือ โซนที่ราคาพักตัวสั้น ๆ ก่อนจะวิ่งออกไปแรง โซน Demand อยู่ด้านล่าง เป็นจุดที่แรงซื้อเคยชนะขาด โซน Supply อยู่ด้านบน เป็นจุดที่แรงขายเคยชนะขาด แนวคิดนี้เก่ากว่า SMC และมีหลักคล้าย Order Block มาก ต่างกันที่โซนมักรวมแท่งพักตัวหลายแท่ง จึงกว้างกว่า OB ที่ใช้แท่งเดียว

ทั้ง Order Block และ Supply Demand Zone จึงเป็นระดับที่ราคาเคยกลับตัวแรง ซึ่งเป็นแก่นของแนวรับแนวต้าน การคิดเป็นโซนและการให้น้ำหนักกับโซนจากกรอบใหญ่ อธิบายไว้ในบท แนวรับแนวต้านและการตีเป็นโซน

ระบบเทรด SMC ทำงานยังไง และจุดที่ต้องระวัง

ระบบเทรด SMC ที่ผู้สอนส่วนใหญ่อธิบายมีลำดับคล้ายกัน คือดูทิศจากกรอบใหญ่ รอให้ราคาเก็บ Liquidity แถวยอดหรือก้นที่ชัด รอ CHoCH หรือ BOS บนกรอบเล็ก แล้วรอราคากลับมาที่ Order Block หรือ FVG ที่เกิดจากการวิ่งนั้น วางจุดตัดขาดทุนเลยโซนออกไป และตั้งเป้าที่ Liquidity ฝั่งตรงข้าม ลำดับนี้เป็นคำอธิบายของคนในสายนี้ ไม่ใช่คำแนะนำให้เทรดตาม

  • กราฟหนึ่งมีโซนให้เลือกหลายจุด ราคามักกลับมาแตะสักโซน ทำให้ภาพย้อนหลังดูแม่นเกินจริง
  • ภาพตัวอย่างที่ใช้สอนมักเลือกเฉพาะรอบที่ได้ผล
  • คำอธิบายเรื่องคำสั่งของสถาบันตรวจสอบไม่ได้จากข้อมูลบนกราฟทอง CFD
  • ถ้าคอร์สหรือกลุ่มไหนอ้างว่าระบบนี้ไม่ขาดทุน ให้ถือว่าเป็นสัญญาณให้ระวัง ไม่มีระบบเทรดแบบไหนทำแบบนั้นได้

ถ้าอยากเทียบว่าแนวคิดนี้อยู่ตรงไหนเมื่อเทียบกับกลยุทธ์ตระกูลอื่น เช่น การเทรดตามเทรนด์ เบรกเอาต์ หรือการเทรดในกรอบ ดู ภาพรวมเทคนิคเทรดทองหลายแนวทาง ซึ่งอธิบายว่าแต่ละแบบเขียนเป็นกฎที่ทดสอบได้ยังไง

ทำไม Order Block เขียนเป็นกฎของ EA ได้ยาก

ถ้าจะให้ EA หา Order Block ผู้เขียนต้องตัดสินใจหลายเรื่อง การวิ่งแรงคือราคาเคลื่อนเกินกี่เท่าของ ATR ในกี่แท่ง ยอดก้นนิยามด้วยอะไร เช่น หลักห้าแท่งแบบ Fractals โซนใช้ไส้หรือตัวแท่ง หมดอายุเมื่อไหร่ และถ้ามีหลายโซนซ้อนกันจะเลือกโซนไหน ทุกตัวเลือกเปลี่ยนจำนวนโซนที่บอทเห็น ผลทดสอบย้อนหลังจึงเปลี่ยนตาม

อีกเรื่องคือ Custom Indicator ที่วาดโซน SMC ให้อัตโนมัติ บางตัววาดโซนย้อนหลังหลังจากรู้แล้วว่าราคาไปทางไหน กราฟในอดีตจึงดูแม่นมาก อาการนี้เรียกว่า Repaint วิธีเช็กอธิบายไว้ในบท Indicator และอาการ Repaint ถ้าดู EA ที่อ้างว่าเทรดแบบ SMC ให้ถามว่านิยามโซนยังไง และทดสอบกับข้อมูลทองช่วงไหนบ้าง

คำถามที่พบบ่อยเรื่อง Order Block

Order Block คือแนวรับแนวต้านแบบหนึ่งใช่ไหม?

ในทางปฏิบัติใช่ มันคือโซนที่ราคาเคยวิ่งออกแรง และคาดว่าจะมีปฏิกิริยาเมื่อกลับมา ความต่างอยู่ที่วิธีเลือกโซน และคำอธิบายว่าโซนนั้นเกิดจากคำสั่งของผู้เล่นรายใหญ่

MT5 มี Indicator สำหรับหา Order Block ไหม?

ไม่มีใน 38 ตัวที่ติดมากับโปรแกรม ถ้าจะใช้ต้องเป็น Custom Indicator จากแหล่งอื่น ซึ่งควรตรวจที่มาของไฟล์และเช็กอาการ Repaint ก่อนใช้ ส่วนการตีเองใช้ Rectangle ได้เลย

Order Block ควรดูบน Timeframe ไหน?

คนสายนี้ส่วนใหญ่หาโซนจาก H4 หรือ H1 แล้วใช้กรอบเล็กดูจังหวะตอนราคากลับมา โซนจากกรอบนาทีมีเยอะมากและถูกทะลุง่าย จึงแยกโซนที่มีความหมายได้ยาก

Order Block ใช้กับกราฟทองได้ไหม?

ใช้วิธีเดียวกันได้ แต่ทองวิ่งแรงช่วงข่าว และมักแทงทะลุโซนไปก่อนจะกลับ ถ้าจะใช้ ควรวางจุดตัดขาดทุนให้เผื่อระยะแกว่งของทอง และบันทึกผลทุกครั้งเพื่อดูว่าวิธีเลือกโซนของคุณใช้ได้จริงไหม

ต้องเรียน SMC ก่อนถึงจะเทรดทองได้ไหม?

ไม่จำเป็น SMC เป็นแนวคิดหนึ่งในหลายแนวทาง พื้นฐานที่ใช้ร่วมกันทุกสายคือการอ่านโครงสร้าง ระดับราคา และการคุมความเสียหาย ถ้าเข้าใจสามเรื่องนี้ คุณจะประเมินได้เองว่าแนวคิดไหนเหมาะกับตัวเอง

สรุป: Order Block คือวิธีเลือกโซน ไม่ใช่ข้อมูลลับของตลาด

Order Block คือการเลือกโซนจากแท่งต้นทางของการวิ่งแรง พร้อมคำอธิบายว่าโซนนั้นมาจากคำสั่งของผู้เล่นรายใหญ่ ส่วนที่ใช้ได้จริงคือการคิดเป็นโซน การอ่านโครงสร้าง และการรอให้ราคามาหา ส่วนที่ต้องระวังคือการตีความที่ยืดหยุ่นเกินไป และภาพย้อนหลังที่ดูแม่นกว่าความจริง ถ้าจะใช้ ให้นิยามโซนให้ชัด บันทึกผล และทดสอบก่อนใช้เงินจริงเสมอ

ถ้าคุณอยากใช้ระบบที่ทำงานด้วยกฎตายตัวและทดสอบย้อนหลังได้ ดูข้อมูลได้ที่ หน้าแรกของเว็บนี้ มีแพ็กเกจ Starter สำหรับคุยปรึกษาก่อนแบบไม่มีค่าใช้จ่าย แพ็กเกจที่ซื้อแล้วไม่มีการคืนเงิน จึงควรถามทุกเรื่องที่สงสัยให้ครบก่อนตัดสินใจ

อ่านต่อ

  • Price Action คืออะไร: อ่านพฤติกรรมราคาทองโดยไม่พึ่ง Indicator
  • เทคนิคเทรดทอง: กลยุทธ์หลักที่เทรดเดอร์และ EA ใช้ เลือกให้เข้ากับตัวเอง
  • แนวรับแนวต้าน คืออะไร: หาแนวรับแนวต้านทองคำยังไง
  • ทดสอบ EA ย้อนหลังด้วย Strategy Tester ของ MT5
