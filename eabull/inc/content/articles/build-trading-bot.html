สร้างบอทเทรดเองบน MT5 ทำได้ด้วยภาษา MQL5 และโปรแกรม MetaEditor ที่ติดมากับ MT5 อยู่แล้ว ขั้นตอนหลักคือเขียนกฎให้ชัด สร้างโครงโปรแกรม เขียนโค้ด คอมไพล์ไฟล์ .mq5 ให้เป็น .ex5 แล้วทดสอบใน Strategy Tester ก่อนใช้เงินจริง ส่วนที่กินเวลาที่สุดมักไม่ใช่การพิมพ์โค้ด แต่เป็นการทดสอบและแก้จุดที่โปรแกรมทำไม่ตรงกับที่คุณตั้งใจ

สรุปสั้น

  • EA บน MT5 เขียนด้วย MQL5 ไฟล์ต้นฉบับเป็น .mq5 และต้องคอมไพล์เป็น .ex5 ก่อนใช้งาน
  • MetaEditor มี MQL5 Wizard ที่สร้างโครงโปรแกรมให้ หรือประกอบ EA จากโมดูลสำเร็จรูปโดยไม่ต้องเขียนโค้ดเอง
  • บอทเทรดทองควรอ่านค่าจากบัญชีจริง เช่น ขนาดสัญญาและ Lot ขั้นต่ำ แทนการใส่ตัวเลขตายตัว
  • คอมไพล์ผ่านไม่ได้แปลว่าบอทถูก ต้องดูการทำงานในโหมดภาพ ทดสอบย้อนหลัง และรันบัญชีทดลอง
  • ถ้าจ้างคนเขียน ต้องมีสเปกที่ชัด และตกลงเรื่องไฟล์ต้นฉบับกับการแก้งานตั้งแต่แรก

บทนี้ขยายทางเลือก "สร้างเอง" จาก คู่มือบอทเทรดทองฉบับเต็ม ถ้าคุณยังไม่แน่ใจว่าบอททำงานยังไงบน MT5 อ่านบทนั้นก่อน แล้วค่อยกลับมาที่นี่เมื่ออยากลงมือเขียนกฎของตัวเองเป็นโปรแกรม

ก่อนสร้างบอทเทรด ต้องมีอะไรบ้าง

บัญชีทดลองให้บอทลองส่งคำสั่งจริงกับตลาดโดยไม่เสี่ยงเงิน

EA ใช้ภาษาอะไร: MQL5 และไฟล์ที่เกี่ยวข้อง

คำถามว่า EA ใช้ภาษาอะไร มีคำตอบตามแพลตฟอร์ม EA ของ MT5 เขียนด้วย MQL5 ส่วน EA ของ MT4 เขียนด้วย MQL4 คู่มือ MT5 อธิบายว่า MQL5 เป็นภาษาเชิงวัตถุที่ไวยากรณ์คล้าย C++ มีฟังก์ชันสำหรับงานเทรดอยู่ในตัว เช่น อ่านราคา อ่านค่า Indicator และส่งคำสั่งซื้อขาย รายชื่อฟังก์ชันทั้งหมดอยู่ใน MQL5 Reference ของ MetaQuotes

ไฟล์คืออะไรใครใช้
.mq5โค้ดต้นฉบับของโปรแกรม เปิดอ่านและแก้ได้คนเขียนบอท
.ex5ไฟล์ที่คอมไพล์แล้ว MT5 ใช้รัน เปิดอ่านโค้ดไม่ได้คนใช้บอท
.mqhไฟล์ส่วนประกอบที่โปรแกรมอื่นดึงไปใช้ คอมไพล์เดี่ยว ๆ ไม่ได้คนเขียนบอทที่แยกโค้ดเป็นส่วน
.mq4 และ .ex4ไฟล์ของ MT4ใช้กับ MT5 ไม่ได้ ต้องเขียนใหม่ด้วย MQL5

MT5 ยังให้โปรแกรม Python ภายนอกเชื่อมเข้ามาอ่านข้อมูลและส่งคำสั่งได้ แต่สิ่งที่ได้คือสคริปต์ที่รันนอก MT5 ไม่ใช่ไฟล์ EA ที่ติดบนกราฟ ถ้าเป้าหมายคือบอทที่วางบนกราฟแล้วรันบน VPS ได้เหมือน EA ทั่วไป MQL5 คือทางหลัก

สร้างบอทเทรด MT5 ด้วย MQL5 Wizard

ทางที่เร็วที่สุดในการเห็นบอทตัวแรกทำงาน คือให้ MQL5 Wizard ใน MetaEditor สร้างให้ ขั้นตอนด้านล่างอ้างอิง คู่มือการสร้าง EA ด้วย Wizard ของ MetaEditor (ตรวจเมื่อ พ.ย. 2569)

  1. เปิด MetaEditor

    ใน MT5 กด F4 หรือคลิกขวาที่หัวข้อ Expert Advisors ในหน้าต่าง Navigator แล้วเลือกสร้างใน MetaEditor

  2. เปิด Wizard แล้วเลือกชนิดโปรแกรม

    กด New ในเมนู File หรือบนแถบเครื่องมือ หน้าแรกมีให้เลือกหลายชนิด ถ้าจะเขียนโค้ดเองเลือก Expert Advisor (template) ถ้าอยากให้ประกอบจากโมดูลเลือก Expert Advisor (generate)

  3. ตั้งชื่อ สัญลักษณ์ และ Timeframe

    ถ้าเลือกเป็น current บอทจะใช้กับกราฟที่วางอยู่ ถ้าระบุสัญลักษณ์หรือกรอบเวลาไว้ บอทจะไม่ทำงานบนกราฟอื่น

  4. เลือกโมดูลสัญญาณ Trailing และการคำนวณขนาดไม้

    แบบ generate มีโมดูลสัญญาณให้เลือก 64 แบบ ใช้หลายตัวร่วมกันได้ แต่ละตัวมีน้ำหนักที่มีผลต่อการตัดสินใจสุดท้าย

  5. กด Finish แล้วคอมไพล์

    Wizard สร้างไฟล์ .mq5 ให้ กด F7 เพื่อได้ไฟล์ .ex5 ที่นำไปทดสอบได้

EA ที่ได้จาก Wizard เหมาะกับการเรียนรู้ว่าบอทประกอบขึ้นจากอะไร และลองไอเดียง่าย ๆ ได้เร็ว แต่ถ้ากฎของคุณมีเงื่อนไขเฉพาะ เช่น ไม่เทรดบางช่วงเวลา หรือหยุดทั้งระบบเมื่อขาดทุนรวมถึงระดับหนึ่ง สุดท้ายก็ต้องแก้โค้ดเอง

โครงของ EA หนึ่งตัว: ฟังก์ชันที่ต้องรู้จัก

เปิดไฟล์ที่ Wizard สร้างแบบ template จะเห็นฟังก์ชันว่างรอให้เติม แต่ละตัวถูก MT5 เรียกในจังหวะต่างกัน

ฟังก์ชันMT5 เรียกเมื่อไหร่มักใส่อะไร
OnInitตอนวางบอทบนกราฟหรือโหลดใหม่ตรวจค่าที่ผู้ใช้กรอก สร้าง Indicator ที่ต้องใช้ อ่านข้อมูลสัญลักษณ์
OnTickทุกครั้งที่มีราคาใหม่เข้ามาคำนวณ ตรวจเงื่อนไข เปิดหรือปิดออเดอร์ ดูแลไม้ที่ถืออยู่
OnTimerตามรอบเวลาที่ตั้งไว้งานที่ไม่ต้องทำทุกราคา เช่น เช็กเวลาก่อนตลาดปิด
OnTradeเมื่อมีความเปลี่ยนแปลงด้านการเทรดในบัญชีตามดูว่าออเดอร์เปิดหรือปิดสำเร็จ
OnDeinitตอนถอดบอทหรือปิดโปรแกรมล้างสิ่งที่สร้างไว้ เช่น วัตถุบนกราฟ

เวลาเรียนเขียนบอทเทรด ให้เริ่มจาก OnTick เพราะเป็นหัวใจของ EA ทุกตัว ลองเขียนบอทที่แค่พิมพ์ราคาล่าสุดลงแท็บ Experts ก่อน แล้วค่อยเพิ่มการเปิดไม้ทีละเงื่อนไข จะรู้ว่าผิดตรงไหนง่ายกว่าเขียนทั้งระบบในรอบเดียว

สร้างบอทเทรดทอง: ค่าที่ต้องอ่านจากโบรกเกอร์ ไม่ใช่เดาเอง

บอทที่ทำงานได้บนบัญชีหนึ่ง อาจพังบนอีกบัญชี เพราะทองแต่ละโบรกเกอร์ตั้งค่าไม่เหมือนกัน MQL5 มีคำสั่ง SymbolInfoDouble และ SymbolInfoInteger ให้อ่านค่าเหล่านี้จากบัญชีที่บอทรันอยู่จริง

ค่าชื่อใน MQL5ถ้าใส่ตัวเลขตายตัว
ขนาดสัญญาต่อ 1 LotSYMBOL_TRADE_CONTRACT_SIZEคำนวณความเสี่ยงต่อไม้ผิดทั้งหมด ถ้าโบรกเกอร์ไม่ได้ใช้ค่าที่คุณคิด
Lot ขั้นต่ำและขั้นการเพิ่มSYMBOL_VOLUME_MIN และ SYMBOL_VOLUME_STEPคำสั่งถูกปฏิเสธเพราะขนาดไม้ไม่ลงตัว
ระยะห่างขั้นต่ำของ StopSYMBOL_TRADE_STOPS_LEVELStop Loss หรือ Take Profit ที่ตั้งชิดราคาเกินไปถูกปฏิเสธ
จำนวนทศนิยมและขนาด PointSYMBOL_DIGITS และ SYMBOL_POINTระยะที่ตั้งไว้เป็นจุดกลายเป็นใกล้หรือไกลกว่าที่ตั้งใจหลายเท่า
Spread ปัจจุบันSYMBOL_SPREADบอทเข้าไม้ในจังหวะที่ต้นทุนสูงผิดปกติ
รูปแบบการจับคู่คำสั่งSYMBOL_FILLING_MODEคำสั่งถูกปฏิเสธบนบางบัญชีแต่ผ่านบนบางบัญชี

มีอีกสามเรื่องที่บอทเทรดทองควรมีตั้งแต่ต้น ข้อแรก ใช้ชื่อสัญลักษณ์ของกราฟที่บอทวางอยู่ แทนการพิมพ์ XAUUSD ลงในโค้ด เพราะบางโบรกเกอร์มีตัวอักษรต่อท้าย ข้อสอง ใส่เลข Magic Number ให้ทุกออเดอร์ที่บอทเปิด เพื่อแยกไม้ของบอทออกจากไม้ที่คุณกดเองหรือของบอทตัวอื่น ข้อสาม ระวังเรื่องเวลา เวลาในข้อมูลราคาเป็นเวลาของเซิร์ฟเวอร์โบรกเกอร์ ซึ่งมักไม่ตรงกับเวลาไทย

คอมไพล์: เปลี่ยน .mq5 ให้เป็น .ex5

เมื่อเขียนเสร็จ เปิดไฟล์หลักแล้วกด F7 หรือเลือก Compile ในเมนู File ตามขั้นตอนในคู่มือของ MetaEditor ไฟล์ .ex5 จะถูกสร้างในโฟลเดอร์เดียวกับไฟล์ต้นฉบับ ผลการคอมไพล์ขึ้นในแท็บ Errors ด้านล่าง ซึ่งแยกข้อความไว้สองระดับ

  • Error: มีแม้แต่ข้อเดียวก็จะไม่ได้ไฟล์ .ex5 ต้องแก้ให้หมดก่อน MetaEditor ทำเครื่องหมายตรงส่วนของโค้ดที่ผิดไว้ให้ด้วย
  • Warning: ยังได้ไฟล์ .ex5 แต่คู่มือเตือนว่าไม่ควรมองข้าม เพราะมักชี้จุดที่อาจทำงานผิด เช่น ตัวแปรที่ใช้ก่อนกำหนดค่า

คอมไพล์ผ่านแปลว่าภาษาถูกไวยากรณ์ ไม่ได้แปลว่าบอททำตามกฎที่คุณคิด บอทที่คอมไพล์ผ่านแต่เปิดไม้ซ้ำทุกราคาที่ขยับ ก็ผ่านขั้นนี้ได้สบาย

วิธีสร้างบอทเทรดให้ใช้ได้จริง: ทดสอบทีละชั้น

การสร้างบอทเทรดใน MT5 จบที่การทดสอบ ไม่ได้จบที่การเขียนโค้ด แต่ละชั้นจับปัญหาคนละแบบ

  1. ดูด้วยตาในโหมดภาพ

    รันใน Strategy Tester (Ctrl+R) แบบเปิดภาพ แล้วดูว่าบอทเปิดไม้ตรงจุดที่กฎบอกจริงไหม ชั้นนี้จับข้อผิดพลาดด้านตรรกะได้ดีที่สุด

  2. ทดสอบย้อนหลังให้ยาวพอ

    ใช้ข้อมูลที่มีทั้งช่วงทองขึ้นแรง ลงแรง และแกว่งในกรอบ หลักการเลือกโหมดและอ่านรายงานอยู่ในบท Backtest คืออะไร และใช้ตรวจบอทยังไง

  3. กันตัวเองจากการปรับค่าเกินพอดี

    เก็บข้อมูลบางช่วงไว้ไม่ให้ใช้ปรับค่า แล้วค่อยลองกับช่วงนั้น ถ้าผลพังทันที ค่าที่ได้อาจเข้ากับอดีตมากเกินไป อาการนี้อธิบายไว้ในบท ทำไมบอทที่ทดสอบผลสวยถึงพังกับตลาดจริง

  4. รันกับบัญชีทดลอง

    ดูว่าคำสั่งถูกปฏิเสธไหม Spread จริงต่างจากที่ทดสอบแค่ไหน และบอทรับมือกับช่วงเปิดตลาดได้หรือเปล่า

  5. เริ่มเงินจริงด้วยไม้เล็กที่สุด

    จดผลเทียบกับการทดสอบทุกสัปดาห์ ก่อนตัดสินใจเพิ่มขนาด

ข้อผิดพลาดที่คนเขียนบอทครั้งแรกเจอบ่อย

  • เปิดไม้ใหม่ทุกครั้งที่ราคาขยับ เพราะไม่ได้เช็กก่อนว่ามีไม้ของบอทเปิดอยู่แล้ว
  • ตั้ง Stop Loss เป็นจุดแต่คิดเป็นดอลลาร์ หรือกลับกัน ระยะจริงจึงผิดไปหลายเท่า
  • คำนวณ Lot ได้เศษที่ไม่ลงตัวกับขั้นของโบรกเกอร์ แล้วไม่ปัดให้ถูกก่อนส่งคำสั่ง
  • ส่งคำสั่งแล้วไม่ตรวจผลลัพธ์ บอทจึงไม่รู้ว่าคำสั่งถูกปฏิเสธ
  • ใช้เวลาไทยในเงื่อนไข ทั้งที่ข้อมูลราคาใช้เวลาของเซิร์ฟเวอร์
  • เปิดค่าให้ปรับเยอะเกินไป แล้วไล่หาชุดที่สวยที่สุดจากข้อมูลช่วงเดียว

ทุกข้อในรายการนี้คอมไพล์ผ่านได้ทั้งหมด จึงต้องเจอด้วยการทดสอบเท่านั้น ถ้าคุณใช้ AI ช่วยเขียนโค้ด ข้อผิดพลาดแบบนี้ยิ่งต้องตรวจละเอียดขึ้น เราอธิบายวิธีตรวจไว้ในบท ใช้ AI ช่วยเขียนบอทแล้วต้องตรวจอะไร

รับเขียนบอทเทรด: ถ้าจะจ้างผู้พัฒนาแทนการเขียนเอง

คนที่มีระบบชัดแต่ไม่อยากเรียนเขียนโปรแกรม มักค้นหาบริการรับเขียนบอทเทรด ช่องทางที่มีกติกาชัดคือ บริการ Freelance ของ MQL5 ซึ่งพักเงินของผู้จ้างไว้ระหว่างพัฒนา และโอนให้ผู้เขียนเมื่อผู้จ้างรับงานแล้ว ไม่ว่าจะจ้างผ่านช่องทางไหน ให้ตกลงเรื่องเหล่านี้ไว้ก่อนเริ่มงาน

คำถามที่พบบ่อยเรื่องการสร้างบอทเทรด

สอนเขียนบอทเทรด ควรเริ่มเรียนจากตรงไหน?

เริ่มจากสร้าง EA ด้วย Wizard แล้วเปิดโค้ดที่ได้มาอ่านทีละส่วน ควบคู่กับ MQL5 Reference และตัวอย่างใน Code Base ของ mql5.com จากนั้นลองเขียนบอทเล็ก ๆ ที่ทำงานอย่างเดียว เช่น แค่เปิดไม้เมื่อราคาปิดเหนือเส้นค่าเฉลี่ย

ไม่มีพื้นฐานเขียนโปรแกรม สร้างบอทเทรดได้ไหม?

ได้ในระดับเริ่มต้น ด้วย MQL5 Wizard แบบ generate ที่ประกอบ EA จากโมดูลสัญญาณ Trailing และการคำนวณขนาดไม้ แต่ถ้ากฎของคุณไม่ตรงกับโมดูลที่มี ต้องเรียนเขียนโค้ดเพิ่มหรือจ้างคนเขียน

สร้างบอทใน MT5 แล้วเอาไปใช้กับ MT4 ได้ไหม?

ไม่ได้ ไฟล์ .ex5 ใช้ได้เฉพาะ MT5 ถ้าต้องการรุ่น MT4 ต้องเขียนใหม่ด้วย MQL4 จากกฎชุดเดิม ฟังก์ชันการเทรดของสองภาษาต่างกันพอสมควร

เขียนบอทเทรดด้วย Python แทน MQL5 ได้ไหม?

ได้ในแง่ที่สคริปต์ Python เชื่อมกับ MT5 เพื่ออ่านข้อมูลและส่งคำสั่งได้ แต่สคริปต์นั้นรันนอก MT5 ต้องดูแลเครื่องและโปรแกรมเพิ่มอีกชุด และ MT5 มีตัวเลือกปิดการเทรดผ่าน Python แยกไว้ คนส่วนใหญ่ที่อยากได้บอทติดกราฟจึงเลือก MQL5

สร้างบอทเทรดเองใช้เวลานานแค่ไหน?

ขึ้นกับพื้นฐานและความซับซ้อนของกฎ บอทจาก Wizard เสร็จได้ในวันเดียว แต่บอทที่ทำตามกฎเฉพาะของคุณได้ตรงและผ่านการทดสอบหลายชั้น มักใช้เวลานานกว่าที่คาด ส่วนใหญ่หมดไปกับการทดสอบ

ไม่อยากเขียนเอง: ใช้ EA สำเร็จรูปแล้วเรียนรู้ระหว่างทาง

การสร้างบอทเองให้ความเข้าใจที่ลึกมาก แต่ไม่ใช่ทุกคนที่มีเวลาเรียนภาษาและทดสอบหลายเดือน อีกทางคือใช้ EA ที่ผู้พัฒนาเขียนและทดสอบไว้แล้ว แล้วเอาความรู้ในบทนี้ไปใช้ตรวจ ถามเรื่องกฎ และอ่านผลทดสอบให้เป็น ภาพรวมของการเทรดด้วยโปรแกรมบน MT5 อยู่ในบท Algo Trading ใน MT5 ทำงานยังไง
