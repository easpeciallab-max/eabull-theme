รัน EA คือการเปิดให้ EA (Expert Advisor) ทำงานอยู่บนกราฟในโปรแกรม MetaTrader 5 จนมันอ่านราคาและส่งคำสั่งซื้อขายได้เอง เงื่อนไขมีไม่กี่ข้อ คือ MT5 ต้องเปิดอยู่ ล็อกอินบัญชีและต่อเน็ตได้ และปุ่ม Algo Trading ต้องเปิด ถ้าอยากให้ EA ทำงานต่อเนื่อง 24 ชั่วโมง คุณต้องมีเครื่อง Windows ที่เปิดทิ้งไว้ได้ตลอด จะเป็นคอมที่บ้านหรือ VPS ก็ได้

สรุปสั้น

  • รัน EA หมายถึงการติด EA ไว้บนกราฟใน MT5 แล้วปล่อยให้มันทำงานเองทุกครั้งที่ราคาขยับ ไม่ใช่แค่มีไฟล์อยู่ในเครื่อง
  • EA หยุดทันทีเมื่อ MT5 ถูกปิด คอมดับหรือเข้าโหมดสลีป หรือเน็ตหลุด ออเดอร์ที่เปิดไว้ยังอยู่ในบัญชี แต่ไม่มีใครดูแลต่อ
  • รันได้บน MT5 ในคอม Windows หรือ VPS ส่วนแอป MT5 บนมือถือและ MT5 บนเว็บใช้ติด EA ไม่ได้
  • คอมที่บ้านเหมาะกับการเริ่มต้นและซ้อมกับบัญชีทดลอง ถ้าจะรันยาวด้วยเงินจริง VPS ช่วยตัดปัญหาไฟและเน็ตที่บ้าน
  • รันแล้วต้องเช็กเป็นประจำ: การเชื่อมต่อ ปุ่ม Algo Trading ไอคอนบนกราฟ และข้อความในแท็บ Experts

บทนี้เป็นบทหลักของชุด "รัน EA 24 ชั่วโมง" รวมทุกเรื่องที่คุณต้องรู้ตั้งแต่ความหมาย เงื่อนไขที่ทำให้ EA ทำงาน ที่ที่รันได้ การเลือกระหว่างคอมกับ VPS ไปจนถึงการดูแลรายวันและการรับมือตอนไฟดับ แต่ละหัวข้อมีบทเจาะลึกให้อ่านต่อ ถ้ายังไม่แน่ใจว่า EA คืออะไรและทำงานแบบไหน แนะนำให้อ่านบท บอทเทรดทอง คืออะไร ก่อน แล้วค่อยกลับมาที่บทนี้

รัน EA คืออะไร

ในวงคนใช้ MT5 คำว่ารัน EA คือการทำให้ EA อยู่ในสถานะ "กำลังทำงาน" ไฟล์ EA นามสกุล .ex5 ที่วางไว้ในโฟลเดอร์ Experts ยังไม่ทำอะไรเลยจนกว่าคุณจะลากมันไปวางบนกราฟ อนุญาตให้มันเทรด และเปิดปุ่ม Algo Trading บนแถบเครื่องมือ เมื่อครบแล้ว MT5 จะเรียก EA ขึ้นมาทำงานทุกครั้งที่มีราคาใหม่เข้ามา EA ก็จะคิดตามกฎของมันและส่งคำสั่งไปที่เซิร์ฟเวอร์ของโบรกเกอร์เมื่อเงื่อนไขครบ

ถ้าคุณค้นว่ารันea คืออะไร จะเจอคำเรียกอื่นที่หมายถึงเรื่องเดียวกัน เช่น เปิดบอท ติดบอท หรือปล่อยบอท ทั้งหมดพูดถึงสถานะที่ EA ติดอยู่บนกราฟและได้สิทธิ์ส่งคำสั่ง ส่วนการรัน EA ให้ต่อเนื่อง หมายถึงการรักษาสถานะนี้ไม่ให้ขาดตอน ทั้งกลางวัน กลางคืน และช่วงที่คุณไม่ได้นั่งหน้าจอ

จุดที่คนใช้ใหม่มักเข้าใจผิดคือคิดว่า EA ทำงานอยู่ที่โบรกเกอร์ ความจริงคือ EA ทำงานในโปรแกรม MT5 บนเครื่องที่คุณเปิดไว้ โบรกเกอร์มีหน้าที่รับคำสั่งที่ EA ส่งไปและจับคู่ราคาให้เท่านั้น ถ้าเครื่องนั้นดับ EA ก็หยุดคิดทันที เรื่องนี้เป็นเหตุผลทั้งหมดที่ทำให้คนใช้ EA ต้องสนใจว่าจะรันบนเครื่องไหน

สถานะของ EAเห็นอะไรใน MT5EA ทำงานไหม
มีไฟล์อยู่ในโฟลเดอร์ Expertsชื่อ EA อยู่ในหน้าต่าง Navigatorไม่ทำงาน แค่พร้อมให้ใช้
ติดบนกราฟแล้ว แต่ปุ่ม Algo Trading ปิดมีชื่อ EA ที่มุมกราฟ แต่ปุ่มบนแถบเครื่องมือไม่เป็นสีเขียวคำนวณได้ แต่ส่งคำสั่งเทรดไม่ได้
ติดบนกราฟ อนุญาตให้เทรด และเปิดปุ่มแล้วปุ่ม Algo Trading เป็นสีเขียว ไอคอนที่มุมกราฟไม่เป็นสีเทาทำงานเต็มรูปแบบ
เครื่องดับ สลีป หรือปิด MT5ไม่มีอะไรทำงานอยู่หยุดทั้งหมด จนกว่าจะเปิด MT5 ใหม่

EA จะทำงานได้ต้องมีอะไรครบบ้าง

การรัน EA ให้ได้ผลจริงต้องผ่านเงื่อนไข 5 ข้อพร้อมกัน ขาดข้อใดข้อหนึ่ง EA อาจยังโชว์ชื่ออยู่บนกราฟ แต่ไม่ส่งคำสั่งเลย ตารางนี้บอกว่าแต่ละข้อดูได้ที่ไหนใน MT5 และถ้าไม่ครบจะเกิดอะไร

เงื่อนไขดูตรงไหนถ้าไม่ครบ
1. MT5 เปิดอยู่บนเครื่องที่ไม่สลีปหน้าต่าง MT5 ยังอยู่ ไม่ได้ถูกปิดหรือย่อแล้วเครื่องหลับEA ไม่ถูกเรียกให้ทำงานเลย
2. ล็อกอินบัญชีและเชื่อมต่อเซิร์ฟเวอร์ได้แถบสถานะล่างขวาโชว์ค่า ping ของการเชื่อมต่อ ถ้าหลุดจะเห็นคำว่า No connection แทนEA ไม่ได้ราคาใหม่และส่งคำสั่งไม่ได้
3. ปุ่ม Algo Trading เปิดสีของปุ่ม Algo Trading แถวบนสุดของโปรแกรมต้องเป็นเขียวไม่มี EA ตัวไหนในโปรแกรมเปิดหรือปิดไม้ได้เลย
4. EA ได้รับอนุญาตบนกราฟนั้นติ๊ก Allow Algo Trading ในแท็บ Common ตอนตั้งค่า EAEA ตัวนั้นตัวเดียวไม่เทรด แม้ปุ่มด้านบนจะเปิด
5. ตลาดเปิดและบัญชีเทรดได้เวลาเทรดของสัญลักษณ์นั้นใน Specification และสถานะบัญชีEA รอจนกว่าตลาดจะเปิดหรือบัญชีพร้อม

นอกจากตารางนี้ ให้ทำความคุ้นเคยกับหน้าต่าง Toolbox ด้านล่างของ MT5 โดยเฉพาะแท็บ Experts กับ Journal เพราะ MT5 จะเขียนข้อความไว้ที่นี่ทุกครั้งที่ EA เริ่มทำงาน ถูกถอดออก หรือส่งคำสั่งไม่ผ่าน ข้อความในสองแท็บนี้ช่วยให้รู้สาเหตุได้เร็วกว่าการเดา

ถ้าทุกข้อดูปกติแต่ EA ยังเงียบ หรือ EA หายไปจากกราฟเฉย ๆ บท EA MT5 ไม่ทำงาน พาไล่เช็กทีละจุดว่า EA ยังรันอยู่จริงไหม ตั้งแต่ไอคอนบนกราฟไปจนถึงข้อความผิดพลาดที่เจอบ่อย

วิธีรัน EA MT5 ครั้งแรก ทีละขั้น

วิธีรัน EA MT5 ครั้งแรกใช้เวลาไม่นาน ขั้นตอนด้านล่างเป็นภาพรวมของการรัน EA MT5 บนเครื่อง Windows ซึ่งใช้ได้ทั้งบนคอมที่บ้านและบน VPS เพราะหน้าตาโปรแกรมเหมือนกัน (อ้างอิงคู่มือ MetaTrader 5 ตรวจเมื่อ พ.ย. 2569)

  1. ติดตั้ง MT5 และล็อกอินบัญชี

    ลงโปรแกรม MT5 บนเครื่องที่จะใช้รัน แล้วล็อกอินด้วยเลขบัญชี รหัสผ่าน และชื่อ Server จากโบรกเกอร์ ถ้ายังไม่เคยใช้ EA มาก่อน เริ่มจากบัญชีทดลองได้

  2. วางไฟล์ .ex5 ไว้ในโฟลเดอร์ Experts

    ใน MT5 กด File แล้วเลือก Open Data Folder เมื่อหน้าต่างโฟลเดอร์เปิดขึ้น ให้เข้า MQL5 ต่อด้วย Experts แล้ววางไฟล์ .ex5 ลงไป กลับมาที่ Navigator คลิกขวาตรง Expert Advisors เลือก Refresh ชื่อ EA ที่เพิ่งใส่จะโผล่ในรายการ

  3. เปิดกราฟที่ EA ต้องการ

    เปิดกราฟสัญลักษณ์และ Timeframe ตามที่คู่มือของ EA กำหนด ชื่อสัญลักษณ์ต้องตรงกับที่โบรกเกอร์ใช้ เพราะบางโบรกเกอร์มีตัวอักษรต่อท้าย

  4. ลาก EA ลงกราฟและตั้งค่า

    ลากชื่อ EA จาก Navigator ไปวางบนกราฟ ในหน้าต่างที่เด้งขึ้นมา ติ๊ก Allow Algo Trading ในแท็บ Common แล้วใส่ค่าในแท็บ Inputs ตามคู่มือ ก่อนกด OK

  5. เปิดปุ่ม Algo Trading

    กดปุ่ม Algo Trading บนแถบเครื่องมือให้เป็นสีเขียว ปุ่มนี้คุม EA ทุกตัวในโปรแกรมพร้อมกัน ถ้าปิดอยู่ EA จะไม่ส่งคำสั่งแม้ตั้งค่าบนกราฟถูกหมดแล้ว

  6. ยืนยันว่า EA ทำงานจริง

    ดูไอคอนและชื่อ EA ที่มุมขวาบนของกราฟ เปิดแท็บ Experts ใน Toolbox ว่ามีข้อความว่า EA โหลดสำเร็จ และไม่มีบรรทัดแจ้งข้อผิดพลาด

รายละเอียดแต่ละขั้น พร้อมปัญหาที่คนใช้ครั้งแรกเจอบ่อย อยู่ในบท วิธีใช้บอทเทรดบน MT5 ครั้งแรก และถ้าต้องการภาพหน้าจอประกอบทุกขั้น ดูได้ที่ คู่มือติดตั้ง EA บน MT5

รัน EA ที่ไหนได้บ้าง

MT5 มีให้ใช้หลายแบบ แต่ไม่ใช่ทุกแบบที่ให้ EA ทำงานได้ EA ต้องการโปรแกรม MT5 ตัวเต็มที่ทำงานบน Windows เท่านั้น ส่วนแบบอื่นใช้ดูกราฟและเทรดเองได้ แต่ไม่มีพื้นที่ให้ EA ทำงาน

ที่รันใช้ EA ได้ไหมเหมาะกับข้อที่ต้องรู้
คอม Windows ที่บ้านได้ซ้อม ทดสอบ และเริ่มต้นต้องเปิดเครื่องไว้ ปิดสลีป และพึ่งไฟกับเน็ตที่บ้าน
Windows VPSได้รันยาวด้วยเงินจริงมีค่าเช่า และต้องเข้าไปดูแลผ่าน Remote Desktop
Virtual Hosting ในเมนูของ MT5ได้ ในรูปแบบที่ระบบกำหนดคนที่อยากย้าย EA จากในโปรแกรมโดยตรงวิธีทำงานต่างจาก VPS ทั่วไป ต้องอ่านเงื่อนไขก่อนใช้
Mac หรือ Linuxได้ผ่านตัวช่วยอย่าง Wineคนที่ไม่มีเครื่อง Windowsต้องทดสอบว่า EA ที่ใช้ทำงานปกติบนระบบนั้น
แอป MT5 บนมือถือไม่ได้ดูออเดอร์และผลของ EAใช้คู่กับเครื่องที่ EA ทำงานอยู่แล้ว
MT5 บนเว็บเบราว์เซอร์ไม่ได้เปิดดูบัญชีชั่วคราวบนคอมที่ไม่ได้ลงโปรแกรม MT5เทรดเองได้ แต่ติด EA ไม่ได้

คนจำนวนมากเห็นว่า MT5 เปิดบนเว็บได้ จึงคิดว่าน่าจะติด EA ได้ด้วย บท MT5 Web Terminal อธิบายว่าเวอร์ชันเว็บทำอะไรได้และทำไมติด EA ไม่ได้ ส่วนบริการ Virtual Hosting ที่อยู่ในเมนูของ MT5 เอง กับ MQL5 Cloud Network ที่ใช้ช่วยทดสอบ มักถูกเรียกรวมกันว่า "MT5 Cloud" ทั้งที่ทำหน้าที่ต่างกัน เราแยกให้เห็นชัดในบท MT5 Cloud ต่างกันยังไง

ถ้าคุณใช้ Mac หรืออยากประหยัดด้วย VPS ที่เป็น Linux ทางเลือกนี้ทำได้ แต่มีเงื่อนไขมากกว่า Windows พอสมควร อ่านข้อดีข้อเสียก่อนตัดสินใจในบท MT5 บน Linux

รัน EA บนมือถือได้ไหม

คำถามว่ารัน EA บนมือถือได้ไหม เป็นคำถามที่เจอบ่อยที่สุดข้อหนึ่ง คำตอบคือไม่ได้ แอป MT5 บน Android และ iPhone ไม่มีส่วนที่ให้ติดตั้ง EA มันออกแบบมาให้ดูกราฟ เปิดปิดออเดอร์เอง และดูประวัติบัญชีเท่านั้น ไฟล์ .ex5 จึงเปิดในแอปไม่ได้

แต่มือถือยังมีประโยชน์มากสำหรับคนใช้ EA ทำได้สองแบบ แบบแรก ล็อกอินบัญชีเดียวกันในแอป MT5 เพื่อดูว่า EA เปิดออเดอร์อะไรไว้ ยอด Equity เป็นเท่าไหร่ โดยไม่ต้องเข้าเครื่องที่รัน แบบที่สอง ใช้แอปควบคุมเครื่องระยะไกลเข้าไปดูหน้าจอของ VPS โดยตรง เพื่อเช็กปุ่ม Algo Trading หรือแก้ปัญหาเร่งด่วน

แอปทางการของ Microsoft สำหรับเข้า VPS จากมือถือชื่อ Windows App ซึ่งมาแทนแอป Remote Desktop บนมือถือรุ่นเดิม (ข้อมูลจาก Microsoft Learn: What is Windows App ตรวจเมื่อ พ.ย. 2569) วิธีใช้และสิ่งที่ต้องระวังอยู่ในบท Windows App คืออะไร

ถ้าคุณเห็นใครแนะนำแอปหรือไฟล์ที่อ้างว่าทำให้ "EA ทำงานบนมือถือได้" ให้ถามก่อนว่ามันรันอยู่ที่ไหนจริง ส่วนใหญ่คือหน้าจอที่ต่อไปยังเครื่องอื่น ไม่ใช่ EA ที่ทำงานในโทรศัพท์

คอมรัน EA ที่บ้าน: ต้องตั้งค่าอะไรบ้าง

ใช้คอมรัน EA ที่บ้านเป็นทางที่เริ่มได้ทันทีโดยไม่มีค่าใช้จ่ายเพิ่ม เหมาะกับช่วงที่คุณยังเรียนรู้ ทดสอบกับบัญชีทดลอง หรืออยากดูพฤติกรรมของ EA ใกล้ ๆ แต่คอมทั่วไปถูกตั้งมาให้ประหยัดไฟและพักเองเมื่อไม่มีคนใช้ ถ้าไม่ปรับก่อน EA จะหยุดตอนคุณไม่รู้ตัว

  • ตั้งให้เครื่องไม่เข้าโหมดสลีปเมื่อเสียบปลั๊ก ส่วนหน้าจอปิดเองได้ตามปกติ
  • ถ้าเป็นโน้ตบุ๊ก ตั้งให้การพับจอไม่ทำให้เครื่องหลับ และเสียบสายชาร์จไว้ตลอด
  • กำหนดช่วงเวลาที่ Windows อัปเดตและรีสตาร์ตได้ ไม่ให้เกิดกลางสัปดาห์ตอนตลาดเปิด
  • ต่อเน็ตด้วยสาย LAN ถ้าทำได้ เพราะเสถียรกว่า Wi-Fi ในบ้านส่วนใหญ่
  • ปิดโปรแกรมที่ไม่ใช้ และไม่ใช้เครื่องนี้เล่นเกมหรือทำงานหนักไปพร้อมกัน

ขั้นตอนตั้งค่าใน Windows ทีละเมนู รวมถึงวิธีปิดจอโดยไม่ปิดเครื่อง และวิธีกันเครื่องรีสตาร์ตเองตอนอัปเดต อยู่ในบท ปิดสลีปคอมระหว่างรัน EA

ข้อจำกัดที่ตั้งค่าแก้ไม่ได้คือไฟดับและเน็ตบ้านล่ม ถ้าบ้านคุณไฟตกบ่อย เครื่องสำรองไฟช่วยได้ระยะสั้น แต่ถ้าดับนานหรือเน็ตล่มทั้งซอย EA ก็หยุดอยู่ดี นี่คือจุดที่คนส่วนใหญ่เริ่มมองหา VPS

VPS คืออะไร และทำไมคนใช้ EA ถึงย้ายไปใช้

VPS คือคอมพิวเตอร์เสมือนที่แบ่งมาจากเครื่องเซิร์ฟเวอร์ในศูนย์ข้อมูล มี Windows ของตัวเอง เปิดอยู่ตลอดเวลา มีไฟสำรองและเน็ตความเร็วสูงของศูนย์ข้อมูลรองรับ คุณเช่าเป็นรายเดือนแล้วเข้าไปใช้งานจากคอมหรือมือถือผ่านโปรแกรมควบคุมระยะไกล เมื่อ MT5 อยู่บน VPS คุณจะปิดคอมที่บ้านได้โดยที่ EA ยังทำงานต่อ

เรื่องคอมที่บ้านWindows VPS
ไฟดับ เน็ตบ้านล่มEA หยุดทันทีไม่กระทบ เพราะเครื่องอยู่ที่ศูนย์ข้อมูล
ค่าใช้จ่ายค่าไฟและค่าเน็ตที่จ่ายอยู่แล้วค่าเช่ารายเดือนตามสเปก
ความเร็วถึงเซิร์ฟเวอร์โบรกเกอร์ขึ้นกับเน็ตบ้านเลือกศูนย์ข้อมูลที่อยู่ไม่ไกลจากโบรกเกอร์ได้
การดูแลนั่งหน้าเครื่องได้เลยเข้าผ่าน Remote Desktop หรือ Windows App
การใช้เครื่องทำอย่างอื่นใช้ร่วมกันได้ แต่เสี่ยงไปรบกวน MT5แยกไว้รัน MT5 อย่างเดียว

ถ้าอยากเข้าใจว่า VPS ต่างจาก Hosting เว็บหรือ Cloud ยังไง และเช่าแล้วได้อะไรมาบ้าง อ่านต่อในบท VPS คืออะไร ส่วนคำถามว่าต้องใช้สเปกแค่ไหน และเครื่องเดียวรันได้กี่บัญชี บท VPS รัน EA ได้กี่ตัว สอนวิธีคิดจาก CPU RAM และจำนวน MT5 ที่จะเปิด

วิธีรัน EA บน VPS: ภาพรวม 5 ขั้น

วิธีรัน EA บน VPS ไม่ต่างจากบนคอมเท่าไหร่ เพราะในหน้าจอ VPS คุณเจอ Windows หน้าตาเดิม สิ่งที่เพิ่มขึ้นมาคือขั้นเข้าเครื่องจากระยะไกล และวิธีออกจากเครื่องที่ต้องทำให้ถูก ไม่อย่างนั้น MT5 จะปิดตาม

  1. เช่า VPS ที่เป็น Windows

    ผู้ให้บริการจะส่งข้อมูลเข้าเครื่องมาให้ 3 อย่าง คือ IP ชื่อผู้ใช้ และรหัสผ่าน เก็บไว้ในที่ปลอดภัย อย่าส่งต่อในแชต

  2. เข้า VPS ด้วย Remote Desktop

    บนคอม Windows ใช้โปรแกรม Remote Desktop Connection ที่มีอยู่แล้วในเครื่อง ใส่ IP แล้วใส่ชื่อผู้ใช้กับรหัสผ่านของ VPS หน้าจอ Windows ของ VPS จะเปิดขึ้นในหน้าต่างใหม่

  3. ติดตั้ง MT5 ในหน้าจอ VPS

    เปิดเบราว์เซอร์ใน VPS ดาวน์โหลด MT5 จากแหล่งทางการหรือจากโบรกเกอร์ แล้วล็อกอินบัญชีเทรด

  4. ติดตั้ง EA ตามขั้นเดิม

    วางไฟล์ EA ในโฟลเดอร์ Experts ลากลงกราฟ ตั้งค่า และเปิดปุ่ม Algo Trading แบบเดียวกับที่ทำบนคอม

  5. ออกจาก VPS ด้วยการตัดการเชื่อมต่อ

    ปิดหน้าต่าง Remote Desktop ด้วยกากบาทด้านบน เครื่อง VPS ยังเปิดอยู่และ MT5 ทำงานต่อ ห้ามกด Sign out หรือ Shut down ใน VPS เพราะ MT5 จะปิดตามไปด้วย

ความต่างระหว่างการตัดการเชื่อมต่อกับการออกจากระบบ รวมถึงคีย์ลัดที่ช่วยให้ใช้งานใน VPS ง่ายขึ้น เราอธิบายแยกไว้ในบท Remote Desktop คืออะไร ส่วนขั้นตอนพร้อมภาพหน้าจอทุกจุด ตั้งแต่เปิดโปรแกรมจนปิดหน้าต่างให้ถูกวิธี ดูได้ในคู่มือ VPS บน Windows

ดูแล EA ที่รันอยู่: เช็กอะไร บ่อยแค่ไหน

รัน EA ไม่ได้แปลว่าตั้งครั้งเดียวแล้วลืม เครื่องที่เปิดยาวหลายสัปดาห์มีโอกาสเจอเรื่องเล็ก ๆ ที่ทำให้ EA หยุดโดยไม่มีใครเห็น เช่น เน็ตหลุดแล้วต่อใหม่ไม่ได้ Windows รีสตาร์ตหลังอัปเดต หรือมีคนกดปุ่ม Algo Trading ปิดโดยไม่ตั้งใจ ตารางนี้เป็นรอบการเช็กที่ใช้ได้กับ EA ทั่วไป

ความถี่เช็กอะไรใช้เวลา
ทุกวันเปิดแอป MT5 บนมือถือดูออเดอร์และ Equity ว่าเป็นไปตามที่คาด ถ้ามีอะไรแปลกให้เข้า VPS ไปดูต่อ1 ถึง 2 นาที
ทุก 2 ถึง 3 วันเปิดหน้าจอเครื่องที่ MT5 ทำงานอยู่ แล้วไล่ดูสีปุ่ม Algo Trading สัญลักษณ์ EA มุมกราฟ และข้อความล่าสุดในแท็บ Experts กับ Journal5 นาที
ทุกสัปดาห์ดูพื้นที่ดิสก์ของเครื่อง ว่ามีการรีสตาร์ตที่ไม่ได้วางแผนไหม และวางแผนอัปเดตช่วงตลาดปิด10 นาที
เมื่อมีรุ่นใหม่อัปเดต MT5 หรือ EA แล้วเช็กว่า EA กลับมาบนกราฟครบ และค่าใน Inputs ยังเหมือนเดิม10 ถึง 15 นาที

เรื่องที่ทำให้ EA สะดุดบ่อยคือการอัปเดตโปรแกรม เมื่อ MT5 มีรุ่นใหม่ โปรแกรมอาจต้องปิดแล้วเปิดใหม่ ถ้าไม่มีใครเช็กหลังจากนั้น EA อาจไม่ได้กลับมาทำงาน วิธีอัปเดตทั้งในคอมและ VPS โดยไม่ให้ EA ขาดช่วง อยู่ในบท อัปเดต MT5 ให้ EA ไม่สะดุด

จดค่า Inputs ของ EA ทุกกราฟไว้ในที่หนึ่ง หรือบันทึกเป็นไฟล์ด้วยปุ่ม Save ในหน้าต่างตั้งค่า ถ้าวันหนึ่งต้องติดตั้งใหม่ คุณจะใส่ค่าเดิมกลับได้ในไม่กี่นาที

ไฟดับ เน็ตหลุด เครื่องรีสตาร์ต: ออเดอร์จะเป็นยังไง

เมื่อเครื่องที่เปิด MT5 ไว้ดับหรือหลุดจากเน็ต ออเดอร์ที่เปิดไว้ไม่ได้ถูกปิดตามไปด้วย มันยังอยู่ในบัญชีที่เซิร์ฟเวอร์ของโบรกเกอร์ ราคายังวิ่งต่อและกำไรขาดทุนยังเปลี่ยนตามตลาด สิ่งที่หายไปคือ "คนดูแล" เพราะ EA ไม่ได้ทำงานแล้ว

ตรงนี้ต้องแยกให้ออกว่าอะไรทำงานต่อได้และอะไรหยุด Stop Loss และ Take Profit ที่ผูกไว้กับออเดอร์ทำงานที่ฝั่งเซิร์ฟเวอร์ จึงยังปิดออเดอร์ให้เมื่อราคาไปถึง แม้ MT5 ของคุณจะปิดอยู่ ส่วน Trailing Stop ของ MT5 ทำงานในโปรแกรมบนเครื่องคุณ ถ้าโปรแกรมปิด Trailing Stop ก็ไม่ขยับ (ข้อมูลจาก คู่มือ MetaTrader 5 เรื่องประเภทคำสั่ง ตรวจเมื่อ พ.ย. 2569) และกฎที่ EA ใช้ดูแลไม้เอง เช่น ปิดตามเงื่อนไขหรือปิดก่อนตลาดหยุด จะไม่ทำงานจนกว่า EA จะกลับมา

สิ่งที่ตั้งไว้ทำงานอยู่ที่ตอนเครื่องดับ
Stop Loss และ Take Profit บนออเดอร์เซิร์ฟเวอร์ของโบรกเกอร์ยังทำงาน
Pending Order ที่ส่งไปแล้วเซิร์ฟเวอร์ของโบรกเกอร์ยังรอราคาตามปกติ
Trailing Stop ของ MT5โปรแกรม MT5 บนเครื่องคุณหยุดขยับ
กฎของ EA เช่น เปิดไม้ใหม่ ปิดตามเงื่อนไขโปรแกรม MT5 บนเครื่องคุณหยุดทั้งหมด

เมื่อเครื่องกลับมา ให้เปิด MT5 เช็กว่าล็อกอินและเชื่อมต่อแล้ว ปุ่ม Algo Trading เปิด EA อยู่บนกราฟครบ แล้วค่อยดูออเดอร์ที่ค้างว่าตรงกับที่ EA ควรถือหรือไม่ รายละเอียดว่าต้องเช็กอะไรก่อนหลัง และควรแตะออเดอร์เองเมื่อไหร่ อยู่ในบท ไฟดับ เน็ตหลุด ระหว่าง EA เทรด

ความปลอดภัยของเครื่องที่เปิด EA ทิ้งไว้

เครื่องนี้คือเครื่องที่ล็อกอินบัญชีเทรดของคุณค้างไว้ตลอดเวลา ใครเข้าเครื่องนี้ได้ก็เปิดปิดออเดอร์หรือแก้ค่า EA ได้ทันที การดูแลความปลอดภัยจึงสำคัญไม่น้อยกว่าการดูแลให้ EA ทำงาน

  • รหัสเข้า VPS ควรยาว เดายาก และไม่ใช้ซ้ำกับอีเมลหรือบริการอื่น เก็บไว้กับตัวเองคนเดียว
  • ถ้าต้องให้คนอื่นดูบัญชี ใช้รหัสผ่านแบบ Investor ซึ่งดูได้อย่างเดียว เทรดไม่ได้
  • ไม่ลงโปรแกรมที่ไม่รู้ที่มาบนเครื่องนี้ โดยเฉพาะไฟล์ที่อ้างว่าช่วยเร่งบอท
  • บันทึกรหัสผ่านไว้ในแอปควบคุมระยะไกลเฉพาะบนมือถือหรือคอมส่วนตัวที่ล็อกหน้าจอไว้
  • เปิดการยืนยันตัวตนสองชั้นของบัญชีเทรดและอีเมลที่ผูกกับโบรกเกอร์ ถ้ารองรับ

ถ้าคุณใช้คอมที่บ้านรัน ให้ระวังเรื่องคนในบ้านใช้เครื่องร่วมกันด้วย การกดปิดโปรแกรมหรือรีสตาร์ตเครื่องโดยไม่รู้ว่า EA ทำงานอยู่ เป็นสาเหตุที่เจอบ่อยกว่าที่คิด

คำถามที่พบบ่อยเรื่องรัน EA

รัน EA คือ อะไร อธิบายแบบสั้นที่สุด?

คือการติด EA ไว้บนกราฟใน MT5 อนุญาตให้มันเทรด และเปิดปุ่ม Algo Trading แล้วปล่อยให้มันทำงานเองทุกครั้งที่ราคาขยับ ตราบที่ MT5 ยังเปิดอยู่และต่อเน็ตได้

ปิดหน้าจอคอมแล้ว EA ยังทำงานไหม?

ทำงาน ถ้าแค่หน้าจอดับแต่ตัวเครื่องยังเปิดอยู่ แต่ถ้าเครื่องเข้าโหมดสลีป ไฮเบอร์เนต หรือปิดเครื่อง EA จะหยุดทันที ต้องตั้งค่าพลังงานให้เครื่องไม่หลับเองก่อน

รัน EA บนมือถือได้ไหม?

ไม่ได้ แอป MT5 บนมือถือไม่มีที่ให้ติด EA ต้องรันบน MT5 ในเครื่อง Windows หรือ VPS ส่วนมือถือใช้ดูออเดอร์ หรือใช้ Windows App เข้าไปดูแล VPS ได้

รัน EA หลายตัวพร้อมกันได้ไหม?

ได้ กราฟหนึ่งติด EA ได้หนึ่งตัว ถ้าจะรันหลายตัวให้เปิดหลายกราฟ และถ้าจะรันหลายบัญชีพร้อมกัน ให้ติดตั้ง MT5 แยกโฟลเดอร์ บัญชีละชุด จำนวนที่เครื่องรับไหวขึ้นกับ CPU และ RAM

ไม่มีออเดอร์ค้าง ต้องเปิด MT5 ไว้ตลอดไหม?

ถ้าอยากให้ EA หาจังหวะเข้าไม้ใหม่ ต้องเปิดไว้ เพราะ EA คิดได้เฉพาะตอนที่ MT5 ทำงาน ถ้าปิดโปรแกรม EA จะพลาดทุกจังหวะที่เกิดระหว่างนั้น

ใช้คอม Mac รัน EA ได้ไหม?

MT5 บน Mac ทำงานผ่านตัวช่วยอย่าง Wine จึงใช้ EA ได้ในหลายกรณี แต่ควรทดสอบกับบัญชีทดลองก่อนว่า EA ที่ใช้ทำงานปกติ อีกทางที่ง่ายกว่าคือเช่า Windows VPS แล้วใช้ Mac เป็นแค่เครื่องเข้าไปดูแล

รัน EA บน VPS แล้ว ต้องเปิดคอมที่บ้านไว้ด้วยไหม?

ไม่ต้อง MT5 ทำงานอยู่บน VPS คอมที่บ้านเป็นแค่ช่องทางเข้าไปดู ปิดได้ตามปกติ ขอเพียงออกจาก VPS ด้วยการปิดหน้าต่าง ไม่ได้กด Sign out ใน VPS

สรุป: เริ่มรัน EA ให้ต่อเนื่องกับ EA BULL

รัน EA ให้ทำงานต่อเนื่องมีหลักแค่สามข้อ คือมีเครื่อง Windows ที่เปิดอยู่ตลอด ตั้งค่า MT5 ให้ครบทุกเงื่อนไข และหมั่นเช็กว่ามันยังทำงานจริง ส่วนจะใช้คอมที่บ้านหรือ VPS ขึ้นกับว่าคุณอยู่ช่วงซ้อมหรือช่วงใช้เงินจริง

EA BULL ทำ EA สำหรับ MetaTrader 5 และคุยกับลูกค้าทาง LINE ถ้าคุณอยากเริ่มใช้ EA โดยไม่ต้องตั้งเครื่องเองทั้งหมด แพ็กเกจ VIP ราคา 9,990 บาท ให้ทีมงานติดตั้งบนคอมหรือ VPS ของคุณ และเช็กค่าให้ก่อนเริ่มรัน ถ้าถนัดทำเอง แพ็กเกจ Pro ราคา 6,990 บาท ใช้ได้ 1 ถึง 2 บัญชี โดยติดตั้งตามคู่มือบนเว็บ ทั้งสองแบบจ่ายครั้งเดียว ไม่มีรายเดือน และค่าเช่า VPS แยกจากแพ็กเกจ ส่วนแพ็กเกจ Starter คือการปรึกษาฟรีก่อนตัดสินใจ

สิทธิ์ใช้งานผูกกับเลขบัญชี MT5 คู่กับชื่อ Server ที่ล็อกอิน ก่อนติดตั้งบน VPS จึงควรเช็กว่าใช้บัญชีชุดเดียวกับที่แจ้งทีมงานไว้ ขั้นตอนเข้า VPS และย้าย MT5 ขึ้นไปพร้อมภาพทุกขั้น อยู่ในคู่มือ ตั้ง VPS บน Windows ทีละขั้น และถ้าจะดูแลจากโทรศัพท์ มีคู่มือ VPS บน Android กับ VPS บน iPhone และ iPad ให้ด้วย ถ้ายังไม่แน่ใจว่าควรเริ่มจากคอมหรือ VPS ทักมาคุยกับทีมงานได้

อ่านต่อ

  • คู่มือรัน EA บน Windows VPS ด้วย Remote Desktop
  • VPS คืออะไร: ทำไมคนใช้ EA ถึงเช่า VPS แทนเปิดคอมทิ้งไว้
  • ปิดสลีปคอม: ตั้ง Windows ไม่ให้หลับระหว่างรัน EA
  • ไฟดับ เน็ตหลุด ระหว่าง EA เทรด: ออเดอร์ค้างเป็นยังไง และต้องเช็กอะไร
