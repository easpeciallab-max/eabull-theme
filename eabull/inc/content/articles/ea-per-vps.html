VPS รัน EA ได้กี่ตัว ไม่มีตัวเลขตายตัว เพราะสิ่งที่กินแรมและ CPU จริง ๆ คือโปรแกรม MT5 แต่ละชุด จำนวนกราฟที่เปิด และงานที่ EA ต้องคำนวณ หลักนับง่าย ๆ คือกราฟหนึ่งติด EA ได้หนึ่งตัว MT5 หนึ่งชุดเชื่อมต่อได้ทีละบัญชี จากนั้นวัดแรมที่ MT5 ใช้จริงบนเครื่องของคุณ แล้วค่อยเลือกสเปกที่พอดี

สรุปสั้น

  • กราฟหนึ่งติด EA ได้ 1 ตัว ถ้าจะรันหลายตัว ให้เปิดหลายกราฟใน MT5 ชุดเดียวกัน
  • MT5 หนึ่งชุดทำงานกับบัญชีเดียวในแต่ละช่วงเวลา จะรันหลายบัญชีพร้อมกันต้องติดตั้ง MT5 แยกโฟลเดอร์
  • คู่มือ MT5 ไม่ได้ให้ตัวเลขสเปกขั้นต่ำ บอกเพียงว่าขึ้นกับจำนวนกราฟ สัญลักษณ์ และโปรแกรม MQL5 ที่ทำงาน
  • วิธีที่แม่นที่สุดคือเปิด MT5 ครบตามแผนแล้ววัดจาก Task Manager จากนั้นเผื่อที่ให้ Windows
  • แรมมักเต็มก่อน CPU ถ้าเครื่องเริ่มช้า ลองลดกราฟหรือค่า Max bars in chart ก่อนอัปเกรด

บทนี้ต่อจากการตัดสินใจว่าจะใช้ VPS แล้ว ถ้าคุณยังชั่งใจระหว่างคอมที่บ้านกับ VPS หรืออยากรู้ว่าการรัน EA ให้ต่อเนื่องต้องมีอะไรครบบ้าง อ่านบท รัน EA บน MT5 ต้องเตรียมอะไร ก่อน และถ้ายังไม่แน่ใจว่า VPS ต่างจาก Hosting หรือ Cloud ยังไง บท VPS คืออะไร อธิบายไว้ครบ

VPS รัน EA ได้กี่ตัว: คำตอบแบบสั้น

ถ้าตอบแบบสั้นที่สุด VPS รัน EA ได้เท่าที่แรมและ CPU ของมันรับ MT5 และกราฟที่คุณเปิดไหว EA ตัวหนึ่งเป็นแค่โปรแกรมเล็ก ๆ ที่ MT5 เรียกขึ้นมาทำงาน ตัวที่ใช้ทรัพยากรมากคือ MT5 เอง ซึ่งต้องเก็บข้อมูลราคา วาดกราฟ และรักษาการเชื่อมต่อกับเซิร์ฟเวอร์ตลอดเวลา

คนที่ถามคำถามนี้ส่วนใหญ่อยากรู้หนึ่งในสองเรื่อง เรื่องแรกคือ "รัน EA หลายตัวในบัญชีเดียวได้ไหม" ซึ่งทำได้ด้วยการเปิดหลายกราฟ เรื่องที่สองคือ "รันหลายบัญชีในเครื่องเดียวได้ไหม" ซึ่งทำได้ด้วยการติดตั้ง MT5 หลายชุด สองเรื่องนี้ใช้ทรัพยากรต่างกันมาก เพราะ MT5 แต่ละชุดคือโปรแกรมเต็มตัวที่เปิดแยกกัน ส่วนกราฟที่เพิ่มในชุดเดิมกินทรัพยากรน้อยกว่าหลายเท่า

ดังนั้นก่อนถามว่าต้องใช้ VPS สเปกไหน ให้นับก่อนว่าคุณจะเปิด MT5 กี่ชุด และแต่ละชุดมีกี่กราฟ ตัวเลขสองตัวนี้คือฐานของการคิดทั้งหมดในบทนี้

นับให้ถูก: EA กราฟ MT5 และบัญชีเกี่ยวกันยังไง

กฎสองข้อที่ต้องรู้มาจากคู่มือ MT5 โดยตรง ข้อแรก กราฟหนึ่งรัน EA ได้ครั้งละหนึ่งตัว ถ้าลาก EA ตัวที่สองลงกราฟเดิม ตัวแรกจะถูกถอดออก ถ้าต้องการรัน EA ตัวเดียวกันด้วยค่าต่างกัน ให้วางบนกราฟคนละอัน (ข้อมูลจาก คู่มือ MetaTrader 5: Expert Advisors and Custom Indicators) ข้อสอง ถ้าต้องทำงานกับหลายบัญชีพร้อมกัน คู่มือแนะนำให้ติดตั้งโปรแกรมตามจำนวนบัญชีในโฟลเดอร์แยกกัน (ข้อมูลจาก คู่มือ MetaTrader 5: Platform Installation ตรวจทั้งสองหน้าเมื่อ พ.ย. 2569)

หน่วยกฎกินทรัพยากรแค่ไหน
EA1 ตัวต่อ 1 กราฟน้อย ถ้า EA คำนวณไม่หนัก
กราฟเปิดได้หลายอันใน MT5 ชุดเดียวปานกลาง ขึ้นกับจำนวนแท่งและ Indicator บนกราฟ
MT5 หนึ่งชุดล็อกอินได้ทีละบัญชีมากที่สุด เพราะเป็นโปรแกรมเต็มตัว
บัญชีเทรดรันพร้อมกันได้เท่าจำนวน MT5 ที่ติดตั้งแยกเพิ่มตาม MT5 ที่ต้องเปิดเพิ่ม

ลองดูตัวอย่าง สมมติคุณมี 2 บัญชี แต่ละบัญชีรัน EA บน 2 กราฟ คุณต้องเปิด MT5 ทั้งหมด 2 ชุด รวม 4 กราฟ และมี EA ทำงาน 4 ตัว ถ้าเปลี่ยนเป็น 1 บัญชีแต่รัน EA 4 กราฟ คุณเปิด MT5 แค่ชุดเดียว เครื่องจะใช้แรมน้อยกว่าแบบแรกชัดเจน ทั้งที่จำนวน EA เท่ากัน

MT5 กินแรมเท่าไหร่

คำถามว่า MT5 กินแรมเท่าไหร่ ไม่มีตัวเลขทางการ คู่มือของ MT5 บอกไว้ว่าความต้องการด้านฮาร์ดแวร์ขึ้นกับลักษณะการใช้งาน เช่น ภาระจากโปรแกรม MQL5 ที่ทำงาน จำนวนสัญลักษณ์ที่เปิดอยู่ และจำนวนกราฟ ตัวเลขที่คนอื่นบอกต่อกันมาจึงใช้กับเครื่องของคุณได้ไม่ตรงนัก

สิ่งที่ทำให้ MT5 ใช้แรมเพิ่มมีอยู่ไม่กี่อย่าง และส่วนใหญ่ปรับได้เอง

ปัจจัยผลต่อแรมปรับยังไง
จำนวนกราฟที่เปิดทุกกราฟเก็บข้อมูลราคาและภาพของตัวเองปิดกราฟที่ไม่ได้ติด EA
Max bars in chartยิ่งตั้งสูง แต่ละกราฟยิ่งเก็บแท่งเทียนมากลดค่าใน Tools → Options → Charts แล้วเปิด MT5 ใหม่
สัญลักษณ์ใน Market Watchทุกตัวที่แสดงต้องรับราคาเข้ามาตลอดซ่อนตัวที่ไม่ใช้
Indicator บนกราฟบางตัวคำนวณย้อนหลังมาก ใช้ทั้งแรมและ CPUถอดตัวที่ EA ไม่ได้ใช้
Strategy Testerตอนทดสอบหรือ Optimize ใช้ทรัพยากรสูงมากทดสอบบนเครื่องอื่น ไม่ใช่เครื่องที่ใช้เทรด

นอกจากนี้ EA แต่ละตัวก็หนักไม่เท่ากัน EA ที่ดูแค่สัญลักษณ์เดียวบน Timeframe เดียวใช้แรงเครื่องน้อย ส่วน EA ที่ดึงข้อมูลหลายสัญลักษณ์หรือหลาย Timeframe มาคำนวณพร้อมกันจะใช้มากขึ้น ถ้าคุณไม่แน่ใจว่าช่องไหนใน Inputs ทำให้ EA ต้องคำนวณเพิ่ม อ่านวิธีอ่านช่องตั้งค่าได้ในบท ตั้งค่า EA ช่อง Inputs แล้วถามผู้พัฒนาเพิ่มเติม

CPU RAM ดิสก์ และเน็ต: แต่ละอย่างมีผลยังไง

เวลาดูแพ็กเกจ VPS คุณจะเจอตัวเลขสี่ตัวนี้เสมอ แต่ละตัวมีผลกับ MT5 ไม่เท่ากัน

ทรัพยากรMT5 ใช้ทำอะไรอาการเมื่อไม่พอ
RAMเก็บข้อมูลราคา กราฟ และตัวโปรแกรมของทุกชุดที่เปิดเครื่องช้าทั้งระบบ เปิดเมนูค้าง MT5 อาจปิดตัวเอง
CPUคำนวณของ EA และ Indicator ทุกครั้งที่ราคาขยับช่วงตลาดวิ่งแรง โปรแกรมตอบสนองช้า
ดิสก์เก็บประวัติราคา ไฟล์ log และอัปเดตของ Windowsดิสก์เต็มแล้ว MT5 เขียนข้อมูลไม่ได้ หรืออัปเดตไม่ผ่าน
เน็ตและที่ตั้งเป็นเส้นทางที่ราคาไหลเข้ามา และคำสั่งของ EA วิ่งออกไปหาโบรกเกอร์ค่า ping สูง คำสั่งไปถึงช้า หรือหลุดการเชื่อมต่อบ่อย

สำหรับคนใช้ EA ทั่วไป แรมคือข้อที่ต้องดูก่อน เพราะเป็นตัวที่เต็มเร็วที่สุดเมื่อเพิ่ม MT5 ส่วน CPU จำนวนคอร์ไม่ต้องมากนัก ถ้าไม่ได้รันการทดสอบบนเครื่องเดียวกัน ดิสก์ให้เผื่อพื้นที่ว่างไว้เสมอ เพราะ Windows ต้องใช้ตอนอัปเดต

วิธีวัดสเปกที่ต้องใช้จากเครื่องจริง

แทนที่จะเดาจากตัวเลขของคนอื่น ให้วัดจากการใช้งานของคุณเอง ทำได้บนคอมที่บ้านหรือบน VPS ช่วงทดลองใช้ ขั้นตอนนี้ใช้เวลาเตรียมราวครึ่งชั่วโมง แล้วปล่อยทิ้งไว้หนึ่งวัน

  1. ดูแรมที่ Windows ใช้เองก่อน

    ก่อนเปิด MT5 กด Ctrl + Shift + Esc เพื่อเปิด Task Manager ไปที่แท็บ Performance เลือก Memory แล้วจดตัวเลขที่ใช้อยู่ นี่คือส่วนที่ Windows กินเองตอนว่าง

  2. เปิด MT5 ให้ครบตามแผน

    เปิด MT5 ทุกชุด ทุกกราฟ และติด EA ให้เหมือนตอนใช้งานจริง จะใช้บัญชีทดลองก็ได้ เพราะเราวัดแค่การใช้ทรัพยากร

  3. ปล่อยไว้หนึ่งวันทำการ

    แรมของ MT5 จะค่อย ๆ เพิ่มขึ้นตามข้อมูลราคาที่สะสม การวัดทันทีหลังเปิดจะได้ตัวเลขต่ำกว่าความจริง

  4. ดูแรมของ MT5 แต่ละชุด

    ใน Task Manager แท็บ Details หาโปรเซสชื่อ terminal64.exe แต่ละตัวคือ MT5 หนึ่งชุด จดคอลัมน์หน่วยความจำของทุกตัว

  5. รวมตัวเลขแล้วเผื่อที่

    เอาแรมของ Windows บวกแรมของ MT5 ทุกชุด แล้วเผื่อเพิ่มอีกราวหนึ่งในสาม สำหรับช่วงที่ตลาดวิ่งแรง การอัปเดต และการเข้าเครื่องด้วย Remote Desktop

ตัวอย่างการคิด

ตัวเลขต่อไปนี้เป็นตัวเลขสมมติเพื่อแสดงวิธีคิด ไม่ใช่ค่าที่เครื่องทุกเครื่องจะได้ สมมติ Windows ใช้แรมเองตอนว่าง 2 GB คุณเปิด MT5 3 ชุด วัดได้ชุดละ 500 MB รวม MT5 เป็น 1.5 GB ยอดรวมคือ 3.5 GB เมื่อเผื่ออีกหนึ่งในสามจะได้ราว 4.7 GB ดังนั้นแพ็กเกจที่มีแรม 6 GB ขึ้นไปจะพอดีกว่าแพ็กเกจ 4 GB ที่ดูเหมือนพอแต่ไม่มีที่ว่างเหลือ ทำแบบนี้แล้วคุณจะตอบได้เองว่า VPS รัน EA ได้กี่ตัวสำหรับงานของคุณ

VPS รัน MT5 หลายบัญชี: ติดตั้งแยกโฟลเดอร์

ถ้าแผนของคุณคือใช้ VPS รัน MT5 หลายบัญชีในเครื่องเดียว วิธีมาตรฐานคือติดตั้งโปรแกรมหลายครั้งในโฟลเดอร์คนละชื่อ แต่ละชุดมีกราฟ ค่า EA และข้อมูลของตัวเอง ไม่ปนกัน

  1. เปิดตัวติดตั้งอีกครั้ง

    รันไฟล์ติดตั้ง MT5 ใหม่ ก่อนกดติดตั้งให้เข้า Settings ของตัวติดตั้ง แล้วเปลี่ยนโฟลเดอร์ปลายทางเป็นชื่อใหม่ เช่น ต่อท้ายด้วยชื่อบัญชีหรือชื่อโบรกเกอร์

  2. ตั้งชื่อทางลัดให้แยกง่าย

    เปลี่ยนชื่อไอคอนบนหน้าจอให้บอกว่าเป็นบัญชีไหน กันเปิดผิดชุดตอนเข้าจากมือถือ

  3. ล็อกอินและติด EA ทีละชุด

    เปิดแต่ละชุด ล็อกอินบัญชีของมัน วางไฟล์ EA ในโฟลเดอร์ Experts ของชุดนั้นเอง แล้วตั้งค่าบนกราฟ เพราะโฟลเดอร์ข้อมูลของแต่ละชุดแยกกัน

  4. เช็กว่าแต่ละชุดเชื่อมต่อแล้ว

    ดูมุมขวาล่างของทุกหน้าต่างว่าไม่ขึ้น No connection และปุ่ม Algo Trading ของทุกชุดเป็นสีเขียว ปุ่มนี้เป็นของแต่ละชุด ไม่ได้เปิดพร้อมกันทั้งเครื่อง

เมื่อมีหลายชุด การเข้าไปเช็กจะใช้เวลามากขึ้นตามไปด้วย วิธีควบคุมหน้าจอ VPS ให้คล่อง รวมถึงคีย์ลัดสลับหน้าต่างใน Remote Desktop อยู่ในบท ใช้ Remote Desktop ดูแล VPS

ทำให้ MT5 เบาลงโดยไม่กระทบ EA

ก่อนตัดสินใจอัปเกรดแพ็กเกจ ลองลดภาระของ MT5 ก่อน หลายครั้งแค่ปรับไม่กี่จุด เครื่องเดิมก็รับงานเพิ่มได้

  • ปิดกราฟที่ไม่ได้ติด EA เหลือเฉพาะกราฟที่ EA ต้องใช้
  • ใน Market Watch คลิกขวาแล้วซ่อนสัญลักษณ์ที่ไม่ได้ใช้ เหลือเฉพาะตัวที่ EA เทรด
  • ลดค่า Max bars in chart ที่ Tools → Options → Charts ค่านี้มีผลหลังปิดเปิด MT5 ใหม่
  • ถอด Indicator ที่ติดไว้ดูเองออกจากกราฟบน VPS ไปดูบนเครื่องอื่นแทน
  • ไม่รัน Strategy Tester หรือ Optimize บนเครื่องที่ EA กำลังเทรด
  • ปิดเบราว์เซอร์และโปรแกรมอื่นใน VPS หลังใช้งานเสร็จ

ถ้าปรับแล้วเครื่องยังช้า หรือ MT5 ปิดตัวเองเป็นระยะ ให้ดูข้อความในแท็บ Journal ประกอบด้วย อาการที่ EA หายไปจากกราฟหรือหยุดทำงานเงียบ ๆ มีวิธีไล่เช็กอยู่ในบท EA MT5 ไม่ทำงาน ต้องเช็กอะไร

VPS สำหรับ MT5 ควรดูอะไรนอกจากแรม

สเปกที่พอดีเป็นแค่ครึ่งหนึ่งของการเลือก อีกครึ่งคือเงื่อนไขที่ทำให้ MT5 ทำงานได้ราบรื่นตลอดเดือน

เรื่องทำไมต้องดู
รุ่นของ Windowsคู่มือ MT5 ระบุว่าโปรแกรมทำงานบน Windows 10 และ 11 ถ้า VPS ติดตั้ง Windows Server มา ให้ลองติดตั้ง MT5 ในช่วงทดลองใช้ก่อนจ่ายยาว
ที่ตั้งของศูนย์ข้อมูลยิ่งใกล้เซิร์ฟเวอร์ของโบรกเกอร์ ค่า ping ยิ่งต่ำ หลังติดตั้งให้ดูตัวเลขที่มุมขวาล่างของ MT5
ดิสก์แบบ SSDเปิดโปรแกรมและโหลดประวัติราคาเร็วกว่า ช่วยให้ MT5 กลับมาทำงานเร็วหลังรีสตาร์ต
การแจ้งบำรุงรักษาถ้าเครื่องจะถูกรีสตาร์ต ควรรู้ล่วงหน้าเพื่อเข้าไปเช็กว่า EA กลับมาครบ
การอัปเกรดแพ็กเกจถ้าเพิ่มบัญชีภายหลัง ควรเพิ่มแรมได้โดยไม่ต้องย้ายเครื่องใหม่

VPS MT5 ราคา ขึ้นกับอะไร

ราคา VPS สำหรับ MT5 ต่างกันได้หลายเท่า เพราะผู้ให้บริการคิดจากหลายปัจจัยรวมกัน เราไม่แนะนำผู้ให้บริการรายใดรายหนึ่ง แต่ถ้ารู้ว่าราคาขึ้นกับอะไร คุณจะเทียบได้เองว่าจ่ายแล้วได้อะไร

  • แรมและจำนวนคอร์ของ CPU เป็นตัวกำหนดราคาหลัก
  • ค่าลิขสิทธิ์ Windows บางรายรวมไว้ในราคา บางรายคิดแยก
  • ที่ตั้งของศูนย์ข้อมูล บางประเทศค่าบริการสูงกว่า
  • รอบการจ่าย การจ่ายรายปีมักถูกกว่าต่อเดือน แต่ถ้าย้ายกลางทางอาจไม่ได้เงินคืน

ถ้าเพิ่งเริ่ม จ่ายรายเดือนก่อนจะยืดหยุ่นกว่า ใช้สักเดือนแล้ววัดแรมตามขั้นตอนด้านบน ถ้าพอดีค่อยพิจารณาจ่ายรอบยาว

คำถามที่พบบ่อยเรื่องจำนวน EA บน VPS

รัน EA สองตัวบนกราฟเดียวได้ไหม?

ไม่ได้ กราฟหนึ่งรัน EA ได้ครั้งละหนึ่งตัว ถ้าต้องการรันสองตัวบนสัญลักษณ์เดียวกัน ให้เปิดกราฟสัญลักษณ์นั้นสองอันแล้วติด EA คนละกราฟ

VPS แรม 2 GB พอรัน MT5 ไหม?

ขึ้นกับว่า Windows ในเครื่องนั้นใช้แรมเองไปเท่าไหร่ และคุณเปิด MT5 กี่ชุด ถ้า Windows กินไปเกือบหมดแล้ว MT5 จะเหลือที่น้อยมาก ให้วัดตามขั้นตอนในบทนี้ก่อนตัดสินใจ

VPS เครื่องเดียวใช้หลายโบรกเกอร์ได้ไหม?

ได้ ติดตั้ง MT5 แยกโฟลเดอร์สำหรับแต่ละบัญชี ไม่ว่าจะอยู่โบรกเกอร์เดียวกันหรือต่างกัน แต่ละชุดล็อกอินด้วยข้อมูลของบัญชีตัวเอง

เปิด MT5 นาน ๆ แล้วเครื่องช้าลง ต้องทำยังไง?

ดูแรมใน Task Manager ว่าเต็มหรือยัง ถ้าใกล้เต็ม ลองลดกราฟ ซ่อนสัญลักษณ์ที่ไม่ใช้ หรือปิดเปิด MT5 ใหม่ในช่วงตลาดปิด ถ้ายังไม่พอ ค่อยเพิ่มแรมของแพ็กเกจ

EA หลายตัวบน MT5 ชุดเดียว จะชนกันไหม?

เรื่องทรัพยากรไม่ชนกัน แต่เรื่องออเดอร์อาจชนได้ถ้า EA สองตัวเทรดสัญลักษณ์เดียวกันและแยกออเดอร์ของตัวเองไม่ได้ EA ส่วนใหญ่ใช้เลข Magic Number แยกกัน ให้เช็กในคู่มือของ EA ว่าต้องตั้งค่านี้หรือไม่

สรุป: คิดสเปกให้พอดี แล้วเริ่มรันบน VPS

สรุปแล้ว VPS รัน EA ได้กี่ตัว ขึ้นกับจำนวน MT5 ที่เปิดมากกว่าจำนวน EA นับบัญชีและกราฟให้ชัด วัดแรมจากเครื่องจริง แล้วเผื่อที่ไว้ คุณจะได้แพ็กเกจที่ไม่เล็กจนเครื่องค้าง และไม่ใหญ่จนจ่ายเกินจำเป็น

ถ้าคุณใช้ EA ของ EA BULL สิทธิ์จะผูกกับเลขบัญชี MT5 คู่กับชื่อ Server การวางแผนว่าจะรันกี่บัญชีจึงเกี่ยวกับแพ็กเกจด้วย แพ็กเกจ Pro ใช้ได้ 1 ถึง 2 บัญชีและติดตั้งเองตามคู่มือ ส่วน VIP ทีมงานติดตั้งให้บนคอมหรือ VPS และเช็กค่าก่อนเริ่มรัน ค่าเช่า VPS แยกจากแพ็กเกจทุกแบบ เมื่อได้เครื่องแล้ว ทำตามคู่มือ เชื่อมต่อ Windows VPS และย้าย MT5 ขึ้นไป ได้ทีละขั้น ถ้าอยากเช็กว่าแผนจำนวนบัญชีของคุณเหมาะกับแพ็กเกจไหน ถามทีมงานทาง LINE ได้
