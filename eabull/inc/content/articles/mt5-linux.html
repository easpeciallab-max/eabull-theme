MT5 Linux ทำได้ โดยรันโปรแกรมผ่าน Wine ซึ่ง MetaQuotes มีหน้าคู่มือและสคริปต์ติดตั้งให้สำหรับ Ubuntu Debian Linux Mint และ Fedora แต่ตัว MT5 ยังเป็นโปรแกรม Windows ที่ทำงานผ่านตัวแปลง และคู่มือการติดตั้งระบุระบบที่โปรแกรมทำงานได้ไว้ว่า Windows 10 และ 11 ถ้าจะใช้ EA บน Linux หรือบน VPS Linux คุณจึงต้องทดสอบเองว่า EA ทำงานปกติ และต้องเตรียมหน้าจอกราฟิกกับวิธีเข้าเครื่องเพิ่ม

สรุปสั้น

  • MT5 บน Linux ทำงานผ่าน Wine ซึ่งเป็นตัวกลางฟรีที่ให้โปรแกรม Windows รันบนระบบตระกูล Unix ได้
  • สคริปต์ทางการตรวจรุ่นของระบบเอง ติดตั้ง Wine ให้ แล้วเปิดตัวติดตั้ง MT5 รองรับ Ubuntu Debian Linux Mint และ Fedora
  • คู่มือไม่ได้พูดถึง VPS Linux ที่ไม่มีหน้าจอ ระบบตระกูลอื่น หรือ EA ที่เรียก DLL ส่วนนี้ต้องลองเองทั้งหมด
  • VPS Linux หลายแบบไม่มีหน้าจอกราฟิกมาให้ ต้องติดตั้งหน้าจอและโปรแกรมเข้าเครื่องระยะไกลเพิ่มก่อนลง MT5
  • ก่อนใช้เงินจริง รัน EA กับบัญชีทดลองบนเครื่อง Linux ที่จะใช้จริงสักระยะ แล้วเทียบกับตอนรันบน Windows

บทนี้อยู่ในชุดเรื่องการให้ EA ทำงานตลอด 24 ชั่วโมง Linux เป็นทางเลือกหนึ่งที่คนนึกถึงเมื่ออยากประหยัดหรือไม่มีเครื่อง Windows ถ้าคุณยังไม่ได้เทียบว่า รัน EA บนเครื่องแบบไหนได้บ้าง และแต่ละแบบต้องดูแลอะไร อ่านบทหลักก่อน แล้วค่อยกลับมาดูรายละเอียดของ Linux ในบทนี้

MT5 Linux ทำได้ไหม: คำตอบตามคู่มือทางการ

คู่มือ MetaTrader 5 มีหน้าเฉพาะสำหรับการติดตั้งบน Linux จึงถือว่าเป็นวิธีที่ผู้พัฒนาเตรียมไว้ให้ ไม่ใช่วิธีลัดที่ผู้ใช้คิดกันเอง แต่ให้อ่านให้ครบว่าคู่มือพูดถึงอะไร และอะไรที่ไม่ได้พูดถึง (ข้อมูลจาก คู่มือ MetaTrader 5: Installation on Linux และ Platform Installation ตรวจเมื่อ พ.ย. 2569)

คู่มือทางการบอกไว้คู่มือทางการไม่ได้พูดถึง
โปรแกรมรันบน Linux ด้วย Wineระบบตระกูลอื่นนอกจาก Ubuntu Debian Linux Mint และ Fedora
มีสคริปต์ที่ตรวจรุ่นของระบบ ติดตั้ง Wine และเปิดตัวติดตั้ง MT5 ให้เครื่องเซิร์ฟเวอร์ที่ไม่มีหน้าจอกราฟิก
แนะนำให้ใช้ระบบปฏิบัติการและ Wine รุ่นล่าสุดเสมอการรัน MT5 หลายชุดบนเครื่อง Linux เดียวกัน
ตำแหน่งโฟลเดอร์ข้อมูลของโปรแกรมที่ติดตั้งผ่าน WineEA ที่เรียก DLL ของ Windows หรือโปรแกรมเสริมอื่น จะทำงานได้หรือไม่
หน้าติดตั้งหลักระบุว่าโปรแกรมทำงานบน Windows 10 และ 11การเทียบความเร็วหรือการใช้หน่วยความจำกับ Windows

อ่านจากตารางแล้ว คำตอบที่ตรงที่สุดคือ MT5 บน Linux เป็นวิธีที่มีคู่มือรองรับในระดับการติดตั้ง แต่การใช้งานจริงกับ EA แต่ละตัวเป็นหน้าที่ของคุณที่ต้องทดสอบ

Wine คืออะไร และทำไม MT5 ต้องใช้

Wine คือซอฟต์แวร์ฟรีที่ทำหน้าที่เป็นชั้นกลาง ให้โปรแกรมที่เขียนมาสำหรับ Windows ทำงานบนระบบตระกูล Unix อย่าง Linux และ macOS ได้ โดยไม่ต้องติดตั้ง Windows จริง มันไม่ใช่เครื่องจำลองทั้งเครื่อง แต่แปลคำสั่งที่โปรแกรมเรียกหา Windows ไปเป็นคำสั่งของ Linux

ตามคู่มือ Wine สร้างไดรฟ์จำลองแยกให้แต่ละโปรแกรม พร้อมสภาพแวดล้อมที่โปรแกรมต้องใช้ MT5 จึง "เห็น" ตัวเองอยู่บน Windows ทั้งที่จริงทำงานบน Linux ข้อนี้คือเหตุผลที่ทั้งตัวโปรแกรมและ EA ส่วนใหญ่ใช้งานได้ และก็เป็นเหตุผลเดียวกันที่บางอย่างทำงานไม่เหมือนเดิม เพราะ Wine แปลได้ไม่ครบทุกส่วนของ Windows

วิธีดูว่าโปรแกรมรันผ่าน Wine อยู่หรือไม่ ให้ดูบรรทัดแรก ๆ ในแท็บ Journal ตอนเปิดโปรแกรม ตัวอย่างในคู่มือฉบับ macOS แสดงข้อมูลรุ่น Windows ตามด้วยคำว่า Wine และเลขรุ่นของ Wine ข้อมูลนี้มีประโยชน์ตอนต้องแจ้งปัญหาให้ผู้พัฒนา EA

MT5 Linux install: ติดตั้งด้วยสคริปต์ทางการ

ขั้นตอนนี้สรุปจากหน้าคู่มือการติดตั้งบน Linux ใช้ได้กับเครื่องที่มีหน้าจอกราฟิกอยู่แล้ว เช่น คอมที่ลง MT5 Linux Ubuntu แบบเดสก์ท็อป คำสั่งที่ใช้ให้คัดลอกจากหน้าคู่มือทางการโดยตรง อย่าคัดลอกจากเว็บอื่นหรือจากแชต เพราะคำสั่งในหน้าต่าง Terminal มีสิทธิ์ทำอะไรกับเครื่องได้มาก

  1. เปิด Terminal แบบผู้ใช้ปกติ

    คู่มือให้เปิดหน้าต่างคำสั่งโดยไม่ใช้สิทธิ์ผู้ดูแล คือไม่ต้องพิมพ์ sudo นำหน้า

  2. รันคำสั่งจากหน้าคู่มือ

    คำสั่งบรรทัดเดียวในคู่มือจะดาวน์โหลดสคริปต์ชื่อ mt5linux.sh ทำให้รันได้ แล้วเริ่มรันทันที ระบบจะถามรหัสผ่านบัญชีผู้ใช้ของ Linux เพื่ออนุญาตการติดตั้ง

  3. ตอบรับแพ็กเกจเสริมของ Wine

    ถ้ามีหน้าต่างถามให้ติดตั้ง Mono หรือ Gecko ให้ตอบรับ เพราะเป็นส่วนที่โปรแกรมต้องใช้

  4. ติดตั้ง MT5 ตามขั้นตอนปกติ

    ตัวติดตั้ง MT5 จะเปิดขึ้นเหมือนบน Windows ทำตามขั้นจนเสร็จ

  5. รีสตาร์ตเครื่อง แล้วล็อกอินบัญชี

    คู่มือให้รีสตาร์ตระบบหลังติดตั้งเสร็จ จากนั้นเปิด MT5 แล้วล็อกอินด้วยเลขบัญชี รหัสผ่าน และชื่อ Server

หลังติดตั้ง โฟลเดอร์ข้อมูลของโปรแกรมตามค่าเริ่มต้นจะอยู่ในโฟลเดอร์ซ่อน .mt5 ใต้โฮมของผู้ใช้ ต่อด้วย drive_c → Program Files → MetaTrader 5 ถ้าจะคัดลอกไฟล์ EA เข้าเครื่องจากฝั่ง Linux ให้วางในโฟลเดอร์ MQL5 → Experts ที่อยู่ใต้ตำแหน่งนี้ ส่วน Wine และระบบปฏิบัติการ คู่มือแนะนำให้อัปเดตเป็นรุ่นล่าสุดอยู่เสมอ แยกจากการอัปเดตของ MT5 เอง ซึ่งเราอธิบายจังหวะที่เหมาะไว้ในบท อัปเดต MT5 โดยไม่ให้ EA สะดุด

MT5 Linux VPS: ต้องเตรียมอะไรเพิ่ม

คนที่ค้นหา MT5 Linux VPS ส่วนใหญ่อยากรู้ว่าเช่า VPS ที่เป็น Linux มาลง MT5 แทน Windows VPS ได้ไหม ทำได้ แต่ต้องรู้ก่อนว่า VPS Linux หลายแบบมาเป็นระบบเซิร์ฟเวอร์ที่ใช้งานผ่านบรรทัดคำสั่งอย่างเดียว ไม่มีหน้าจอกราฟิก ขณะที่ MT5 เป็นโปรแกรมที่ต้องมีหน้าต่างให้เห็น งานที่ต้องทำเพิ่มจึงมีดังนี้

  • ติดตั้งหน้าจอกราฟิกแบบเดสก์ท็อปลงบน VPS
  • ติดตั้งตัวรับการเชื่อมต่อระยะไกลที่ใช้กับ Linux ได้ แล้วเข้าเครื่องจากคอมหรือมือถือด้วยโปรแกรมที่เข้ากัน
  • ตั้งให้หน้าจอยังทำงานต่อเมื่อคุณตัดการเชื่อมต่อ ไม่อย่างนั้น MT5 อาจปิดตามเซสชัน
  • ตั้งให้ MT5 เปิดเองหลังเครื่องรีสตาร์ต และทดลองรีสตาร์ตจริงหนึ่งครั้ง
  • อัปเดตระบบและปิดช่องทางเข้าเครื่องที่ไม่ใช้ เพราะเครื่องนี้ล็อกอินบัญชีเทรดค้างไว้ตลอด

Linux ต่างจาก Windows ตรงไหน สำหรับคนใช้ EA

ถ้าติดตั้งสำเร็จ หน้าตา MT5 บน Linux แทบไม่ต่างจากบน Windows เมนูเดิม ปุ่ม Algo Trading เดิม การลาก EA ลงกราฟก็เหมือนเดิม ความต่างอยู่ในจุดที่มองไม่เห็นจากหน้าจอ

จุดที่ต่างผลที่อาจเจอควรทำอะไร
EA ที่เรียกไฟล์ DLL ของ Windowsอาจทำงานไม่ได้หรือทำงานไม่ครบ ถ้า Wine แปลส่วนนั้นไม่ได้ถามผู้พัฒนาว่า EA ใช้ DLL ไหม และเคยทดสอบบน Linux หรือยัง
ตำแหน่งไฟล์ไฟล์อยู่ในไดรฟ์จำลองของ Wine หาไม่เจอถ้าค้นแบบ Windowsจดตำแหน่งโฟลเดอร์ข้อมูลไว้ตั้งแต่ติดตั้ง
รุ่นของ WineWine รุ่นเก่าอาจทำให้โปรแกรมไม่เสถียรอัปเดตระบบและ Wine ตามที่คู่มือแนะนำ แล้วเช็ก EA หลังอัปเดต
การแจ้งปัญหาผู้พัฒนา EA อาจทดสอบไว้บน Windows อย่างเดียวแจ้งตั้งแต่แรกว่ารันผ่าน Wine บน Linux และส่งบรรทัด Journal ตอนเปิดโปรแกรมไปด้วย

ทดสอบ EA บน Linux ก่อนใช้เงินจริง

เพราะไม่มีใครรับรองได้ล่วงหน้าว่า EA ทุกตัวทำงานบน Wine เหมือนบน Windows ทางที่ปลอดภัยคือทดสอบบนเครื่องที่จะใช้จริง ไม่ใช่ทดสอบบนคอมอีกเครื่องแล้วย้ายมา รายการนี้ช่วยให้มั่นใจขึ้นก่อนเปลี่ยนไปบัญชีจริง

  1. ติด EA กับบัญชีทดลอง

    วางไฟล์ ลากลงกราฟ แล้วดูว่าแท็บ Journal ขึ้นว่าโหลดสำเร็จ และแท็บ Experts ไม่มีข้อผิดพลาด

  2. ปล่อยรันหลายวันทำการ

    ดูว่า EA เปิด ปิด และแก้ออเดอร์ได้ตามที่คู่มือของมันบอก ไม่มีข้อความแปลกในแท็บ Experts

  3. เทียบกับตอนรันบน Windows

    ถ้ามีเครื่อง Windows รัน EA ตัวเดียวกันกับบัญชีทดลองในช่วงเดียวกัน ให้เทียบว่าพฤติกรรมสอดคล้องกันไหม

  4. ลองใช้ Strategy Tester

    เปิดด้วย Ctrl+R แล้วลองทดสอบย้อนหลังสั้น ๆ ถ้าคุณใช้การทดสอบเป็นประจำ ส่วนเมนูและโหมดต่าง ๆ ของเครื่องมือนี้อธิบายไว้ในบท Strategy Tester MT5 ทุกเมนู

  5. รีสตาร์ตเครื่องหนึ่งครั้ง

    ดูว่า MT5 เปิดเอง ล็อกอินบัญชี และ EA กลับมาบนกราฟพร้อมปุ่ม Algo Trading ที่เปิดอยู่

ถ้าขั้นไหนไม่ผ่าน และหาสาเหตุไม่เจอ ให้ลองรัน EA ตัวเดียวกันบน Windows เพื่อแยกว่าปัญหาอยู่ที่ EA หรืออยู่ที่สภาพแวดล้อมของ Linux

คำถามที่พบบ่อยเรื่อง MT5 บน Linux

ใช้ Linux ตระกูลอื่นนอกจากที่คู่มือบอกได้ไหม?

สคริปต์ทางการรองรับ Ubuntu Debian Linux Mint และ Fedora ระบบอื่นอาจติดตั้ง Wine เองแล้วลง MT5 ได้ แต่อยู่นอกขั้นตอนของคู่มือ ต้องแก้ปัญหาเองทั้งหมด

MT5 บน Linux กินแรมน้อยกว่า Windows ไหม?

คู่มือไม่ได้ให้ตัวเลขเทียบไว้ ตัวที่กินแรมมากคือจำนวนกราฟและโปรแกรมที่เปิด ให้วัดจากเครื่องจริงหลังเปิด MT5 ครบตามแผน วิธีคิดสเปกจากการวัดอยู่ในบท VPS รัน EA ได้กี่ตัว

ใช้ Mac แทน Linux ได้ไหม หลักเดียวกันหรือเปล่า?

หลักเดียวกัน บน macOS มีตัวติดตั้งทางการที่ติดตั้ง Wine และ MT5 ให้อัตโนมัติ คู่มือระบุว่าต้องเป็น macOS Catalina 10.15.7 ขึ้นไป และรองรับชิปของ Apple การทดสอบ EA ก่อนใช้จริงก็ต้องทำเหมือนบน Linux

อัปเดต MT5 บน Linux ยังไง?

ตัวโปรแกรม MT5 มีระบบอัปเดตของตัวเอง ส่วน Wine และระบบปฏิบัติการต้องอัปเดตแยกผ่านตัวจัดการแพ็กเกจของ Linux คู่มือแนะนำให้ใช้รุ่นล่าสุดเสมอ หลังอัปเดตทุกครั้งให้เช็กว่า EA ยังทำงานปกติ

รัน MT5 หลายบัญชีบน Linux เครื่องเดียวได้ไหม?

คู่มือฉบับ Linux อธิบายเฉพาะการติดตั้งชุดเดียวตามค่าเริ่มต้น การติดตั้งหลายชุดผ่าน Wine เป็นเรื่องที่ต้องตั้งเอง ถ้าแผนของคุณคือรันหลายบัญชี Windows VPS ทำตามคู่มือหลักได้ตรงกว่า

สรุป: MT5 Linux ทำได้ แต่ต้องทดสอบเองให้ครบ

MT5 Linux มีคู่มือและสคริปต์ทางการรองรับการติดตั้ง ใช้ได้จริงสำหรับคนที่คุ้นกับ Linux และพร้อมทดสอบ EA ด้วยตัวเอง แต่การใช้งานกับ EA แต่ละตัว VPS ที่ไม่มีหน้าจอ และระบบตระกูลอื่น อยู่นอกสิ่งที่คู่มือพูดถึง ถ้าคุณเพิ่งเริ่มรัน EA และอยากให้ทุกขั้นตรงกับคู่มือ Windows VPS ตรงไปตรงมากว่า

สำหรับลูกค้า EA BULL ค่าเช่า VPS ไม่รวมอยู่ในแพ็กเกจ คุณเลือกเครื่องเองได้ ถ้าเลือก Windows VPS ทำตาม คู่มือย้าย MT5 ขึ้น Windows VPS ได้ทีละขั้นพร้อมภาพ หรือเลือกแพ็กเกจ VIP ให้ทีมงานติดตั้งบนคอมหรือ VPS ของคุณและเช็กค่าก่อนเริ่มรัน ถ้ากำลังคิดจะใช้เครื่อง Linux ทักมาคุยกับทีมงานก่อนเช่า จะได้ตัดสินใจจากข้อมูลครบ
