ปิดสลีปคอมใน Windows 11 ทำได้ที่ Settings → System → Power & battery → Screen, sleep, & hibernate timeouts แล้วตั้งช่องเข้าโหมดสลีปเป็น Never ตอนเสียบปลั๊ก ส่วนหน้าจอปล่อยให้ดับเองได้ เพราะ EA หยุดเมื่อเครื่องหลับ ไม่ได้หยุดเมื่อจอดับ จากนั้นตั้งเพิ่มอีกสามจุด คือการพับจอโน้ตบุ๊ก เวลาอัปเดตของ Windows และให้ MT5 เปิดเองหลังรีสตาร์ต

สรุปสั้น

  • EA ทำงานต่อเมื่อจอดับหรือล็อกหน้าจอ แต่หยุดทันทีเมื่อเครื่องสลีป ไฮเบอร์เนต Sign out หรือปิดเครื่อง
  • ตั้ง Make my device sleep after เป็น Never ตอนเสียบปลั๊ก และให้ Turn my screen off after เป็นไม่กี่นาทีได้
  • โน้ตบุ๊กต้องตั้ง When I close the lid ให้เครื่องไม่หลับตอนพับจอ และเสียบสายชาร์จไว้ตลอด
  • Windows Update หยุดชั่วคราวได้สูงสุด 35 วัน และตั้ง Active hours กันรีสตาร์ตช่วงที่คุณใช้งาน
  • วางทางลัด MT5 ไว้ในโฟลเดอร์ shell:startup ให้โปรแกรมเปิดเองหลังลงชื่อเข้าใช้ แล้วเช็กว่า EA กลับมาครบ

บทนี้เหมาะกับคนที่ใช้คอมที่บ้านรัน EA ซึ่งเป็นทางเลือกหนึ่งในหลายแบบ ถ้าอยากเห็นภาพรวมว่ารัน EA ให้ทำงานตลอด 24 ชั่วโมงทำได้กี่ทาง และแต่ละทางต่างกันยังไง อ่านบท รัน EA ให้ทำงานต่อเนื่องบน MT5 ประกอบ

ปิดคอมแล้ว EA ทำงานไหม

คำถามว่าปิดคอมแล้ว EA ทำงานไหม คำตอบคือไม่ทำงาน EA อยู่ในโปรแกรม MT5 ที่เปิดบนคอมเครื่องนั้น เมื่อเครื่องปิด โปรแกรมก็ปิด EA จึงหยุดคิดทันที ออเดอร์ที่เปิดค้างไว้ยังอยู่ในบัญชีที่โบรกเกอร์ แต่จะไม่มีใครดูแลต่อจนกว่าคุณจะเปิด MT5 ใหม่

ที่ทำให้หลายคนสับสนคือ Windows มีหลายสถานะที่ดูเหมือน "ปิด" แต่ผลต่อ EA ไม่เหมือนกัน ตารางนี้แยกให้เห็น

สถานะของคอมเกิดอะไรขึ้นEA ทำงานไหม
หน้าจอดับปิดแค่จอภาพ ตัวเครื่องยังทำงานทำงาน
ล็อกหน้าจอ (Windows + L)ต้องใส่รหัสก่อนใช้ต่อ แต่โปรแกรมยังเปิดอยู่ทำงาน
สลีปเครื่องพักเกือบทั้งหมด ใช้ไฟน้อยมากหยุด
ไฮเบอร์เนตบันทึกสถานะลงดิสก์แล้วตัดไฟหยุด
Sign outปิดโปรแกรมทั้งหมดของผู้ใช้หยุด
Restart หรือ Shut downปิดเครื่อง หรือปิดแล้วเปิดใหม่หยุด จนกว่าจะเปิด MT5 ใหม่

ข้อสรุปคือ คุณดับจอหรือล็อกเครื่องได้ตามสบาย แต่ต้องกันไม่ให้เครื่องเข้าสลีปหรือไฮเบอร์เนตเอง ซึ่งเป็นค่าเริ่มต้นของ Windows แทบทุกเครื่อง

ปิดสลีปคอมใน Windows 11 ทีละขั้น

ขั้นตอนนี้อ้างอิงหน้าช่วยเหลือของ Microsoft (ข้อมูลจาก Microsoft Support: การตั้งค่าพลังงานใน Windows 11 ตรวจเมื่อ พ.ย. 2569) ชื่อในวงเล็บคือชื่อเมนูถ้า Windows ของคุณเป็นภาษาไทย

  1. เปิด Settings

    กดปุ่ม Start แล้วเลือก Settings (การตั้งค่า) หรือกด Windows + I

  2. ไปที่ Power & battery

    เลือก System (ระบบ) แล้วเลือก Power & battery (พลังงาน & แบตเตอรี่) บนคอมตั้งโต๊ะบางเครื่องอาจขึ้นเป็น Power อย่างเดียว

  3. เปิดหัวข้อเวลาหมดของหน้าจอและสลีป

    กดเปิดหัวข้อ Screen, sleep, & hibernate timeouts (การหมดเวลาของหน้าจอ โหมดสลีป & ไฮเบอร์เนต)

  4. ตั้งไม่ให้เครื่องหลับ

    ที่ช่อง Make my device sleep after (ทำให้อุปกรณ์ของฉันเข้าสู่โหมดสลีปหลังจาก) เลือก Never ในคอลัมน์ตอนเสียบปลั๊ก ถ้าเป็นโน้ตบุ๊ก ช่องตอนใช้แบตเตอรี่ปล่อยไว้ได้ เพราะเราจะเสียบสายไว้ตลอด

  5. ตั้งเวลาดับจอตามสะดวก

    ที่ช่อง Turn my screen off after (ปิดหน้าจอของฉันหลังจาก) เลือกเวลาสั้น ๆ ได้ เช่น 5 หรือ 10 นาที จอดับเร็วช่วยประหยัดไฟโดยไม่กระทบ EA

Microsoft ปรับค่าเริ่มต้นของการดับจอและสลีปให้สั้นลงในรุ่นใหม่ ๆ เครื่องที่เพิ่งซื้อหรือเพิ่งอัปเดตจึงอาจหลับเร็วกว่าที่คุณเคยเจอ ควรกลับมาดูหน้านี้อีกครั้งหลังอัปเดตใหญ่ของ Windows

ถ้าใช้ Windows 10

บน Windows 10 เมนูอยู่ที่ Settings → System → Power & sleep ตั้งช่อง Sleep ตอนเสียบปลั๊กเป็น Never แบบเดียวกัน แต่ควรรู้ว่า Microsoft หยุดซัพพอร์ต Windows 10 ไปแล้วตั้งแต่ 14 ต.ค. 2568 เครื่องที่ใช้รัน EA นาน ๆ ควรวางแผนย้ายไป Windows 11 หรือย้าย MT5 ไปไว้บน VPS

ปิดจอคอมแต่ไม่ปิดเครื่อง

คนที่วางคอมไว้ในห้องนอนมักอยากให้จอดับแต่เครื่องยังทำงาน การปิดจอคอมแต่ไม่ปิดเครื่องทำได้สามทาง เลือกทางที่สะดวก

  • ตั้งเวลาดับจอให้สั้นตามขั้นตอนด้านบน แล้วปล่อยให้จอดับเอง
  • กดปุ่มเปิดปิดที่ตัวจอภาพของคอมตั้งโต๊ะ ปุ่มนี้ปิดแค่จอ ไม่ได้ส่งคำสั่งให้ Windows
  • กด Windows + L เพื่อล็อกเครื่อง แล้วรอให้จอดับตามเวลาที่ตั้งไว้

โน้ตบุ๊ก: ตั้งการพับจอไม่ให้เครื่องหลับ

โน้ตบุ๊กเกือบทุกเครื่องถูกตั้งให้สลีปเมื่อพับจอ ถ้าอยากพับจอแล้วให้ EA ทำงานต่อ ต้องเปลี่ยนค่านี้ก่อน ตามขั้นตอนในหน้าช่วยเหลือของ Microsoft เรื่องปิดเครื่อง สลีป และไฮเบอร์เนต

  1. เปิด Power Options

    พิมพ์ control panel ในช่องค้นหาบนแถบงานแล้วเปิดขึ้นมา เลือก System and Security แล้วเลือก Power Options

  2. เลือกการตั้งค่าการพับจอ

    กด Choose what closing the lid does หรือ Choose what the power buttons do ที่เมนูด้านซ้าย

  3. ปลดล็อกช่องที่เทาอยู่

    ถ้าช่องตั้งค่ากดไม่ได้ ให้กด Change settings that are currently unavailable ก่อน

  4. ตั้งค่าตอนเสียบปลั๊ก

    ที่แถว When I close the lid ในคอลัมน์ Plugged in เลือก Do nothing แล้วกด Save changes

เมื่อพับจอทิ้งไว้ ความร้อนระบายได้น้อยลง ควรวางเครื่องบนพื้นแข็งที่อากาศถ่ายเทได้ ไม่วางบนที่นอนหรือโซฟา

ไฮเบอร์เนต ปุ่ม Power และโหมดพลังงาน

นอกจากสลีป ยังมีอีกสามจุดที่ทำให้เครื่องหยุดได้โดยไม่ตั้งใจ จุดแรกคือไฮเบอร์เนต ซึ่งบันทึกสถานะของเครื่องลงดิสก์แล้วตัดไฟ ใช้ไฟน้อยกว่าสลีป แต่ผลต่อ EA เหมือนกันคือหยุด ถ้าในหน้าตั้งค่ามีช่องเวลาไฮเบอร์เนต ให้ตั้งเป็น Never ตอนเสียบปลั๊กเช่นกัน

จุดที่สองคือปุ่ม Power ที่ตัวเครื่อง ในหน้า Choose what the power buttons do ช่อง When I press the power button อาจตั้งเป็น Sleep หรือ Shut down ไว้ ถ้ามีคนในบ้านกดโดนโดยไม่รู้ EA จะหยุดทันที เปลี่ยนเป็น Do nothing หรือ Turn off the display จะปลอดภัยกว่า

จุดที่สามคือโหมดพลังงาน ใน Settings → System → Power & battery มีตัวเลือก Power mode โหมด Best Power Efficiency จะจำกัดการทำงานเบื้องหลังเพื่อประหยัดไฟ สำหรับเครื่องที่ใช้รัน MT5 ควรเลือก Balanced หรือ Best performance แทน

ปิดคอมออโต้ เกิดจากอะไร และตั้งเองได้ยังไง

คำว่าปิดคอมออโต้มีคนค้นสองแบบ แบบแรกคือคอมปิดหรือรีสตาร์ตเองโดยไม่ได้สั่ง ซึ่งเป็นปัญหาของคนรัน EA แบบที่สองคืออยากตั้งให้คอมปิดเองตามเวลา เราตอบทั้งสองแบบ

อาการสาเหตุที่พบบ่อยวิธีกัน
รีสตาร์ตเองกลางดึกWindows Update ติดตั้งเสร็จแล้วรีสตาร์ตตั้ง Active hours และหยุดอัปเดตชั่วคราวช่วงตลาดเปิด
จอดำ เครื่องเงียบ ขยับเมาส์แล้วตื่นเครื่องเข้าสลีป ไม่ได้ปิดตั้งสลีปเป็น Never ตอนเสียบปลั๊ก
ปิดตรงเวลาเดิมทุกวันมีคนตั้งคำสั่งปิดเครื่องหรืองานตามเวลาไว้เช็ก Task Scheduler และถามคนที่ใช้เครื่องร่วม
ดับทันทีไม่มีสัญญาณไฟตก ไฟดับ หรือเครื่องร้อนเกินใช้เครื่องสำรองไฟ ทำความสะอาดฝุ่น วางเครื่องในที่โปร่ง
โน้ตบุ๊กปิดเองแบตเตอรี่ต่ำมาก Windows บันทึกงานแล้วปิดเครื่องเสียบสายชาร์จไว้ตลอด และเช็กว่าปลั๊กไม่หลวม

ตั้งให้คอมปิดเองตามเวลา

ถ้าคุณตั้งใจให้คอมปิดเองหลังเลิกใช้งาน เช่น หลังตลาดปิดช่วงสุดสัปดาห์และ EA ไม่มีออเดอร์ค้าง ใช้คำสั่ง shutdown ของ Windows ได้ เปิด Command Prompt แล้วพิมพ์ shutdown /s /t 3600 เครื่องจะปิดในอีก 3,600 วินาที หรือ 1 ชั่วโมง ถ้าเปลี่ยนใจ พิมพ์ shutdown /a ในหน้าต่างใหม่ก่อนหมดเวลาเพื่อยกเลิก (ข้อมูลจาก Microsoft Learn: shutdown ตรวจเมื่อ พ.ย. 2569) ก่อนตั้งให้ปิดเครื่อง ให้แน่ใจว่าตลาดปิดจริงและรู้ว่าออเดอร์ที่ค้างจะเป็นยังไงช่วงนั้น เรื่องนี้อธิบายไว้ในบท เทรดทองวันเสาร์อาทิตย์ได้ไหม

ปิดอัพเดทคอม: หยุดชั่วคราวได้ แต่ไม่ควรปิดถาวร

คนรัน EA ส่วนใหญ่ค้นวิธีปิดอัพเดทคอม เพราะเคยเจอเครื่องรีสตาร์ตเองกลางสัปดาห์ ทางที่ถูกคือไม่ปิดการอัปเดตถาวร เพราะอัปเดตความปลอดภัยสำคัญกับเครื่องที่ล็อกอินบัญชีเทรดค้างไว้ แต่ให้ควบคุมว่ามันจะเกิดเมื่อไหร่แทน

  1. หยุดอัปเดตชั่วคราว

    ใน Windows 11 ไปที่ Settings → Windows Update ที่หัวข้อ Pause updates กด Pick a date แล้วเลือกวันที่จะให้อัปเดตกลับมา หยุดได้ไม่เกิน 35 วันนับจากวันนี้ ระหว่างนั้นเครื่องจะไม่รีสตาร์ตเองเพื่อติดตั้งอัปเดต

  2. ตั้ง Active hours

    ไปที่ Settings → Windows Update → Advanced options แล้วเลือก Active hours ตั้งช่วงเวลาที่คุณใช้เครื่อง Windows จะพยายามเลี่ยงการรีสตาร์ตในช่วงนั้น

  3. นัดวันอัปเดตเอง

    เลือกวันที่ตลาดปิด เช่น วันเสาร์ กด Resume updates ให้ติดตั้งให้เสร็จ รีสตาร์ตเครื่อง แล้วเปิด MT5 เช็กว่า EA กลับมาครบก่อนตลาดเปิดสัปดาห์ใหม่

เมื่อการหยุดชั่วคราวหมดอายุ Windows จะกลับมาอัปเดตเองโดยอัตโนมัติ ถ้าไม่ได้ทำอะไร (ข้อมูลจาก Microsoft Support: หยุดการอัปเดตชั่วคราวใน Windows ตรวจเมื่อ พ.ย. 2569) จึงควรจดวันหมดเวลาไว้ในปฏิทิน ส่วน MT5 เองก็มีรุ่นใหม่ออกมาเป็นระยะ วิธีอัปเดตโปรแกรมโดยไม่ให้ EA ขาดช่วงอยู่ในบท อัปเดต MT5 ในคอมและ VPS

ให้ MT5 เปิดเองหลังคอมรีสตาร์ต

ถ้าเครื่องรีสตาร์ตเพราะอัปเดตหรือไฟดับแล้วกลับมา คุณอยากให้ MT5 เปิดขึ้นเองโดยไม่ต้องมีคนกด Windows มีโฟลเดอร์ Startup สำหรับเรื่องนี้

  1. เปิดโฟลเดอร์ Startup

    กด Windows + R พิมพ์ shell:startup แล้วกด Enter หน้าต่างโฟลเดอร์ของโปรแกรมที่เปิดตอนลงชื่อเข้าใช้จะขึ้นมา

  2. ใส่ทางลัดของ MT5

    คัดลอกไอคอน MT5 จากหน้าจอ Desktop แล้ววางลงในโฟลเดอร์นี้ ถ้ามี MT5 หลายชุด ใส่ทางลัดของทุกชุด

  3. ทดลองรีสตาร์ตในวันที่ตลาดปิด

    รีสตาร์ตเครื่องหนึ่งครั้ง ลงชื่อเข้าใช้ แล้วดูว่า MT5 เปิดเอง ล็อกอินบัญชี และกราฟพร้อม EA กลับมาครบหรือไม่

ข้อจำกัดที่ต้องรู้คือ โปรแกรมในโฟลเดอร์ Startup เปิดตอนผู้ใช้ลงชื่อเข้าใช้ Windows ถ้าเครื่องตั้งรหัสผ่านไว้และยังไม่มีใครลงชื่อเข้าใช้หลังรีสตาร์ต MT5 ก็ยังไม่เปิด และแม้ MT5 จะเปิดกราฟชุดเดิมกลับมาแล้ว คุณก็ยังควรเข้าไปดูปุ่ม Algo Trading กับไอคอน EA บนกราฟทุกครั้ง

เช็กลิสต์ก่อนปล่อยคอมรัน EA ข้ามคืน

  • สลีปและไฮเบอร์เนตตอนเสียบปลั๊กตั้งเป็น Never แล้ว
  • โน้ตบุ๊กเสียบสายชาร์จ และตั้งการพับจอเป็น Do nothing
  • Windows Update หยุดชั่วคราวหรือมี Active hours ครอบช่วงที่ตลาดเปิด
  • MT5 ล็อกอินแล้ว มุมขวาล่างไม่ขึ้น No connection
  • ปุ่ม Algo Trading เป็นสีเขียว และ EA บนทุกกราฟไม่เป็นไอคอนสีเทา
  • ปิดโปรแกรมอื่นที่ไม่จำเป็น และบอกคนในบ้านว่าอย่าปิดเครื่อง
  • แอป MT5 บนมือถือล็อกอินบัญชีเดียวกันไว้ สำหรับดูออเดอร์ตอนไม่อยู่หน้าเครื่อง

เมื่อไหร่ควรเลิกพึ่งคอมที่บ้าน

ตั้งค่าครบทุกข้อแล้ว คอมที่บ้านก็ยังแพ้เรื่องที่ควบคุมไม่ได้ คือไฟดับและเน็ตบ้านล่ม ถ้าเกิดตอน EA ถือออเดอร์อยู่ คุณต้องรู้ว่าออเดอร์จะเป็นยังไงและต้องเช็กอะไรเมื่อเครื่องกลับมา ซึ่งอธิบายไว้ในบท ไฟดับ เน็ตหลุด ระหว่าง EA เทรด

ถ้าเรื่องแบบนี้เกิดบ่อย หรือคุณเริ่มรัน EA ด้วยเงินจริงและอยากให้มันทำงานไม่ขาดช่วง การย้าย MT5 ไปไว้บน VPS มักคุ้มกว่า เปรียบเทียบค่าใช้จ่ายและข้อดีข้อเสียได้ในบท VPS คืออะไร ทำไมคนใช้ EA ถึงเช่า

คำถามที่พบบ่อยเรื่องปิดสลีปคอม

ล็อกหน้าจอด้วย Windows + L แล้ว EA ยังทำงานไหม?

ทำงาน การล็อกหน้าจอแค่บังคับให้ใส่รหัสก่อนใช้ต่อ โปรแกรมทั้งหมดรวมถึง MT5 ยังเปิดอยู่ ขอเพียงเครื่องไม่เข้าสลีปตามเวลาที่ตั้งไว้

ตั้งสลีปเป็น Never แล้ว แต่คอมยังหลับเอง?

เช็กว่าตั้งในคอลัมน์ตอนเสียบปลั๊ก ไม่ใช่ตอนใช้แบตเตอรี่ แล้วดูช่องไฮเบอร์เนตกับการพับจอด้วย ถ้ายังหลับ เปิด Power Options ใน Control Panel แล้วดูการตั้งค่าของแผนพลังงานที่ใช้อยู่ บางเครื่องมีโปรแกรมประหยัดไฟของผู้ผลิตที่ตั้งทับไว้

เปิดคอมทิ้งไว้ตลอดจะทำให้เครื่องเสียเร็วไหม?

สิ่งที่ทำให้เครื่องมีปัญหามักเป็นความร้อนและฝุ่นมากกว่าการเปิดนาน วางเครื่องในที่อากาศถ่ายเท ทำความสะอาดช่องลมเป็นระยะ และให้จอดับเองเมื่อไม่ได้ใช้

ปิดอัพเดท Windows ถาวรได้ไหม?

ในหน้าตั้งค่าปกติทำได้แค่หยุดชั่วคราว ไม่เกิน 35 วันต่อครั้ง และไม่แนะนำให้ปิดถาวร เพราะเครื่องที่ล็อกอินบัญชีเทรดค้างไว้ควรได้อัปเดตความปลอดภัย ให้นัดวันอัปเดตเองช่วงตลาดปิดแทน

คอมดับไปแล้วเปิดใหม่ EA กลับมาทำงานเองไหม?

ถ้าใส่ทางลัด MT5 ไว้ในโฟลเดอร์ Startup และมีคนลงชื่อเข้าใช้ Windows แล้ว MT5 จะเปิดเอง ส่วนใหญ่กราฟและ EA ชุดเดิมจะกลับมาด้วย แต่ต้องเข้าไปเช็กปุ่ม Algo Trading และออเดอร์ที่ค้างทุกครั้ง

สรุป: ปิดสลีปคอมแล้ว ต่อไปคือทำให้ EA ไม่พึ่งเครื่องที่บ้าน

การปิดสลีปคอมเป็นขั้นแรกที่ทุกคนที่รัน EA บนคอมต้องทำ ตามด้วยตั้งการพับจอ วางเวลาอัปเดต และให้ MT5 เปิดเองหลังรีสตาร์ต ครบสี่เรื่องนี้แล้ว คอมที่บ้านจะรัน EA ได้นิ่งพอสำหรับการซ้อมและการใช้งานช่วงแรก

เมื่อคุณพร้อมย้ายไป VPS คู่มือ ย้าย MT5 ขึ้น Windows VPS มีขั้นตอนพร้อมภาพทุกจุด ถ้าไม่อยากตั้งเอง แพ็กเกจ VIP ของ EA BULL ให้ทีมงานติดตั้งบนคอมหรือ VPS ของคุณ และเช็กค่าก่อนเริ่มรัน ส่วนแพ็กเกจ Pro คุณติดตั้งเองตามคู่มือบนเว็บ ทั้งสองแบบจ่ายครั้งเดียว และค่าเช่า VPS แยกต่างหาก ถ้าตั้งค่าตามบทนี้แล้วคอมยังหลับเอง ส่งภาพหน้าจอการตั้งค่ามาถามทีมงานได้

อ่านต่อ

  • คู่มือ VPS บน Windows สำหรับรัน EA
  • VPS คืออะไร: ทำไมคนใช้ EA ถึงเช่า VPS แทนเปิดคอมทิ้งไว้
  • ไฟดับ เน็ตหลุด ระหว่าง EA เทรด: ออเดอร์ค้างเป็นยังไง และต้องเช็กอะไร
  • เทรดทองวันเสาร์อาทิตย์ได้ไหม: ตลาดปิดแล้วออเดอร์และ EA เป็นยังไง
