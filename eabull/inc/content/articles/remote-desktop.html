Remote Desktop คือวิธีเข้าไปใช้คอม Windows อีกเครื่องผ่านอินเทอร์เน็ต คุณเห็นหน้าจอของเครื่องนั้นในหน้าต่างหนึ่ง และใช้เมาส์กับคีย์บอร์ดของคุณสั่งงานได้เหมือนนั่งอยู่หน้าเครื่อง คนใช้ EA ใช้มันเข้า Windows VPS เพื่อติดตั้ง MT5 เช็กว่า EA ยังทำงาน และแก้ปัญหา โดยที่โปรแกรมทั้งหมดยังทำงานอยู่บน VPS ไม่ได้ย้ายมาอยู่บนเครื่องของคุณ

สรุปสั้น

  • บนคอม Windows ใช้โปรแกรม Remote Desktop Connection ที่ติดมากับเครื่อง เปิดเร็ว ๆ ได้ด้วยคำสั่ง mstsc
  • บนมือถือและแท็บเล็ตใช้ Windows App ของ Microsoft ซึ่งมาแทนแอป Remote Desktop รุ่นเดิม
  • ปิดหน้าต่างด้วยกากบาทคือการตัดการเชื่อมต่อ MT5 บน VPS ทำงานต่อ ส่วน Sign out จะปิดโปรแกรมทั้งหมด
  • คีย์ลัดบางตัวในหน้าจอระยะไกลต่างจาก Windows ปกติ เช่น Ctrl + Alt + End ใช้แทน Ctrl + Alt + Del
  • ภาพกระตุกหรือค้าง ส่วนใหญ่แก้ได้ด้วยการลดความละเอียดและจำนวนสี หรือเลือกความเร็วการเชื่อมต่อให้ต่ำลง

บทนี้อยู่ในชุดเรื่องการให้ EA ทำงานตลอด 24 ชั่วโมง ถ้าคุณยังไม่ได้ตัดสินใจว่าจะรันบนคอมหรือ VPS ดูภาพรวมได้ในบท คู่มือรวมเรื่องรัน EA ส่วนบทนี้จะเน้นเครื่องมือที่ใช้เข้าไปดูแล VPS หลังจากเช่ามาแล้ว

Remote Desktop คืออะไร

Remote Desktop คือความสามารถของ Windows ที่ให้เครื่องหนึ่งควบคุมอีกเครื่องหนึ่งจากระยะไกล ใช้มาตรฐานการเชื่อมต่อที่ชื่อ RDP (Remote Desktop Protocol) ของ Microsoft ฝั่งที่ถูกควบคุมเรียกว่าเครื่องปลายทาง หรือ host ส่วนฝั่งที่คุณนั่งใช้เรียกว่าเครื่องลูก หรือ client

บนคอม Windows โปรแกรมฝั่ง client ชื่อ Remote Desktop Connection ติดมากับ Windows ทุกรุ่น ส่วนฝั่ง host ต้องเป็น Windows รุ่น Pro ขึ้นไปหรือ Windows Server เพราะ Windows รุ่น Home ใช้เข้าเครื่องอื่นได้ แต่เปิดให้เครื่องอื่นเข้ามาควบคุมไม่ได้ (ข้อมูลจาก Microsoft Learn: Enable Remote Desktop on your PC ตรวจเมื่อ พ.ย. 2569) Windows VPS ที่เช่ามาถูกตั้งให้เป็น host พร้อมใช้อยู่แล้ว คุณจึงแค่ต้องมีโปรแกรมฝั่ง client

สำหรับคนใช้ EA เรื่องที่ต้องเข้าใจที่สุดคือ Remote Desktop ไม่ได้ย้ายโปรแกรมมาไว้ที่เครื่องคุณ MT5 และ EA ยังทำงานบน VPS ตลอด สิ่งที่วิ่งไปมาบนอินเทอร์เน็ตมีแค่ภาพหน้าจอจาก VPS กับการกดเมาส์และคีย์บอร์ดจากเครื่องคุณ เมื่อเลิกดู VPS ก็ยังทำงานต่อเหมือนเดิม

ถ้ายังไม่ชัดว่า VPS คือเครื่องแบบไหน และทำไมคนใช้ EA ถึงเช่ามันแทนการเปิดคอมทิ้งไว้ อ่านพื้นฐานได้ในบท VPS คืออะไร

อะไรอยู่ที่เครื่องไหน เมื่อใช้ Remote Desktop

คนใช้ใหม่มักสับสนว่าไฟล์ที่เห็นในหน้าต่างอยู่ที่ไหน หรือถ้าปิดคอมแล้วจะเกิดอะไร ตารางนี้แยกให้เห็น

สิ่งที่เห็นในหน้าต่างอยู่ที่ถ้าปิดคอมของคุณ
หน้าจอ Windows เมนู Start ไอคอนVPSยังอยู่ครบ รอคุณกลับเข้าไป
โปรแกรม MT5 และ EA บนกราฟVPSทำงานต่อตามปกติ
ไฟล์ในโฟลเดอร์ของ VPSดิสก์ของ VPSไม่หาย
เมาส์ คีย์บอร์ด และหน้าจอที่ใช้ดูเครื่องของคุณแค่ดูไม่ได้ จนกว่าจะเชื่อมต่อใหม่
รหัสผ่านที่บันทึกไว้ในโปรแกรมเครื่องของคุณยังอยู่ ถ้าเครื่องนี้หาย คนที่ได้ไปอาจเข้า VPS ได้

Remote Desktop วิธีใช้ครั้งแรก

คำถามว่า Remote Desktop ทำยังไง คำตอบคือใช้ข้อมูลสามอย่างที่ผู้ให้บริการ VPS ส่งมา คือ IP ชื่อผู้ใช้ และรหัสผ่าน แล้วทำตามขั้นนี้บนคอม Windows ของคุณ

  1. เปิดโปรแกรม

    พิมพ์ Remote Desktop Connection ในช่องค้นหาของเมนู Start แล้วเปิดโปรแกรมที่ขึ้นมา หรือกดปุ่ม Windows + R พิมพ์ mstsc แล้วกด Enter

  2. ใส่ IP ของ VPS

    พิมพ์ IP ลงช่อง Computer ถ้าผู้ให้บริการให้หมายเลขพอร์ตมาด้วย ให้พิมพ์ต่อท้ายเป็น IP:พอร์ต

  3. ตั้งค่าก่อนต่อ (ถ้าต้องการ)

    กด Show Options เพื่อเปิดแท็บตั้งค่า ใส่ชื่อผู้ใช้ไว้ในช่อง User name ปรับขนาดจอในแท็บ Display หรือเลือกความเร็วการเชื่อมต่อในแท็บ Experience

  4. กด Connect แล้วใส่รหัสผ่าน

    ถ้าหน้าต่างขอรหัสแสดงชื่อผู้ใช้ของคอมคุณเอง ให้เลือกบัญชีอื่นแล้วพิมพ์ชื่อผู้ใช้กับรหัสผ่านของ VPS

  5. ยืนยันเครื่องในครั้งแรก

    ครั้งแรกจะมีหน้าต่างเตือนว่ายืนยันตัวตนของเครื่องปลายทางไม่ได้ ตรวจว่า IP ตรงกับ VPS ที่เช่าแล้วกด Yes

  6. ใช้งานในหน้าจอ VPS

    หน้าจอ Windows ของ VPS จะเปิดขึ้น ติดตั้งโปรแกรมหรือเปิด MT5 ได้ตามปกติ แถบด้านบนของหน้าต่างมีปุ่มย่อ ขยาย และปิด

ถ้าต้องการภาพหน้าจอประกอบทุกขั้น ตั้งแต่ช่อง Computer จนถึงการติดตั้ง MT5 บน VPS ดูได้ในคู่มือบนเว็บที่ลิงก์ไว้ท้ายบท

ปิดหน้าต่าง Sign out และ Shut down ต่างกันยังไง

นี่คือเรื่องที่ทำให้ EA หยุดโดยไม่ตั้งใจมากที่สุด เพราะปุ่มเหล่านี้ดูคล้ายกัน แต่ผลต่อ MT5 ต่างกันคนละเรื่อง

สิ่งที่กดเกิดอะไรขึ้นบน VPSMT5 และ EA
กากบาทบนแถบด้านบนของหน้าต่างตัดการเชื่อมต่อ เซสชันของคุณยังเปิดค้างไว้ทำงานต่อ
Disconnect ในเมนูของ VPS (บางรุ่นอยู่ใต้ปุ่ม Power)ตัดการเชื่อมต่อเหมือนกดกากบาททำงานต่อ
Sign out ในเมนู Start ของ VPSออกจากระบบ ปิดทุกโปรแกรมของผู้ใช้นั้นปิด EA หยุด
Restartรีสตาร์ตเครื่อง VPSหยุดจนกว่าคุณจะเข้าไปเปิด MT5 ใหม่
Shut downปิดเครื่อง VPSหยุด และอาจต้องเปิดเครื่องจากหน้าจัดการของผู้ให้บริการ

ติดนิสัยออกจาก VPS ด้วยกากบาททุกครั้ง แล้วเปิดแอป MT5 บนมือถือดูว่าบัญชียังมีความเคลื่อนไหวตามปกติ ถ้ามีคนอื่นใช้ VPS ร่วมด้วย บอกให้รู้เรื่องนี้ตั้งแต่แรก

Remote Desktop คีย์ลัดที่ควรรู้

ในหน้าจอระยะไกล คีย์ลัดบางชุดของ Windows ถูกเครื่องของคุณดักไว้ก่อน ไม่ส่งไปถึง VPS Microsoft จึงมีคีย์ลัดเฉพาะของ Remote Desktop ให้ใช้แทน ตารางนี้คัดตัวที่ใช้บ่อยเวลาดูแล MT5 (ข้อมูลจาก Microsoft Learn: Remote Desktop Services Shortcut Keys ตรวจเมื่อ พ.ย. 2569)

คีย์ลัดทำอะไรใช้ตอนไหน
Ctrl + Alt + Endเปิดหน้า Windows Security ของ VPS แทน Ctrl + Alt + Delเปิด Task Manager ของ VPS หรือเปลี่ยนรหัสผ่าน
Ctrl + Alt + Breakสลับระหว่างเต็มจอกับหน้าต่างอยากกลับมาใช้เครื่องตัวเองชั่วคราว
Ctrl + Alt + Homeเปิดแถบการเชื่อมต่อด้านบนหาปุ่มปิดหรือย่อตอนเต็มจอ
Alt + Page Up / Alt + Page Downสลับโปรแกรมใน VPS แทน Alt + Tabสลับระหว่าง MT5 หลายชุด
Alt + Homeเปิดเมนู Start ของ VPSเมื่อปุ่ม Windows ไปเปิดเมนูของเครื่องคุณแทน
Ctrl + Alt + เครื่องหมายบวกเก็บภาพหน้าจอ VPS ทั้งหน้าไว้ในคลิปบอร์ดแคปหน้าจอ MT5 ส่งให้คนช่วยดูปัญหา

โน้ตบุ๊กหลายรุ่นไม่มีปุ่ม Break คู่มือเดียวกันให้ใช้ Ctrl + Alt + Pause หรือคีย์ทดแทนตามคู่มือของเครื่องแทน และถ้าอยากให้คีย์ลัดของ Windows ปกติทำงานกับ VPS ตลอด ให้เข้า Show Options แท็บ Local Resources แล้วตั้ง Apply Windows key combinations เป็น On the remote computer

Remote Desktop มือถือ: เข้า VPS จากโทรศัพท์

Remote Desktop มือถือทำได้ด้วยแอป Windows App ของ Microsoft ซึ่งเป็นแอปเดียวกันทั้งบน Android iPhone และ iPad ใช้ข้อมูลเข้าเครื่องชุดเดียวกับบนคอม คือ IP ชื่อผู้ใช้ และรหัสผ่าน ไม่ต้องสมัครบัญชีกับ Microsoft เพื่อเข้าเครื่องแบบนี้

บนมือถือ หน้าจอเล็กและนิ้วแตะไม่แม่นเท่าเมาส์ จึงเหมาะกับงานสั้น ๆ เช่น ดูว่าปุ่ม Algo Trading ยังเขียว ดูแท็บ Experts หรือเปิด MT5 ใหม่หลัง VPS รีสตาร์ต ส่วนงานละเอียดอย่างตั้งค่า EA ทำบนคอมจะผิดพลาดน้อยกว่า ความต่างของแอปนี้กับ Remote Desktop บนคอม และวิธีตั้งค่าครั้งแรก อยู่ในบท Windows App คืออะไร

Remote Desktop ค้าง หรือ กระตุก: สาเหตุและวิธีแก้

อาการ Remote Desktop ค้าง หรือ Remote Desktop กระตุก ส่วนใหญ่เกิดจากฝั่งการเชื่อมต่อ ไม่ได้แปลว่า MT5 บน VPS มีปัญหา ตารางนี้ช่วยแยกสาเหตุ

อาการสาเหตุที่พบบ่อยลองแก้
ภาพขยับช้า เมาส์หน่วงเน็ตฝั่งคุณช้าหรือไม่เสถียรลดความละเอียดในแท็บ Display และเลือกสีให้น้อยลง
ภาพกระตุกเป็นช่วง ๆส่งภาพละเอียดเกินกว่าความเร็วเน็ตในแท็บ Experience เลือกความเร็วการเชื่อมต่อให้ต่ำลง และปิดภาพพื้นหลังกับเอฟเฟกต์
หน้าจอดำหลังเชื่อมต่อภาพที่โปรแกรมจำไว้ในเครื่องคุณมีปัญหาในแท็บ Experience เอาติ๊ก Persistent bitmap caching ออกแล้วต่อใหม่
หน้าต่างค้าง กดอะไรไม่ได้การเชื่อมต่อหลุดกลางทางปิดหน้าต่างแล้วเชื่อมต่อใหม่ MT5 บน VPS ยังทำงานอยู่
เชื่อมต่อแล้ว MT5 ค้างอยู่ข้างในตัว VPS ทำงานหนัก แรมหรือ CPU เต็มกด Ctrl + Alt + End เปิด Task Manager ของ VPS ดูว่าโปรแกรมไหนกินทรัพยากร

ถ้าแก้ฝั่งการเชื่อมต่อแล้วยังช้า และ Task Manager ของ VPS แสดงว่าแรมเกือบเต็ม ปัญหาอยู่ที่สเปกของเครื่อง ไม่ใช่ Remote Desktop วิธีคิดว่าเครื่องต้องใช้แรมเท่าไหร่ตามจำนวน MT5 ที่เปิด อยู่ในบท VPS รัน EA ได้กี่ตัว

ใช้ Remote Desktop ให้ปลอดภัย

คนที่เข้า VPS ได้คือคนที่คุม MT5 ของคุณได้ทั้งหมด ข้อมูลเข้าเครื่องชุดนี้จึงต้องดูแลให้ดีกว่ารหัสผ่านทั่วไป

  • ติ๊ก Remember me หรือบันทึกรหัสผ่าน เฉพาะบนคอมส่วนตัวที่ตั้งรหัสล็อกหน้าจอแล้ว
  • ถ้าเคยส่งรหัส VPS ให้ใครช่วยติดตั้ง ให้เปลี่ยนรหัสหลังงานเสร็จ ทำได้จากหน้า Windows Security ด้วย Ctrl + Alt + End
  • เช็ก IP ทุกครั้งที่หน้าต่างเตือนเรื่องใบรับรองขึ้นมาแบบไม่คาดคิด
  • ไม่เข้า VPS จากคอมสาธารณะหรือเครื่องของคนอื่น

นอกจากรหัส VPS แล้ว บัญชีเทรดเองก็ควรมีชั้นป้องกันเพิ่ม เพราะถ้ามีคนได้รหัสบัญชีไป เขาไม่จำเป็นต้องผ่าน VPS เลย วิธีเปิด OTP ให้บัญชีอยู่ในบท MT5 2FA กันคนอื่นเข้าบัญชีเทรด

คำถามที่พบบ่อยเรื่อง Remote Desktop

ปิดหน้าต่าง Remote Desktop แล้ว EA ยังทำงานไหม?

ทำงาน ถ้าปิดด้วยกากบาทบนแถบด้านบน เพราะเป็นการตัดการเชื่อมต่อ เซสชันบน VPS ยังเปิดอยู่ แต่ถ้ากด Sign out หรือ Shut down ใน VPS MT5 จะปิดและ EA หยุด

คอม Windows Home ใช้ Remote Desktop เข้า VPS ได้ไหม?

ได้ Windows Home ใช้เป็นฝั่งที่เข้าเครื่องอื่นได้ตามปกติ ข้อจำกัดของรุ่น Home คือเปิดให้คนอื่นเข้ามาควบคุมตัวมันไม่ได้ ซึ่งไม่เกี่ยวกับการเข้า VPS

คัดลอกไฟล์ EA จากคอมไปไว้ใน VPS ยังไง?

วิธีที่ง่ายที่สุดคือคัดลอกไฟล์ในเครื่องคุณ แล้วไปวางในโฟลเดอร์ของ VPS ผ่านหน้าต่าง Remote Desktop ซึ่งใช้ได้เมื่อเปิด Clipboard ไว้ในแท็บ Local Resources หรือจะดาวน์โหลดไฟล์จากในเบราว์เซอร์ของ VPS โดยตรงก็ได้

เข้า VPS แล้วจอดำ ทำยังไง?

ปิดหน้าต่างแล้วเชื่อมต่อใหม่ก่อน ถ้ายังดำ ให้เข้า Show Options แท็บ Experience เอาติ๊ก Persistent bitmap caching ออกแล้วลองอีกครั้ง ถ้ายังไม่หาย ให้ติดต่อผู้ให้บริการ VPS เพราะเครื่องปลายทางอาจมีปัญหา

ลืมรหัสผ่าน VPS ต้องทำยังไง?

ติดต่อผู้ให้บริการ VPS หรือใช้หน้าจัดการเครื่องของผู้ให้บริการเพื่อตั้งรหัสใหม่ หลังได้รหัสใหม่แล้ว อย่าลืมแก้รหัสที่บันทึกไว้ทั้งในคอมและในแอปบนมือถือ

สรุป: Remote Desktop คือประตูเข้า VPS ที่ต้องใช้ให้เป็น

สรุปสั้น ๆ Remote Desktop คือเครื่องมือที่ทำให้คุณดูแล MT5 บน VPS ได้จากทุกที่ จำไว้สามเรื่องก็พอ เข้าให้ถูกเครื่อง ออกด้วยการตัดการเชื่อมต่อ และเก็บรหัสผ่านไว้กับตัว เมื่อคุ้นแล้ว การเข้าไปเช็ก EA จะใช้เวลาไม่กี่นาที

ถ้าคุณเช่า VPS ไว้แล้วและอยากย้าย MT5 ขึ้นไป คู่มือ เชื่อมต่อ Windows VPS ด้วย Remote Desktop มีภาพหน้าจอให้ทำตามทุกขั้น ถ้าไม่อยากตั้งเอง แพ็กเกจ VIP ของ EA BULL ให้ทีมงานติดตั้งบนคอมหรือ VPS ของคุณ และเช็กค่าก่อนเริ่มรัน ส่วนค่าเช่า VPS คุณจ่ายกับผู้ให้บริการเอง ถ้าเชื่อมต่อไม่ผ่านหรือไม่แน่ใจว่าติดตรงไหน ส่งภาพหน้าจอมาถามทีมงานได้

อ่านต่อ

  • คู่มือ VPS บน Windows ทีละขั้น
  • Windows App คืออะไร: แอปเข้า VPS จากมือถือที่มาแทน Remote Desktop
  • เข้า VPS จาก Android ด้วย Windows App
  • VPS รัน EA ได้กี่ตัว: คิดจาก CPU RAM และจำนวน MT5
