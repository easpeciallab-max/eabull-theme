ตั้งค่า EA ใน MT5 คือการใส่ค่าในหน้าต่าง Properties ที่เด้งขึ้นมาตอนลาก EA ลงกราฟ ส่วนที่สำคัญที่สุดคือแท็บ Inputs ซึ่งเป็นรายการค่าที่ผู้พัฒนาเปิดให้คุณปรับ เช่น ขนาดไม้ ระยะตัดขาดทุน และช่วงเวลาเทรด อ่านชื่อและหน่วยของแต่ละช่องให้ออกก่อน แล้วแก้เฉพาะค่าที่คู่มือของ EA บอกว่าแก้ได้

สรุปสั้น

  • หน้าต่างค่าของ EA มีแท็บ Common และ Inputs เสมอ ส่วนแท็บ Dependencies ขึ้นเฉพาะ EA ที่เรียกใช้ไฟล์ภายนอก
  • ช่อง Inputs แต่ละตัวมีชนิดของมัน เช่น ตัวเลข ทศนิยม เปิดปิด หรือรายการให้เลือก ใส่ผิดชนิดหรือผิดหน่วยคือที่มาของปัญหาส่วนใหญ่
  • ค่าที่มักต้องปรับให้เข้ากับบัญชีคือขนาดไม้ ชื่อสัญลักษณ์ และเวลา ส่วนค่าที่เป็นกฎของระบบควรยึดตามคู่มือ
  • กด Save เก็บชุดค่าเป็นไฟล์ไว้ทุกครั้งก่อนแก้ จะย้อนกลับได้เสมอ
  • เปลี่ยนค่าแล้วควรลองใน Strategy Tester ก่อนใช้กับบัญชีจริง

บทนี้อยู่ในชุดทดสอบและปรับค่า EA ถ้าคุณยังไม่เคยทดสอบระบบกับข้อมูลย้อนหลัง อ่าน Backtest คืออะไร และใช้ตรวจค่ายังไง ประกอบไปด้วย เพราะทุกค่าที่แก้ในบทนี้ควรผ่านการทดสอบก่อนเสมอ

ตั้งค่า EA MT5 อยู่ตรงไหน

หน้าต่างค่าของ EA เปิดได้สองจังหวะ จังหวะแรกคือตอนติด EA ครั้งแรก ลากชื่อ EA จากหน้าต่าง Navigator ไปวางบนกราฟ หรือดับเบิลคลิกชื่อ EA หน้าต่าง Properties จะเด้งขึ้นมา กด OK แล้ว EA จะเริ่มทำงาน ชื่อกับไอคอนของมันจะขึ้นที่มุมขวาบนของกราฟ

จังหวะที่สองคือตอนที่ EA ทำงานอยู่แล้วและคุณอยากแก้ค่า คลิกขวาบนกราฟ เลือก Expert List เลือกชื่อ EA แล้วกด Properties หน้าต่างเดิมจะเปิดขึ้นพร้อมค่าที่ใช้อยู่ กราฟหนึ่งรัน EA ได้ทีละตัว ถ้าลาก EA ตัวใหม่ลงกราฟเดิม ตัวเก่าจะถูกถอดออก

แท็บมีอะไรอยู่ควรทำอะไร
Commonชื่อ รุ่น และรายละเอียดของ EA พร้อมช่องอนุญาตให้ EA เทรดติ๊ก Allow Algo Trading ไม่อย่างนั้น EA จะไม่ส่งคำสั่งเลย
Inputsค่าทั้งหมดที่ผู้พัฒนาเปิดให้ปรับอ่านทีละช่อง แก้ตามคู่มือ แล้วกด Save เก็บไว้
Dependenciesรายการไฟล์ภายนอกที่ EA เรียกใช้ และช่อง Allow DLL importsเปิดเฉพาะเมื่อรู้ที่มาของ EA และผู้พัฒนาบอกว่าจำเป็น

แท็บ Dependencies ไม่ได้ขึ้นกับ EA ทุกตัว มันโผล่เฉพาะเมื่อ EA ดึงฟังก์ชันจากไฟล์ DLL หรือไฟล์ EX5 อื่น คู่มือของ MetaTrader เองเตือนว่าอย่าเปิด DLL ถ้าไม่แน่ใจว่าโปรแกรมนั้นปลอดภัย รายละเอียดทุกแท็บดูได้ที่ คู่มือ Expert Advisors and Custom Indicators

แท็บ Common: สวิตช์ที่ทำให้ EA เทรดได้

คนจำนวนมากใส่ค่าใน Inputs ครบทุกช่อง แต่ EA ไม่เปิดออเดอร์สักไม้ เพราะลืมสวิตช์ในแท็บนี้ การให้ EA เทรดได้จริงต้องผ่านสองชั้น ชั้นแรกคือช่อง Allow Algo Trading ในแท็บ Common ของ EA ตัวนั้น ชั้นที่สองคือปุ่ม Algo Trading บนแถบเครื่องมือของ MT5 ซึ่งคุมทุก EA ในโปรแกรมพร้อมกัน ถ้าปุ่มใหญ่ปิดอยู่ ต่อให้ติ๊กช่องของ EA ไว้ ก็ไม่มี EA ตัวไหนเทรดได้

วิธีเช็กเร็วที่สุดคือดูไอคอนมุมขวาบนของกราฟ ถ้าไอคอนบอกว่าปิดการเทรดอัตโนมัติอยู่ ให้ไล่เปิดทั้งสองชั้น ขั้นตอนเปิดใช้ครั้งแรกแบบละเอียดอยู่ในบท เปิดให้ EA เทรดบน MT5 ครั้งแรก

ค่า Input EA แต่ละชนิดอ่านยังไง

แท็บ Inputs เป็นตารางสองคอลัมน์ ซ้ายคือชื่อค่า ขวาคือค่าที่ใช้อยู่ ดับเบิลคลิกที่ช่องค่าเพื่อแก้ ชื่อที่เห็นอาจไม่ใช่ชื่อตัวแปรในโค้ด เพราะผู้พัฒนาตั้งคำอธิบายให้แสดงแทนได้ และจัดค่าเป็นกลุ่มที่มีหัวข้อคั่นได้ด้วย ค่าเหล่านี้เปลี่ยนได้จากหน้าต่างนี้เท่านั้น ตัว EA เองแก้ค่าที่คุณใส่ไม่ได้

ชนิดของค่าหน้าตาในช่องตัวอย่าง (สมมติ)จุดที่พลาดบ่อย
เปิดหรือปิดเลือก true หรือ falseใช้ Trailing Stop = trueเปิดฟังก์ชันที่ไม่เข้าใจโดยไม่ได้ทดสอบ
จำนวนเต็มตัวเลขไม่มีทศนิยมStop Loss = 500ไม่รู้ว่าหน่วยเป็นจุด (point) หรือเป็นเงิน
ทศนิยมตัวเลขมีจุดLot = 0.01ใส่ขนาดไม้ที่ไม่ตรงขั้นที่โบรกเกอร์รับ
รายการให้เลือกกดแล้วมีตัวเลือกลงมาวิธีคิดขนาดไม้ = Fixedเลือกโหมดโดยไม่ได้อ่านว่าแต่ละโหมดทำอะไร
ข้อความพิมพ์ตัวอักษรเองคอมเมนต์ออเดอร์พิมพ์ชื่อสัญลักษณ์ผิดแม้แค่ตัวเดียว
วันเวลาหรือสีเลือกวันเวลาหรือสีจากตัวเลือกสีเส้นที่ EA วาดบนกราฟมักไม่มีผลกับการเทรด ไม่ต้องกังวลมาก

เรื่องหน่วยสำคัญที่สุด EA ส่วนใหญ่ใช้หน่วยจุดหรือ point ซึ่งเท่ากับการขยับของทศนิยมตัวสุดท้ายของราคา ถ้าโบรกเกอร์แสดงราคาทองสองตำแหน่ง 1 point คือ 0.01 ดอลลาร์ ค่า 500 points จึงเท่ากับราคาขยับ 5.00 ดอลลาร์ แต่ถ้าแสดงสามตำแหน่ง 500 points จะเหลือแค่ 0.50 ดอลลาร์ ระยะต่างกันสิบเท่าจากค่าเดียวกัน ดูจำนวนทศนิยมได้ใน Specification ของสัญลักษณ์ ความหมายของชนิดค่าในฝั่งผู้เขียนโปรแกรมอ่านได้ที่ MQL5 Reference: Input Variables

กลุ่มค่าที่ EA ส่วนใหญ่มี

EA แต่ละตัวตั้งชื่อค่าไม่เหมือนกัน แต่ถ้าดูหลายตัวจะเห็นว่าค่ามักจับกลุ่มคล้ายกัน ตารางนี้เป็นตัวอย่างทั่วไปเพื่อช่วยให้คุณอ่านแท็บ Inputs ได้เร็วขึ้น ไม่ใช่ค่าของ EA ตัวใดตัวหนึ่ง ชื่อและความหมายจริงต้องดูจากคู่มือของ EA ที่คุณใช้

กลุ่มชื่อที่มักเห็นถ้าตั้งผิดจะเกิดอะไร
ขนาดไม้Lot, Fixed Lot, Riskไม้ใหญ่เกินทุน พอร์ตลดลงเร็วกว่าที่ตั้งใจ
ระยะตัดขาดทุนและทำกำไรStop Loss, Take Profitระยะคลาดไปมากเพราะหน่วยหรือจำนวนทศนิยมต่างกัน
ตัวแยกออเดอร์Magic NumberEA สองตัวใช้เลขเดียวกัน แล้วไปจัดการออเดอร์ของกันและกัน
ต้นทุนการเข้าไม้Max Spread, Slippageเข้าไม้ตอน Spread กว้าง หรือไม่ยอมเข้าไม้เลย
ช่วงเวลาเทรดStart Hour, End Hourใส่เป็นเวลาไทย ทั้งที่ EA อ่านเวลาเซิร์ฟเวอร์
ตัวกรองข่าวNews Filterหยุดเทรดผิดช่วง หรือคิดว่ามีตัวกรองทั้งที่ปิดอยู่
ชื่อสัญลักษณ์Symbol, SuffixEA หาสัญลักษณ์ไม่เจอ เพราะโบรกเกอร์มีตัวอักษรต่อท้ายชื่อ

สองกลุ่มที่ทำให้ผลต่างกันมากที่สุดคือขนาดไม้กับต้นทุน ถ้า EA ให้เลือกว่าจะใช้ไม้คงที่หรือให้คำนวณจากทุน ข้อดีข้อเสียของแต่ละแบบอธิบายไว้ในบท Fixed Lot กับ Lot อัตโนมัติ ส่วนค่ากันเข้าไม้ตอน Spread กว้าง ดูหลักการได้ใน Max Spread คืออะไร และถ้า EA มีตัวกรองข่าว บท News Filter EA ทำงานยังไง ช่วยให้รู้ว่าควรถามผู้พัฒนาเรื่องอะไร

วิธีตั้งค่า EA: ช่องไหนแก้ได้ ช่องไหนควรปล่อยไว้

หลักง่าย ๆ คือแยกค่าออกเป็นสองแบบ แบบแรกคือค่าที่ผูกกับบัญชีของคุณ เช่น ทุน ชื่อสัญลักษณ์ และเวลาเซิร์ฟเวอร์ ค่ากลุ่มนี้คุณต้องปรับให้ตรงกับบัญชีจริง แบบที่สองคือค่าที่เป็นกฎของระบบ เช่น เงื่อนไขเข้าไม้ ค่าของ Indicator และระยะที่ระบบใช้ตัดสินใจ ค่ากลุ่มนี้ผู้พัฒนาทดสอบมาแล้ว ควรยึดตามคู่มือ

  • ขนาดไม้หรือระดับความเสี่ยงต่อไม้ ให้เหมาะกับทุนของคุณ
  • ชื่อสัญลักษณ์และตัวอักษรต่อท้าย ให้ตรงกับที่โบรกเกอร์ใช้
  • ช่วงเวลาเทรด ให้แปลงเป็นเวลาเซิร์ฟเวอร์ของโบรกเกอร์
  • Magic Number ให้ไม่ซ้ำกันเมื่อรัน EA หลายตัวในบัญชีเดียว
  • ค่าเงื่อนไขเข้าไม้และค่าของ Indicator ที่ผู้พัฒนาไม่ได้บอกให้ปรับ
  • ปิด Stop Loss หรือขยายระยะตัดขาดทุนเพราะไม่อยากเห็นออเดอร์โดนตัด
  • เปลี่ยน Magic Number ระหว่างที่ยังมีออเดอร์ค้าง เพราะ EA หลายตัวใช้เลขนี้หาออเดอร์ของตัวเอง ถ้าเปลี่ยน มันอาจมองไม่เห็นออเดอร์เดิม
  • แก้หลายค่าพร้อมกันในครั้งเดียว จนไม่รู้ว่าผลที่เปลี่ยนมาจากค่าไหน

ถ้าอยากรู้ว่าค่าที่เป็นกฎของระบบควรปรับหรือไม่ วิธีที่ถูกคือทดสอบอย่างเป็นระบบ ไม่ใช่เดา บท Optimize EA MT5 อธิบายวิธีให้ Strategy Tester ลองค่าหลายชุดโดยไม่หลอกตัวเอง

บันทึกและโหลดชุดค่าด้วยไฟล์ .set

ปุ่มสามปุ่มด้านขวาของแท็บ Inputs ช่วยให้การแก้ค่าไม่น่ากลัว ใช้ให้เป็นนิสัยจะย้อนกลับได้ทุกครั้งที่แก้แล้วไม่ดี

  1. กด Save ก่อนแก้อะไร

    ตั้งชื่อไฟล์ให้บอกที่มา เช่น ชื่อ EA ตามด้วยวันที่ ไฟล์ชุดค่าจะถูกเก็บในโฟลเดอร์ Presets ของ MT5

  2. แก้ทีละค่า

    ดับเบิลคลิกช่องค่า ใส่ค่าใหม่ แล้วจดไว้ว่าแก้อะไรจากเท่าไหร่เป็นเท่าไหร่

  3. กด OK ให้ค่าใหม่มีผล

    ถ้า EA ทำงานอยู่ มันจะเริ่มต้นใหม่ด้วยค่าชุดใหม่ทันทีที่กด OK ดูข้อความในแท็บ Experts ว่าไม่มีข้อผิดพลาด

  4. ใช้ Load เมื่ออยากย้อนกลับ

    กด Load แล้วเลือกไฟล์ที่บันทึกไว้ ค่าทุกช่องจะกลับมาเหมือนเดิม ส่วนปุ่ม Reset จะคืนค่าเริ่มต้นที่ผู้พัฒนาใส่มากับ EA

ไฟล์ .set ยังใช้ได้กับ Strategy Tester ด้วย แท็บ Inputs ของ Tester มีปุ่มบันทึกและโหลดแบบเดียวกัน คุณจึงทดสอบด้วยชุดค่าเดียวกับที่จะรันจริงได้พอดี

การตั้งค่า EA Forex ใช้กับทองได้ไหม

คำตอบสั้นคือไม่ควรยกมาใช้ตรง ๆ การตั้งค่า EA Forex ที่ทำมาให้คู่เงินอย่าง EURUSD มักคิดระยะเป็นจุดที่เหมาะกับคู่เงินนั้น แต่ทองขยับเป็นดอลลาร์ต่อวันได้กว้างกว่ามาก ขนาดสัญญาก็ต่างกัน ค่า Stop Loss 300 จุดที่พอดีกับคู่เงิน อาจแคบจนโดนตัดบ่อยเมื่อใช้กับทอง หรือในทางกลับกัน ขนาดไม้ที่เคยใช้กับคู่เงินอาจทำให้ความเสี่ยงต่อไม้ในทองสูงกว่าที่คิดหลายเท่า

ถ้า EA ทำมาให้ใช้ได้หลายสัญลักษณ์ ผู้พัฒนาควรมีชุดค่าแยกให้แต่ละตัว ถ้าไม่มี ให้ถามก่อน อย่าใช้ชุดของสัญลักษณ์หนึ่งกับอีกสัญลักษณ์โดยไม่ทดสอบ

เช็กลิสต์ตั้งค่า EA ก่อนรัน

ก่อนกด OK ครั้งสุดท้าย ไล่เช็กรายการนี้ ใช้เวลาไม่ถึงห้านาที แต่กันความผิดพลาดที่แพงที่สุดได้เกือบหมด

  • ติด EA บนกราฟสัญลักษณ์และ Timeframe ที่คู่มือกำหนด
  • สวิตช์อนุญาตให้เทรดเปิดครบทั้งสองชั้น คือช่องของ EA และปุ่มใหญ่ด้านบนของโปรแกรม
  • ขนาดไม้ตรงกับทุนและความเสี่ยงที่คุณรับได้
  • รู้หน่วยของทุกค่าที่เป็นระยะ และเช็กจำนวนทศนิยมของสัญลักษณ์แล้ว
  • เวลาเทรดคิดเป็นเวลาเซิร์ฟเวอร์ ไม่ใช่เวลาไทย
  • บันทึกชุดค่าเป็นไฟล์ .set แล้ว และเคยทดสอบชุดนี้ใน Strategy Tester

แก้ค่าตอน EA มีออเดอร์ค้างอยู่ได้ไหม?

ได้ในทางเทคนิค เมื่อกด OK EA จะเริ่มต้นใหม่ด้วยค่าใหม่ แต่ผลกับออเดอร์ที่ค้างอยู่ขึ้นกับวิธีเขียนของ EA แต่ละตัว ถ้าไม่แน่ใจ ให้ถามผู้พัฒนาก่อน และอย่าเปลี่ยนค่าที่ EA ใช้หาออเดอร์ของตัวเอง เช่น Magic Number

ชื่อค่าในแท็บ Inputs เป็นภาษาอังกฤษ อ่านไม่เข้าใจ ทำยังไง?

เริ่มจากคู่มือของ EA ซึ่งควรอธิบายทุกช่อง ถ้าไม่มีคู่มือหรือคู่มือไม่ครบ ให้ถามผู้ขายทีละช่อง ค่าที่ยังไม่รู้ความหมายให้ปล่อยไว้ตามค่าเดิม อย่าเดา

ตั้งค่าแล้ว แต่ EA ไม่เปิดออเดอร์เลย เกิดจากอะไร?

สาเหตุที่พบบ่อยคือยังไม่เปิดสิทธิ์ให้ EA เทรด ชื่อสัญลักษณ์ไม่ตรง ค่า Max Spread ต่ำเกินจนไม่เคยถึงเงื่อนไข หรืออยู่นอกช่วงเวลาที่ตั้งให้เทรด ดูข้อความในแท็บ Experts และ Journal เพื่อหาเบาะแส

ย้าย EA ไปคอมหรือ VPS อีกเครื่อง ต้องตั้งใหม่หมดไหม?

ไม่ต้อง คัดลอกไฟล์ .set ที่บันทึกไว้ไปที่เครื่องใหม่ แล้วกด Load ในแท็บ Inputs ค่าทุกช่องจะกลับมาครบ แต่ยังต้องเช็กสวิตช์ในแท็บ Common และปุ่ม Algo Trading ของเครื่องใหม่อีกครั้ง

ควรเปลี่ยนค่าบ่อยแค่ไหน?

ยิ่งน้อยยิ่งดี การแก้ค่าทุกครั้งที่ขาดทุนทำให้ระบบไม่เคยได้ทำงานตามกฎของมันจริง ๆ เปลี่ยนเมื่อมีเหตุผลชัด เช่น ทุนเปลี่ยน ย้ายโบรกเกอร์ หรือผู้พัฒนาออกรุ่นใหม่ และทดสอบก่อนทุกครั้ง

สรุป: ตั้งให้ตรงคู่มือ แล้วค่อยทดสอบ

การตั้งค่าที่ดีไม่ได้มาจากการหาตัวเลขวิเศษ แต่มาจากการอ่านทุกช่องให้เข้าใจ ปรับเฉพาะค่าที่ผูกกับบัญชีของคุณ และทดสอบก่อนใช้จริง ถ้าคุณใช้ EA BULL ขั้นตอนตั้งแต่วางไฟล์จนติด EA ลงกราฟอยู่ใน คู่มือติดตั้ง EA บน MT5 ทีละขั้น สำหรับแพ็กเกจ Pro ที่ลงเอง ส่วนแพ็กเกจ VIP ทีมงานติดตั้งให้บนคอมหรือ VPS และเช็กค่าก่อนเริ่มรัน ถ้ามีช่องไหนที่ไม่แน่ใจ ถามทีมงานได้ทาง LINE

อ่านต่อ

  • Backtest คืออะไร: ทดสอบระบบเทรดย้อนหลังให้เป็นก่อนใช้เงินจริง
  • Optimize EA MT5: หาค่าที่เหมาะโดยไม่หลอกตัวเอง
  • Fixed Lot กับ Lot อัตโนมัติ: EA ควรออกไม้แบบไหน
  • วิธีใช้บอทเทรด: เปิดให้ EA เทรดบน MT5 ครั้งแรกทีละขั้น
