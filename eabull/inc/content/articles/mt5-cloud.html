MT5 Cloud เป็นคำที่คนใช้เรียกบริการสองอย่างในโปรแกรม MetaTrader 5 ซึ่งทำงานคนละเรื่อง อย่างแรกคือ Virtual Hosting ที่เช่าเครื่องเสมือนให้ EA ทำงานแทนคอมของคุณตลอด 24 ชั่วโมงและเทรดบัญชีจริง อย่างที่สองคือ MQL5 Cloud Network ที่รวมพลังคอมพิวเตอร์ทั่วโลกไว้ช่วยคำนวณตอนทดสอบหรือ Optimize EA ใน Strategy Tester โดยไม่ได้แตะบัญชีเทรดเลย

สรุปสั้น

  • Virtual Hosting เปิดจากหน้าต่าง Navigator คลิกขวาที่บัญชีเทรดแล้วเลือก Register a Virtual Server และดูแลต่อในหน้าต่าง Toolbox ส่วน VPS
  • MQL5 Cloud Network อยู่ใน Strategy Tester แท็บ Agents ใช้เฉพาะงานทดสอบและ Optimize ไม่ได้เทรดจริง
  • ทั้งสองบริการต้องมีบัญชี MQL5.community และเป็นบริการที่มีค่าใช้จ่าย คิดเงินคนละแบบ
  • เครื่องของ Virtual Hosting ไม่มีหน้าจอให้ใช้ ห้ามเรียก DLL และย้ายสคริปต์ไปไม่ได้ EA บางตัวจึงใช้กับบริการนี้ไม่ได้
  • ข้อความว่าโหมด Cloud Network ปิดอยู่เกี่ยวกับงานทดสอบเท่านั้น ไม่ได้แปลว่า EA บนกราฟหยุด

บทนี้อยู่ในชุดเรื่องการให้ EA ทำงานตลอด 24 ชั่วโมง Virtual Hosting เป็นหนึ่งใน ทางเลือกของการรัน EA ที่เราสรุปไว้ในบทหลัก ส่วนบทนี้จะแยกให้เห็นว่าบริการที่ชื่อคล้ายคลาวด์ทั้งสองตัวทำอะไร อยู่ตรงไหนในโปรแกรม และมีเงื่อนไขอะไรที่ควรรู้ก่อนใช้ เราไม่ได้แนะนำให้ใช้ตัวไหนเป็นพิเศษ

MT5 Cloud Server: Virtual Hosting ทำงานยังไง

บางคนเรียก Virtual Hosting ว่า MT5 Cloud Server หรือ MT5 VPS ตามคู่มือ MetaTrader 5 บริการนี้เช่าให้กับบัญชีเทรดบัญชีหนึ่ง เมื่อคุณสั่งลงทะเบียนจาก Navigator ระบบจะเลือกเครื่องที่อยู่ใกล้เซิร์ฟเวอร์ของโบรกเกอร์ให้เอง และแสดงค่าหน่วงของเครือข่ายเทียบระหว่างเครื่องเสมือนกับคอมของคุณให้ดูก่อนจ่ายเงิน การชำระเงินทำผ่านบัญชี MQL5.community ที่ต้องใส่ไว้ใน Tools → Options → Community

หลังเช่าแล้ว คุณไม่ได้เข้าไปใช้เครื่องนั้นตรง ๆ แต่ใช้วิธีที่คู่มือเรียกว่า Migration คือคัดลอกสภาพแวดล้อมจาก MT5 บนคอมของคุณขึ้นไป ทั้งกราฟ EA Indicator ค่า Inputs และการตั้งค่าบางส่วน การคัดลอกเป็นทางเดียวเสมอ จากเครื่องคุณขึ้นไปยังเครื่องเสมือน ไม่มีการดึงกลับ ถ้าคุณแก้อะไรในเครื่องตัวเอง ต้องสั่งย้ายใหม่ ค่าบนเครื่องเสมือนจึงจะเปลี่ยนตาม

ก่อนย้าย EA ขึ้น Virtual Hosting ต้องรู้อะไร

คู่มือเรื่อง Migration มีเงื่อนไขหลายข้อที่ทำให้ EA บางตัวทำงานบนเครื่องเสมือนไม่เหมือนบนคอม (ข้อมูลจาก คู่มือ MetaTrader 5: Virtual Hosting Migration ตรวจเมื่อ พ.ย. 2569) ข้อที่คนใช้ EA ควรรู้มีดังนี้

  • การเรียก DLL ถูกห้ามทั้งหมด EA ที่ต้องใช้ไฟล์ DLL จะทำงานไม่ได้
  • สคริปต์ย้ายขึ้นไปไม่ได้ แม้จะรันค้างอยู่บนกราฟตอนสั่งย้าย
  • กราฟที่ไม่มี EA ถูกข้าม Indicator ที่วางไว้เฉย ๆ บนกราฟเปล่าจะไม่ถูกย้ายตามไป
  • EA ที่ส่งข้อมูลออกไปเว็บไซต์ภายนอกด้วย WebRequest ต้องใส่รายชื่อเว็บที่อนุญาตไว้ในแท็บ Expert Advisors ก่อนย้าย
  • บนเครื่องเสมือน การเทรดอัตโนมัติเปิดอยู่เสมอ EA ทุกตัวที่ย้ายขึ้นไปเทรดได้ทันที แม้บนคอมคุณจะปิดปุ่มไว้
  • เมื่อย้าย EA สำเร็จ การเทรดอัตโนมัติบนคอมของคุณถูกปิดให้เอง เพื่อกันไม่ให้สองเครื่องเทรดบัญชีเดียวกันด้วย EA ตัวเดียวกัน

สองข้อสุดท้ายสำคัญมาก ถ้าวันหนึ่งคุณเปิด MT5 บนคอมแล้วเห็นปุ่ม Algo Trading ไม่เป็นสีเขียว อาจไม่ได้แปลว่ามีอะไรเสีย แต่เป็นเพราะ EA ถูกย้ายไปทำงานบนเครื่องเสมือนแล้ว อย่ากดเปิดปุ่มบนคอมซ้ำโดยไม่คิด เพราะ EA จะทำงานพร้อมกันสองที่ ส่วนอาการ EA หยุดที่เกิดจากสาเหตุอื่น ดูวิธีไล่เช็กได้ในบท EA บน MT5 ไม่ทำงาน ต้องดูตรงไหน

เรื่องรอบการเช่าก็ต้องดูเช่นกัน คู่มือระบุว่าถ้าหมดอายุ ข้อมูลบนเครื่องเสมือนจะถูกลบทั้งหมด และต้องตั้งใหม่ตั้งแต่ต้น ระบบจึงมีตัวเลือกต่ออายุอัตโนมัติ ถ้ายกเลิกเอง ข้อมูลก็ถูกลบเช่นกัน

MT5 Cloud VPS ต่างจาก Windows VPS ที่เช่าเองยังไง

คนที่ค้นคำว่า MT5 Cloud VPS ส่วนใหญ่กำลังเทียบระหว่าง Virtual Hosting ในเมนูของ MT5 กับ Windows VPS ที่เช่าจากผู้ให้บริการแล้วเข้าไปใช้หน้าจอเอง ทั้งสองแบบทำให้ EA ทำงานได้โดยไม่ต้องเปิดคอมที่บ้าน แต่วิธีใช้และข้อจำกัดต่างกันมาก

แก้ค่า EAแก้บนคอมคุณ แล้วสั่งย้ายขึ้นไปใหม่แก้บนกราฟใน VPS ได้โดยตรง

ไม่มีแบบไหนดีกว่าในทุกกรณี Virtual Hosting ตั้งง่ายสำหรับคนที่ใช้บัญชีเดียวและ EA ไม่ต้องพึ่งไฟล์ภายนอก ส่วน Windows VPS ยืดหยุ่นกว่าสำหรับคนที่อยากเห็นหน้าจอ ดูแลหลายบัญชี หรือใช้ EA ที่ต้องการสิ่งที่เครื่องเสมือนห้าม ถ้ายังไม่คุ้นกับ VPS แบบทั่วไป อ่านพื้นฐานได้ในบท VPS คืออะไร และเช่าแล้วได้อะไร และถ้าจะรันหลายบัญชีในเครื่องเดียว บท คิดสเปก VPS ตามจำนวน MT5 ช่วยประเมินได้

MQL5 Cloud Network คืออะไร และใช้ตอนไหน

MQL5 Cloud Network คือเครือข่ายที่รวม Agent จากคอมพิวเตอร์จำนวนมากทั่วโลกไว้ด้วยกัน Agent คือโปรแกรมย่อยที่รับงานคำนวณรอบทดสอบไปทำ เวลาคุณ Optimize EA ด้วยการลองค่าหลายพันชุด Strategy Tester จะแบ่งงานส่งให้ Agent ช่วยกันคิด แล้วรวมผลกลับมาให้ เครือข่ายนี้มาจากคอมของคนที่ติดตั้งโปรแกรม MetaTester แล้วเปิดให้ใช้พลังเครื่องที่ว่างอยู่

ใน Strategy Tester มี Agent สามแบบ แบบในเครื่องติดตั้งมาให้พร้อมโปรแกรม จำนวนเท่ากับคอร์เชิงตรรกะของ CPU แบบระยะไกลคือคอมเครื่องอื่นในเครือข่ายของคุณเอง และแบบคลาวด์คือ MQL5 Cloud Network เงื่อนไขของแบบคลาวด์ตามคู่มือมีดังนี้ (ข้อมูลจาก คู่มือ MetaTrader 5: MQL5 Cloud Network How to Use ตรวจเมื่อ พ.ย. 2569)

  1. ใส่บัญชี MQL5.community

    ใส่ชื่อผู้ใช้และรหัสผ่านใน Tools → Options → Community ถ้ายังไม่ได้ใส่ ระบบจะถามตอนเปิดใช้

  2. เติมเงินในบัญชี MQL5

    บริการนี้คิดเงินตามงานที่ใช้จริง และต้องมีเงินในบัญชี MQL5 อย่างน้อย 1 ดอลลาร์สหรัฐ คู่มือบอกไว้ว่าระบบประเมินค่าใช้จ่ายทั้งหมดล่วงหน้าไม่ได้

  3. เปิดใช้ในแท็บ Agents

    เปิด Strategy Tester ด้วย Ctrl+R ไปที่แท็บ Agents คลิกขวาที่กลุ่ม MQL5 Cloud Network แล้วเลือก Enable

  4. ตั้งค่าการทดสอบตามปกติ แล้วกด Start

    ระหว่างคำนวณ แท็บ Agents จะแสดงจำนวน Agent ที่ใช้อยู่ของแต่ละจุดเชื่อมต่อ ซึ่งแบ่งตามภูมิภาค

ข้อจำกัดที่ควรรู้คือ พลังของเครือข่ายใช้ได้เต็มที่เฉพาะการ Optimize แบบไล่ทุกชุดค่า ถ้าเป็นแบบ Genetic จะใช้ Agent ของจุดเชื่อมต่อเดียว ใช้ได้เฉพาะระบบ 64 บิต และงานแต่ละรอบเขียนดิสก์หรือใช้หน่วยความจำได้ไม่เกิน 4 GB ถ้าเกิน รอบนั้นจะไม่ได้ผล แต่ยังถูกคิดค่าเวลาที่ใช้ไป ก่อนตัดสินใจจ่ายเพื่อความเร็ว ลองลดจำนวนชุดค่าที่ทดสอบก่อน วิธีตั้งช่วงค่าให้พอดีอยู่ในบท Optimize EA ให้ไม่หลอกตัวเอง

MT5 Cloud Network Mode is Off หมายถึงอะไร

บางคนเห็นข้อความทำนอง MT5 Cloud Network Mode is Off หรือเห็นกลุ่ม MQL5 Cloud Network ในแท็บ Agents ขึ้นว่ายังไม่ได้เปิดใช้ แล้วกังวลว่า EA จะหยุด เราไม่พบหน้าคู่มือทางการที่อธิบายข้อความนี้แบบคำต่อคำ (ตรวจเมื่อ พ.ย. 2569) แต่จากคำอธิบายเรื่อง Agent ในคู่มือ ความหมายคือ Strategy Tester ยังไม่ได้ใช้ Agent จากเครือข่ายคลาวด์ ใช้แค่ Agent ในเครื่องหรือในเครือข่ายของคุณเอง

คำถามคำตอบ
EA ที่ติดอยู่บนกราฟหยุดไหมไม่เกี่ยวกัน การเทรดบนกราฟไม่ได้ใช้ Cloud Network
Virtual Hosting ได้รับผลไหมไม่ได้รับผล เป็นคนละบริการ
ทดสอบ EA ได้ไหมได้ ใช้ Agent ในเครื่องตามปกติ แค่อาจช้ากว่าเมื่อชุดค่ามีมาก
ต้องแก้ไหมไม่ต้อง ถ้าคุณไม่ได้ตั้งใจใช้เครือข่ายคลาวด์ ถ้าต้องการใช้ ทำตามขั้นตอนในหัวข้อก่อนหน้า

อีกกรณีคือคนที่ติดตั้ง MetaTester เพื่อเปิดให้คนอื่นใช้พลังเครื่อง ในโปรแกรมนั้นมีคอลัมน์ Cloud บอกว่า Agent เชื่อมต่อกับเครือข่ายแล้วหรือยัง และมีตัวเลือกให้ขายพลังประมวลผลผ่านบัญชี MQL5 ถ้าตัวเลือกนี้ปิด Agent ก็ไม่รับงานจากเครือข่าย เรื่องนี้ไม่เกี่ยวกับการรัน EA บนบัญชีเทรดเช่นกัน

ใช้ MQL5 Cloud Network ทดสอบแล้ว มันเทรดเงินจริงให้ด้วยไหม?

ไม่ เครือข่ายนี้คำนวณการทดสอบกับข้อมูลราคาย้อนหลังเท่านั้น ไม่ได้ต่อกับบัญชีเทรดของคุณ ถ้าอยากให้ EA เทรดตลอดเวลา ต้องใช้เครื่องที่เปิดอยู่ตลอด เช่น Windows VPS หรือ Virtual Hosting

ใช้ Virtual Hosting แล้ว ต้องเปิดคอมที่บ้านไว้ไหม?

ไม่ต้อง หลังย้ายเสร็จ EA ทำงานบนเครื่องเสมือน แต่เมื่อต้องการแก้ค่าหรือเพิ่มกราฟ คุณต้องเปิด MT5 บนคอม แก้ แล้วสั่งย้ายขึ้นไปใหม่ เพราะการคัดลอกเป็นทางเดียว

Virtual Hosting ใช้กับหลายบัญชีได้ไหม?

คู่มือระบุว่าเช่าให้กับบัญชีเทรดบัญชีหนึ่ง ถ้ามีหลายบัญชีที่อยากรันพร้อมกัน ต้องเช่าแยกตามบัญชี ส่วนการย้ายการเช่าไปบัญชีใหม่ทำได้จากหน้าโปรไฟล์ MQL5.community

ยกเลิก Virtual Hosting แล้วข้อมูลเป็นยังไง?

เครื่องเสมือนและข้อมูลที่ย้ายขึ้นไปจะถูกลบทั้งหมด กู้คืนไม่ได้ ตามคู่มือ การคืนเงินทำได้เฉพาะเมื่อยกเลิกภายใน 24 ชั่วโมงแรก หลังจากนั้นเวลาที่เหลือจะถูกเก็บเป็นเวลาใช้ฟรีในบัญชี MQL5

ควร Optimize EA บนเครื่องที่ใช้เทรดจริงไหม?

ไม่ควร การ Optimize ใช้ CPU และหน่วยความจำมาก อาจทำให้ MT5 ที่กำลังเทรดช้าลง ทำบนคอมอีกเครื่อง หรือส่งงานไปเครือข่ายคลาวด์แทน แล้วปล่อยเครื่องที่รัน EA ไว้ทำงานเดียว

สรุป: MT5 Cloud สองแบบ ใช้คนละงาน

ถ้าจำได้ข้อเดียว ให้จำว่า Virtual Hosting คือที่ให้ EA ทำงาน ส่วน MQL5 Cloud Network คือเครื่องช่วยคิดตอนทดสอบ ทั้งสองมีค่าใช้จ่าย ต้องมีบัญชี MQL5.community และมีเงื่อนไขที่ควรอ่านก่อนใช้ โดยเฉพาะข้อห้ามเรื่อง DLL บนเครื่องเสมือน ซึ่งทำให้ EA บางตัวใช้กับ Virtual Hosting ไม่ได้ ก่อนย้าย EA ตัวไหนขึ้นไป ให้ถามผู้พัฒนาก่อนว่ารองรับไหม

สำหรับลูกค้า EA BULL ค่าเช่าเครื่องไม่ว่าแบบไหนไม่รวมอยู่ในแพ็กเกจ ถ้าคุณเลือก Windows VPS ทำตาม ขั้นตอนตั้ง Windows VPS พร้อมภาพหน้าจอ ได้ทีละจุด หรือเลือกแพ็กเกจ VIP ให้ทีมงานติดตั้งบนคอมหรือ VPS ของคุณและเช็กค่าก่อนเริ่มรัน ถ้ากำลังคิดจะใช้ Virtual Hosting กับ EA ของเรา ถามทีมงานทาง LINE ก่อนย้าย จะได้รู้ว่าต้องเตรียมอะไร
