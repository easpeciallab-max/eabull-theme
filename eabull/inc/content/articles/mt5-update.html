MT5 อัพเดทตัวเองผ่านระบบ LiveUpdate ทุกครั้งที่เชื่อมต่อเซิร์ฟเวอร์ โปรแกรมจะเช็กว่ามีรุ่นใหม่ไหม ถ้ามีก็ดาวน์โหลดเบื้องหลัง แล้วขึ้นหน้าต่างให้เลือก Restart หรือ Later ระบบนี้ปิดไม่ได้ สิ่งที่คุณควบคุมได้คือจังหวะที่โปรแกรมปิดแล้วเปิดใหม่ ให้เลือกช่วงตลาดปิดหรือช่วงที่ EA ไม่ได้ถือออเดอร์ แล้วเช็กทุกครั้งว่า EA กลับมาบนกราฟครบ

สรุปสั้น

  • LiveUpdate เช็กรุ่นใหม่ตอนเชื่อมต่อเซิร์ฟเวอร์ ดาวน์โหลดให้เอง และปิดการทำงานของระบบนี้ไม่ได้
  • กด Restart โปรแกรมจะปิด อัปเดต แล้วเปิดใหม่ทันที ส่วน Later จะเลื่อนไปอัปเดตตอนเปิดโปรแกรมครั้งถัดไป
  • ระหว่างที่ MT5 ปิดอยู่ EA หยุดคิด แต่ Stop Loss และ Take Profit บนออเดอร์ยังทำงานที่เซิร์ฟเวอร์
  • บนเครื่องที่มี MT5 หลายชุด ไฟล์อัปเดตดาวน์โหลดครั้งเดียวใช้ร่วมกัน แต่ทุกชุดต้องรีสตาร์ตและเช็กแยกกัน
  • หลังอัปเดตทุกครั้ง ดูการเชื่อมต่อ ปุ่ม Algo Trading ไอคอน EA บนกราฟ และบรรทัดล่าสุดใน Journal

บทนี้อยู่ในชุดเรื่องการให้ EA ทำงานตลอด 24 ชั่วโมง การอัปเดตเป็นหนึ่งในเหตุที่ทำให้ EA ขาดช่วงบ่อยที่สุด ถ้าอยากเห็น ภาพรวมของการรัน EA ให้ไม่ขาดตอน ทั้งเรื่องเครื่อง การตั้งค่า และการดูแลรายวัน อ่านบทหลักประกอบ คำว่า "อัพเดท" ที่คนส่วนใหญ่พิมพ์ค้นหา เขียนตามหลักภาษาว่า อัปเดต บทนี้ใช้แบบหลังเป็นหลัก

อัพเดท MT5 ยังไง: ระบบ LiveUpdate ทำงานแบบนี้

คุณไม่ต้องไปโหลดตัวติดตั้งใหม่ทุกครั้งที่มีรุ่นใหม่ เพราะ MT5 มีระบบอัปเดตอัตโนมัติในตัวที่ชื่อ LiveUpdate คู่มือ MetaTrader 5 อธิบายขั้นตอนไว้ดังนี้ (ข้อมูลจาก คู่มือ MetaTrader 5: Live Update ตรวจเมื่อ พ.ย. 2569)

  1. เช็กตอนเชื่อมต่อ

    ทุกครั้งที่โปรแกรมต่อเข้าเซิร์ฟเวอร์เทรด ระบบจะเช็กว่ามีส่วนประกอบรุ่นใหม่หรือไม่

  2. ดาวน์โหลดเบื้องหลัง

    ถ้าเจอรุ่นใหม่ ไฟล์จะถูกดาวน์โหลดลงโฟลเดอร์ WebInstall ใน AppData\Roaming\MetaQuotes ของผู้ใช้ Windows คนนั้น MT5 ชุดอื่นในเครื่องใช้ไฟล์ที่โหลดไว้แล้วได้ ไม่ต้องโหลดซ้ำ

  3. ขึ้นหน้าต่างถาม

    เมื่อโหลดเสร็จ จะมีหน้าต่างให้เลือก Restart หรือ Later

  4. บันทึกใน Journal

    ทุกขั้นของการอัปเดตถูกเขียนไว้ในแท็บ Journal โดยคอลัมน์ Source จะเป็นคำว่า LiveUpdate ถ้าอัปเดตไม่สำเร็จเพราะการเชื่อมต่อหลุด ระบบจะลองใหม่ในอีกหนึ่งชั่วโมง และโหลดเฉพาะส่วนที่ยังขาด

ปุ่มในหน้าต่างอัปเดตสิ่งที่เกิดขึ้นผลกับ EA
Restartปิดหน้าต่าง MT5 และ MetaEditor ถ้าเปิดอยู่ ติดตั้งรุ่นใหม่ แล้วเปิดโปรแกรมขึ้นมาใหม่หยุดชั่วครู่ แล้วกลับมาพร้อมกราฟเมื่อโปรแกรมเปิด
Laterซ่อนหน้าต่าง รุ่นใหม่จะถูกติดตั้งเองตอนเปิดโปรแกรมครั้งถัดไปทำงานต่อตามปกติจนกว่าโปรแกรมจะถูกปิด

ถ้าเครื่องเปิด UAC ไว้ หรือผู้ใช้ Windows ไม่มีสิทธิ์พอ จะมีหน้าต่างขอสิทธิ์ผู้ดูแลเครื่องขึ้นมาด้วย ต้องกดยืนยันหรือใส่รหัสผู้ดูแล การอัปเดตจึงจะเดินต่อ

กด Restart แล้ว EA กับออเดอร์เป็นยังไง

ตอนกด Restart โปรแกรม MT5 ถูกปิดจริง EA ทุกตัวบนกราฟจึงหยุดไปด้วยในช่วงนั้น เมื่อโปรแกรมเปิดกลับมา กราฟชุดเดิมจะถูกเปิดคืนพร้อม EA ที่ติดไว้ และ EA เริ่มทำงานใหม่ตั้งแต่ต้น ช่วงที่หายไปมักสั้น แต่สิ่งที่เกิดระหว่างนั้นควรรู้ไว้

  • ออเดอร์ที่เปิดอยู่ยังอยู่ในบัญชีที่เซิร์ฟเวอร์ ไม่ได้ถูกปิดเพราะการอัปเดต
  • Stop Loss Take Profit และคำสั่งรอที่ส่งไปแล้ว ยังทำงานที่เซิร์ฟเวอร์ตามปกติ
  • Trailing Stop ของ MT5 และกฎดูแลไม้ของ EA หยุดชั่วคราว จนกว่าโปรแกรมจะเปิดกลับมา
  • ถ้าราคาวิ่งแรงในจังหวะที่โปรแกรมปิด EA จะเห็นสภาพตลาดใหม่ในรอบแรกที่กลับมา

ส่วนการกด Later ไม่ได้ทำให้หนีการอัปเดตได้ตลอด รุ่นใหม่จะถูกติดตั้งทันทีที่โปรแกรมเปิดครั้งถัดไปด้วยเหตุใดก็ตาม รวมถึงตอนที่เครื่องรีสตาร์ตเพราะ Windows Update หรือไฟดับ ถ้าคุณกด Later ไว้ จึงควรนัดเวลารีสตาร์ตเองให้เร็ว แทนที่จะปล่อยให้มันเกิดตอนไหนก็ไม่รู้

วางแผนอัปเดตบนคอมที่บ้าน

บนคอมที่คุณนั่งใช้ หน้าต่างอัปเดตมักขึ้นตอนคุณอยู่หน้าเครื่องพอดี อย่ากด Restart ทันทีเพราะเคยชิน ให้ดูก่อนว่า EA ถือออเดอร์อยู่ไหม และตลาดอยู่ช่วงไหน ช่วงที่เหมาะคือตลาดปิดวันเสาร์อาทิตย์ หรือช่วงที่ EA ไม่มีออเดอร์ค้างตามคู่มือของ EA ตัวนั้น

  1. ดูออเดอร์ที่เปิดอยู่

    เปิดแท็บ Trade ใน Toolbox ถ้ามีออเดอร์ที่ EA กำลังดูแล ให้รอจังหวะที่เหมาะกว่า หรือกด Later ไว้ก่อน

  2. เก็บค่าตั้งของ EA

    เปิดคุณสมบัติของ EA แต่ละกราฟ แท็บ Inputs กด Save เก็บชุดค่าเป็นไฟล์ ซึ่งจะอยู่ในโฟลเดอร์ Presets ถ้าต้องติดใหม่ภายหลังจะใส่ค่าเดิมได้ทันที

  3. กด Restart เมื่อพร้อม

    ถ้ากด Later ไปแล้ว ปิด MT5 ตามปกติแล้วเปิดใหม่ รุ่นใหม่จะถูกติดตั้งตอนเปิด

  4. เช็กผลในเครื่อง

    ดู Journal ว่ามีบรรทัด LiveUpdate และไม่มีข้อผิดพลาด แล้วไล่ตามเช็กลิสต์หลังอัปเดตด้านล่าง

วิธีอัพเดท MT5 ในคอม แบบสั่งเอง

ถ้าอยากให้โปรแกรมเช็กรุ่นใหม่ทันทีโดยไม่รอ ใช้เมนู Help → Check Desktop Updates → Latest Release Version ชื่อเมนูอาจต่างเล็กน้อยตามรุ่นของโปรแกรม อีกทางคือติดตั้งทับโปรแกรมเดิมด้วยตัวติดตั้งรุ่นล่าสุด คู่มือการติดตั้งระบุว่าการติดตั้งทับเก็บการตั้งค่าเดิมไว้ ยกเว้นโปรไฟล์และเทมเพลตที่มากับโปรแกรม และชุดโปรแกรม MQL5 ตัวอย่างมาตรฐาน ตัวติดตั้งควรโหลดจากแหล่งทางการเท่านั้น ซึ่งเราแนะนำวิธีดูไว้ในบท โหลด MT5 ของแท้จากที่ไหน

อย่าลืมว่า Windows เองก็มีรอบอัปเดตที่ทำให้เครื่องรีสตาร์ต ถ้าสองอย่างนี้เกิดคนละเวลากัน EA จะสะดุดสองรอบ นัดให้เกิดในวันเดียวกันช่วงตลาดปิดจะง่ายกว่า วิธีตั้งเวลาอัปเดตของ Windows อยู่ในบท ตั้ง Windows ไม่ให้หลับและไม่รีสตาร์ตเอง

วางแผนอัปเดตบน VPS

บน VPS หน้าต่างอัปเดตจะรอคุณอยู่ในหน้าจอของเครื่อง คุณจะเห็นมันก็ต่อเมื่อเข้าไปดูผ่าน Remote Desktop หรือ Windows App ตามปกติโปรแกรมยังทำงานต่อระหว่างที่หน้าต่างรออยู่ รุ่นใหม่จะถูกติดตั้งเมื่อมีคนกด Restart หรือเมื่อโปรแกรมเปิดใหม่ครั้งถัดไป จุดที่ต่างจากคอมที่บ้านมีดังนี้

เรื่องคอมที่บ้านVPS
เห็นหน้าต่างอัปเดตเมื่อไหร่ตอนนั่งหน้าเครื่องตอนเข้าไปดูหน้าจอ VPS
MT5 หลายชุดมักมีชุดเดียวมักมีหลายชุด ทุกชุดต้องรีสตาร์ตของตัวเอง
รีสตาร์ตที่ไม่ได้วางแผนWindows Update ไฟดับWindows Update และการบำรุงรักษาของผู้ให้บริการ
หลังรีสตาร์ตเครื่องมีคนลงชื่อเข้าใช้ได้ทันทีต้องเข้าไปลงชื่อเข้าใช้ ถ้ายังไม่ได้ตั้งให้ MT5 เปิดเอง

ถ้ามี MT5 หลายชุดบน VPS ให้รีสตาร์ตทีละชุด รอให้ชุดแรกกลับมาเชื่อมต่อและเช็กเสร็จก่อนค่อยทำชุดถัดไป จะได้รู้ทันทีว่าชุดไหนมีปัญหา และไม่ทำให้ทุกบัญชีหยุดพร้อมกัน ออกจาก VPS ด้วยการตัดการเชื่อมต่อเสมอ ไม่ใช่ Sign out รายละเอียดเรื่องนี้อยู่ในบท ใช้ Remote Desktop เข้า VPS

MT5 อัพเดท ล่าสุด ดูยังไง

คำถามว่า MT5 อัพเดทล่าสุดเป็นรุ่นอะไร คำตอบเปลี่ยนทุกครั้งที่ MetaQuotes ออกรุ่นใหม่ บทความจึงไม่ใส่เลข build ไว้ เพราะจะเก่าเร็ว ให้ดูจากแหล่งที่อัปเดตตามจริงแทน

  • รุ่นที่คุณใช้อยู่: ดูจากหน้าต่าง About ในเมนู Help หรือบรรทัดแรก ๆ ในแท็บ Journal ตอนเปิดโปรแกรม ซึ่งบอกเลข build ไว้
  • รุ่นใหม่ล่าสุดและสิ่งที่เปลี่ยน: ดูหน้า MetaTrader 5 Release Notes ซึ่งเรียงรุ่นพร้อมวันที่ออก
  • เช็กว่าเครื่องคุณได้รุ่นนั้นหรือยัง: ใช้ Help → Check Desktop Updates → Latest Release Version

ในเมนูเดียวกันมีตัวเลือก Latest Beta Version ด้วย รุ่นเบต้าคือรุ่นทดลองก่อนออกจริง เหมาะกับนักพัฒนาที่อยากลองของใหม่ ไม่ควรใช้กับเครื่องที่ EA เทรดเงินจริง ถ้าเผลอติดตั้งไปแล้ว ให้ทดสอบ EA กับบัญชีทดลองก่อนกลับไปใช้กับบัญชีจริง

อัปเดตตัว EA ต่างจากอัปเดต MT5 ยังไง

LiveUpdate อัปเดตเฉพาะตัวโปรแกรม MT5 ไฟล์ EA ที่คุณได้มาจากผู้พัฒนาจะไม่ถูกเปลี่ยนตาม ถ้า EA มีรุ่นใหม่ คุณต้องเปลี่ยนไฟล์เองตามที่ผู้พัฒนาแนะนำ ทั้งสองเรื่องนี้ทำแยกกัน และไม่ควรทำพร้อมกันในรอบเดียว เพราะถ้ามีอะไรผิดปกติ จะแยกไม่ออกว่าเกิดจากโปรแกรมหรือจาก EA

เรื่องอัปเดต MT5อัปเดต EA
ใครเป็นคนออกรุ่นใหม่MetaQuotesผู้พัฒนา EA
เกิดขึ้นยังไงโหลดเองผ่าน LiveUpdate แล้วถามให้รีสตาร์ตคุณได้ไฟล์ใหม่มาแล้ววางแทนไฟล์เดิม
ดูรุ่นได้ที่ไหนหน้าต่าง About หรือ Journal ตอนเปิดโปรแกรมแท็บ Common ในหน้าต่างตั้งค่าของ EA
ต้องตั้งค่าใหม่ไหมปกติไม่ต้อง กราฟและ EA กลับมาเองขึ้นกับคู่มือของรุ่นนั้น บางรุ่นมีช่องตั้งค่าเพิ่มหรือเปลี่ยน

ก่อนเปลี่ยนไฟล์ EA ให้อ่านว่ารุ่นใหม่เปลี่ยนอะไร เก็บชุดค่าเดิมด้วยปุ่ม Save และถ้าเป็นไปได้ ลองรุ่นใหม่กับบัญชีทดลองก่อน

เช็กลิสต์หลังอัปเดตทุกครั้ง

ไม่ว่าจะอัปเดต MT5 หรือ EA ใช้รายการนี้เช็กทุกครั้งก่อนปล่อยเครื่องไว้ ใช้เวลาไม่เกินห้านาที

  • มุมขวาล่างแสดงค่า ping ไม่ใช่ No connection
  • บัญชีที่ล็อกอินเป็นบัญชีเดิม และ Server ถูกต้อง
  • ปุ่ม Algo Trading เป็นสีเขียว
  • ทุกกราฟที่เคยติด EA ยังมีชื่อ EA และไอคอนที่ได้รับอนุญาต
  • ค่าในแท็บ Inputs ตรงกับชุดค่าที่เก็บไว้
  • บรรทัดหลังเวลาที่เปิดโปรแกรมใหม่ใน Journal กับ Experts ไม่มีคำว่า error หรือ failed

ถ้าข้อไหนไม่ผ่าน เช่น EA หายไปจากกราฟ หรือไอคอนบอกว่าไม่อนุญาต ไล่สาเหตุต่อได้ในบท เช็กว่า EA ยังรันอยู่จริงไหม

คำถามที่พบบ่อยเรื่องอัปเดต MT5

ปิดการอัปเดตอัตโนมัติของ MT5 ได้ไหม?

ไม่ได้ คู่มือ MetaTrader 5 ระบุว่าระบบ LiveUpdate ปิดไม่ได้ สิ่งที่ทำได้คือกด Later แล้วเลือกเวลารีสตาร์ตเองในช่วงที่เหมาะ

กด Later ไปแล้ว MT5 จะอัปเดตเมื่อไหร่?

ตอนเปิดโปรแกรมครั้งถัดไป ไม่ว่าคุณจะปิดเอง หรือเครื่องรีสตาร์ตเพราะเหตุอื่น ระหว่างนั้นโปรแกรมและ EA ทำงานต่อตามปกติ

มี MT5 หลายชุดในเครื่อง ต้องโหลดอัปเดตทีละชุดไหม?

ไม่ต้อง ไฟล์อัปเดตที่โหลดแล้วใช้ร่วมกันได้ในผู้ใช้ Windows เดียวกัน แต่แต่ละชุดต้องรีสตาร์ตของตัวเอง และควรเช็ก EA แยกทีละชุด

อัปเดตไม่ผ่าน ค้างอยู่ ทำยังไง?

ถ้าการเชื่อมต่อหลุดระหว่างโหลด ระบบจะลองใหม่เองในอีกหนึ่งชั่วโมง ให้เช็กเน็ต พื้นที่ดิสก์ และหน้าต่างขอสิทธิ์ผู้ดูแลเครื่องที่อาจซ่อนอยู่ ถ้ายังไม่ผ่าน ติดตั้งทับด้วยตัวติดตั้งรุ่นล่าสุดจากแหล่งทางการ

อัปเดตแล้วต้องล็อกอินบัญชีใหม่ไหม?

ปกติไม่ต้อง โปรแกรมจำบัญชีที่บันทึกไว้ แต่ถ้าติดตั้งใหม่ในโฟลเดอร์ใหม่ หรือโปรแกรมถามรหัส ให้ล็อกอินด้วยเลขบัญชี รหัสผ่าน และชื่อ Server ชุดเดิม

สรุป: ให้ MT5 อัพเดทในเวลาที่คุณเลือก

การอัปเดต MT5 เลี่ยงไม่ได้ และไม่ควรเลี่ยง เพราะรุ่นใหม่แก้ปัญหาและปรับความปลอดภัย หลักคือให้มันเกิดในเวลาที่คุณเลือก ไม่ใช่ปล่อยให้เกิดเอง กด Later เมื่อจังหวะไม่เหมาะ นัดรีสตาร์ตช่วงตลาดปิด ทำทีละชุดบน VPS และเช็กลิสต์หลังอัปเดตทุกครั้ง EA ของคุณจะสะดุดน้อยที่สุด

ถ้าการติดตั้งใหม่ทำให้โปรแกรมถามข้อมูลบัญชี วิธีเข้าระบบและหาชื่อ Server ที่ถูกต้องอยู่ในหน้า เข้าระบบ MT5 อีกครั้งหลังติดตั้งใหม่ ข้อมูลคู่นี้สำคัญกับลูกค้า EA BULL ด้วย เพราะสิทธิ์ใช้งานผูกกับเลขบัญชี MT5 และชื่อ Server เมื่อ EA ของ EA BULL มีรุ่นใหม่ ทีมงานแจ้งทาง LINE คุณจึงวางแผนเปลี่ยนไฟล์ให้ไม่ชนกับรอบอัปเดตของ MT5 ได้ ถ้าไม่สะดวกทำเอง แพ็กเกจ VIP ให้ทีมงานติดตั้งบนคอมหรือ VPS และเช็กค่าให้ก่อนเริ่มรัน

อ่านต่อ

  • ล็อกอิน MT5: ใส่เลขบัญชี รหัสผ่าน และ Server ให้ถูก
  • ปิดสลีปคอม: ตั้ง Windows ไม่ให้หลับระหว่างรัน EA
  • EA MT5 ไม่ทำงาน: เช็กทีละจุดว่า EA ยังรันอยู่จริงไหม
  • ดาวน์โหลด MT5: โหลดของแท้จากที่ไหน ทั้งคอม มือถือ และ VPS
