Position Size คือขนาดของไม้ที่คุณเปิด ซึ่ง MT5 วัดเป็น lot ส่วนการคิด Position Size คือการหาว่าไม้ควรใหญ่แค่ไหน จากสองตัวเลข ได้แก่เงินที่ยอมเสียถ้าไม้นี้ผิด และระยะจากราคาเข้าถึงจุด Stop Loss สูตรสั้นที่สุดคือ lot = เงินที่ยอมเสีย ÷ (ระยะ Stop Loss × มูลค่าของระยะนั้นต่อ 1 lot)

สรุปสั้น

  • คิดขนาดไม้จากเงินที่ยอมเสีย ทำให้ทุกไม้เสียใกล้เคียงกัน ไม่ว่า Stop Loss จะใกล้หรือไกล
  • สำหรับทองที่ขนาดสัญญา 100 ออนซ์ สูตรคือ lot = เงินที่ยอมเสีย ÷ (ระยะ SL เป็น USD × 100)
  • ตัวเลขที่คำนวณได้มักมีเศษ ให้ตัดเศษทิ้งตาม Volume step ของบัญชี อย่าปัดให้ไม้โตขึ้น
  • ถ้าผลต่ำกว่าไม้เล็กสุดที่เปิดได้ แปลว่าแผนนี้ใช้กับทุนนี้ไม่ได้ ไม่ใช่สัญญาณให้เปิดไม้เล็กสุดแทน
  • เปิดหลายไม้หรือใช้ EA ต้องคิดความเสี่ยงรวมของทุกไม้

คำถามว่าควรเปิดไม้ขนาดไหน กับคำถามว่าต้องมีเงินในบัญชีเท่าไหร่ เป็นเรื่องเดียวกันที่มองคนละด้าน ด้านทุนอธิบายไว้ในบทหลักเรื่องเทรดทองต้องมีทุนเท่าไหร่ ส่วนบทนี้ลงลึกด้านขนาดไม้ ตัวอย่างทั้งหมดเป็นตัวเลขสมมติ ใช้ทองคำที่ขนาดสัญญา 100 ออนซ์ต่อ 1 lot และบัญชีสกุล USD

Position Size คืออะไร

ในภาษาเทรด Position คือไม้ที่เปิดอยู่ และ Size คือขนาดของมัน ถ้าคุณเปิด Buy ทองคำ 0.03 lot Position Size ของไม้นั้นคือ 0.03 lot ฟังดูง่าย แต่คำนี้มักถูกใช้ในอีกความหมายหนึ่งที่สำคัญกว่า คือการตัดสินใจว่าไม้ควรใหญ่เท่าไหร่ ซึ่งบางตำราเรียกว่า Position Sizing

หลักของ Position Sizing คือ ขนาดไม้ไม่ได้มาจากความรู้สึกว่ามั่นใจแค่ไหน แต่มาจากเงินก้อนที่คุณยอมเสียถ้าไม้นี้ผิด เมื่อกำหนดเงินก้อนนี้ไว้แล้ว ขนาดไม้จะถูกคำนวณออกมาเองจากระยะ Stop Loss ไม้ที่ต้องวาง Stop Loss ไกลจะเล็กลง ไม้ที่วางใกล้จะใหญ่ขึ้น โดยเงินที่เสียเมื่อโดน Stop Loss แทบเท่ากันทุกไม้

ทำไมต้องคิดขนาดไม้จากระยะ Stop Loss

ลองดูคนที่เปิดไม้ 0.05 lot ทุกครั้งโดยไม่คิดอะไร วันหนึ่งเขาวาง Stop Loss ห่าง 3 USD ถ้าโดนจะเสีย 0.05 × 100 × 3 = 15 USD อีกวันหนึ่งกราฟแกว่งแรง เขาวาง Stop Loss ห่าง 20 USD ถ้าโดนจะเสีย 100 USD ไม้ขนาดเท่ากัน แต่ความเสี่ยงต่างกันเกือบเจ็ดเท่า

ผลคือไม้ที่เสียหนักที่สุดมักเป็นไม้ในวันที่ตลาดผันผวน ซึ่งเป็นวันที่ยากที่สุดอยู่แล้ว การคิดขนาดไม้จากระยะ Stop Loss แก้ปัญหานี้ตรง ๆ เพราะวันที่ต้องวางไกล ไม้จะเล็กลงให้อัตโนมัติ

ส่วนคำถามว่า Stop Loss ควรวางตรงไหนของกราฟ เป็นอีกเรื่องหนึ่งที่ต้องตัดสินใจก่อนคำนวณ หลักการวางและความสัมพันธ์กับจุดทำกำไร อธิบายไว้ในบท Stop Loss กับ Take Profit คืออะไร

สูตรคำนวณ Position Size

สูตรทั่วไปที่ใช้ได้กับทุกสินทรัพย์คือ

lot = เงินที่ยอมเสีย ÷ (ระยะ Stop Loss × มูลค่าของระยะ 1 หน่วยต่อ 1 lot)

มูลค่าของระยะ 1 หน่วยต่อ 1 lot หาได้จาก Tick value และ Tick size ใน Specification ของสัญลักษณ์ ตามชื่อช่องในคู่มือ Market Watch ของ MT5 ถ้าวัดระยะเป็น USD ของราคาทอง และ Tick size 0.01 กับ Tick value 1 USD ราคาขยับ 1 USD เท่ากับ 100 USD ต่อ 1 lot สูตรของทองจึงเหลือแค่

lot ทองคำ = เงินที่ยอมเสีย ÷ (ระยะ Stop Loss เป็น USD × 100)

สินทรัพย์ (ตัวอย่างค่าทั่วไป)วัดระยะ SL เป็นมูลค่าต่อ 1 หน่วยระยะ ต่อ 1 lotสูตร

สองแถวแรกเป็นสูตรเดียวกัน ต่างกันแค่หน่วยที่ใช้วัดระยะ ใช้แถวไหนก็ได้ ขอแค่หน่วยของระยะกับมูลค่าต่อหน่วยตรงกัน

คำนวณ position size ทองคำทีละขั้น

ตัวอย่างสมมติ บัญชีมี Equity 1,500 USD คุณจะเปิด Buy ที่ 4,000.00 และดูจากกราฟแล้วว่าจุด Stop Loss ที่สมเหตุสมผลอยู่ที่ 3,993.50

  1. ดูเงินในบัญชี

    ใช้ Equity ในแท็บ Trade ถ้ามีไม้อื่นเปิดค้างอยู่ เพราะ Balance ไม่นับขาดทุนลอยตัว ในตัวอย่างนี้คือ 1,500 USD

  2. ตั้งเปอร์เซ็นต์ที่ยอมเสีย

    สมมติยอมเสีย 1.5% ต่อไม้ เท่ากับ 1,500 × 1.5% = 22.50 USD

  3. วัดระยะ Stop Loss

    4,000.00 ลบ 3,993.50 = 6.50 USD ของราคา ถ้านับเป็น pip แบบ 1 pip = 0.10 จะเท่ากับ 65 pip

  4. เช็กค่าใน Specification

    ยืนยันว่า Contract size เป็น 100 และดู Volume step กับ Minimal volume ของบัญชี ในตัวอย่างนี้ปรับได้ทีละ 0.01

  5. คำนวณแล้วปัดลง

    22.50 ÷ (6.50 × 100) = 0.0346 lot ปัดลงตาม Volume step เป็น 0.03 lot

  6. เช็กผลหลังปัด

    ถ้าโดน Stop Loss จะเสีย 0.03 × 100 × 6.50 = 19.50 USD หรือราว 1.3% ของบัญชี ต่ำกว่ากรอบที่ตั้งไว้ และดูว่า Free Margin พอสำหรับไม้นี้

ทั้งหมดใช้เวลาไม่ถึงนาทีเมื่อทำจนชิน สิ่งที่ห้ามข้ามคือขั้นที่ 6 เพราะการปัดเศษและ Spread ทำให้เงินที่เสียจริงไม่ตรงกับตัวเลขที่ตั้งไว้เป๊ะ

เครื่องคำนวณปัดผลลงตามขนาดที่ปรับได้ทีละเท่าไหร่ให้เอง ถ้าโบรกเกอร์ของคุณนับ pip ของทองต่างไป หรือขนาดสัญญาไม่ใช่ 100 ออนซ์ ให้เลือก "ใส่มูลค่า pip เอง" แล้วพิมพ์ค่าที่คิดจาก Specification ของบัญชีคุณ

ปัดเศษ ไม้เล็กสุด และ Volume Step

MT5 ไม่ให้เปิดขนาดไม้ทุกค่าที่คิดได้ ค่า Minimal volume บอกไม้เล็กสุด Maximal volume บอกไม้ใหญ่สุดต่อคำสั่ง และ Volume step บอกว่าเพิ่มลดได้ทีละเท่าไหร่ ถ้า Volume step เป็น 0.01 ผล 0.0346 จะเปิดได้แค่ 0.03 หรือ 0.04 เท่านั้น

หลักคือปัดลงเสมอ เพราะการปัดขึ้นทำให้เสียเกินกรอบที่ตั้งไว้ ผลต่างอาจดูนิดเดียวในไม้เดียว แต่ถ้าปัดขึ้นทุกไม้ ความเสี่ยงจริงของคุณจะสูงกว่าแผนตลอดเวลา ส่วนกรณีทุนน้อยที่ผลคำนวณชนไม้เล็กสุดบ่อย ๆ ผลของมันต่อแผนอธิบายไว้ในบทเรื่องมูลค่าไม้ทอง 0.01 lot เป็นเงินบาท ซึ่งแสดงมูลค่าต่อการขยับของไม้เล็กสุดเป็นเงินบาท

Position Size เมื่อเปิดหลายไม้ หรือใช้ EA

สูตรข้างบนคิดทีละไม้ ถ้าคุณเปิดทองหลายไม้ทิศเดียวกันพร้อมกัน ให้มองเป็นไม้ใหญ่ไม้เดียว ไม้ Buy 0.02 lot สามไม้ที่ Stop Loss ห่าง 10 USD เท่ากัน เท่ากับเสี่ยง 60 USD ไม่ใช่ 20 USD การคิดเปอร์เซ็นต์ต่อไม้โดยไม่รวมไม้อื่น ทำให้ความเสี่ยงรวมของบัญชีสูงกว่าที่ตั้งใจได้ง่าย

กับ EA เรื่องนี้ยิ่งสำคัญ เพราะ EA บางตัวใช้ขนาดไม้คงที่ บางตัวคิดขนาดไม้จากทุนให้เอง และบางตัวเปิดหลายไม้ต่อเนื่อง ความต่างของสองแนวทางแรกเทียบไว้ในบท Fixed Lot กับ Lot อัตโนมัติ ส่วนระบบที่ไม่ได้วาง Stop Loss ทุกไม้ ใช้สูตรในบทนี้ตรง ๆ ไม่ได้ ต้องคิดจากระยะสวนสูงสุดแทน ซึ่งอยู่ในบทเรื่องทุนต่อไม้ 0.01 lot

ข้อผิดพลาดที่เจอบ่อยเวลาคำนวณ

  • สับสนหน่วยของระยะ ใส่ 650 แทน 65 เพราะเอาจำนวน point มาใส่ในช่องที่นับเป็น pip ไม้จะเล็กกว่าที่ควรสิบเท่า หรือกลับกันจะใหญ่กว่าสิบเท่า
  • เอา Margin มาคิดเป็นเงินที่ยอมเสีย Margin คือเงินที่ถูกกันไว้ ไม่ใช่เงินที่เสียเมื่อโดน Stop Loss
  • ใช้ Balance ทั้งที่มีขาดทุนลอยตัวก้อนใหญ่ค้างอยู่ ทำให้ไม้ใหม่ใหญ่เกินเงินที่มีจริง
  • คำนวณเสร็จแล้วไปเลื่อน Stop Loss ให้ไกลขึ้น โดยไม่ลดขนาดไม้ตาม
  • ลืมว่าไม้ Sell ปิดที่ราคา Ask Stop Loss ของไม้ Sell จึงอาจโดนเร็วกว่าที่เห็นบนกราฟ Bid เมื่อ Spread กว้าง
  • บัญชีไม่ได้เป็นสกุล USD แต่ใส่เงินที่ยอมเสียเป็น USD โดยไม่แปลงก่อน

คำถามที่พบบ่อยเรื่อง Position Size

Position Size คือ อะไร ต่างจาก Lot ไหม?

Lot คือหน่วยวัดขนาดไม้ใน MT5 ส่วน Position Size คือขนาดของไม้หนึ่งไม้ ซึ่งวัดเป็น lot อีกที เวลาคนพูดว่าคิด Position Size มักหมายถึงการหาว่าควรเปิดกี่ lot จากเงินที่ยอมเสียและระยะ Stop Loss

แต่ละไม้ ตั้งเงินที่ยอมเสียไว้กี่เปอร์เซ็นต์ของบัญชีดี?

ไม่มีตัวเลขที่ถูกสำหรับทุกคน หลายตำราใช้ตัวอย่าง 1% ถึง 2% วิธีคิดที่ดีกว่าคือย้อนจากคำถามว่า ถ้าแพ้ติดกันสิบไม้ คุณรับยอดที่ลดลงได้ไหม แล้วค่อยตั้งเปอร์เซ็นต์ให้ตรงกับคำตอบนั้น

คำนวณ position size ทองต่างจาก Forex ยังไง?

สูตรเหมือนกัน ต่างกันที่มูลค่าต่อหน่วยระยะ ทองคิดจากขนาดสัญญาเป็นออนซ์ คู่เงินคิดจากหน่วยสกุลเงิน ให้ดู Tick size และ Tick value ใน Specification ของสัญลักษณ์ที่จะเทรดทุกครั้ง ไม่ใช้ค่าของตัวหนึ่งไปคิดอีกตัว

ไม่ได้ตั้ง Stop Loss คิด Position Size ได้ไหม?

ใช้สูตรนี้ไม่ได้ เพราะไม่มีระยะให้หาร สิ่งที่ทำแทนได้คือกำหนดระยะสวนสูงสุดที่จะยอมถือ แล้วใช้ระยะนั้นแทน Stop Loss ซึ่งต้องมีวินัยปิดไม้เองเมื่อถึงระยะ หรือคิดทุนจากระยะสวนที่ลึกที่สุดที่ระบบเคยเจอ

ใช้ Balance หรือ Equity คำนวณดี?

ถ้าไม่มีไม้เปิดค้าง สองค่าเท่ากัน ถ้ามีไม้ค้างอยู่ Equity ใกล้ความจริงกว่า เพราะนับกำไรขาดทุนลอยตัวแล้ว การใช้ Balance ตอนที่ติดลบค้างอยู่ทำให้ไม้ใหม่ใหญ่เกินเงินที่มีจริง

สรุป: ตั้งเงินที่ยอมเสียก่อน แล้วให้ขนาดไม้ตามมา

Position Size ที่ดีเริ่มจากสองตัวเลขที่ตัดสินใจไว้ก่อนเปิดไม้ คือเงินที่ยอมเสียกับจุด Stop Loss จากนั้นหารด้วยมูลค่าต่อหน่วยระยะจาก Specification แล้วปัดลงตาม Volume step วิธีนี้ทำให้ทุกไม้เสียใกล้เคียงกัน และทำให้คุณรู้ล่วงหน้าเสมอว่าแพ้ติดกันกี่ไม้แล้วบัญชีจะเหลือเท่าไหร่

เครื่องคำนวณในบทนี้เป็นตัวเดียวกับที่อยู่ในหน้าเครื่องมือคำนวณของเว็บ ซึ่งเปิดใช้ได้ทุกเวลาก่อนเปิดไม้หรือก่อนแก้ค่าขนาดไม้ใน EA ถ้าคุณใช้ EA และไม่แน่ใจว่าควรตั้งขนาดไม้ยังไงให้ตรงกับทุน ถามทีมงานทาง LINE ก่อนแก้ค่าได้
