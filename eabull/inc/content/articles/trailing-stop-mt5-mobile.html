ตั้ง Trailing Stop MT5 มือถือ ในแอปโดยตรงทำไม่ได้ เพราะคู่มือแอปทางการทั้ง Android และ iPhone ไม่มีคำสั่งนี้ในหมวด Trade เลย Trailing Stop ของ MT5 อยู่ในโปรแกรมบนคอม และทำงานเฉพาะตอนที่โปรแกรมนั้นเปิดอยู่ ทางที่ใช้ได้จริงจึงเป็นการให้ MT5 บนคอมหรือ VPS เป็นคนไล่ SL แล้วใช้มือถือดูผลและสั่งงานแทน หรือเลื่อน SL เองจากมือถือทีละครั้ง

สรุปสั้น

  • แอป MT5 บนมือถือตั้ง SL TP แก้ไม้ และปิดไม้ได้ แต่ไม่มีเมนู Trailing Stop ตามคู่มือทางการ
  • ตั้ง Trailing Stop บนโปรแกรม MT5 ในคอมหรือ VPS แล้ว SL ที่เลื่อนจะไปอยู่ที่เซิร์ฟเวอร์ มือถือที่ล็อกอินบัญชีเดียวกันจึงเห็น SL ขยับตาม
  • VPS ทำให้ Trailing Stop ทำงานได้ตลอดเวลา และคุณเข้าไปตั้งจากมือถือได้ด้วยแอป Windows App ของ Microsoft
  • EA ที่มีระบบไล่ SL ก็ต้องรันบนคอมหรือ VPS เช่นกัน เพราะแอปมือถือรัน EA ไม่ได้
  • ถ้าไม่มีเครื่องอื่นเลย ทางเดียวคือเลื่อน SL เองด้วยเมนู Modify position ตามกติกาที่ตั้งไว้ก่อน

บทนี้อยู่ในชุดจัดการออเดอร์ และต่อจากเรื่องที่ว่า Stop Loss คืออะไร และระบบเก็บมันไว้ที่ไหน ซึ่งเป็นกุญแจของทั้งบท เพราะ SL อยู่ที่เซิร์ฟเวอร์ แต่ Trailing Stop อยู่ในโปรแกรมของเครื่องที่ตั้ง ส่วนพื้นฐานว่า Trailing Stop เลื่อน SL ยังไง ดูได้ในบท ความหมายและวิธีตั้ง Trailing Stop บนคอม

ตั้ง Trailing Stop MT5 มือถือได้ไหม: ดูจากคู่มือทางการ

วิธีตรวจที่ตรงที่สุดคือเปิด คู่มือแอป MetaTrader 5 สำหรับ Android แล้วดูหมวด Trade (ตรวจเมื่อ พ.ย. 2569) หัวข้อที่มีคือหลักการซื้อขาย การเปิดและปิดไม้ Close By การแก้ไขไม้ การวางคำสั่งรอ การจัดการคำสั่งรอ และคำสั่งกลุ่ม Bulk Operations คู่มือฉบับ iPhone มีหัวข้อหลักชุดเดียวกัน และทั้งสองฉบับไม่มีหัวข้อ Trailing Stop

เรื่องนี้ไม่แปลกถ้าดูว่า Trailing Stop ทำงานยังไง คู่มือของโปรแกรมบนคอมเขียนไว้ชัดว่ามันทำงานในโปรแกรมซื้อขาย ไม่ได้ทำงานที่เซิร์ฟเวอร์เหมือน SL หรือ TP โปรแกรมต้องเฝ้าราคาอยู่ตลอดแล้วส่งคำสั่งแก้ SL เมื่อถึงจังหวะ ซึ่งต้องมีโปรแกรมเปิดค้างไว้ตลอดช่วงที่ถือไม้

ทำไมมือถือเห็น SL ขยับ ทั้งที่ตั้งบนคอม

หลายคนตั้ง Trailing Stop MT5 บนคอมไว้ แล้วเปิดมือถือดูเห็น SL ขยับขึ้นเรื่อย ๆ จนนึกว่าแอปมือถือทำ Trailing Stop ได้เอง ความจริงคือคนที่ขยับคือโปรแกรมบนคอม ทุกครั้งที่มันเลื่อน SL ระดับใหม่จะถูกส่งไปเก็บที่เซิร์ฟเวอร์ของโบรกเกอร์ ทุกเครื่องที่ล็อกอินบัญชีเดียวกันจึงเห็นค่าเดียวกัน

เข้าใจตรงนี้แล้วจะรู้ทันทีว่าต้องระวังอะไร ถ้าคอมเครื่องนั้นปิด สลีป หรือเน็ตหลุด SL ที่มือถือแสดงจะหยุดอยู่ที่ระดับสุดท้าย และจะไม่ขยับอีกแม้ราคาจะวิ่งไปไกล แอปมือถือไม่ได้รับช่วงต่อ และถ้าคุณล็อกอินบัญชีเดียวกันบนคอมอีกเครื่อง ค่า Trailing Stop ก็ไม่ตามไป เพราะมันอยู่ในโปรแกรมของเครื่องที่ตั้งเท่านั้น

ถ้าจะทดสอบว่าเข้าใจถูก ลองในบัญชีทดลอง ตั้ง Trailing Stop บนคอม แล้วดู SL บนมือถือขณะราคาวิ่ง จากนั้นปิดโปรแกรมบนคอมแล้วดูต่อ คุณจะเห็นว่า SL บนมือถือหยุดขยับทันที

ทางเลือกแทนการตั้ง Trailing Stop MT5 มือถือ: สี่แบบที่ใช้ได้จริง

เมื่อรู้แล้วว่าต้องมีเครื่องที่เปิดโปรแกรมค้างไว้ คำถามที่เหลือคือจะใช้เครื่องไหน และมือถือมีบทบาทแค่ไหน ตารางนี้เทียบทางเลือกที่คนใช้มือถือเป็นหลักเลือกกันจริง

ทางเลือกใครเป็นคนไล่ SLมือถือทำอะไรข้อจำกัด
1. MT5 บนคอมที่บ้านโปรแกรมบนคอมดูไม้และ SLคอมต้องเปิดตลอด ไฟดับหรือเน็ตบ้านหลุดก็หยุด
2. MT5 บน Windows VPSโปรแกรมบน VPSดูไม้ และเข้าไปตั้งค่าผ่าน Windows Appมีค่าเช่า VPS และต้องเรียนวิธีเชื่อมต่อ
3. EA ที่มีระบบไล่ SLEA บนคอมหรือ VPSดูผลต้องรู้ว่า EA ตัวนั้นไล่ SL ยังไง และทดสอบก่อน
4. เลื่อน SL เองคุณเองแก้ SL ด้วย Modify positionไม่อัตโนมัติ ต้องดูจอตามจังหวะ

คนที่มีไม้ค้างข้ามคืนบ่อยมักจบที่ทางเลือกที่ 2 เพราะไม่ต้องพึ่งไฟและเน็ตที่บ้าน ส่วนคนที่เทรดเป็นครั้งคราวและอยู่หน้าจอได้บ้าง ทางเลือกที่ 4 ก็พอ ไม่ต้องมีค่าใช้จ่ายเพิ่ม

ตั้ง Trailing Stop บน VPS แล้วใช้มือถือดูแล

ทางเลือกที่ 1 และ 2 ใช้ขั้นตอนเดียวกัน ต่างกันแค่โปรแกรม MT5 อยู่ที่ไหน ขั้นตอนด้านล่างเขียนสำหรับ VPS เพราะเป็นกรณีที่คนตั้งจากมือถือได้ตลอด

[eabull_photo file="trailing-stop-mt5-mobile/server-rack-green-lights-vps-trailing-stop.webp" alt="ตู้เซิร์ฟเวอร์ในห้องมืดที่มีไฟสีเขียว เครื่องแบบที่ VPS ใช้เปิด MT5 ค้างไว้ให้ Trailing Stop ไล่ SL ได้ตลอด" caption="ตั้ง Trailing Stop ใน MT5 บน VPS ครั้งเดียว แล้วใช้มือถือคอยดูไม้" w="1200" h="675" credit="ภาพ: Tyler / Unsplash"]

  1. เชื่อมต่อ VPS จากมือถือ

    เปิดแอป Windows App ของ Microsoft แล้วเข้าเครื่อง VPS ด้วยที่อยู่และบัญชีผู้ใช้ที่ผู้ให้บริการส่งมา หน้าจอ Windows ของ VPS จะขึ้นบนมือถือ

  2. เปิด MT5 และหาไม้

    เปิดโปรแกรม MT5 ที่ล็อกอินบัญชีเดียวกับในมือถือ ไปที่แท็บ Trade ในหน้าต่าง Toolbox

  3. ตั้ง Trailing Stop ที่ไม้

    แตะค้างหรือคลิกขวาที่ไม้ ชี้ที่ Trailing Stop แล้วเลือกระยะ ระยะที่เลือกเป็นหน่วย point

  4. ออกจาก VPS โดยไม่ปิดโปรแกรม

    ตัดการเชื่อมต่อด้วยการปิดหน้าต่างรีโมต อย่าเลือก Sign out หรือ Shut down เพราะ MT5 จะถูกปิดไปด้วย และ Trailing Stop ก็หยุด

  5. ดูผลจากแอป MT5

    เปิดแอป MT5 บนมือถือ ดูแท็บ Trade เมื่อไม้กำไรเกินระยะที่ตั้ง SL จะเริ่มขยับตาม

การกดเมนูบนหน้าจอ Windows ผ่านมือถือต้องใช้ความคุ้นเคยสักหน่อย ถ้ายังไม่เคยเข้าคอมจากระยะไกลมาก่อน อ่านหลักการของ Remote Desktop และการเข้า VPS จากที่อื่นก่อน จะเข้าใจว่าตอนตัดการเชื่อมต่อ โปรแกรมบน VPS ยังทำงานต่อได้ยังไง

ใช้ EA ที่ไล่ SL ให้ ต้องเช็กอะไร

Trailing Stop ที่มากับ MT5 ใช้ระยะคงที่ค่าเดียว ถ้าอยากได้เงื่อนไขมากกว่านั้น เช่น ให้เริ่มไล่หลังกำไรถึงระดับหนึ่ง หรือให้ระยะยืดหดตามความผันผวน ต้องใช้ EA หรือโปรแกรมเสริมที่เขียนกฎนี้ไว้ แต่เงื่อนไขเรื่องเครื่องยังเหมือนเดิม คือแอปมือถือรัน EA ไม่ได้ EA ต้องติดอยู่บนกราฟใน MT5 บนคอมหรือ VPS และปุ่ม Algo Trading ต้องเปิดอยู่

  • EA ไล่ SL ของไม้แบบไหน เฉพาะไม้ที่มันเปิดเอง หรือไม้ที่คุณเปิดด้วยมือด้วย
  • ไล่ทุกครั้งที่ราคาขยับ หรือรอให้ราคาขยับครบระยะก่อนจึงแก้ SL หนึ่งครั้ง
  • อย่าตั้ง Trailing Stop จากเมนูซ้อนกับ EA ที่ไล่ SL ไม้เดียวกัน เพราะจะมีสองตัวแก้ SL พร้อมกัน
  • ทดสอบในบัญชีทดลองก่อน แล้วดูจากมือถือว่า SL ขยับตามที่คาดจริง

ถ้าคุณสนใจระยะที่ปรับตามความผันผวนของทอง แทนระยะตายตัว วิธีคิดอยู่ในบท ไล่ SL ด้วยระยะจากค่า ATR ส่วนบริการ Virtual Hosting ของ MetaQuotes ที่ย้าย EA ขึ้นเซิร์ฟเวอร์ให้ คู่มือการย้ายพูดถึง EA และ Indicator บนกราฟ ไม่ได้พูดถึง Trailing Stop ที่ตั้งจากเมนู ถ้าจะใช้ทางนี้ ให้ถือว่าต้องเป็น EA ที่ไล่ SL เอง

เลื่อน SL เองบนมือถือ: Trailing แบบทำมือ

ถ้าไม่มีคอมหรือ VPS เลย คุณยังทำสิ่งที่ Trailing Stop ทำได้ด้วยมือ คือเลื่อน SL ตามราคาเป็นช่วง ๆ ขั้นตอนบนแอปทั้ง Android และ iPhone เหมือนกัน คือไปที่แท็บ Trade เลือกไม้ แล้วเปิดเมนู Modify position ปรับค่า SL ด้วยปุ่มลบและบวกข้างช่อง หรือแตะช่องเพื่อพิมพ์ แล้วกด Modify ปุ่มนี้จะกดไม่ได้จนกว่าค่าที่ใส่จะอยู่ในระยะที่โบรกเกอร์ยอมรับ

สิ่งที่ทำให้วิธีนี้ได้ผลคือกติกาที่ตั้งไว้ก่อน ไม่ใช่การเลื่อนตามความรู้สึก ลองดูตัวอย่างสมมติกับไม้ Buy XAUUSD ที่ตั้งกติกาว่า "ทุกครั้งที่ราคาขึ้นจากจุดเลื่อนครั้งก่อนครบ 4.00 ดอลลาร์ ให้เลื่อน SL ขึ้น 4.00 ดอลลาร์"

ให้มือถือแจ้งเตือนเมื่อไม้ถูกปิด

ถ้าให้คอมหรือ VPS ไล่ SL แทน มือถือก็ควรรู้ทันทีเมื่อไม้ถูกปิด MT5 บนคอมส่งการแจ้งเตือนแบบ Push ไปที่แอปมือถือได้ ตาม คู่มือการตั้งค่าโปรแกรม MetaTrader 5 (ตรวจเมื่อ พ.ย. 2569)

  1. หา MetaQuotes ID ในมือถือ

    เปิดแอป MT5 ไปที่ส่วน Messages จะเห็นรหัส MetaQuotes ID ของเครื่องนั้น

  2. ใส่รหัสในโปรแกรมบนคอม

    บน MT5 ในคอมหรือ VPS ไปที่ Tools → Options → แท็บ Notifications ติ๊ก Enable Push Notifications แล้วใส่ MetaQuotes ID ใส่ได้สูงสุด 4 รหัส คั่นด้วยจุลภาค

  3. ทดสอบ

    กดปุ่ม Test แล้วดูว่ามือถือได้รับข้อความ

ตามคู่มือ การแจ้งเตือนจากโปรแกรมในเครื่องจะส่งเมื่อมีรายการซื้อขายที่สำเร็จ แต่ต้องเปิดโปรแกรมไว้ ส่วนการแจ้งเตือนจากเซิร์ฟเวอร์ไม่ต้องเปิดโปรแกรม แต่ขึ้นกับว่าโบรกเกอร์เปิดให้ใช้หรือไม่ ถ้าใช้ VPS อยู่แล้ว แบบแรกก็เพียงพอ

MT5 Android Trailing Stop มีไหม?

คู่มือแอป MT5 Android ทางการไม่มีคำสั่ง Trailing Stop ในหมวด Trade สิ่งที่ทำได้บนแอปคือตั้งและแก้ SL TP ด้วย Modify position ถ้าอยากให้ SL ไล่ตามราคาเอง ต้องตั้งบนโปรแกรม MT5 ในคอมหรือ VPS

Trailing Stop MetaTrader 5 Mobile บน iPhone ตั้งได้ไหม?

ไม่ได้เช่นกัน คู่มือฉบับ iPhone มีหัวข้อแก้ไขไม้ คำสั่งรอ และคำสั่งกลุ่ม แต่ไม่มี Trailing Stop ทางที่ใช้ได้คือเข้า VPS ด้วยแอป Windows App แล้วตั้งบนโปรแกรมในนั้น

ตั้ง Trailing Stop บนคอมแล้ว ปิดคอมแล้วให้มือถือทำต่อได้ไหม?

ไม่ได้ เมื่อปิดโปรแกรมบนคอม Trailing Stop จะหยุดทันที SL จะค้างอยู่ที่ระดับสุดท้ายที่เลื่อนไว้ แอปมือถือแค่แสดงค่านั้น ไม่ได้รับช่วงไล่ต่อ

อยากใช้ Trailing Stop ต้องเช่า VPS ไหม?

ไม่จำเป็นเสมอไป ถ้าคอมที่บ้านเปิดได้ตลอดช่วงที่มีไม้ค้างก็ใช้ได้ แต่ถ้าไม้ค้างข้ามคืนบ่อย หรือไฟและเน็ตที่บ้านไม่นิ่ง VPS จะช่วยให้โปรแกรมเปิดอยู่ต่อเนื่องกว่า

รู้ได้ยังไงว่า Trailing Stop บน VPS ยังทำงานอยู่?

ดูจากมือถือว่า SL ขยับตามเมื่อไม้กำไรเกินระยะที่ตั้ง และเข้าไปดู VPS เป็นระยะว่า MT5 ยังเปิดและต่อเซิร์ฟเวอร์อยู่ ถ้าเพิ่งรีสตาร์ต VPS ให้เช็กว่าโปรแกรมถูกเปิดกลับมาแล้ว

สรุป: มือถือดูแล ส่วนคอมหรือ VPS เป็นคนไล่ SL

คำตอบของการตั้ง Trailing Stop MT5 มือถือ คือแอปทำเองไม่ได้ แต่คุณยังใช้ Trailing Stop ได้ครบ ถ้าแบ่งหน้าที่ให้ถูก โปรแกรมบนคอมหรือ VPS เป็นคนไล่ SL มือถือเป็นตัวดู ตัวรับแจ้งเตือน และตัวเข้าไปสั่งงานผ่าน Windows App เมื่อต้องการ ถ้าไม่มีเครื่องอื่นเลย ให้ตั้งกติกาเลื่อน SL เองให้ชัด แล้วทำตามนั้น

หลักเดียวกันนี้ใช้กับ EA ทุกตัว เพราะ EA ก็ต้องรันบนโปรแกรมที่เปิดค้างไว้ EA BULL จึงทำคู่มือ VPS ไว้ให้อ่านฟรี เริ่มจาก วิธีตั้ง Windows VPS ให้ MT5 เปิดได้ทั้งวัน ซึ่งไล่ตั้งแต่เชื่อมต่อเครื่องจนย้ายโปรแกรมขึ้นไป ค่าเช่า VPS ไม่รวมในแพ็กเกจของเรา ถ้าเลือก VIP ทีมงานติดตั้งให้บนคอมหรือ VPS ของคุณ และถ้ายังไม่แน่ใจว่าควรใช้ VPS ไหม ถามทีมงานทาง LINE ได้

อ่านต่อ

  • Remote Desktop คืออะไร: ควบคุม VPS ระยะไกลเพื่อดูแล EA
  • Trailing Stop คืออะไร: เลื่อน Stop Loss ตามราคาอัตโนมัติ
  • แก้ไขออเดอร์ MT5: เลื่อน SL TP และแก้คำสั่งรอ
  • Windows App คืออะไร: แอปเข้า VPS จากมือถือที่มาแทน Remote Desktop
