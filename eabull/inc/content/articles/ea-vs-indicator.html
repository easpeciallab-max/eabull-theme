EA กับ Indicator ต่างกันที่หน้าที่ EA หรือ Expert Advisor คือโปรแกรมที่เปิด ปิด และแก้ออเดอร์ให้เองตลอดเวลาที่ติดอยู่บนกราฟ ส่วน Indicator ทำได้แค่คำนวณและแสดงผล เช่น วาดเส้นหรือลูกศร แต่ส่งคำสั่งซื้อขายไม่ได้ ใน MT5 ยังมี Script ที่ทำงานรอบเดียวแล้วจบ และ Service ที่ทำงานเบื้องหลัง แต่ละแบบมีโฟลเดอร์ของตัวเองใน MQL5

สรุปสั้น

  • EA เทรดได้ต่อเนื่อง หนึ่งกราฟรันได้ตัวเดียว ส่วน Indicator ซื้อขายไม่ได้ แต่ใส่บนกราฟได้ไม่จำกัด
  • Script ทำงานครั้งเดียวแล้วหลุดจากกราฟ ส่วน Service ไม่ผูกกับกราฟใดเลย
  • ไฟล์ที่ใช้งานได้ทุกแบบเป็นนามสกุล .ex5 ดูนามสกุลอย่างเดียวจึงแยกไม่ออก
  • วางไฟล์ให้ตรงโฟลเดอร์ใน MQL5 คือ Experts, Indicators, Scripts หรือ Services แล้วกด Refresh
  • ไฟล์ .ex4 เป็นของ MT4 ใช้กับ MT5 ไม่ได้ไม่ว่าจะเป็นแบบไหน

ตารางเทียบสั้น ๆ ของสามแบบนี้อยู่ใน ภาพรวมบอทเทรดทองบน MT5 แล้ว บทนี้ลงรายละเอียดว่าแต่ละแบบทำงานต่างกันอย่างไร ไฟล์ไหนอยู่ตรงไหน และจะรู้ได้ยังไงว่าไฟล์ที่ผู้ขายส่งมาเป็นบอทจริง

EA กับ Indicator ต่างกันยังไง: ดูจากหน้าที่

MT5 แบ่งโปรแกรมเสริมเป็นสี่ชนิด ข้อมูลในตารางสรุปจาก คู่มือ MQL5 เรื่องการทำงานของโปรแกรม (ตรวจเมื่อ พ.ย. 2569)

ชนิดทำอะไรส่งคำสั่งซื้อขายได้ไหมทำงานเมื่อไหร่ต่อกราฟ
Expert Advisor (EA)ตัดสินใจและดูแลออเดอร์ได้ทุกครั้งที่ราคาใหม่เข้ามา ตลอดเวลาที่ติดอยู่ครั้งละ 1 ตัว
Indicatorคำนวณและวาดผลบนกราฟไม่ได้ทุกครั้งที่ราคาเปลี่ยนไม่จำกัดจำนวน
Scriptทำงานชุดเดียวตามที่เขียนไว้ได้ครั้งเดียวตอนวางลงกราฟ แล้วหลุดออกเองไม่ได้อยู่ค้าง
Serviceงานเบื้องหลังที่ไม่ต้องใช้กราฟไม่ใช่งานหลักของมันเริ่มเองเมื่อเปิด MT5 ถ้าเคยเปิดไว้ก่อนปิดโปรแกรมไม่ผูกกับกราฟ

ที่ Indicator ส่งคำสั่งไม่ได้ ไม่ใช่เพราะคนเขียนไม่ใส่ แต่เพราะภาษา MQL5 ห้ามไว้ คำสั่งอย่าง OrderSend ใช้ในโปรแกรมชนิด Indicator ไม่ได้ อีกเรื่องที่น่ารู้คือ Indicator ทุกตัวบนสัญลักษณ์เดียวกันใช้เธรดการทำงานร่วมกัน ถ้า Indicator ตัวหนึ่งค้าง ตัวอื่นบนสัญลักษณ์นั้นจะค้างตาม ส่วน EA กับ Script มีเธรดของตัวเอง ตัวหนึ่งช้าไม่ได้ฉุดตัวอื่น

ไฟล์ ex5 คืออะไร และบอกได้ไหมว่าเป็น EA หรือ Indicator

ไฟล์ ex5 คือไฟล์ที่คอมไพล์จากโค้ดต้นฉบับ .mq5 แล้ว MT5 ใช้ไฟล์นี้รันโปรแกรมทุกชนิด ทั้ง EA Indicator Script และ Service นามสกุลจึงบอกได้แค่ว่าเป็นโปรแกรมของ MT5 ไม่ได้บอกว่าเป็นชนิดไหน และเพราะเป็นไฟล์ที่คอมไพล์แล้ว คุณเปิดดูกฎข้างในไม่ได้

นามสกุลคืออะไรคนใช้บอทต้องสนใจไหม
.ex5โปรแกรมที่พร้อมรันบน MT5ต้อง เป็นไฟล์ที่คุณวางลงโฟลเดอร์
.mq5โค้ดต้นฉบับ แก้ได้และต้องคอมไพล์ก่อนใช้เฉพาะเมื่อได้โค้ดมาด้วย
.mqhส่วนประกอบของโค้ดที่โปรแกรมอื่นดึงไปใช้ไม่ต้อง ถ้าไม่ได้เขียนโปรแกรม
.setชุดค่าตั้ง Inputs ที่บันทึกไว้ โหลดกลับเข้า EA ได้ต้อง ถ้าผู้พัฒนาส่งค่าตั้งมาเป็นไฟล์
.dllโปรแกรมภายนอกที่บาง EA เรียกใช้ต้องระวัง เปิด Allow DLL imports ให้เฉพาะผู้พัฒนาที่ไว้ใจ
.ex4 และ .mq4ไฟล์ของ MT4ใช้กับ MT5 ไม่ได้ ต้องขอรุ่น MT5

วิธีรู้ว่าไฟล์ .ex5 ในมือเป็นชนิดไหน มีสามทาง ทางแรกคือถามผู้ขายตรง ๆ ว่าเป็น Expert Advisor หรือ Indicator ทางที่สองคือดูว่ามันขึ้นในหัวข้อไหนของ Navigator หลังวางไฟล์ตามที่ผู้ขายบอกแล้วกด Refresh ทางที่สามคือดูตอนวางลงกราฟ ถ้าเป็น EA ที่ทำงานได้ ชื่อและไอคอนของมันจะขึ้นที่มุมขวาบนของกราฟ ส่วน Indicator จะวาดผลบนกราฟหรือในหน้าต่างย่อยด้านล่าง

วางไฟล์ให้ถูกโฟลเดอร์

เปิดโฟลเดอร์ข้อมูลด้วยเมนู File → Open Data Folder แล้วเข้าโฟลเดอร์ MQL5 ข้างในแบ่งตามชนิดโปรแกรม รายชื่อโฟลเดอร์อ้างอิง คู่มือโครงสร้างโฟลเดอร์ของ MetaEditor

Indicator MT5: ทำอะไรได้ และทำอะไรไม่ได้

Indicator MT5 มีทั้งแบบมาตรฐานที่ติดมากับโปรแกรม และแบบ Custom ที่คนเขียนเพิ่ม ทั้งสองแบบอยู่ในขอบเขตเดียวกัน

  • คำนวณค่าจากราคา เช่น เส้นค่าเฉลี่ย หรือแรงซื้อขาย แล้ววาดบนกราฟ
  • วาดลูกศรหรือเครื่องหมายเมื่อเงื่อนไขครบ และหลายตัวส่งเสียงเตือนได้
  • ให้ EA เรียกค่าไปใช้ตัดสินใจ ถ้า EA ถูกเขียนมาให้อ่าน Indicator ตัวนั้น
  • เปิด ปิด หรือแก้ออเดอร์ไม่ได้ ลูกศรซื้อที่ขึ้นบนจอเป็นแค่ภาพ
  • ไม่ได้ดูแลไม้ที่คุณเปิดค้างไว้ ไม่ว่าจะตั้งค่าแบบไหน
  • ทดสอบผลกำไรขาดทุนตรง ๆ ไม่ได้ ต้องมี EA ที่เทรดตามสัญญาณของมัน

ข้อสุดท้ายสำคัญเวลามีคนขาย Indicator พร้อมภาพกราฟที่ลูกศรชี้ถูกทุกจุด ภาพแบบนั้นไม่ใช่ผลทดสอบการเทรด และบาง Indicator วาดสัญญาณในอดีตใหม่ได้ ถ้าอยากรู้ว่า Indicator แต่ละกลุ่มวัดอะไร และวิธีใส่หรือปรับค่าบนกราฟ อ่านต่อในบท Indicator มีกี่แบบ และใช้บนกราฟยังไง

Script MT5 และ Service: โปรแกรมที่ไม่ได้อยู่บนกราฟตลอด

Script: คำสั่งลัดที่ทำงานครั้งเดียว

Script MT5 เหมาะกับงานที่ทำเป็นครั้งคราว เช่น ปิดออเดอร์ทั้งหมดในคลิกเดียว ลบคำสั่งรอที่ค้าง หรือตั้ง Stop Loss ให้ทุกไม้พร้อมกัน วิธีใช้คือลากจากหัวข้อ Scripts ใน Navigator ไปวางบนกราฟ มันจะทำงานทันที และหลุดออกจากกราฟเองเมื่อทำเสร็จ

Script ที่ซื้อขายได้ต้องได้รับอนุญาตเหมือน EA ถ้าปุ่ม Algo Trading ปิดอยู่ มันจะรันได้แต่ส่งคำสั่งไม่ได้ และต้องระวังว่า Script ปิดออเดอร์บางตัวอาจปิดทุกไม้ในบัญชี รวมถึงไม้ที่บอทกำลังดูแลอยู่ อ่านคำอธิบายของ Script ก่อนใช้ทุกครั้ง

Service: งานเบื้องหลังที่ไม่ต้องเปิดกราฟ

Service ไม่ผูกกับกราฟใด จึงไม่หายไปเมื่อคุณปิดกราฟ และถ้าเปิดค้างไว้ตอนปิด MT5 มันจะเริ่มทำงานเองเมื่อเปิดโปรแกรมครั้งถัดไป จัดการได้จากหัวข้อ Services ใน Navigator โดยคลิกขวาแล้วเลือก Add service คนใช้บอททั่วไปแทบไม่ต้องยุ่งกับส่วนนี้ ยกเว้นผู้พัฒนาส่งมาให้และบอกวิธีใช้ไว้

เปลี่ยนกราฟหรือโหลดเทมเพลตแล้ว โปรแกรมแต่ละแบบเป็นยังไง

คนใช้บอทมักแปลกใจว่าทำไมบอทหายไปจากกราฟ หรือทำไม Indicator ตั้งค่าใหม่เอง สาเหตุส่วนใหญ่อยู่ในตารางนี้ ซึ่งสรุปจากคู่มือ MQL5 หน้าเดียวกับข้างบน

แถวที่สองควรจำไว้ บอทที่ถูกเปลี่ยนไปอยู่บนสัญลักษณ์อื่นจะทำงานต่อกับสินค้าใหม่ทันที ถ้าในหน้า Options ไม่ได้ตั้งให้ปิดการเทรดอัตโนมัติเมื่อเปลี่ยนสัญลักษณ์หรือกรอบเวลา บอทที่ทำมาสำหรับทองอาจไปเปิดไม้บนคู่เงินอื่นได้ ความหมายของสวิตช์เหล่านี้อธิบายไว้ในบท สวิตช์ Algo Trading ใน MT5

ซื้อบอทแต่ได้ Indicator: เช็กก่อนจ่าย

การขาย Indicator ไม่ใช่เรื่องผิด แต่ถ้าผู้ซื้อแยก EA กับ Indicator ไม่ออก แล้วเข้าใจว่าได้โปรแกรมที่เทรดให้ เขาจะผิดหวังตั้งแต่วันแรก ถามคำถามเหล่านี้ก่อนโอนเงินทุกครั้ง

[eabull_photo file="ea-vs-indicator/desk-printed-charts-check-before-paying.webp" alt="โต๊ะทำงานที่มีรายงานกราฟพิมพ์ออกมาและมือถือเปิดเครื่องคิดเลข ก่อนจ่ายเงินให้ขอดูผลทดสอบการเทรด ไม่ใช่แค่ภาพลูกศรบนกราฟ" caption="ภาพประกอบ: บอทจริงทดสอบใน Strategy Tester ได้ และมีรายงานผลเป็นตัวเลข" w="1200" h="675" credit="ภาพ: Jakub Żerdzicki / Unsplash"]

  1. ถามชนิดของโปรแกรม

    เป็น Expert Advisor ที่เปิดปิดออเดอร์เองใช่ไหม หรือเป็น Indicator ที่แค่แสดงสัญญาณ

  2. ถามว่าต้องใช้ไฟล์อื่นประกอบไหม

    เช่น Indicator เฉพาะ ไฟล์ค่าตั้ง .set หรือไฟล์ DLL ถ้ามี DLL ให้ถามเหตุผลที่ต้องใช้

  3. ถามว่าเป็นไฟล์ของ MT5

    ต้องเป็น .ex5 ถ้าได้ .ex4 คือของ MT4 ซึ่งบัญชี MT5 ใช้ไม่ได้

  4. ขอดูผลทดสอบการเทรด ไม่ใช่ภาพลูกศร

    บอทจริงทดสอบใน Strategy Tester ได้ และมีรายงานผลเป็นตัวเลข

ถ้าตัดสินใจซื้อแล้ว ขั้นตอนตั้งแต่คุยกับผู้ขายจนได้ไฟล์ อยู่ในบท ซื้อบอทเทรดทองบน MT5 อย่างรอบคอบ

คำถามที่พบบ่อยเรื่อง EA Indicator และ Script

เปลี่ยน Indicator ให้เป็น EA ได้ไหม?

ไม่ได้แปลงตรง ๆ แต่เขียน EA ขึ้นมาใหม่ให้อ่านค่าหรือสัญญาณจาก Indicator ตัวนั้นแล้วเทรดตามได้ ต้องรู้ว่าค่าที่ Indicator ส่งออกมาหมายถึงอะไร และต้องทดสอบ EA นั้นเหมือนบอททั่วไป

ไฟล์ ex5 เปิดดูโค้ดข้างในได้ไหม?

ไม่ได้ ไฟล์ .ex5 เป็นไฟล์ที่คอมไพล์แล้ว คนที่แก้โค้ดได้คือคนที่มีไฟล์ต้นฉบับ .mq5 ถ้าอยากรู้ว่าบอทเทรดด้วยกฎอะไร ให้ถามผู้พัฒนาหรืออ่านคู่มือของบอท

EA ใช้ค่าจาก Indicator ที่เราใส่บนกราฟไหม?

โดยทั่วไป EA คำนวณค่า Indicator ที่ต้องใช้เองภายในโปรแกรม เส้นที่คุณใส่บนกราฟจึงเป็นแค่ภาพให้คุณดู ลบออกหรือเปลี่ยนค่าก็ไม่ได้เปลี่ยนการตัดสินใจของบอท ยกเว้นคู่มือของบอทจะบอกไว้เป็นอย่างอื่น

ทำไมลาก EA ตัวใหม่ลงกราฟแล้วตัวเก่าหายไป?

เพราะหนึ่งกราฟรัน EA ได้ครั้งละตัว ตัวใหม่จะแทนที่ตัวเก่าทันที ถ้าอยากรันสองตัวพร้อมกัน ให้เปิดกราฟใหม่อีกหน้าต่างแล้ววางแยกกัน และคิดความเสี่ยงรวมของทั้งสองตัวด้วย

Script MT5 ใช้ปิดออเดอร์ทั้งหมดได้ไหม?

ได้ ถ้ามี Script ที่เขียนมาเพื่องานนี้ วางลงกราฟแล้วมันจะทำงานรอบเดียว แต่ต้องเปิดสิทธิ์ Algo Trading ไว้ และควรรู้ก่อนว่า Script ตัวนั้นปิดเฉพาะไม้ของสัญลักษณ์บนกราฟ หรือปิดทุกไม้ในบัญชี

สรุป: ถ้าอยากให้มีโปรแกรมเทรดแทน ต้องเป็น EA

EA กับ Indicator ทำงานร่วมกันได้ แต่ทำหน้าที่ต่างกันชัดเจน EA เป็นตัวตัดสินใจและส่งคำสั่ง Indicator เป็นเครื่องวัด Script เป็นคำสั่งลัด และ Service เป็นงานเบื้องหลัง ถ้าเป้าหมายของคุณคือไม่ต้องกดเอง สิ่งที่ต้องมีคือไฟล์ EA นามสกุล .ex5 ที่วางในโฟลเดอร์ Experts แล้วเปิดสิทธิ์ให้มันเทรด วิธีทำทีละขั้นหลังจากนั้นอยู่ในบท เปิดให้บอทเทรดบน MT5 ทีละขั้น

ลูกค้า EA BULL แพ็กเกจ Pro ติดตั้ง EA เองได้ตามหน้า วิธีวางไฟล์ EA ในโฟลเดอร์ Experts พร้อมภาพ ส่วนแพ็กเกจ VIP ทีมงานลงให้บนคอมหรือ VPS และตรวจค่าตั้งก่อนเริ่มรัน ถ้าได้ไฟล์มาแล้วไม่แน่ใจว่าวางถูกที่หรือยัง ทักถามทีมงานได้
