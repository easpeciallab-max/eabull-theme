Visual Mode MT5 คือการทดสอบ EA ใน Strategy Tester แบบเปิดภาพ โปรแกรมจะเปิดหน้าต่างแยกที่เล่นราคาย้อนหลังบนกราฟ และวาดทุกออเดอร์ที่ EA เปิดปิดให้เห็นทันที คุณหยุดชั่วคราว เร่ง หรือชะลอได้ตามต้องการ เหมาะกับการตรวจว่า EA เข้าไม้ตรงจุดที่ควรเข้าหรือเปล่า แต่ไม่เหมาะกับการเก็บสถิติช่วงยาว เพราะช้ากว่าการทดสอบปกติมาก

สรุปสั้น

  • เปิดด้วยการติ๊ก Visualization ในแท็บ Settings ปิด Optimization และใช้ Agent ในเครื่อง
  • หน้าต่างภาพมีกราฟ Market Watch Data Window และ Toolbox เหมือนโปรแกรมเทรดย่อส่วน
  • แถบเครื่องมือใช้หยุดชั่วคราว เร่ง ชะลอ และกระโดดไปวันที่ต้องการได้
  • ใส่ Indicator บนกราฟทดสอบได้ด้วยเทมเพลตที่ตั้งชื่อตรงกับชื่อ EA
  • ทดสอบช่วงยาวแบบปกติแล้วค่อยดูดีลบนกราฟทีหลังก็ได้ ด้วยคำสั่ง Open Chart

โหมดนี้เป็นทางกลางระหว่างการเลื่อนกราฟดูเองกับการปล่อยให้โปรแกรมรันจนจบแล้วอ่านแค่ตัวเลข ถ้าอยากเห็นภาพรวมของทั้งสองแบบก่อน อ่าน Backtest คือ อะไร ต่างจากทดสอบด้วยมือยังไง แล้วกลับมาเปิดโหมดเห็นกราฟตามขั้นตอนในบทนี้

Visual Mode MT5 คืออะไร ต่างจากทดสอบปกติยังไง

คู่มือของ MetaTrader อธิบายโหมดนี้ว่าใช้ดูให้เห็นว่า EA ทำรายการเทรดอย่างไรระหว่างทดสอบย้อนหลัง ทุกดีลจะขึ้นบนกราฟของสัญลักษณ์นั้น หน้าต่างภาพทำงานแยกจากโปรแกรมหลัก เหมือนมี MT5 อีกตัวที่เวลาเดินย้อนหลังอยู่ คนไทยหลายคนเรียกวิธีนี้ว่า Backtest แบบเห็นกราฟ เพราะได้ดูราคาเดินทีละแท่งพร้อมกับเห็น EA ตัดสินใจไปด้วย

โหมดนี้ยังใช้ทดสอบ Indicator ได้ด้วย ถ้าเลือกประเภทโปรแกรมเป็น Indicators โปรแกรมจะเปิดภาพให้อัตโนมัติ เหมาะกับการดูรุ่นทดลองของ Indicator ว่าวาดอะไรบนราคาในอดีตก่อนตัดสินใจซื้อ

Strategy Tester Visualization: เปิดใช้ทีละขั้น

ตัวเลือก Strategy Tester Visualization อยู่ในแท็บ Settings แต่จะใช้ได้เมื่อเงื่อนไขอื่นครบด้วย ขั้นตอนนี้อ้างอิงคู่มือ MetaTrader 5 ทางการ (ตรวจเมื่อ พ.ย. 2569)

  1. เปิด Strategy Tester แล้วเลือก EA

    กด Ctrl+R เลือก EA สัญลักษณ์ และ Timeframe ที่ต้องการดู Timeframe ที่เลือกตรงนี้คือ Timeframe ของกราฟในหน้าต่างภาพ เปลี่ยนทีหลังไม่ได้

  2. ตั้งช่วงวันที่ให้สั้น

    เริ่มจากไม่กี่วันถึงไม่กี่สัปดาห์ที่มีเหตุการณ์ที่อยากดู ช่วงยาวจะใช้เวลานานโดยไม่จำเป็น

  3. ปิด Optimization

    โหมดเห็นกราฟใช้ได้กับการทดสอบรอบเดียวเท่านั้น ถ้าเปิด Optimization ไว้ ช่อง Visualization จะใช้ไม่ได้

  4. ติ๊ก Visualization

    เลือกโหมดจำลองราคาตามที่ต้องการ ถ้าจะดูพฤติกรรมช่วง Spread กว้างหรือระยะตัดขาดทุนแคบ ใช้โหมด tick จริง

  5. เช็กว่าใช้ Agent ในเครื่อง

    ถ้าเลือก Agent ระยะไกลอยู่ ไปที่แท็บ Agents คลิกขวาที่ Agent ในเครื่องแล้วเลือก Select

  6. กด Start

    หน้าต่างภาพจะเปิดขึ้นแยกจากโปรแกรมหลัก และเริ่มเล่นราคาตามช่วงวันที่ที่ตั้งไว้

ทุกช่องในแท็บ Settings ทั้งการหน่วงเวลา ทุน และเลเวอเรจ ยังมีผลเหมือนการทดสอบปกติ ความหมายของแต่ละช่องสรุปไว้ในบท แผนที่เมนู Strategy Tester MT5

หน้าต่างภาพมีอะไรให้ดูบ้าง

หน้าต่างภาพเหมือนโปรแกรมเทรดขนาดย่อ มีสี่ส่วนหลัก เปิดปิดได้จากเมนู View หรือปุ่มลัด

ส่วนปุ่มลัดใช้ดูอะไร
กราฟไม่มีราคาที่จำลองระหว่างทดสอบ ดีลขึ้นเป็นเครื่องหมาย Buy และ Sell พร้อมเส้นประเชื่อมจุดเข้ากับจุดออก ปรับได้แค่ชนิดกราฟ กริด และสเกล
Market WatchCtrl+Mราคาปัจจุบันของการทดสอบ หัวหน้าต่างบอกเวลาจำลอง แท็บ Ticks แสดงกราฟ tick ได้ถึง 64,000 tick
Data WindowCtrl+Dราคาเปิด สูงสุด ต่ำสุด ปิด เวลา Spread ปริมาณ และค่า Indicator ตรงจุดที่เมาส์ชี้
ToolboxCtrl+Tแท็บ Trade History Operations และ Journal ของการทดสอบ

แท็บที่มีประโยชน์ที่สุดใน Toolbox คือ Operations มันจดทุกคำขอที่ EA ส่ง ไม่ใช่แค่ซื้อขาย แต่รวมการแก้คำสั่งรอและการขยับจุดตัดขาดทุนด้วย ถ้า EA แก้ไม้ถี่ผิดปกติ จะเห็นจากแท็บนี้ทันที ส่วนแท็บ History สลับดูได้สามแบบจากเมนูคลิกขวา คือเฉพาะดีล เฉพาะคำสั่ง หรือทั้งสองแบบเป็นแผนผังต่อกัน

ระหว่างที่หน้าต่างภาพเปิดอยู่ บันทึกของ Agent จะไม่ถูกส่งกลับไปที่ Strategy Tester ในโปรแกรมหลัก ถ้าอยากอ่านจากโปรแกรมหลัก ใช้คำสั่ง Journals of local agents ในเมนูคลิกขวา รายละเอียดของทุกส่วนอยู่ใน คู่มือ Testing Visualization ของ MetaTrader 5

ควบคุมการเล่น: หยุด เร่ง ชะลอ และข้ามไปวันที่ต้องการ

คู่มือระบุว่าแถบเครื่องมือของหน้าต่างภาพใช้หยุดชั่วคราว เร่ง หรือชะลอการทดสอบได้ และกระโดดไปยังวันที่ที่ต้องการในช่วงทดสอบได้ ส่วนปุ่มลัดของแต่ละคำสั่ง โปรแกรมเขียนไว้ข้างชื่อคำสั่งในเมนู วิธีใช้ให้คุ้มเวลาคือเร่งผ่านช่วงที่ไม่สำคัญ แล้วชะลอตรงช่วงที่อยากดู

ตัวอย่างการใช้งานแบบสมมติ คุณทดสอบช่วงสองสัปดาห์ และอยากรู้ว่าทำไม EA เปิดไม้ในวันพุธบ่าย ให้กระโดดไปวันอังคาร แล้วชะลอความเร็วลงเมื่อเข้าใกล้ช่วงเวลานั้น พอเห็นไม้เปิด กดหยุดชั่วคราว เลื่อนเมาส์ไปที่แท่งที่ EA เข้าไม้ แล้วอ่าน Data Window ว่าราคา Spread และค่า Indicator ตอนนั้นเป็นเท่าไหร่ จากนั้นเปิดแท็บ Operations ดูว่า EA ส่งคำขออะไรไปบ้าง

จดสิ่งที่เห็นไว้ทุกครั้ง เช่น วันเวลา ราคา และสิ่งที่ EA ทำ เวลาถามผู้พัฒนาว่าทำไมไม้นี้เข้าตรงนี้ ข้อมูลแบบนี้ทำให้ได้คำตอบเร็วกว่าการเล่าจากความจำมาก

ใส่ Indicator บนกราฟทดสอบด้วยเทมเพลต

กราฟในหน้าต่างภาพตั้งค่าได้น้อย ถ้าอยากเห็น Indicator หรือเส้นที่ช่วยอ่าน ต้องเตรียมเทมเพลตไว้ก่อนกด Start กติกาคือชื่อเทมเพลตต้องตรงกับชื่อ EA ที่ทดสอบ เช่น EA ชื่อ ExpertMACD ใช้เทมเพลตชื่อ ExpertMACD.tpl และไฟล์ต้องอยู่ในโฟลเดอร์ /profiles/templates ของโปรแกรม

  1. จัดกราฟปกติให้หน้าตาที่ต้องการ

    เปิดกราฟธรรมดาในโปรแกรมหลัก ใส่ Indicator ตั้งสี และชนิดกราฟตามที่อยากเห็นตอนทดสอบ

  2. บันทึกเป็นเทมเพลตชื่อเดียวกับ EA

    คลิกขวาบนกราฟ เลือกบันทึกเทมเพลต แล้วตั้งชื่อให้ตรงกับชื่อ EA ทุกตัวอักษร

  3. เริ่มทดสอบแบบเห็นกราฟ

    เมื่อหน้าต่างภาพเปิด กราฟจะใช้เทมเพลตนั้นให้เอง ถ้าไม่เห็น Indicator ให้ตรวจชื่อไฟล์และโฟลเดอร์อีกครั้ง

อ่านแท่งเทียนระหว่างดู EA เทรด

ข้อดีของ Visual Mode MT5 คือคุณเห็นบริบทที่ตัวเลขในรายงานไม่บอก เช่น EA เข้าไม้ตอนแท่งใหม่เปิด หรือเข้ากลางแท่ง ไส้เทียนยาวแค่ไหนตอนที่ไม้โดนตัดขาดทุน ถ้ายังอ่านตัวเทียนกับไส้เทียนไม่คล่อง อ่านบท อ่านแท่งเทียนทองคำให้เป็น ก่อน จะดูได้เร็วขึ้นมาก ระหว่างดู ไล่เช็กรายการนี้

  • EA เข้าไม้ตามเงื่อนไขที่คู่มืออธิบายไว้จริงหรือไม่
  • ทุกไม้มีจุดตัดขาดทุนและจุดทำกำไรไหม ในแท็บ Trade ถ้าไม่ได้ตั้งไว้ ช่อง S/L หรือ T/P จะเป็นศูนย์
  • ระยะตัดขาดทุนเหมาะกับขนาดของแท่งเทียนช่วงนั้นหรือแคบจนไส้เทียนปกติก็ชน
  • ในแท็บ History แบบดูคำสั่ง ไม้ที่ปิดด้วยจุดตัดขาดทุนจะมีช่อง S/L สีแดงและคำว่า [s/l] ในคอมเมนต์ ส่วนไม้ที่ปิดด้วยจุดทำกำไรเป็นสีเขียวพร้อม [t/p]
  • EA ทำอะไรตอน Spread กว้างขึ้น ดูค่าจาก Data Window เทียบกับค่ากันสเปรดกว้างที่อธิบายในบทเรื่องค่า Max Spread ของ EA

ระวังกับดักหนึ่งข้อ การดูไม่กี่ไม้แล้วรีบแก้กฎให้ไม้ที่เห็นออกมาดี คือการปรับระบบให้เข้ากับอดีตทีละจุด ใช้โหมดนี้เพื่อเข้าใจและหาข้อผิดพลาด แล้วค่อยยืนยันการเปลี่ยนแปลงด้วยการทดสอบช่วงยาว

ดูดีลหลังทดสอบจบด้วย Open Chart

ถ้าอยากดูดีลของช่วงหลายเดือนหรือหลายปี การเปิดภาพตลอดทางจะช้าเกินไป ทางเลือกคือทดสอบแบบปกติให้จบ แล้วคลิกขวาในแท็บรายงานผลเลือก Open Chart โปรแกรมจะเปิดกราฟที่มีทุกดีลวาดไว้ ใช้เทมเพลต tester.tpl ถ้ามี หรือ default.tpl ถ้าไม่มี และ Indicator ที่ EA ใช้บนสัญลักษณ์และ Timeframe เดียวกันจะขึ้นมาด้วย เว้นแต่ EA สั่งปลดออกเองในโค้ด รายละเอียดอยู่ใน คู่มือ Strategy Testing

ข้อจำกัดของ Visual Mode

  • ช้ากว่าการทดสอบปกติมาก ไม่เหมาะกับการเก็บสถิติหรือเทียบผลหลายชุด
  • ใช้กับ Optimization ไม่ได้ และใช้ได้เฉพาะ Agent ในเครื่อง
  • เปลี่ยน Timeframe ของกราฟหลักไม่ได้ และเลือกได้เฉพาะสัญลักษณ์หลักกับสัญลักษณ์ที่ EA ใช้
  • ราคาที่เห็นคือราคาที่โหมดจำลองสร้างขึ้น ถ้าใช้โหมดที่สร้าง tick จากแท่ง 1 นาที การขยับในแท่งที่เห็นเป็นการจำลอง ไม่ใช่ลำดับจริง ความต่างนี้อธิบายในบทเรื่องโหมดทดสอบด้วย tick จริงของโบรกเกอร์

คำถามที่พบบ่อยเรื่อง Visual Mode

กด Start แล้วไม่มีหน้าต่างภาพขึ้นมา เกิดจากอะไร?

เช็กสามอย่าง คือติ๊ก Visualization แล้วหรือยัง ปิด Optimization หรือยัง และเลือก Agent ในเครื่องอยู่หรือไม่ ถ้าขาดข้อใดข้อหนึ่ง โปรแกรมจะไม่เปิดหน้าต่างภาพ

Visual Mode ช้ามาก ทำให้เร็วขึ้นได้ไหม?

เร่งความเร็วจากแถบเครื่องมือได้ และกระโดดไปวันที่ต้องการได้ ถ้ายังช้าเกินไป ให้ทดสอบแบบปกติแล้วใช้ Open Chart ดูดีลทีหลัง หรือแบ่งช่วงวันที่ให้สั้นลง

เปลี่ยน Timeframe ในหน้าต่างภาพได้ไหม?

ไม่ได้ กราฟหลักใช้ Timeframe ที่เลือกในแท็บ Settings ตลอดการทดสอบ ถ้าอยากดูอีก Timeframe ต้องเริ่มทดสอบใหม่

ทำไมไม่เห็น Indicator บนกราฟทดสอบ?

ส่วนใหญ่เพราะชื่อเทมเพลตไม่ตรงกับชื่อ EA ทุกตัวอักษร หรือไฟล์ไม่ได้อยู่ในโฟลเดอร์ /profiles/templates ของโปรแกรมที่ใช้ทดสอบ แก้ชื่อหรือย้ายไฟล์แล้วเริ่มใหม่

ไม่ควร โหมดนี้ใช้ดูพฤติกรรมช่วงสั้น ส่วนการตัดสินว่าระบบน่าเชื่อแค่ไหนต้องใช้การทดสอบช่วงยาวที่มีเทรดจำนวนมาก ใช้ทั้งสองแบบคู่กันจะเห็นทั้งภาพใหญ่และรายละเอียด

สรุป: ใช้ภาพเพื่อเข้าใจ ใช้ตัวเลขเพื่อตัดสิน

Visual Mode MT5 ทำให้การทดสอบย้อนหลังเป็นสิ่งที่มองเห็นได้ คุณได้รู้ว่า EA คิดยังไงในแต่ละแท่ง และจับความผิดปกติที่ซ่อนอยู่ในรายงานได้ แต่การตัดสินใจว่าจะใช้ระบบหรือไม่ ยังต้องพึ่งตัวเลขจากการทดสอบช่วงยาว ขั้นตอนทดสอบเต็มรอบพร้อมวิธีอ่านรายงานอยู่ที่ หน้าขั้นตอน Backtest EA MT5

เมื่อ EA ของเรามีรุ่นใหม่ ทีมงานจะแจ้งทาง LINE ถ้าคุณอยากดูพฤติกรรมของ EA ด้วยตาตัวเองก่อนรันจริง โหมดนี้คือเครื่องมือที่เหมาะที่สุด และถ้าเห็นอะไรที่ไม่แน่ใจระหว่างดู ส่งวันเวลาที่จดไว้มาถามทีมงานได้

อ่านต่อ

  • Strategy Tester MT5: เมนูและโหมดทดสอบทุกตัวที่ต้องรู้
  • กราฟแท่งเทียน คืออะไร: อ่านแท่งเทียนทองคำให้เป็น

  • Backtest คืออะไร: ทดสอบระบบเทรดย้อนหลังให้เป็นก่อนใช้เงินจริง
