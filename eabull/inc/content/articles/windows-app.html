Windows App คือแอปของ Microsoft สำหรับเชื่อมต่อเครื่อง Windows จากระยะไกล ใช้ได้ทั้งบน Android iPhone iPad Mac และ Windows บนมือถือมันมาแทนแอป Remote Desktop รุ่นเดิม คนใช้ EA ใช้แอปนี้เข้า Windows VPS จากโทรศัพท์ เพื่อเช็กว่า MT5 กับ EA ยังทำงาน โดยใช้แค่ IP ชื่อผู้ใช้ และรหัสผ่านของ VPS ไม่ต้องสมัครบัญชีกับ Microsoft

สรุปสั้น

  • Windows App เป็นแอปฟรีของ Microsoft Corporation ใน App Store ใช้ชื่อ Windows App Mobile ส่วนใน Google Play ใช้ชื่อ Windows App
  • เข้าเครื่องแบบ PC หรือ VPS ได้โดยไม่ต้องล็อกอินแอป การล็อกอินใช้เฉพาะบริการคลาวด์ขององค์กร
  • เพิ่มเครื่องด้วยปุ่ม + เลือก PC ใส่ IP ในช่อง PC Name แล้วบันทึก การ์ดเครื่องจะอยู่ในแท็บ Devices
  • ออกจาก VPS ด้วยการตัดการเชื่อมต่อในแอป ห้ามกด Sign out ใน VPS เพราะ MT5 จะปิดตาม
  • มือถือเป็นแค่หน้าจอ EA ยังทำงานอยู่บน VPS ตลอด แอป MT5 บนมือถือเองรัน EA ไม่ได้

บทนี้เป็นส่วนหนึ่งของชุดเรื่องการให้ EA ทำงานตลอดเวลา ถ้าคุณยังไม่มี VPS หรือยังไม่แน่ใจว่าเครื่องแบบไหนเหมาะกับการรัน EA ให้ต่อเนื่อง อ่านบท รัน EA คืออะไร ก่อน แล้วค่อยกลับมาตั้งแอปนี้ไว้ดูแลจากมือถือ

Windows App คืออะไร

Windows App คือแอปรวมของ Microsoft ที่ใช้เข้าถึงเครื่อง Windows จากที่อื่น Microsoft ออกแบบให้เป็นแอปเดียวที่ต่อได้ทั้งเครื่องคอมทั่วไปที่เปิด Remote Desktop ไว้ และบริการคลาวด์ขององค์กร เช่น Azure Virtual Desktop และ Windows 365 ตามข้อมูลของ Microsoft แอปนี้มีให้ใช้บน Windows macOS iOS และ iPadOS Android และ Chrome OS รวมถึงบนเว็บเบราว์เซอร์ (ข้อมูลจาก Microsoft Learn: What is Windows App ตรวจเมื่อ พ.ย. 2569)

สำหรับคนใช้ EA สิ่งที่ต้องรู้มีแค่ส่วนเดียว คือการเชื่อมต่อแบบ Remote PC ซึ่งก็คือการเข้า Windows VPS ด้วย IP ที่ผู้ให้บริการส่งมา ส่วนบริการคลาวด์ขององค์กรเป็นเรื่องของบริษัทที่ใช้ระบบ Microsoft ไม่เกี่ยวกับการรัน MT5

ก่อนหน้านี้ Microsoft มีแอปชื่อ Remote Desktop บนมือถือและ Mac เมื่อเปลี่ยนมาเป็น Windows App คนที่เคยใช้แอปเดิมจึงมักงงว่าแอปหายไปไหน คำตอบคือมันถูกแทนด้วยแอปนี้ หลักการทำงานเหมือนเดิม คือส่งภาพหน้าจอจาก VPS มาให้ดู และส่งการแตะของคุณกลับไป ความต่างอยู่ที่หน้าตาและเมนูที่จัดใหม่

Windows App Mobile คือ แอปตัวไหน

ถ้าค้นใน App Store จะเจอชื่อ Windows App Mobile ซึ่งเป็นแอปเดียวกันที่ใช้ได้ทั้งบน iPhone และ iPad ส่วนใน Google Play แอปใช้ชื่อ Windows App เฉย ๆ ทั้งสองตัวมีผู้พัฒนาเป็น Microsoft Corporation ให้เช็กชื่อผู้พัฒนาทุกครั้งก่อนติดตั้ง เพราะมีแอปของคนอื่นที่ตั้งชื่อคล้ายกันปะปนอยู่

รุ่นระบบขั้นต่ำในตารางมาจากหน้าคู่มือเริ่มต้นใช้งานของ Microsoft (ตรวจเมื่อ พ.ย. 2569) ถ้ามือถือของคุณเก่ากว่านี้ ร้านค้าอาจไม่ให้ติดตั้ง หรือติดตั้งได้แต่ไม่ได้รับอัปเดต

ต้องสมัคร Windows App ไหม

หลายคนค้นคำว่าสมัคร Windows App เพราะเปิดแอปครั้งแรกแล้วเจอปุ่ม Sign in คำตอบคือถ้าจะใช้เข้า VPS ไม่ต้องสมัครและไม่ต้องล็อกอิน Microsoft ระบุไว้ว่าการล็อกอินแอปจำเป็นเฉพาะตอนเชื่อมต่อบริการขององค์กร เช่น Azure Virtual Desktop หรือ Windows 365 ส่วนการเชื่อมต่อเครื่อง PC ใช้แอปได้โดยไม่ต้องล็อกอิน

อีกเรื่องที่ควรรู้คือ ปุ่ม Sign in ในแอปรับเฉพาะบัญชีที่ทำงานหรือโรงเรียนซึ่งผู้ดูแลระบบออกให้ บัญชี Microsoft ส่วนตัวที่ใช้กับ Outlook หรือ Xbox ใช้ล็อกอินแอปนี้ไม่ได้ ถ้าคุณพยายามล็อกอินด้วยบัญชีส่วนตัวแล้วไม่ผ่าน นั่นเป็นเรื่องปกติ ให้ข้ามไปเพิ่มเครื่องด้วยปุ่ม + แทน

สิ่งเดียวที่ต้องเตรียมคือข้อมูลเข้า VPS จากผู้ให้บริการ ได้แก่ IP ชื่อผู้ใช้ และรหัสผ่าน ถ้ามีใครขอให้คุณ "สมัคร" หรือจ่ายเงินเพื่อเปิดใช้แอปนี้ ให้สงสัยไว้ก่อน เพราะตัวแอปติดตั้งได้ฟรีจากร้านค้า

Windows App กับ Remote Desktop แบบเดิมต่างกันยังไง

ชื่อเรียกของเครื่องมือเหล่านี้เปลี่ยนไปหลายครั้ง ตารางนี้สรุปว่าบนอุปกรณ์แต่ละแบบ คุณควรใช้อะไรเข้า VPS

บนคอม การใช้ Remote Desktop Connection มีรายละเอียดของตัวเองที่ควรรู้ เช่น คีย์ลัดที่ต่างจาก Windows ปกติ และวิธีแก้ภาพกระตุก เราอธิบายแยกไว้ในบท วิธีใช้ Remote Desktop บนคอม

Windows App วิธีใช้บนมือถือ ทีละขั้น

ขั้นตอนนี้คือ Windows App Mobile วิธีใช้ครั้งแรกสำหรับเข้า VPS อ้างอิงคู่มือของ Microsoft (ตรวจเมื่อ พ.ย. 2569) ชื่อปุ่มบน iPhone กับ Android ต่างกันเล็กน้อย เราเขียนไว้ทั้งสองแบบ

  1. ติดตั้งแอปจากร้านค้า

    เข้าร้านแอปของมือถือ พิมพ์คำว่า Windows App ดูใต้ชื่อแอปว่าเป็นของ Microsoft Corporation จริง แล้วกดติดตั้งหรือรับแอป

  2. ผ่านหน้าแนะนำและคำขอสิทธิ์

    ครั้งแรกแอปจะพาดูหน้าแนะนำ กด Skip ข้ามได้ บน iPhone อาจถามเรื่องบลูทูธและการเชื่อมต่ออุปกรณ์ในเครือข่าย ตอบตามที่คุณสะดวก การเข้า VPS ไม่ได้ใช้สองอย่างนี้

  3. แตะ + แล้วเลือกเพิ่มเครื่อง

    แอปอาจถามให้เพิ่มการเชื่อมต่อทันที หรือแตะไอคอน + เอง บน iPhone และ iPad เลือก PC ส่วนบน Android เลือก PC connection อย่าเลือก Sign in หรือ Workspace

  4. ใส่ IP ในช่อง PC Name

    พิมพ์ IP ของ VPS ลงในช่อง PC Name ถ้าผู้ให้บริการให้หมายเลขพอร์ตมาด้วย ให้พิมพ์ต่อท้ายแบบ IP:พอร์ต

  5. เพิ่มบัญชีผู้ใช้และตั้งชื่อเครื่อง

    ในช่องบัญชีผู้ใช้ ใส่ชื่อผู้ใช้และรหัสผ่านของ VPS แล้วตั้ง Friendly Name เป็นชื่อที่จำง่าย เช่น VPS MT5 ถ้าข้ามขั้นนี้ แอปจะถามชื่อผู้ใช้ตอนเชื่อมต่อแทน

  6. บันทึกแล้วแตะการ์ดเพื่อเชื่อมต่อ

    แตะ Save เครื่องจะขึ้นเป็นการ์ดในแท็บ Devices แตะการ์ดนั้น แอปจะถามให้ยืนยันว่าเชื่อถือเครื่องปลายทาง ตรวจ IP แล้วแตะ Connect หน้าจอ Windows ของ VPS จะเปิดขึ้น

ถ้าอยากดูภาพหน้าจอประกอบทุกขั้น เราทำคู่มือแยกตามระบบไว้ ลิงก์อยู่ในส่วนสรุปท้ายบท

เข้า VPS จากมือถือแล้ว ควรเช็กอะไรบ้าง

หน้าจอมือถือเล็ก การเข้า VPS แต่ละครั้งจึงควรมีเป้าหมายชัด ไม่ต้องไล่ดูทุกอย่าง ใช้รายการนี้เป็นรอบเช็กสั้น ๆ ที่ใช้เวลาไม่กี่นาที

  • หน้าต่าง MT5 ยังเปิดอยู่ ไม่ได้ถูกปิดหรือค้างเป็นสีขาว
  • มุมขวาล่างของ MT5 ไม่ขึ้นคำว่า No connection
  • ปุ่ม Algo Trading บนแถบเครื่องมือยังเป็นสีเขียว
  • ทุกกราฟที่ติด EA ยังมีชื่อ EA ที่มุมขวาบน และไอคอนไม่เป็นสีเทา
  • บรรทัดล่าสุดใน Experts กับ Journal ไม่มีคำเตือนหรือ error ที่เพิ่งเกิดหลังการเช็กรอบก่อน

หมุนมือถือเป็นแนวนอนจะเห็นหน้าจอ VPS ได้กว้างขึ้น และใช้สองนิ้วถ่างเพื่อซูมดูตัวหนังสือเล็ก ถ้าเจอว่า EA หายไปจากกราฟหรือไม่ยอมทำงาน ให้จดข้อความในแท็บ Experts ไว้ก่อน แล้วไล่เช็กตามบท EA MT5 ไม่ทำงาน: เช็กทีละจุด

สำหรับการดูออเดอร์และยอดเงินอย่างเดียว คุณไม่จำเป็นต้องเข้า VPS ทุกครั้ง ล็อกอินบัญชีเดียวกันในแอป MT5 บนมือถือก็เห็นออเดอร์ที่ EA เปิดไว้แล้ว เก็บการเข้า VPS ไว้ใช้ตอนต้องดูสถานะของตัวโปรแกรม

ออกจาก VPS บนมือถือให้ถูกวิธี

กฎเดียวกับบนคอมใช้ที่นี่ด้วย การออกจาก VPS มีสองแบบที่ผลต่างกันมาก แบบแรกคือตัดการเชื่อมต่อจากเมนูของแอประหว่างเชื่อมต่อ หรือปิดหน้าจอเชื่อมต่อในแอป แบบนี้ VPS ยังทำงานและ MT5 ยังเปิดอยู่ แบบที่สองคือเข้าเมนู Start ในหน้าจอ VPS แล้วกด Sign out หรือ Shut down แบบนี้ MT5 จะถูกปิด และ EA หยุดทันที

วิธีออกMT5 บน VPS
ตัดการเชื่อมต่อจากเมนูของ Windows Appทำงานต่อ
สลับไปแอปอื่น หรือปิดหน้าจอมือถือทำงานต่อ การเชื่อมต่ออาจหลุดเอง แต่ VPS ไม่ปิด
Sign out ในเมนู Start ของ VPSปิด EA หยุด
Shut down หรือ Restart ใน VPSปิด ต้องเข้าไปเปิด MT5 ใหม่

บนจอสัมผัส นิ้วแตะพลาดไปโดนเมนู Start ได้ง่ายกว่าบนคอม ถ้าเผลอเปิดเมนูขึ้นมา ให้แตะที่ว่างบนหน้าจอเพื่อปิดเมนู แล้วค่อยออกด้วยเมนูของแอป

ปัญหาที่เจอบ่อยใน Windows App และวิธีแก้

อาการสาเหตุที่พบบ่อยลองแก้
แอปให้ล็อกอินอย่างเดียว ไม่เห็นที่ใส่ IPกดเข้าทาง Sign in ของบริการองค์กรกลับมาหน้าหลัก แตะ + แล้วเลือก PC หรือ PC connection
เชื่อมต่อไม่ได้เลยIP หรือพอร์ตผิด หรือ VPS ปิดอยู่เทียบ IP กับอีเมลของผู้ให้บริการ แล้วลองเข้าจากคอมเพื่อแยกว่าปัญหาอยู่ที่มือถือหรือไม่
ขึ้นว่ารหัสผ่านไม่ถูกพิมพ์ชื่อผู้ใช้ผิด หรือเปลี่ยนรหัส VPS แล้วแต่ยังใช้รหัสเก่าในแอปแก้บัญชีผู้ใช้ที่บันทึกไว้ในการ์ดของเครื่อง แล้วลองใหม่
หน้าจอช้าหรือภาพแตกสัญญาณมือถืออ่อนย้ายไปใช้ Wi-Fi ที่เสถียร หรือรอสัญญาณดีขึ้น MT5 บน VPS ไม่ได้ช้าตาม
แตะแล้วคีย์บอร์ดไม่ขึ้นยังไม่ได้เปิดคีย์บอร์ดจากแถบของแอปเปิดแถบเครื่องมือของแอประหว่างเชื่อมต่อ แล้วหาไอคอนรูปคีย์บอร์ด

เก็บรหัส VPS ในมือถือให้ปลอดภัย

การบันทึกรหัสผ่านไว้ในแอปช่วยให้เข้า VPS ได้เร็ว แต่ก็หมายความว่าใครได้มือถือของคุณไป ก็เข้า VPS และคุม MT5 ได้ทันที ควรทำอย่างน้อยสามข้อนี้

  • ตั้งรหัสล็อกหน้าจอ ลายนิ้วมือ หรือ Face ID ก่อนบันทึกรหัส VPS ไว้ในแอป
  • ไม่แคปหน้าจอที่มีรหัสผ่าน VPS ส่งในแชต ถ้าเคยส่งแล้วให้เปลี่ยนรหัส
  • ถ้ามือถือหาย เปลี่ยนรหัส VPS จากคอมทันที ผ่านหน้าจัดการของผู้ให้บริการหรือในหน้าจอ VPS เอง

รหัส VPS ปกป้องได้แค่ตัวเครื่อง ส่วนบัญชีเทรดควรมีชั้นป้องกันของตัวเองด้วย วิธีเปิดรหัส OTP ให้บัญชี MT5 อยู่ในบท MT5 2FA: เปิด OTP ให้บัญชีเทรด

คำถามที่พบบ่อยเรื่อง Windows App

Windows App เสียเงินไหม?

ตัวแอปติดตั้งได้ฟรีจาก App Store และ Google Play ค่าใช้จ่ายที่มีคือค่าเช่า VPS ที่คุณจ่ายกับผู้ให้บริการ ไม่ใช่ค่าแอป

ใช้ Windows App บน iPad ได้ไหม?

ได้ แอป Windows App Mobile ตัวเดียวใช้ได้ทั้ง iPhone และ iPad ที่เป็น iPadOS 16.0 ขึ้นไป จอ iPad ใหญ่กว่า จึงดูกราฟและแท็บ Experts ใน MT5 ได้สบายกว่ามือถือ

ใช้ Windows App เข้าคอมที่บ้านแทน VPS ได้ไหม?

ได้ถ้าคอมที่บ้านเป็น Windows รุ่น Pro ขึ้นไปและเปิด Remote Desktop ไว้ รุ่น Home รับการเชื่อมต่อแบบนี้ไม่ได้ และถ้าจะเข้าจากนอกบ้าน ต้องตั้งค่าเครือข่ายเพิ่ม เช่น VPN ซึ่งยุ่งกว่าการใช้ VPS พอสมควร

เปิด Windows App บนเว็บเบราว์เซอร์เข้า VPS ได้ไหม?

ไม่ได้ เวอร์ชันเว็บของ Windows App รองรับบริการคลาวด์ขององค์กร ไม่รองรับการเข้าเครื่อง PC ด้วย IP ต้องใช้แอปบนมือถือ Mac หรือคอม Windows

ใช้ Windows App แล้ว มือถือรัน EA ได้เลยไหม?

ไม่ใช่ EA ยังทำงานอยู่บน VPS มือถือเป็นแค่หน้าจอที่ใช้มองและสั่งงานเครื่องนั้น ถ้า VPS ปิด EA ก็หยุด ไม่ว่ามือถือจะเปิดแอปอยู่หรือไม่

สรุป: Windows App คือแอปที่ทำให้ดูแล EA ได้จากทุกที่

สรุปแล้ว Windows App คือแอปเข้า VPS จากมือถือตัวทางการของ Microsoft ไม่ต้องสมัคร ไม่ต้องจ่ายค่าแอป ใช้ข้อมูลเข้าเครื่องชุดเดียวกับบนคอม และขอให้จำไว้ข้อเดียวว่าออกด้วยการตัดการเชื่อมต่อ ไม่ใช่ Sign out เมื่อตั้งไว้แล้ว การเช็กว่า EA ยังทำงานจะเหลือแค่ไม่กี่แตะ

ถ้าคุณใช้ EA ของ EA BULL คู่มือบนเว็บมีภาพประกอบทุกขั้นแยกตามระบบ ดูได้ที่คู่มือ เข้า VPS จาก Android ด้วย Windows App และคู่มือ เข้า VPS จาก iPhone และ iPad ถ้ายังไม่ได้ย้าย MT5 ขึ้น VPS เริ่มจากคู่มือ VPS บน Windows ก่อน ลูกค้าแพ็กเกจ VIP ให้ทีมงานติดตั้งบน VPS ให้ได้ ส่วนค่าเช่า VPS แยกจากแพ็กเกจ ถ้าตั้งแอปแล้วยังเข้าเครื่องไม่ได้ แคปข้อความที่ขึ้นในแอปส่งมาถามทีมงานได้
