MT5 Web Terminal คือ MetaTrader 5 แบบที่เปิดใช้ในเว็บเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรม ใช้ดูกราฟ เปิดปิดออเดอร์ และดูยอดบัญชีได้ทั้งบัญชีทดลองและบัญชีจริง แต่ใช้รัน EA ไม่ได้ เพราะเวอร์ชันเว็บไม่มีส่วนให้ติดตั้งและเปิดใช้ EA ถ้าอยากให้ EA เทรดแทน คุณต้องใช้ MT5 แบบติดตั้งบนเครื่อง Windows หรือบน VPS แล้วเก็บเวอร์ชันเว็บไว้เป็นหน้าต่างดูบัญชีสำรอง

สรุปสั้น

  • เวอร์ชันเว็บเปิดได้จาก Chrome Safari Edge Firefox หรือ Opera ทั้งบนคอม Windows Mac Linux และมือถือ โดยไม่ต้องลงโปรแกรม
  • เทรดเองได้เกือบครบเท่าโปรแกรมบนคอม มีคำสั่งรอ Trailing Stop Indicator ในตัว 30 ตัว และกราฟ 9 Timeframe
  • รายการความสามารถทางการของเวอร์ชันเว็บไม่มี EA ไม่มี Strategy Tester และไม่มี MetaEditor จึงใช้ติด EA ไม่ได้
  • บัญชีจริงให้เข้าผ่าน Web Terminal ที่โบรกเกอร์เปิดไว้บนโดเมนของตัวเอง และเช็กชื่อโดเมนทุกครั้งก่อนพิมพ์รหัสผ่าน
  • สำหรับคนใช้ EA เวอร์ชันเว็บเหมาะเป็นทางสำรอง เช่น ดูออเดอร์ตอนเข้า VPS ไม่ได้ หรือดูบัญชีจากคอมเครื่องอื่น

บทนี้อยู่ในชุดเรื่องการให้ EA ทำงานตลอด 24 ชั่วโมง เวอร์ชันเว็บเป็นที่หนึ่งที่คนมักเข้าใจผิดว่าใช้รัน EA ได้ ถ้าอยากเห็นภาพรวมก่อนว่า รัน EA ได้ที่ไหนบ้าง และแต่ละที่ต้องเตรียมอะไร อ่านบทหลักของชุดนี้ประกอบ ส่วนบทนี้จะเจาะเฉพาะ MT5 ที่เปิดผ่านเบราว์เซอร์

MT5 Web Terminal คืออะไร

MetaTrader 5 มีให้ใช้สามรูปแบบ คือโปรแกรมที่ติดตั้งบนคอม แอปบนมือถือ และเวอร์ชันที่เปิดผ่านเว็บเบราว์เซอร์ แบบที่สามนี้มีหลายชื่อ ทั้ง Web Terminal, WebTerminal, Web Platform หรือเรียกง่าย ๆ ว่า MT5 บนเว็บ ทุกชื่อหมายถึงหน้าเว็บที่ทำงานเหมือนโปรแกรมเทรด คุณล็อกอินด้วยเลขบัญชีและรหัสผ่านชุดเดียวกับในโปรแกรม แล้วเห็นราคา ออเดอร์ และประวัติของบัญชีเดียวกัน

เวอร์ชันเว็บรุ่นปัจจุบัน MetaQuotes พัฒนาขึ้นใหม่ทั้งตัวและเปิดตัวช่วงปลายปี 2565 จุดเด่นคือใช้บนมือถือได้ดี ทั้ง iPhone และ Android เปิดผ่านเบราว์เซอร์ได้เลยโดยไม่ต้องโหลดแอป ตามหน้าแนะนำของ MetaTrader 5 เวอร์ชันนี้ใช้ได้บน Windows macOS และ Linux และข้อมูลที่วิ่งระหว่างเบราว์เซอร์กับเซิร์ฟเวอร์ถูกเข้ารหัสไว้

ให้มองว่า Web Terminal คือ "หน้าจอ" ที่ต่อเข้าบัญชีของคุณบนเซิร์ฟเวอร์ของโบรกเกอร์ ออเดอร์ที่เปิดจากเว็บไปอยู่ที่เซิร์ฟเวอร์เหมือนที่เปิดจากโปรแกรม ปิดแท็บแล้วออเดอร์ยังอยู่ครบ แต่หน้าเว็บไม่ได้ทำอะไรต่อบนเครื่องคุณแล้ว

MT5 บนเว็บทำอะไรได้บ้าง เทียบกับโปรแกรมบนคอม

คอลัมน์เวอร์ชันเว็บในตารางนี้มาจากหน้าความสามารถของเวอร์ชันเว็บบนเว็บไซต์ MetaTrader 5 (ข้อมูลจาก MetaTrader 5: Web version features ตรวจเมื่อ พ.ย. 2569) ส่วนคอลัมน์โปรแกรมบนคอมเทียบจากหน้าแนะนำและคู่มือของ MT5 ช่วงเวลาเดียวกัน

MT5 Web Terminal รัน EA ได้ไหม

คำตอบคือไม่ได้ และไม่ใช่เพราะคุณตั้งค่าผิด EA คือไฟล์นามสกุล .ex5 ที่โปรแกรม MT5 บนเครื่องโหลดขึ้นมาจากโฟลเดอร์ข้อมูลของตัวเอง (File → Open Data Folder → MQL5 → Experts) แล้วเรียกให้คิดทุกครั้งที่ราคาขยับ เวอร์ชันเว็บไม่มีโฟลเดอร์แบบนี้ให้วางไฟล์ และในรายการความสามารถทางการก็ไม่มีการเปิดใช้ EA การทดสอบย้อนหลัง หรือการเขียนโปรแกรมเลย

เหตุผลข้อที่สองอยู่ที่ธรรมชาติของหน้าเว็บ เบราว์เซอร์ทำงานเฉพาะตอนที่แท็บนั้นเปิดอยู่ ถ้าคุณปิดแท็บ ปิดเครื่อง หรือมือถือพักหน้าจอ หน้าเว็บก็หยุดไปด้วย ต่อให้วาง EA ได้จริง มันก็ทำงานได้แค่ตอนที่คุณนั่งเปิดหน้าเว็บค้างไว้ ซึ่งเปราะกว่าการเปิดคอมทิ้งไว้เสียอีก

สิ่งที่ EA ต้องมีMT5 บนคอมหรือ VPSMT5 บนเว็บ
ที่วางไฟล์ .ex5โฟลเดอร์ MQL5 → Expertsไม่มี
ทำงานต่อตอนคุณไม่ได้ดูหน้าจอได้ ถ้าเครื่องไม่หลับและไม่ปิดโปรแกรมไม่ได้ ขึ้นกับว่าแท็บยังเปิดอยู่ไหม
ทดสอบ EA ก่อนใช้จริงStrategy Tester (Ctrl+R)ไม่มี

ดังนั้นถ้าใครบอกว่า "ล็อกอินบนเว็บไว้ แล้ว EA จะเทรดให้เอง" ให้ถามต่อว่า EA ตัวนั้นทำงานอยู่บนเครื่องไหน คำตอบที่ถูกจะเป็นคอม Windows ที่เปิดค้างไว้ Windows VPS หรือบริการเช่าเครื่องที่อยู่ในเมนูของ MT5 เอง ซึ่งเราแยกให้เห็นความต่างไว้ในบท บริการ Virtual Hosting ในเมนูของ MT5

MT5 WebTrader กับ MT5 Web App คือตัวเดียวกันไหม

เวลาค้นหา คุณจะเจอคำว่า MT5 WebTrader บ่อยพอกับคำว่า Web Terminal คำนี้มักเป็นชื่อที่โบรกเกอร์ใช้เรียกหน้าเทรด MT5 บนเว็บของตัวเอง ตามคำอธิบายของ MetaTrader 5 Web Terminal แต่ละชุดถูกผูกกับโบรกเกอร์รายหนึ่ง และเปิดให้ใช้บนโดเมนของโบรกเกอร์นั้น หน้าตาของแต่ละเจ้าจึงคล้ายกัน ต่างกันที่โลโก้และรายชื่อ Server ที่เลือกได้

ส่วนคำว่า MT5 Web App ส่วนใหญ่หมายถึงการเปิด Web Terminal บนมือถือ เวอร์ชันเว็บรุ่นใหม่จัดหน้าจอให้เหมาะกับจอสัมผัส จึงใช้แทนแอปได้ในบางสถานการณ์ เช่น พื้นที่ในเครื่องเต็มจนลงแอปไม่ได้ หรือต้องยืมมือถือคนอื่นชั่วคราว แต่ถ้าเป็นเครื่องของคุณเองและใช้ทุกวัน แอป MT5 จากร้านค้าแอปสะดวกกว่า เพราะจำการล็อกอินไว้และรับการแจ้งเตือนได้

ทั้งเวอร์ชันเว็บและแอปบนมือถือมีข้อจำกัดเหมือนกันคือรัน EA ไม่ได้ ถ้าอยากรู้ว่านอกจากสองแบบนี้ยังมีโปรแกรมแบบไหนอีก และตัวไหนเทรดแทนคุณได้จริง อ่านบท เทรดทองใช้โปรแกรมอะไรได้บ้าง

MT5 Web Login: เข้าระบบให้ถูกเว็บ

MT5 Web Login ใช้ข้อมูลสามอย่างชุดเดียวกับโปรแกรมบนคอม คือเลขบัญชี รหัสผ่าน และชื่อ Server จากโบรกเกอร์ สิ่งที่ต้องระวังกว่าคือคุณต้องเปิดให้ถูกหน้าเว็บ หน้าวิธีเชื่อมต่อของ MetaTrader 5 อธิบายว่าการเทรดเงินจริงทำผ่านโบรกเกอร์เท่านั้น Web Terminal ของแต่ละโบรกเกอร์อยู่บนโดเมนของโบรกเกอร์นั้น ส่วนเวอร์ชันที่ MetaQuotes เปิดให้ลองบนเว็บของตัวเองเป็นโหมดทดลอง (ข้อมูลจาก MetaTrader 5: How to connect to the web platform ตรวจเมื่อ พ.ย. 2569)

  1. หาลิงก์จากเว็บไซต์ของโบรกเกอร์

    พิมพ์ที่อยู่เว็บของโบรกเกอร์เอง หรือเปิดจากบุ๊กมาร์กที่บันทึกไว้ แล้วหาเมนูเทรดบนเว็บ ไม่กดลิงก์ที่มีคนส่งมาในแชตหรือเจอในโฆษณา

  2. ดูโดเมนในแถบที่อยู่

    ชื่อโดเมนต้องเป็นของโบรกเกอร์ ตัวอย่างในคู่มือคือ ถ้าเว็บโบรกเกอร์อยู่ที่ yourbroker.com หน้าเทรดบนเว็บก็ควรอยู่บน yourbroker.com เหมือนกัน ถ้าโดเมนแปลกหรือสะกดเพี้ยน ให้ปิดทันที

  3. ใส่เลขบัญชี รหัสผ่าน และเลือก Server

    เลือกชื่อ Server ให้ตรงกับที่โบรกเกอร์ส่งมา บัญชีทดลองกับบัญชีจริงมักอยู่คนละ Server ถ้าเลือกผิด ระบบจะบอกว่าข้อมูลไม่ถูกต้องทั้งที่รหัสถูก

  4. เช็กว่าเข้าถูกบัญชี

    ดูเลขบัญชีและยอดเงินว่าตรงกับที่เห็นในแอปหรือในโปรแกรมบนคอม ออเดอร์ที่ EA เปิดไว้ต้องขึ้นครบ

  5. ออกจากระบบเมื่อใช้เครื่องคนอื่น

    กดออกจากระบบ ไม่ให้เบราว์เซอร์จำรหัสผ่าน และปิดหน้าต่างเมื่อใช้เสร็จ โดยเฉพาะคอมที่ทำงานหรือคอมสาธารณะ

ใช้ MT5 บนเว็บตอนไหนดี เทียบกับแอปและโปรแกรมบนคอม

แต่ละรูปแบบของ MT5 เหมาะกับงานคนละแบบ ถ้าเลือกถูก คุณจะไม่ต้องพยายามให้เครื่องมือหนึ่งทำสิ่งที่มันไม่ได้ออกแบบมา

สถานการณ์ใช้อะไรเหตุผล
อยากให้ EA เทรดแทนตลอดเวลาMT5 บน Windows หรือ VPSมีที่วาง EA และเปิดค้างไว้ได้
ใช้คอมที่ทำงานซึ่งลงโปรแกรมเองไม่ได้MT5 บนเว็บไม่ต้องติดตั้งอะไรในเครื่อง
มือถือแบตหมดหรือเสีย แต่ต้องดูออเดอร์ด่วนMT5 บนเว็บจากเครื่องอื่นล็อกอินได้จากเบราว์เซอร์ของทุกเครื่อง
เช็กออเดอร์ของ EA ระหว่างวันแอป MT5 บนมือถือเปิดเร็ว จำการล็อกอินไว้
ดูว่า EA บน VPS ยังทำงานอยู่ไหมWindows App หรือ Remote Desktopปุ่มและไอคอนของ EA ดูได้จากหน้าจอของ VPS เท่านั้น

แถวสุดท้ายสำคัญกว่าที่คิด เวอร์ชันเว็บและแอปบอกได้แค่ว่าบัญชีมีออเดอร์อะไร แต่บอกไม่ได้ว่า EA ยังทำงานอยู่ไหม ถ้าอยากเห็นปุ่ม Algo Trading และไอคอนบนกราฟ ต้องเข้าไปดูหน้าจอของเครื่องที่รัน EA วิธีทำจากโทรศัพท์อยู่ในบท ใช้ Windows App เข้า VPS จากมือถือ ส่วนถ้ายังไม่มีเครื่องที่เปิดค้างไว้ได้ ลองอ่านเรื่อง เครื่องเช่าที่เปิดค้างไว้ได้ตลอดอย่าง VPS ก่อนตัดสินใจ

ใช้ Web Terminal คู่กับ EA ให้ได้ประโยชน์

แม้จะรัน EA ไม่ได้ เวอร์ชันเว็บก็มีที่ใช้สำหรับคนใช้ EA อยู่สองเรื่อง เรื่องแรกคือเป็นทางสำรองตอนเข้าเครื่องหลักไม่ได้ เช่น VPS ค้าง เน็ตบ้านล่ม หรือแอปบนมือถือมีปัญหา คุณยังล็อกอินบัญชีจากเบราว์เซอร์ของเครื่องไหนก็ได้ เพื่อดูออเดอร์หรือปิดออเดอร์เองเมื่อจำเป็น เรื่องที่สองคือใช้ดูบัญชีจากคอมที่ไม่ใช่ของคุณ โดยไม่ต้องติดตั้งโปรแกรมทิ้งไว้ในเครื่องนั้น

การล็อกอินบัญชีเดียวกันบนเว็บไม่ได้ทำให้ EA บนอีกเครื่องหยุด ทั้งสองที่มองบัญชีเดียวกันบนเซิร์ฟเวอร์ แต่ให้ระวังเรื่องเดียว ถ้าคุณปิดหรือแก้ออเดอร์ที่ EA ดูแลอยู่ EA จะเห็นสภาพใหม่ในรอบถัดไป และอาจทำงานต่อไม่ตรงกับที่คุณตั้งใจ ก่อนแตะออเดอร์ของ EA ควรรู้ว่า EA ตัวนั้นรับมือกับการแทรกแบบนี้ยังไง ถ้าไม่แน่ใจ ถามผู้พัฒนาก่อน

  • ดูยอด Equity และ Margin ว่าอยู่ในระดับที่คาดไว้
  • ดูว่าออเดอร์ที่เปิดอยู่มี Stop Loss ตามที่ EA ควรตั้ง
  • ดูเวลาของออเดอร์ล่าสุด ถ้า EA ปกติเปิดไม้บ่อยแต่เงียบนานผิดสังเกต อาจเป็นสัญญาณให้เข้าไปเช็กเครื่องที่รัน EA

MT5 บนเว็บปลอดภัยไหม

MetaTrader 5 ระบุว่าข้อมูลระหว่างเบราว์เซอร์กับเซิร์ฟเวอร์ถูกเข้ารหัส แม้ใช้ Wi-Fi สาธารณะ จุดเสี่ยงจริงจึงไม่ค่อยอยู่ที่ตัวระบบ แต่อยู่ที่หน้าเว็บที่คุณเปิด และรหัสผ่านที่คุณพิมพ์ลงไป ความผิดพลาดที่เจอบ่อยมีดังนี้

  • กดลิงก์ที่อ้างว่าเป็น MT5 บนเว็บจากแชตหรือโฆษณา แล้วพิมพ์รหัสบัญชีจริงโดยไม่ดูโดเมน
  • ปล่อยให้เบราว์เซอร์ของเครื่องคนอื่นบันทึกรหัสผ่านบัญชีเทรด
  • ใช้รหัสผ่านบัญชีเทรดซ้ำกับอีเมลหรือบริการอื่น
  • ส่งรหัสผ่านหลักให้คนอื่นช่วยดูบัญชี แทนที่จะให้รหัสผ่านแบบ Investor ที่ดูได้อย่างเดียว

ถ้าวันหนึ่งพิมพ์รหัสลงหน้าเว็บที่ไม่แน่ใจไปแล้ว ให้เข้าโปรแกรมหรือแอปของจริงแล้วเปลี่ยนรหัสผ่านทันที และแจ้งโบรกเกอร์

คำถามที่พบบ่อยเรื่อง MT5 Web Terminal

เข้า MT5 Web Terminal Real Account ต้องใช้ลิงก์ไหน?

ใช้ลิงก์ Web Terminal ที่โบรกเกอร์ของคุณให้ไว้บนเว็บไซต์ของโบรกเกอร์เอง หน้าเทรดของบัญชีจริงควรอยู่บนโดเมนเดียวกับเว็บโบรกเกอร์ ส่วนเวอร์ชันบนเว็บของ MetaQuotes ใช้ลองในโหมดทดลอง

เปิด MT5 บนเว็บค้างไว้ แทนการเปิดคอมรัน EA ได้ไหม?

ไม่ได้ เวอร์ชันเว็บไม่มีที่ให้ติด EA ไม่ว่าจะเปิดค้างไว้นานแค่ไหน EA ต้องรันบน MT5 แบบติดตั้งในเครื่อง Windows หรือ VPS ที่เปิดอยู่ตลอด

ใช้ Indicator ที่โหลดหรือซื้อมาบน MT5 บนเว็บได้ไหม?

รายการความสามารถทางการของเวอร์ชันเว็บมีเฉพาะ Indicator ที่มาในตัว 30 ตัว ไม่ได้ระบุการเพิ่มตัวอื่นเข้าไป ถ้าต้องใช้ Indicator ที่โหลดหรือซื้อมา ให้ใช้โปรแกรม MT5 บนคอม

เปิดออเดอร์บนเว็บแล้ว จะเห็นในแอปและในโปรแกรมบนคอมไหม?

เห็น เพราะออเดอร์อยู่ในบัญชีบนเซิร์ฟเวอร์ของโบรกเกอร์ ไม่ได้อยู่ที่หน้าเว็บ ทุกที่ที่ล็อกอินบัญชีเดียวกันจะเห็นออเดอร์ชุดเดียวกัน

MT5 บนเว็บต้องโหลดแอปหรือติดตั้งอะไรเพิ่มไหม?

ไม่ต้อง ใช้แค่เบราว์เซอร์ที่ต่ออินเทอร์เน็ตได้ จะเป็นคอม Windows Mac Linux หรือมือถือก็ได้ แต่ถ้าใช้มือถือของตัวเองเป็นประจำ แอป MT5 จะสะดวกกว่า

สรุป: MT5 Web Terminal คือหน้าต่างดูบัญชี ไม่ใช่ที่ทำงานของ EA

MT5 บนเว็บเป็นเครื่องมือที่ดีสำหรับการเทรดเองและการดูบัญชีจากเครื่องที่ไม่ได้ลงโปรแกรม แต่ไม่ได้ออกแบบมาให้ EA ทำงาน ถ้าคุณใช้ EA ให้วาง EA ไว้บน MT5 ในคอมหรือ VPS ที่เปิดค้างได้ แล้วใช้เวอร์ชันเว็บกับแอปเป็นหน้าต่างดูผลและทางสำรอง

ไม่ว่าจะเข้าผ่านเว็บ แอป หรือโปรแกรมบนคอม ข้อมูลที่ต้องใช้คือเลขบัญชีกับชื่อ Server ชุดเดียวกัน ข้อมูลคู่นี้ยังเป็นตัวที่สิทธิ์ใช้งาน EA ของ EA BULL ผูกไว้ด้วย จึงควรจดให้ถูกตั้งแต่แรก วิธีดูชื่อ Server และเข้าระบบในโปรแกรมทีละขั้นอยู่ในหน้า ล็อกอิน MT5 และหาชื่อ Server ถ้าอยากเริ่มใช้ EA โดยให้ทีมงานติดตั้งให้บนคอมหรือ VPS ของคุณ แพ็กเกจ VIP ราคา 9,990 บาทมีบริการนี้และเช็กค่าก่อนเริ่มรัน ส่วนแพ็กเกจ Pro ราคา 6,990 บาท คุณติดตั้งเองตามคู่มือ จ่ายครั้งเดียวทั้งสองแบบ โดยค่าเช่า VPS แยกต่างหาก
