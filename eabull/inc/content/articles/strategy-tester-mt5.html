Strategy Tester MT5 คือหน้าต่างทดสอบ EA ที่ติดมากับโปรแกรม MetaTrader 5 บนคอม กด Ctrl+R ก็เปิดได้ ข้างในมีแท็บ Settings สำหรับเลือก EA ช่วงเวลา และโหมดจำลองราคา แท็บ Inputs สำหรับค่าของ EA แท็บ Agents สำหรับตัวประมวลผล และแท็บผลลัพธ์ที่ขึ้นหลังทดสอบจบ รู้ว่าแต่ละช่องทำอะไร คุณจะตั้งการทดสอบได้ตรงงานตั้งแต่รอบแรก

สรุปสั้น

  • เปิดได้สามทาง คือ Ctrl+R เมนู View หรือคลิกขวาชื่อ EA ใน Navigator แล้วเลือก Test
  • แท็บ Settings คุมเงื่อนไขของรอบทดสอบ ตั้งแต่สัญลักษณ์ ช่วงวันที่ การหน่วงเวลา ถึงโหมดจำลองราคาห้าแบบ
  • ตั้งค่าคอม กติกามาร์จิ้น และสเปกสัญลักษณ์เองได้ เพื่อให้ใกล้บัญชีจริง
  • Agent คือตัวประมวลผลเบื้องหลัง มีทั้งในเครื่อง ในเครือข่าย และบนคลาวด์

บทนี้เป็นแผนที่ของหน้าต่างทดสอบโดยเฉพาะ ถ้าคุณยังไม่แน่ใจว่าการทดสอบย้อนหลังตอบคำถามอะไรได้บ้าง อ่าน แนวคิดเรื่อง Backtest คือ อะไร ก่อน แล้วเปิดหน้าต่างจริงดูไปพร้อมกัน จะจำตำแหน่งแต่ละช่องได้เร็วกว่า

Modelling: ห้าโหมดในย่อหน้าเดียว

Every tick based on real ticks ใช้ tick จริงที่โบรกเกอร์เก็บไว้ Every tick สร้าง tick ทุกตัวจากแท่ง 1 นาที 1 minute OHLC ใช้แค่สี่ราคาของแท่ง 1 นาที Open prices only ใช้ราคาเปิดของแท่งตาม Timeframe ที่เลือก และ Math calculations ไม่โหลดราคาเลย โหมด Open prices only มีข้อจำกัดเพิ่ม คือใช้ Random Delay ไม่ได้ และ EA ดึงข้อมูลของ Timeframe ที่เล็กกว่าที่ทดสอบไม่ได้ ความต่างของสองโหมดบนสุดอยู่ในบท เทียบโหมด tick จริงกับ Every tick

การหน่วงเวลา: No Delay, Random Delay และ Fixed Delay

ในตลาดจริง ระหว่างที่ EA ส่งคำสั่งจนเซิร์ฟเวอร์ทำรายการ ราคาอาจขยับไปแล้ว Tester จำลองช่องว่างนี้ด้วยการแทรกเวลาหน่วง ถ้าสัญลักษณ์ใช้ Instant Execution และราคาขยับเกินค่าที่ EA ยอมรับ EA จะได้รับ requote ด้วย

ตัวเลือกทำงานยังไงใช้ตอนไหน
No Delayทุกคำสั่งได้ราคาที่ขอ ไม่มี requoteดูผลในสภาพอุดมคติ คัดกรองรอบแรก
Random Delayสุ่มเวลาหน่วง ราว 90% อยู่ที่ 0 ถึง 8 วินาที อีกราว 10% อยู่ที่ 9 ถึง 18 วินาทีเช็กความทนในสภาพที่แย่กว่าปกติ
Fixed Delayเวลาหน่วงคงที่ เลือกเองหรือใช้ค่า ping ที่โปรแกรมวัดให้จำลองเน็ตของเครื่องที่จะรันจริง

เวลาหน่วงมีผลเฉพาะคำสั่งที่ EA ส่งเอง เช่น เปิดออเดอร์ วางคำสั่งรอ หรือแก้จุดตัดขาดทุน ส่วนการจับคู่คำสั่งรอเมื่อราคามาถึงไม่ถูกหน่วง เพราะในตลาดจริงขั้นนั้นเกิดบนเซิร์ฟเวอร์ ตัวอย่างสมมติ EA ที่ทำกำไรต่อไม้น้อย ผลดีกับ No Delay แต่กำไรเฉลี่ยหายเกือบหมดเมื่อเปลี่ยนเป็น Random Delay แปลว่าระบบพึ่งความเร็วสูงมาก ถ้าเน็ตหรือ VPS ที่ใช้จริงช้ากว่าที่คิด ผลจริงก็อาจออกมาแบบนั้น

แท็บ Inputs และการเก็บชุดค่าทดสอบ

แท็บ Inputs แสดงค่าที่ผู้พัฒนาเปิดให้ปรับ ค่าที่ใส่ตรงนี้ใช้กับการทดสอบเท่านั้น ไม่แตะ EA ที่ติดอยู่บนกราฟจริง ถ้าเปิด Optimization ช่องติ๊กหน้าค่ากับคอลัมน์ Start Step Stop จะเริ่มมีผล วิธีตั้งให้จำนวนรอบไม่บานปลายอยู่ในบท ตั้ง Start Step Stop เพื่อ Optimize ค่า EA

เมนูคลิกขวาเก็บชุดค่าได้สองแบบ Save บันทึกเป็นไฟล์ .set ที่ย้ายไปเครื่องอื่นหรือส่งให้คนอื่นได้ ส่วน Save Version เก็บไว้ในโปรแกรมเครื่องนี้ แล้วเรียกกลับจากเมนูย่อย Load Version เหมาะกับการสลับหลายชุดไปมาเร็ว ๆ

ตั้งเงื่อนไขบัญชีและสเปกสัญลักษณ์เอง

ปกติ Tester ใช้เงื่อนไขของบัญชีที่ต่ออยู่ ซึ่งอาจไม่ตรงกับบัญชีที่จะรันจริง หน้าต่างทดสอบจึงเปิดให้ตั้งเองได้สี่ส่วน

  • Common: จำนวนออเดอร์และสถานะที่เปิดพร้อมกันได้สูงสุด และช่วงเวลาที่ห้ามเทรด
  • Margin: แบบ netting หรือ hedging ระดับ Margin Call และ Stop Out เป็นเงินหรือเปอร์เซ็นต์
  • Commission: คิดทุกดีล รายวัน หรือรายเดือน ต่อ lot หรือต่อดีล หรือติ๊ก Use predefined commissions เพื่อใช้ค่าของบัญชีที่ต่ออยู่
  • สเปกสัญลักษณ์หลัก: เขียนทับขนาดไม้ โหมดเทรด และมาร์จิ้นได้ เมื่อแก้แล้วไอคอนเฟืองจะมีดอกจันกำกับ

ตัวอย่างสมมติ บัญชีจริงเก็บค่าคอม 7 USD ต่อ lot ต่อรอบซื้อขาย แต่บัญชีที่ใช้ทดสอบไม่มีค่าคอม ถ้า EA เทรด 0.10 lot รวม 400 รอบ ค่าคอมที่หายไปจากรายงานคือ 7 × 0.10 × 400 = 280 USD ไม่เล็กเลยถ้ากำไรรวมอยู่แค่หลักร้อย

คำถามที่พบบ่อยเรื่อง Strategy Tester

ใช้ Strategy Tester ต้องเสียเงินไหม?

ไม่ต้อง ถ้าใช้ Agent ในเครื่องหรือในเครือข่ายของคุณเอง ส่วนที่มีค่าใช้จ่ายคือ MQL5 Cloud Network ซึ่งคิดตามการใช้งาน

ทำไมติ๊กช่อง Visualization ไม่ได้?

มักเป็นเพราะเปิด Optimization ไว้ หรือเลือก Agent ระยะไกลอยู่ ปิด Optimization แล้วไปที่แท็บ Agents คลิกขวาที่ Agent ในเครื่องแล้วเลือก Select

Strategy Tester ใช้ข้อมูลราคาของโบรกเกอร์ไหน?

ใช้ของเซิร์ฟเวอร์ที่บัญชีซึ่งล็อกอินอยู่ต่ออยู่ ถ้าอยากใช้ข้อมูลของโบรกเกอร์ที่จะเทรดจริง ให้ล็อกอินบัญชีนั้นก่อนเปิดหน้าต่างทดสอบ ข้อมูลแต่ละเซิร์ฟเวอร์เก็บแยกกัน ไม่ปนกัน

Agent ในเครื่องมีกี่ตัว ปิดบางตัวได้ไหม?

จำนวนเท่าคอร์เชิงตรรกะของ CPU ปิดบางตัวได้ในแท็บ Agents ด้วยคำสั่ง Edit ในเมนูคลิกขวา Agent ในเครื่องมีให้ตั้งแค่เปิดหรือปิด การปิดบางตัวช่วยเหลือแรงเครื่องไว้ทำงานอื่นระหว่างรอผล

สรุป: รู้ทุกช่องก่อน แล้วค่อยเชื่อตัวเลข
