เชื่อมต่อ Windows VPS ได้แล้ว ส่วนนี้อธิบายต่อว่าทำไมการใช้ VPS รัน EA จึงมั่นคงกว่าคอมที่บ้าน ควรเลือกเครื่องแบบไหน ย้ายไฟล์อย่างไร และเตรียมอะไรไว้ให้ MT5 ไม่ปิดตามตอนออกหรือตอนเครื่องรีสตาร์ต

ทำไมควรใช้ VPS รัน EA แทนคอมที่บ้าน

EA จะทำงานได้ต้องครบสองข้อ คือโปรแกรม MT5 เปิดค้าง และมีสัญญาณถึงเซิร์ฟเวอร์ของโบรกเกอร์ คอมที่บ้านมีหลายจุดที่ทำให้สองข้อนี้หลุด โดยไม่เกี่ยวกับตลาดเลย

[eabull_figure name="vps-flow"]
  • ไฟดับหรือไฟตก: เครื่องดับไปโดยไม่มีใครอยู่หน้าจอ
  • เครื่องจัดการตัวเอง: Windows Update สั่งรีสตาร์ตตอนกลางคืน หรือเครื่องเข้าโหมด Sleep เมื่อไม่มีคนใช้
  • อินเทอร์เน็ตบ้านไม่นิ่ง: หลุดเป็นช่วงสั้น ๆ โดยเฉพาะตอนเราเตอร์รีเซ็ตตัวเอง

Windows VPS อยู่ในศูนย์ข้อมูลที่มีไฟสำรองและเครือข่ายเสถียร ความเสี่ยงกลุ่มนี้จึงลดลงมาก ทีมงานจึงแนะนำให้รัน [eabull_brand] บน VPS ตลอด 24 ชั่วโมง แต่ VPS ไม่ได้ทำให้ผลการเทรดดีขึ้น สิ่งที่ได้คือเครื่องที่พร้อมทำงานแทบตลอดเวลา ส่วนความเสี่ยงของตลาดยังอยู่ครบเหมือนเดิม

เช็กลิสต์ก่อนเช่า Windows VPS

ใช้ตารางนี้ตอนเทียบแพ็กเกจของผู้ให้บริการแต่ละราย ถ้าไม่แน่ใจว่าสเปกไหนพอสำหรับจำนวนบัญชีที่จะรัน ถามทีมงานทาง LINE ได้

หัวข้อมองหาอะไรถ้าไม่ได้ตามนี้
ระบบปฏิบัติการWindows รุ่นที่ยังได้แพตช์ความปลอดภัยต้องพึ่งวิธีอ้อมที่ดูแลยากกว่า เพราะ MT5 เวอร์ชันคอมพิวเตอร์สร้างมาสำหรับ Windows
หน่วยความจำ (RAM)พอสำหรับ Windows บวก MT5 ทุกชุดที่จะเปิดพร้อมกันเครื่องหน่วง กราฟค้าง และโปรแกรมอาจปิดตัวเอง
ดิสก์SSD ที่ยังมีพื้นที่ว่างเหลือดิสก์เต็มจนอัปเดตไม่ผ่าน เพราะไฟล์บันทึกของ MT5 โตขึ้นทุกวัน
ตำแหน่งศูนย์ข้อมูลเมืองหรือประเทศเดียวกับเซิร์ฟเวอร์ของโบรกเกอร์ หรือใกล้ที่สุดระยะทางไกลทำให้ค่า Ping สูง คำสั่งไปถึงโบรกเกอร์ช้าลง
การดูแลจากผู้ให้บริการบอก Uptime ชัด มีแผงควบคุมให้สั่งรีสตาร์ตเอง และมีช่องทางแจ้งปัญหาเวลาเครื่องค้าง คุณต้องรอนานกว่า EA จะกลับมาทำงาน

ปรับ Remote Desktop Connection ให้ย้ายไฟล์และใช้งานง่ายขึ้น

Remote Desktop Connection (คำสั่ง mstsc) มีตัวเลือกที่ช่วยให้ทำงานบน VPS เร็วขึ้น อยู่หลังปุ่ม Show Options ก่อนกด Connect คำอธิบายฉบับเต็มดูได้จาก เอกสาร mstsc บน Microsoft Learn

  • แท็บ Local Resources: ให้ช่อง Clipboard ถูกติ๊กไว้ (ปกติเปิดอยู่แล้ว) เพื่อคัดลอกข้อความและไฟล์ .ex5 จากคอมไปวางบน VPS ได้ทันที ถ้าวางไฟล์ไม่ได้ ให้กด More แล้วติ๊กไดรฟ์ที่เก็บไฟล์ ไดรฟ์นั้นจะไปปรากฏใน This PC ของ VPS
  • ปุ่ม Save As ในแท็บ General: เก็บการตั้งค่าทั้งหมดเป็นไฟล์ .rdp ไว้บนเดสก์ท็อป ครั้งต่อไปดับเบิลคลิกไฟล์นี้ก็เชื่อมต่อได้เลย
  • คีย์ลัดที่ควรจำ: Ctrl + Alt + Break สลับระหว่างเต็มจอกับแบบหน้าต่าง ส่วน Ctrl + Alt + End ใช้แทน Ctrl + Alt + Del บนเครื่อง VPS เช่น ตอนต้องการเปลี่ยนรหัสผ่าน

ย้ายไฟล์ขึ้น VPS แล้ว ขั้นตอนวางไฟล์ในโฟลเดอร์ Experts และเปิด Algo Trading เหมือนกับบนคอมทุกอย่าง ทำต่อได้ตามคู่มือ วิธีติดตั้ง EA บน MT5

ปิดหน้าต่างแบบไหน EA ยังทำงานต่อ

EA หยุดโดยเจ้าของไม่รู้ตัวบ่อยที่สุดตอน "ออก" จาก VPS เพราะการออกแต่ละแบบให้ผลต่างกันคนละขั้ว

สิ่งที่คุณทำผลกับ MT5 และ EA
คลิก X ที่แถบสีฟ้าบนสุดของจอรีโมต หรือปิดหน้าต่างโปรแกรมรีโมต (Disconnect)ปลอดภัย เซสชันบน VPS ค้างอยู่ทุกอย่าง ใช้วิธีนี้เป็นประจำ
เลือก Sign out จากเมนู Start บน VPSWindows ปิดทุกโปรแกรมของผู้ใช้นั้น EA หยุดทันที
สั่ง Restart หรือ Shut downVPS ดับหรือบูตใหม่ EA ว่างงานจนกว่าจะมีคนเปิด MT5 อีกครั้ง
คลิก X มุมขวาบนของหน้าต่าง MT5 โดยไม่ตั้งใจตัวโปรแกรมปิด EA หยุดเหมือนกัน ปุ่มนี้อยู่ใต้แถบรีโมตพอดี จึงพลาดกันบ่อย

ออกถูกวิธีแล้วแต่ MT5 ยังถูกปิดทุกครั้ง อาจมีการตั้งเวลาตัดเซสชันที่ไม่มีคนเชื่อมต่อไว้ ให้ผู้ให้บริการ VPS ยกเลิกเงื่อนไขนั้น ส่วนการแวะดูสถานะจากมือถือ ทำได้ตามคู่มือ เข้า VPS จาก Android และ เข้า VPS จาก iPhone หรือ iPad

เตรียมให้ MT5 กลับมาเองหลัง VPS รีสตาร์ต

เครื่อง VPS บูตใหม่ได้จากหลายสาเหตุ ทั้งแพตช์ของ Windows และงานซ่อมบำรุงฝั่งผู้ให้บริการ ทำสี่อย่างนี้ไว้ตั้งแต่วันแรก

  1. ให้ MT5 จำรหัสผ่าน: ตอนเข้าบัญชีใน MT5 บน VPS ให้ติ๊ก Save password โปรแกรมจะเข้าบัญชีเองทุกครั้งที่เปิด พร้อมโหลดกราฟและ EA ชุดเดิมกลับมา
  2. ใส่ MT5 ไว้ในรายการเปิดอัตโนมัติ: บน VPS คลิกขวาที่ปุ่ม Start → Run → พิมพ์ shell:startup → OK จะได้โฟลเดอร์ Startup ขึ้นมา คัดลอกทางลัด MT5 จากเดสก์ท็อปไปวางไว้ในนั้น ทุกครั้งที่ผู้ใช้นี้ล็อกอินเข้า Windows โปรแกรมจะเปิดขึ้นเอง
  3. ล็อกอินเข้า Windows บน VPS หลังเครื่องบูต: รายการใน Startup ไม่ทำงานจนกว่าจะมีคนเข้าระบบ หลังรีสตาร์ตทุกครั้งให้ต่อ Remote Desktop เข้าไปหนึ่งรอบ รอจนสถานะมุมขวาล่างของ MT5 ขึ้นตัวเลขการรับส่งข้อมูลและปุ่ม Algo Trading พร้อม แล้วค่อย Disconnect
  4. กำหนดเวลาอัปเดตเอง: ใน Windows Update ตั้ง Active hours ให้ทับช่วงเวลาที่ตลาดเปิดซื้อขาย แล้วเก็บงานอัปเดตกับการบูตใหม่ไว้ทำช่วงสุดสัปดาห์ซึ่งตลาด Forex ไม่เปิด อย่าปิดระบบอัปเดตไปเลย เครื่องที่ออนไลน์ทั้งวันทั้งคืนยิ่งต้องได้แพตช์ความปลอดภัย

Remote Desktop can't connect to the remote computerพิมพ์ IP หรือพอร์ตคลาดเคลื่อน เครื่องปลายทางดับหรือกำลังบูต หรือเน็ตที่ใช้อยู่ปิดกั้นการเชื่อมต่อแบบ RDPเทียบ IP กับอีเมลจากผู้ให้บริการ สั่งเปิดเครื่องในแผงควบคุม แล้วรอสักพักหรือเปลี่ยนไปใช้เน็ตอีกวง

ค่า Ping ใน MT5 สูงผิดปกติศูนย์ข้อมูลของ VPS ตั้งอยู่คนละภูมิภาคกับเซิร์ฟเวอร์ของโบรกเกอร์ดูตัวเลข Ping ที่แถบสถานะมุมขวาล่าง ถ้าสูงตลอด ลองย้ายไปศูนย์ข้อมูลที่ใกล้กว่า

ถ้าเครื่องปกติดีแต่ EA ไม่ยอมทำงาน ต้นเหตุมักปรากฏเป็นข้อความใน MT5 เอง วิธีไล่อ่านอยู่ใน อ่านแท็บ Journal และ Experts หาสาเหตุ EA ไม่ทำงาน

คำถามที่พบบ่อยเรื่อง VPS รัน EA

รันหลายบัญชีบน VPS เครื่องเดียวได้หรือเปล่า?

ได้ ตราบที่แรมและ CPU รับไหว ข้อสำคัญคือแต่ละบัญชีต้องมี MT5 ของตัวเองที่ติดตั้งไว้คนละโฟลเดอร์ เนื่องจากโปรแกรมหนึ่งชุดเข้าบัญชีได้ทีละบัญชี

ควรเข้าไปตรวจ VPS บ่อยแค่ไหน?

แวะดูวันละครั้งก็พอ และเพิ่มอีกรอบเมื่อตลาดเปิดต้นสัปดาห์ หรือหลังผู้ให้บริการแจ้งว่าจะซ่อมบำรุงเครื่อง สิ่งที่ต้องดูมีสามจุด คือ MT5 ยังต่อเซิร์ฟเวอร์อยู่ ปุ่ม Algo Trading ยังเปิด และข้อความในแท็บ Journal กับ Experts ดูปกติ

คำเตือนความเสี่ยง: VPS แก้ปัญหาเรื่องเครื่องและเน็ต แต่ความผันผวนของตลาดยังอยู่เท่าเดิม การเทรดที่ใช้ Leverage อาจทำให้เงินในบัญชีหมดได้ EA ไม่รับประกันกำไร และตัวเลขที่ผ่านมาไม่ได้บอกว่าจะเกิดซ้ำ หมั่นตรวจบัญชีเป็นประจำ และฝากเท่าที่ยอมเสียได้ทั้งก้อน รายละเอียดอยู่ที่ ประกาศความเสี่ยงของการใช้ EA
