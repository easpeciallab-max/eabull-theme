EA BULL 1.0 ทำงานอย่างไร

EA BULL 1.0 เป็น Expert Advisor สำหรับเทรดทองคำ XAUUSD บน MetaTrader 5 ทำงานเป็นรอบ แต่ละรอบเริ่มเมื่อตลาดผ่านตัวกรองที่ตั้งไว้ จากนั้นเปิดไม้ตามขั้นกริดทั้งฝั่ง BUY และ SELL แล้วปิดไม้ทั้งตะกร้าพร้อมกันเมื่อกำไรรวมของรอบถึงเป้า

  • กริดสองทาง (Dual Grid): ราคาวิ่งครบระยะกริดเมื่อไร EA เปิดไม้ตามในทิศนั้น ราคาจะขึ้นหรือลงก็มีไม้ทำงาน
  • ปิดทั้งตะกร้า: ระบบไม่ได้ปิดทีละไม้ แต่ดูกำไรรวมของไม้ทั้งรอบ ถึงเป้าเมื่อไรปิดทั้งหมดในครั้งเดียว แล้วรอเริ่มรอบใหม่
  • ไม้กู้ตะกร้าค้าง: รอบที่ค้างนานมีไม้กู้ช่วยพาตะกร้ากลับมาปิด รายละเอียดอยู่ในหัวข้อถัดไป

EA ส่งคำสั่งเองทั้งหมดตามกติกาในระบบ คุณไม่ต้องกดเปิดหรือปิดเอง หน้าที่ของคุณคือเลือกระดับ LOT ให้ตรงกับเงินในบัญชี และดูให้ MT5 ที่รัน EA เปิดอยู่ตลอดช่วงที่ตลาดเปิด

แดชบอร์ดบนกราฟ

เมื่อวาง EA ลงกราฟ แดชบอร์ด GOLD DASHBOARD 1.0 จะขึ้นบนกราฟ รวมสิ่งที่ต้องดูและปุ่มที่ใช้บ่อยไว้ในจุดเดียว

  • พอร์ตและสถานะ: ภาพรวมของบัญชีและสถานะของรอบที่ EA ดูแลอยู่
  • ตลาด: ค่าตัวกรองที่ EA ใช้ตัดสินใจเริ่มรอบ เช่นแรงเทรนด์จาก ADX
  • ขนาด LOT: ปุ่ม ◄ ลด LOT และ เพิ่ม LOT ► เปลี่ยนระดับได้จากบนกราฟ
  • ชุดค่า: เลือกชุดค่าได้บนแดชบอร์ด ชุดตั้งต้นชื่อ TAURUS
  • ปุ่มพักคอก: กดแล้ว EA ไม่เริ่มรอบใหม่ แต่ยังดูแลรอบที่ค้างอยู่จนจบ ใช้ตอนอยากพักโดยไม่ทิ้งออเดอร์ที่เปิดไว้กลางทาง

ไม้กู้ตะกร้าค้าง

ถ้าตะกร้าเปิดค้างนานเกิน 90 นาทีโดยยังไม่ถึงเป้า ระบบไม้กู้จะเริ่มทำงาน โดยดูกรอบราคาสูงสุดและต่ำสุดของช่วง 70 นาทีล่าสุด แล้วเข้าไม้กู้เมื่อราคาแตะขอบกรอบ เป้าของไม้กู้คือพาทั้งตะกร้ากลับมาปิดที่จุดเสมอตัว

  • ไม้กู้จำกัดฝั่งละไม่เกิน 9 ไม้
  • ระหว่างที่ไม้กู้ทำงาน จำนวนไม้และขนาดรวมในบัญชีมากกว่ารอบปกติ เงินในบัญชีต้องรองรับช่วงนี้ได้

ตัวกรองก่อนเริ่มรอบใหม่

EA ไม่เริ่มรอบใหม่ทุกเวลา ต้องผ่านเงื่อนไขในตารางก่อน ส่วนรอบที่เปิดอยู่แล้วยังดูแลต่อตามปกติ

ตัวกรองค่าตั้งต้นทำงานอย่างไร
แรงเทรนด์ ADXADX 14 บนกราฟ M30 ไม่ต่ำกว่า 18ตลาดที่แรงน้อยเกินไป EA รอและยังไม่เริ่มรอบ
ช่วงเวลาเริ่มรอบ11:00 ถึง 24:00 น. เวลาไทยตั้งเป็นเวลาไทย EA แปลงเป็นเวลาของเซิร์ฟเวอร์ให้เอง
วันศุกร์ไม่เริ่มรอบใหม่หลัง 18:00 น. เวลาไทยใกล้ตลาดปิดสุดสัปดาห์ EA หยุดเริ่มรอบใหม่ก่อน
กันคำสั่งรัวเปิดตลอดกันการส่งคำสั่งซ้ำถี่ ๆ และกันไม้ซ้อน
จำสถานะเปิดตลอดปิดแล้วเปิด MT5 ใหม่ EA กลับมาดูแลรอบเดิมต่อได้

สิ่งที่ต้องรู้ก่อนเลือก

  • ไม่มีตัดขาดทุน (Stop Loss) ในตัว: EA ไม่ปิดไม้ขาดทุนเอง ตะกร้าปิดเมื่อถึงเป้าหรือกลับมาเสมอตัวด้วยไม้กู้ ถ้าต้องการหยุด ใช้ปุ่มพักคอกหรือปิดออเดอร์เองใน MT5
  • ติดลบลอยได้ระหว่างรอบ: ช่วงที่ราคาวิ่งทางเดียวยาว ไม้ในตะกร้าเพิ่มขึ้นและติดลบลอยได้มาก เงินในบัญชีต้องพอให้ผ่านช่วงนี้
  • ต้องรันต่อเนื่อง: EA ทำงานเฉพาะตอนที่ MT5 เปิดและต่ออินเทอร์เน็ต รันบน VPS จะไม่ต้องเปิดคอมทิ้งไว้
  • ใช้งานจริงต้องลงทะเบียนบัญชี: แจ้งเลขบัญชี MT5 และชื่อ Server ทาง LINE ให้ทีมงานลงทะเบียนก่อนเริ่มเทรดจริง

ผลทดสอบย้อนหลัง

EA BULL 1.0 ทดสอบใน Strategy Tester ของ MT5 กับทองคำ XAUUSD.s ของ Zaurix (โบรกเกอร์พันธมิตรของ EA BULL) บนกราฟ M1 แบบ Every tick based on real ticks เราไม่ลงตัวเลขผลทดสอบไว้บนเว็บ เพราะผลของระบบกริดขึ้นกับวันที่เริ่มทดสอบ ค่าหน่วงการส่งคำสั่ง และทุนที่ใช้มาก ตัวเลขชุดเดียวจึงบอกภาพได้ไม่ครบ

ขอดูรายงาน MT5 พร้อมเงื่อนไขการทดสอบครบทุกข้อได้ทาง LINE ส่วนวิธีอ่านรายงานทีละช่องอยู่ที่หน้าBacktest

ติดตั้งโดยสรุป

  1. ดาวน์โหลดไฟล์ zip ของ EA BULL 1.0 แล้วแตกไฟล์ จะได้ไฟล์ [eabull_ea product="1"] ไฟล์เดียว
  2. ใน MT5 เปิดเมนู File แล้วเลือก Open Data Folder เข้าโฟลเดอร์ MQL5 แล้วเข้า Experts จากนั้นวางไฟล์ลงไป
  3. กลับมาที่ MT5 คลิกขวาใน Navigator แล้วกด Refresh ชื่อ [eabull_ea product="1" field="name"] จะขึ้นในหมวด Expert Advisors
  4. กด Algo Trading ที่แถบด้านบนของ MT5 ให้ปุ่มขึ้นสีเขียว
  5. เปิดกราฟ XAUUSD.s กรอบเวลา M1 แล้วลาก EA ลงกราฟ แดชบอร์ดจะขึ้นบนกราฟ
  6. เลือกชุดค่าและระดับ LOT บนแดชบอร์ด แล้วแจ้งเลขบัญชี MT5 กับชื่อ Server ทาง LINE ให้ทีมงานลงทะเบียน

คำถามที่พบบ่อย

ต้องเปิดบัญชีกับโบรกเกอร์ไหน

EA BULL แนะนำ Zaurix ซึ่งเป็นโบรกเกอร์พันธมิตรของ EA BULL และ EA BULL 1.0 ทดสอบกับบัญชีของ Zaurix ดูวิธีสมัครได้ที่คู่มือเปิดบัญชี MT5

ใช้กับบัญชี MT5 ได้กี่บัญชี

EA BULL 1.0 ใช้ได้กับแพ็กเกจ Pro และ VIP แพ็กเกจ Pro ใช้ได้ 1 ถึง 2 บัญชี ส่วน VIP ตามที่ตกลงกับทีมงาน ดูรายละเอียดที่หน้าแพ็กเกจ

EA BULL 1.0 มีตัดขาดทุนไหม

ไม่มีตัดขาดทุนอัตโนมัติ ตะกร้าปิดเมื่อถึงเป้าหรือกลับมาเสมอตัวด้วยไม้กู้ คุณหยุดการเริ่มรอบใหม่ได้ด้วยปุ่มพักคอก และปิดออเดอร์เองใน MT5 ได้ทุกเมื่อ

ต้องเปิดคอมทิ้งไว้ตลอดไหม

EA ทำงานเฉพาะตอนที่ MT5 เปิดและต่ออินเทอร์เน็ตอยู่ ถ้าไม่อยากเปิดคอมทิ้งไว้ ให้รัน MT5 บน VPS ดูคู่มือ VPS

ผลทดสอบย้อนหลังดี แปลว่าจะได้กำไรไหม

ไม่ใช่ ผลทดสอบบอกได้แค่ว่ากติกาของ EA ทำงานอย่างไรกับราคาในอดีตภายใต้เงื่อนไขที่ตั้งไว้ ตลาดจริงมีสเปรด การส่งคำสั่ง และเหตุการณ์ที่ไม่เคยเกิด ไม่มี EA ตัวไหนรับรองกำไรได้

เมื่อมีรุ่นใหม่ จะได้อัปเดตอย่างไร

ทีมงานแจ้งทาง LINE เมื่อมีรุ่นใหม่ และการต่ออายุสิทธิ์ไม่มีค่าใช้จ่ายเพิ่ม

หน้าที่ควรอ่านต่อ

  • แพ็กเกจ: เทียบสิ่งที่ได้ในแต่ละแพ็กเกจ
  • ติดตั้ง EA: วางไฟล์ เปิดสวิตช์ ลากลงกราฟ
  • เครื่องคำนวณ Lot: คิดขนาดไม้จากทุนของคุณ
  • Backtest: อ่านตัวเลขในรายงานให้เป็น
