ล็อกอินไม่ได้ ทำอย่างไร

ล็อกอิน MT5 ไม่ผ่าน ดูข้อความที่มุมขวาล่างของโปรแกรม แล้วเทียบกับตารางนี้

อาการสาเหตุที่พบบ่อยวิธีแก้
ขึ้น Invalid accountLogin หรือรหัสผ่านผิด หรือใช้รหัส Portal แทนรหัสบัญชีเทรดตรวจเลขบัญชีและรหัสผ่านจากอีเมลของโบรกเกอร์ หรือเปลี่ยนรหัสผ่านบัญชีเทรดใน Portal
ขึ้น No connectionเลือก Server ผิด หรืออินเทอร์เน็ตมีปัญหาเลือก Server ให้ตรงกับที่โบรกเกอร์แจ้ง เช็กอินเทอร์เน็ต แล้วล็อกอินใหม่
ค้นหาโบรกเกอร์ไม่เจอชื่อในรายการต่างจากที่พิมพ์พิมพ์ชื่อเซิร์ฟเวอร์เต็มตามที่โบรกเกอร์แจ้งลงในช่องค้นหาแล้วกด Enter
ล็อกอินได้แต่ส่งคำสั่งไม่ได้ใช้รหัสผ่านแบบดูอย่างเดียว (Investor password)ล็อกอินใหม่ด้วยรหัสผ่านหลักของบัญชีเทรด
ยอดเงินไม่ตรงกับ Portalล็อกอินผิดบัญชี เช่นบัญชีเดโมเช็กเลขบัญชีใน Navigator แล้วดับเบิลคลิกบัญชีที่ถูกต้อง

ความเสี่ยง: ล็อกอิน MT5 ด้วยบัญชีเงินจริงแล้ว ทุกออเดอร์มีผลกับเงินของคุณ การเทรดด้วย EA อาจขาดทุนจนหมดบัญชี และผลในอดีตไม่ได้รับประกันผลในอนาคต อ่านประกาศความเสี่ยงก่อนเริ่ม

คำถามที่พบบ่อย

ทำไมมือถือรัน EA ไม่ได้

แอป MT5 บน Android และ iOS ไม่รองรับ EA ใช้ได้แค่ดูบัญชีและส่งคำสั่งด้วยมือ ถ้าต้องการให้ EA ทำงานตลอดโดยไม่เปิดคอม ใช้ VPS บน Windows

ล็อกอินบนคอมและมือถือพร้อมกันได้ไหม

ได้ บัญชีเดียวกันล็อกอินได้หลายเครื่องพร้อมกัน EA บนคอมหรือ VPS ทำงานต่อตามปกติ

รหัสผ่านบัญชีเทรดกับรหัส Portal ใช้ตัวเดียวกันไหม

อาจเป็นคนละชุด ดูจากอีเมลที่โบรกเกอร์ส่งตอนสร้างบัญชีเทรด หรือในหน้ารายละเอียดบัญชีใน Portal

ลืมรหัสผ่านบัญชีเทรดทำอย่างไร

เปลี่ยนรหัสผ่านบัญชีเทรดใน Portal ตามที่หน้าเว็บโบรกเกอร์แจ้ง แล้วล็อกอินใหม่ทุกเครื่อง รวมถึงบน VPS

ใช้ MT5 บน Mac ได้ไหม

ถ้าต้องการให้ EA ทำงานต่อเนื่อง ทางที่ตรงที่สุดคือรันบน Windows VPS แล้วใช้ Mac เชื่อมต่อเข้าไปดู ส่วนการรัน EA BULL บน Mac โดยตรง ถามทีมงานทาง LINE ก่อน
