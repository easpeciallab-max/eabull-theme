อ่านส่วนนี้ต่อจากขั้นตอนด้านบน ถ้าอยากล็อกอิน MT5 มือถือและคอมให้ผ่านในรอบเดียว ในนี้มีตารางเทียบหน้าจอเข้าระบบของ Windows, iPhone และ Android อธิบายว่ารหัสผ่านแต่ละชุดให้สิทธิ์ต่างกันแค่ไหน วิธีอ่านข้อความแจ้งเตือนเวลาเข้าไม่ได้ การใช้หลายบัญชี และเหตุที่ EA ต้องรันบนคอมหรือ VPS

หน้าล็อกอิน MT5 บนคอม iPhone และ Android อยู่ตรงไหน

ทุกแพลตฟอร์มใช้ข้อมูลสามอย่างเหมือนกัน คือเลขบัญชี (Login) รหัสผ่าน และชื่อเซิร์ฟเวอร์ ต่างกันแค่ทางเข้าและวิธีเลือกเซิร์ฟเวอร์

แพลตฟอร์มทางเข้าหน้าล็อกอินวิธีเลือกเซิร์ฟเวอร์สัญญาณว่าเชื่อมต่อแล้ว
Windows (คอมหรือ VPS)เมนู File → Login to Trade Accountเลือกจากช่อง Server หรือพิมพ์ชื่อเซิร์ฟเวอร์ลงไปเองมุมขวาล่างมีตัวเลขปริมาณข้อมูลหน่วย kb และราคาใน Market Watch ขยับ
iPhone และ iPadแท็บ Settings → New Accountพิมพ์ชื่อโบรกเกอร์ในช่องค้นหา แล้วแตะเซิร์ฟเวอร์ที่ตรงกับบัญชีแท็บ Trade แสดงยอดเงิน และราคาในแท็บ Quotes เปลี่ยนตามตลาด
Androidเมนูหลัก (ไอคอนสามขีด) → Manage accounts → ปุ่ม +ค้นหาชื่อโบรกเกอร์ แล้วเลือกเซิร์ฟเวอร์ให้ตรงเหมือนกับ iPhone

บนมือถือ หลังแตะชื่อเซิร์ฟเวอร์ แอปจะเสนอให้เปิดบัญชีทดลองใหม่ด้วย ให้เลือกเข้าสู่ระบบด้วยบัญชีที่มีอยู่แล้ว แล้วจึงกรอกเลขบัญชีกับรหัสผ่าน ชื่อปุ่มอาจต่างกันตามเวอร์ชันของแอป

เซิร์ฟเวอร์สำหรับบัญชีของคุณ: [eabull_broker field="server"] · ชื่อที่เลือกต้องเหมือนกันเป๊ะทั้งตัวสะกด ขีด และคำต่อท้าย เนื่องจากโบรกเกอร์มักแยกเซิร์ฟเวอร์ของบัญชีทดลองกับบัญชีเงินจริงออกจากกัน หากคุณเปิดบัญชีกับ Zaurix ผ่านลิงก์ของทีมงาน ขอแจ้งว่า [eabull_brand] เป็นพาร์ตเนอร์ของโบรกเกอร์รายนี้และได้รับค่าตอบแทนจากการเปิดบัญชีนั้น

ดาวน์โหลดโปรแกรมจากแหล่งทางการเท่านั้น เวอร์ชัน Windows อยู่ที่ หน้าดาวน์โหลดของ MetaQuotes แอปสำหรับ iPhone และ iPad อยู่ใน App Store ส่วนแอป Android อยู่ใน Google Play ตรวจชื่อผู้พัฒนาว่าเป็น MetaQuotes ทุกครั้ง ไฟล์ติดตั้งที่ส่งต่อกันในกลุ่มแชทอาจถูกดัดแปลงไว้ดักรหัสผ่าน

รหัสผ่านหลักกับรหัสผ่านนักลงทุน ใช้ต่างกันอย่างไร

บัญชี MT5 หนึ่งเลขผูกกับรหัสผ่านสองชุด ใครถือชุดไหนก็ทำอะไรในบัญชีได้ไม่เท่ากัน

ถ้ามีคนขอรหัสผ่านหลักจากคุณ ไม่ว่าจะแนะนำตัวว่าเป็นใคร ให้ถือว่าผิดปกติไว้ก่อน เวลาทีมงาน [eabull_brand] ต้องเปิดดูบัญชีของคุณ สิ่งที่ขอมีแค่เลข Login ชื่อเซิร์ฟเวอร์ และรหัสชุด Investor

วิธีเปลี่ยนรหัสชุด Investor บน MT5 เวอร์ชัน Windows: Tools → Options → เลือกแท็บ Server → คลิก Change → พิมพ์รหัส Master ที่ใช้อยู่ → เลือกเปลี่ยนรหัสแบบ investor (read only) → ตั้งรหัสใหม่แล้วกด OK พอทีมงานดูเสร็จ คุณตั้งรหัสใหม่ซ้ำอีกรอบได้ทันที โบรกเกอร์บางรายให้ทำขั้นนี้ผ่าน Client Portal ได้ด้วย

Invalid accountเซิร์ฟเวอร์ที่เลือกไม่ใช่ของบัญชีนี้ เช่น บัญชีเงินจริงแต่เลือกเซิร์ฟเวอร์ Demo หรือใส่อีเมลกับรหัสลูกค้าลงช่อง Loginเปิดอีเมลแจ้งข้อมูลบัญชีจากโบรกเกอร์ แล้วไล่เทียบเลข Login กับชื่อเซิร์ฟเวอร์ทีละตัวอักษร
รหัสผ่านถูกปฏิเสธเอารหัสของหน้าสมาชิกโบรกเกอร์มาใส่ แป้นพิมพ์ค้างภาษาไทย หรือคัดลอกรหัสมาพร้อมช่องว่างพิมพ์รหัสบัญชีเทรดเองทีละตัว หากลืมให้ตั้งใหม่ในหน้าสมาชิกของโบรกเกอร์
No connectionเน็ตหลุด โปรแกรมกันไวรัสหรือไฟร์วอลล์กั้นไว้ หรือโบรกเกอร์กำลังซ่อมบำรุงเซิร์ฟเวอร์ลองเปลี่ยนเครือข่าย บน Windows คลิกแถบสถานะตรงมุมขวาล่างแล้วสั่ง Rescan servers เพื่อค้นเส้นทางเชื่อมต่อใหม่

เคยใช้ได้ วันนี้เข้าไม่ได้บัญชีถูกพักเพราะไม่ได้ใช้นาน หรือบัญชีทดลองถึงวันหมดอายุสอบถามโบรกเกอร์ หรือเปิดบัญชีใหม่จากหน้าสมาชิก

เปิดหลายบัญชี หรือดูบัญชีเดียวจากหลายเครื่อง

MT5 บน Windows หนึ่งชุดต่อกับบัญชีได้ทีละบัญชีเท่านั้น หากเปลี่ยนไปเข้าบัญชีอื่นในหน้าต่างเดียวกัน EA บนกราฟจะหยุดดูแลบัญชีเก่าแล้วเริ่มทำงานกับบัญชีใหม่ทันที ซึ่งมักไม่ใช่สิ่งที่ต้องการ ทางที่ถูกคือติดตั้ง MT5 ชุดที่สองโดยเลือกตำแหน่งติดตั้งใหม่ตอนรันตัวติดตั้ง แล้วผูกแต่ละชุดไว้กับบัญชีเดียว บน VPS ก็ใช้หลักนี้

ฝั่งแอปมือถือ จะเพิ่มบัญชีไว้กี่บัญชีก็ได้และแตะสลับได้ตลอด การสลับในแอปไม่มีผลกับ EA ที่รันบนเครื่อง Windows เลย ส่วนการเปิดบัญชีเดียวพร้อมกันจากหลายอุปกรณ์ โดยทั่วไปทำได้ ขอแค่ให้มีเครื่องเดียวที่รัน EA กับบัญชีนั้น ไม่อย่างนั้นอาจเกิดออเดอร์ซ้ำซ้อน

มือถือใช้ติดตาม ส่วน EA ต้องอยู่บนคอมหรือ VPS

แอป MetaTrader 5 บน iPhone และ Android ไม่รองรับการรัน EA ดังนั้น [eabull_brand] ต้องติดตั้งบน MT5 เวอร์ชัน Windows ที่เปิดค้างไว้บนคอมหรือ Windows VPS ตลอดเวลา วิธีวางไฟล์ในโฟลเดอร์ Experts และเปิด Algo Trading อธิบายไว้ในคู่มือ ลง EA ใน MT5 ทีละขั้น ถ้ายังไม่มีเครื่องที่เปิดได้ทั้งวัน ดูวิธีใช้ Windows VPS สำหรับรัน EA

หน้าที่ของแอปมือถือคือหน้าจอติดตาม ใช้ดู Balance, Equity ออเดอร์ที่เปิดอยู่ และประวัติการเทรดได้จากทุกที่ แต่ควรระวังการปิดหรือแก้ออเดอร์ที่ EA ดูแลอยู่จากมือถือ เพราะระบบไม่รู้เจตนาของคุณ ถ้าไม่แน่ใจให้ถามทีมงานก่อน หากต้องการเห็นหน้าจอ MT5 บน VPS ทั้งหน้าจากมือถือ ใช้คู่มือ เข้า VPS จาก Android หรือ เข้า VPS จาก iPhone

อยากรู้ว่าบนแอปมือถือควรดูตัวเลขไหนบ้างและดูบ่อยแค่ไหน อ่านต่อที่ ดูผล EA บนมือถือผ่านแอป MT5

ถ้าต้องการให้ MT5 ส่งข้อความเด้งเข้ามือถือ มีวิธีตั้งค่าแบบละเอียดใน ตั้งแจ้งเตือน MT5 เข้ามือถือด้วย MetaQuotes ID

ถามบ่อยเรื่องล็อกอิน MT5 มือถือและคอม

จำรหัสผ่านบัญชีเทรดไม่ได้ ต้องติดต่อใคร?

ติดต่อโบรกเกอร์ที่คุณเปิดบัญชีไว้ เพราะบัญชีเทรดถูกสร้างและดูแลโดยโบรกเกอร์ ส่วนใหญ่ตั้งรหัสใหม่ได้เองในหน้าสมาชิก หากหาเมนูไม่เจอ ฝ่ายบริการลูกค้าของโบรกเกอร์ช่วยได้

ทำอย่างไรให้ MT5 บน VPS เข้าบัญชีเองหลังเปิดเครื่องใหม่?

ตอนล็อกอินให้ติ๊กช่อง Save password ไว้ ทุกครั้งที่โปรแกรมเปิดขึ้นมา MT5 จะต่อบัญชีเดิมให้อัตโนมัติ ถ้าไม่ติ๊กไว้ หลัง VPS รีบูต EA จะนิ่งอยู่จนกว่าคุณจะเข้าไปกรอกรหัสเอง

เครื่องที่รัน EA ใช้รหัสชุด Investor ได้ไหม?

ไม่ได้ รหัสชุดนี้เปิดดูได้อย่างเดียว EA อาจขึ้นบนกราฟให้เห็นตามปกติ แต่คำสั่งซื้อขายทุกรายการจะถูกปฏิเสธ

คำเตือนความเสี่ยง: การซื้อขายผ่าน MT5 เป็นกิจกรรมที่เสี่ยงสูง ยอดเงินในบัญชีอาจลดลงหรือหมดได้ EA ไม่ได้ทำให้ผลลัพธ์แน่นอน และสิ่งที่เกิดขึ้นแล้วไม่ใช่ตัวทำนายอนาคต เก็บรหัสผ่านหลักไว้กับตัวเองเท่านั้น และลงเงินเท่าที่รับการสูญเสียได้ อ่านต่อที่ ความเสี่ยงของการใช้ EA
