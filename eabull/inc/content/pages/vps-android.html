คู่มือ VPS Android ส่วนนี้ต่อจากขั้นตอนติดตั้งแอปด้านบน อธิบายว่า Windows App ทำอะไรได้บ้าง ตั้งค่าตอนเพิ่มเครื่องอย่างไรให้ดู MT5 สบายตา ใช้นิ้วสั่งงานหน้าจอ Windows อย่างไร ออกจากเซสชันแบบไหนที่ EA ไม่หยุด และแก้อาการที่เจอบ่อยบนมือถือ Android

Windows App บน Android ทำอะไรได้ และทำอะไรไม่ได้

Windows App เป็นแอปของ Microsoft ที่มาแทนแอป Remote Desktop ตัวเดิม หน้าที่ของมันคือส่งภาพหน้าจอของ VPS มาแสดงบนมือถือ แล้วส่งการแตะของคุณกลับไปเป็นการคลิกบน VPS โปรแกรม MT5 และ EA จึงยังทำงานอยู่บน VPS ทั้งหมด ต่อให้ปิดแอป ล็อกเครื่อง หรือแบตมือถือเกลี้ยง EA ก็ยังเดินต่อ

อย่าสับสนกับแอปเทรด MetaTrader 5 ที่ติดตั้งบน Android ซึ่งล็อกอินบัญชีเทรดโดยตรง แอป MT5 เปิดดูยอดเงินและออเดอร์ได้เร็ว แต่ไม่เห็นสถานะของตัว EA และรัน EA ไม่ได้ ใช้คู่กันจะสะดวกที่สุด อยากรู้ยอดเงินเร็ว ๆ เปิดแอป MT5 อยากรู้ว่า EA บน VPS ยังทำงานปกติไหม เปิด Windows App

ดาวน์โหลดได้จาก Windows App บน Google Play ตรวจชื่อผู้พัฒนาว่าเป็น Microsoft Corporation ก่อนติดตั้ง แอปรองรับ Android 10 ขึ้นไป ถ้ายังไม่ได้ตั้ง VPS หรือยังไม่ได้ติดตั้ง MT5 บนเครื่อง ให้ทำบนคอมตามคู่มือ ใช้ Windows VPS รัน EA ก่อน เพราะงานติดตั้งและย้ายไฟล์ทำบนจอใหญ่ได้ง่ายกว่ามาก

ตั้งค่าตอนเพิ่มเครื่องให้ดู MT5 สบายตา

ตอนกรอก PC Name ด้วย IP ของ VPS จะมีส่วน Additional settings ให้แตะเปิดเพิ่ม ตัวเลือกในส่วนนี้ช่วยให้ใช้งานบนจอมือถือได้ดีขึ้น

  • ชื่อที่แสดง (Display name): ตั้งชื่อที่จำง่าย เช่น VPS-EA-1 จะได้แยกออกเมื่อมีหลายเครื่องในแท็บ Devices
  • การแสดงผล (Display settings): ถ้าตัวอักษรใน MT5 เล็กเกินไป ลองปรับความละเอียดหรือการย่อขยายในส่วนนี้ ชื่อตัวเลือกย่อยอาจต่างกันตามเวอร์ชันของแอป
  • การเข้าถึงทรัพยากรในเครื่อง: ค่าเริ่มต้นปิดการส่งต่ออุปกรณ์ไว้ทั้งหมด ซึ่งเหมาะกับการเข้าไปดู MT5 อยู่แล้ว ไม่ต้องเปิดเพิ่ม เพราะงานย้ายไฟล์ EA ควรทำจากคอม
  • Add หรือ Add & Connect: กด Add เพื่อบันทึกไว้ในแท็บ Devices หรือกด Add & Connect เพื่อบันทึกและเชื่อมต่อทันที ครั้งแรกแอปจะถามบัญชีผู้ใช้ของ VPS

สั่งงาน Windows บนจอสัมผัส

หน้าจอ Windows ถูกออกแบบมาสำหรับเมาส์กับคีย์บอร์ด พอย้ายมาอยู่บนจอมือถือจึงต้องปรับวิธีกดนิดหน่อย ระหว่างเชื่อมต่อ แถบเครื่องมือของแอปมีให้สลับโหมดควบคุมสองแบบ คือแตะตรงจุด (Direct touch) กับลูกศรเมาส์ (Mouse pointer) ชื่อเรียกอาจต่างกันเล็กน้อยตามเวอร์ชัน

อยากทำวิธีบนจอสัมผัส
คลิกปุ่มโหมดแตะตรงจุด: แตะที่ปุ่มนั้นเลย · โหมดลูกศร: ลากนิ้วพาลูกศรไปวางก่อน แล้วแตะหนึ่งครั้ง
คลิกขวากดนิ้วเดียวค้างไว้ หรือในโหมดลูกศรให้แตะพร้อมกันสองนิ้ว
เลื่อนรายการใช้สองนิ้วปัดขึ้นหรือปัดลง
ขยายหรือย่อภาพกางสองนิ้วออกเพื่อขยาย หุบเข้าเพื่อย่อ
พิมพ์ข้อความแตะไอคอนแป้นพิมพ์บนแถบเครื่องมือด้านบน

ตะแคงมือถือให้เป็นแนวนอนก่อนเปิดดู MT5 จอจะกว้างพอให้อ่านแท็บต่าง ๆ ได้ และขยายภาพทุกครั้งก่อนแตะแถวปุ่มเล็กมุมขวาบน ตรงนั้นมีปุ่มปิดโปรแกรม MT5 วางเรียงชิดกับปุ่มย่อหน้าต่าง แตะคลาดไปนิดเดียวโปรแกรมก็ปิด ถ้าปุ่มเบียดกันมาก ใช้โหมดลูกศรจะแม่นกว่า

ออกจากเซสชันโดยไม่ให้ EA หยุด

ดูเสร็จแล้ว จะสั่งตัดการเชื่อมต่อในแอป หรือปัดแอปทิ้งจากหน้าสลับแอปก็ได้ สองวิธีนี้ปิดแค่ภาพฝั่งมือถือ ส่วนเซสชันบน VPS ยังเปิดค้างและ EA ยังทำงาน สิ่งที่ต้องเลี่ยงคือคำสั่งที่ปิดโปรแกรมฝั่ง VPS ได้แก่

  • เลือก Sign out จากเมนู Start ของ Windows ซึ่งจะปิดทุกโปรแกรม รวมถึง MT5
  • สั่ง Restart หรือ Shut down เครื่องโดยไม่ได้วางแผนว่าจะกลับเข้าไปเปิด MT5
  • เผลอแตะปุ่ม X ของหน้าต่าง MT5 ในจังหวะที่ตั้งใจจะออกจากแอป

เข้าไปดูเมื่อไร และดูแลความปลอดภัยของมือถือ

การเปิดจอเฝ้าทั้งวันไม่ได้ช่วยอะไร กลับยิ่งทำให้อยากเข้าไปยุ่งกับระบบโดยไม่มีเหตุผล เลือกดูเป็นจังหวะแบบนี้ก็พอ

  • แวะดูสั้น ๆ วันละครั้ง ว่าโปรแกรมยังต่อเซิร์ฟเวอร์และ EA ยังพร้อมทำงาน
  • หลังตลาดเปิดต้นสัปดาห์ เพราะ VPS มักได้รับอัปเดตหรือถูกบูตใหม่ระหว่างวันหยุด
  • เมื่อผู้ให้บริการ VPS หรือโบรกเกอร์ประกาศว่าจะซ่อมบำรุงระบบ

VPS ที่รัน EA ผูกอยู่กับบัญชีเทรดที่มีเงินจริง ขณะที่มือถือติดตัวไปทุกที่และมีโอกาสสูญหายมากกว่าคอม จึงควรล็อกเครื่องด้วยรหัสหรือลายนิ้วมือไว้เสมอ มือถือที่ใช้ร่วมกับคนในบ้าน ไม่ควรให้แอปบันทึกรหัสผ่าน VPS เมื่อมือถือหาย ให้รีบเปลี่ยนรหัสผ่าน VPS จากคอม และอย่าแปะ IP ชื่อผู้ใช้ หรือรหัสผ่าน VPS ไว้ในกลุ่ม OpenChat หรือแชทกลุ่มใด ๆ

แก้ปัญหาเมื่อเข้า VPS Android ไม่ได้

อาการต้นเหตุที่พบบ่อยทางแก้
ต่อไม่ติดเลยIP หรือพอร์ตคลาดเคลื่อน เครื่องปลายทางดับ หรือ Wi-Fi สาธารณะและ Wi-Fi ออฟฟิศกั้น Remote Desktop ไว้เทียบ IP ในการ์ดเครื่องกับอีเมลของผู้ให้บริการ เช็กสถานะเครื่องในแผงควบคุม แล้วลองเปลี่ยนเป็นเน็ตมือถือ
รหัสผ่านไม่ผ่านแป้นพิมพ์มือถือเปลี่ยนตัวแรกเป็นตัวพิมพ์ใหญ่อัตโนมัติ หรือชื่อผู้ใช้สะกดผิดเปิดเมนูของการ์ดเครื่องนั้น เลือกแก้ไขบัญชีผู้ใช้ แล้วพิมพ์ใหม่อย่างช้า ๆ
ตัวหนังสือเล็กจนอ่านไม่ออกความละเอียดของเซสชันสูงเกินขนาดจอมือถือตะแคงจอ ขยายภาพ หรือปรับ Display settings ของเครื่องนั้น
กดโดนปุ่มข้าง ๆ แทนใช้โหมดแตะตรงจุดกับปุ่มที่เล็กมากสลับเป็นโหมดลูกศร แล้ววางลูกศรบนปุ่มก่อนแตะ
ตัวอักษรที่ขึ้นไม่ตรงกับที่พิมพ์มือถือใช้แป้นภาษาหนึ่ง แต่ Windows บน VPS ตั้งไว้อีกภาษาปรับภาษาสองฝั่งให้ตรงกันก่อนกรอกข้อมูล โดยเฉพาะช่องรหัสผ่าน
หลุดเป็นระยะเวลาสัญญาณไม่ดีเครือข่ายมือถือไม่นิ่งEA บน VPS ไม่ได้รับผลกระทบ รอสัญญาณกลับมาแล้วแตะเครื่องเดิมอีกครั้ง ภาพจะต่อจากที่ค้างไว้

เข้าได้แล้วแต่ไม่แน่ใจว่าหน้าจอ MT5 ปกติหรือเปล่า แคปหน้าจอส่งให้ทีมงานช่วยอ่านได้ ไม่ต้องส่งรหัสผ่าน VPS มาด้วย

ถามบ่อยเรื่อง VPS Android

Windows App บังคับให้ลงชื่อเข้าใช้ Microsoft หรือไม่?

ไม่บังคับ การเพิ่มเครื่องด้วย Add PC แล้วใช้ชื่อผู้ใช้กับรหัสผ่านของ VPS ทำได้ทันที ข้ามหน้าลงชื่อเข้าใช้ไปได้เลย

ดู VPS ผ่านเน็ตมือถือกินดาต้ามากแค่ไหน?

ขึ้นกับว่าเปิดค้างนานเท่าไรและภาพบนจอเปลี่ยนบ่อยแค่ไหน แวะดูไม่กี่นาทีแล้วออกแทบไม่กินดาต้า แต่ถ้าเปิดทิ้งไว้เป็นชั่วโมง ปริมาณที่ใช้ก็จะสูงขึ้นตามเวลา

เปิดจากมือถือแล้วไปเปิดจากคอมต่อได้ไหม?

ได้ ถ้าเข้าด้วยชื่อผู้ใช้เดิม อุปกรณ์ที่ต่อทีหลังจะรับหน้าจอเดิมไปแสดงต่อ ส่วนอุปกรณ์แรกจะหลุดออกเอง โดยที่โปรแกรมบน VPS ไม่ได้ถูกปิด

คำเตือนความเสี่ยง: การส่องดู VPS ผ่านมือถือช่วยให้รู้สถานะเร็วขึ้น แต่ไม่ได้ลดความเสี่ยงของการซื้อขาย การเทรดที่ใช้ Leverage อาจทำให้เงินในบัญชีลดลงมากหรือหมด EA ไม่ได้รับประกันผลกำไร และผลลัพธ์ที่ผ่านมาไม่ใช่ตัวบอกอนาคต ลงเงินเท่าที่รับการสูญเสียได้ และอ่าน ประกาศความเสี่ยง ก่อนเริ่มใช้งาน
