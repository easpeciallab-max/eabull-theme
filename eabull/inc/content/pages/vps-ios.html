เปิดแอปครั้งแรก: สิทธิ์ที่แอปขอ และการปักหมุดเครื่อง

ครั้งแรกที่เปิด Windows App บน iPhone หรือ iPad แอปอาจถามขออนุญาตใช้ Bluetooth และเชื่อมต่ออุปกรณ์ในเครือข่ายท้องถิ่น (Local Network) เอกสารของ Microsoft แนะนำให้กด Allow ทั้งสองข้อ จากนั้นดูหน้าแนะนำจนจบแล้วกด Done หรือกด Skip เพื่อข้าม การเชื่อมต่อ VPS ด้วย IP ไม่ต้องลงชื่อเข้าใช้บัญชี Microsoft

  • เพิ่มเครื่อง: แตะปุ่ม + แล้วเลือกเพิ่ม PC กรอก IP ของ VPS ในช่อง PC name ถ้ามีเลขพอร์ตให้ต่อท้ายด้วยโคลอน
  • บัญชีผู้ใช้: แอปจะถามชื่อผู้ใช้และรหัสผ่านของ VPS ตอนเชื่อมต่อ ถ้าไม่อยากให้เครื่องจำรหัส เลือกให้ถามทุกครั้งได้
  • ปักหมุดไว้ใน Favorites: ถ้าเข้า VPS บ่อย ปักหมุดเครื่องไว้ในแท็บ Favorites จะได้แตะเข้าได้ทันทีโดยไม่ต้องหาในรายการ

ควบคุมหน้าจอ VPS บน iPhone และ iPad

ระหว่างเชื่อมต่อ แถบเครื่องมือของแอปให้สลับวิธีควบคุมได้สองแบบ แบบแตะตรงจุด (Direct touch) เหมาะกับปุ่มใหญ่และการลากหน้าต่าง ส่วนแบบลูกศรเมาส์ (Mouse pointer) เหมาะกับปุ่มเล็กในแถบเครื่องมือของ MT5 เพราะวางลูกศรได้แม่นก่อนแตะ

  • คลิกขวา: แตะค้างหนึ่งนิ้ว หรือแตะสองนิ้วพร้อมกันในโหมดลูกศร
  • เลื่อนหน้าและซูม: ลากสองนิ้วเพื่อเลื่อน ถ่างหรือจีบสองนิ้วเพื่อขยายและย่อ
  • พิมพ์: เรียกคีย์บอร์ดจากไอคอนรูปแป้นพิมพ์ในแถบเครื่องมือของเซสชัน

iPad ต่อ Trackpad เมาส์ หรือคีย์บอร์ดภายนอกเพิ่มได้ตามความสามารถของ iPadOS ทำงานกับ MT5 ได้คล่องเกือบเท่าคอมพิวเตอร์ ส่วน iPhone จอเล็กกว่ามาก ให้ตะแคงเครื่องทุกครั้ง และขยายภาพก่อนแตะแถวปุ่มมุมขวาบน เพราะปุ่มปิดโปรแกรมอยู่ติดกับปุ่มอื่น

แบตเตอรี่ การล็อกจอ และการแจ้งเตือนบน iOS

สลับแอปหรือล็อกจอแล้ว EA ยังทำงาน

iOS จำกัดการทำงานเบื้องหลังของแอปเพื่อประหยัดพลังงาน พอคุณไปเปิดแอปอื่นหรือกดล็อกจอสักครู่ Windows App ก็จะหลุดการเชื่อมต่อ เป็นพฤติกรรมปกติของระบบ เครื่อง VPS ยังเก็บเซสชันไว้ MT5 กับ EA ไม่สะดุด เปิดแอปกลับมาแล้วแตะเครื่องเดิมก็กลับเข้าหน้าจอที่ค้างไว้

ใช้พลังงานมากกว่าแอปส่วนใหญ่

ตลอดเวลาที่ต่ออยู่ แอปต้องดึงภาพจากเครื่องปลายทางมาแสดงไม่หยุด แบตเตอรี่และดาต้าจึงหมดไวกว่าการเปิดแอปแชทหรือแอป MT5 วิธีประหยัดที่สุดคือเข้าไปดูเฉพาะเรื่องที่ต้องดูแล้วออก โหมดประหยัดพลังงานของ iPhone ไม่กระทบ EA แม้แต่น้อย เพราะ EA ไม่ได้ใช้ทรัพยากรใดของมือถือ

อยากได้การแจ้งเตือน ให้ใช้ระบบของ MT5

Windows App ทำหน้าที่แค่ถ่ายทอดภาพ จึงไม่แจ้งเตือนอะไรเมื่อบัญชีมีความเคลื่อนไหว ถ้าอยากให้ข้อความจาก MT5 เด้งเข้า iPhone ให้ใช้ระบบ Push Notification ของ MT5 เอง เริ่มจากเปิดแอป MT5 บน iPhone ไปที่ส่วน Messages เพื่อจด MetaQuotes ID ของเครื่อง จากนั้นใน MT5 บน VPS เข้า Tools → Options → แท็บ Notifications เปิด Enable Push Notifications และกรอก ID ที่จดไว้ ปิดท้ายด้วยการเปิดสิทธิ์แจ้งเตือนของแอป MetaTrader 5 ในการตั้งค่า iPhone

ออกจากแอปได้ แต่อย่าปิดอะไรบน VPS

จะปัดปิด Windows App หรือสั่งตัดการเชื่อมต่อในแอปก็ปลอดภัยทั้งคู่ ที่ทำให้ EA หยุดคือการสั่งงานบนเครื่อง VPS เองในลักษณะต่อไปนี้

  • กด Sign out ของ Windows บนเครื่อง VPS
  • รีสตาร์ตหรือปิดเครื่อง VPS โดยไม่ได้กลับเข้าไปเปิด MT5 ต่อ
  • นิ้วไปโดนปุ่มปิดหน้าต่างของ MT5 ซึ่งปิดโปรแกรมทันที

แก้ปัญหาการเข้า VPS iPhone และ iPad

สิ่งที่เกิดขึ้นต้นเหตุที่น่าจะเป็นลองทำแบบนี้
ต่อเครื่องไม่ติดIP หรือพอร์ตคลาดเคลื่อน เครื่องปลายทางดับ หรือเครือข่ายที่ใช้กั้นการเชื่อมต่อแบบ RDPเทียบ IP ในการ์ดเครื่อง เช็กสถานะในแผงควบคุมของผู้ให้บริการ แล้วลองเปลี่ยนจาก Wi-Fi เป็น 4G หรือ 5G
รหัสผ่านไม่ผ่านคีย์บอร์ด iOS เปลี่ยนอักษรตัวแรกเป็นตัวใหญ่เอง หรือเพิ่งมีการเปลี่ยนรหัส VPSเปิดหน้าแก้ไขบัญชีผู้ใช้ของเครื่องนั้นแล้วกรอกใหม่ หรือตั้งให้แอปถามรหัสตอนเชื่อมต่อแทน
กลับมาทีไรต้องต่อใหม่ทุกรอบiOS จำกัดการทำงานเบื้องหลังปล่อยไว้ได้ ไม่มีผลกับ EA กลับมาที่แอปแล้วแตะเครื่องเดิมอีกครั้ง
กดโดนปุ่มข้าง ๆ แทนโหมดแตะตรงจุดไม่แม่นพอสำหรับปุ่มขนาดเล็กเปลี่ยนเป็นโหมดลูกศร แล้วขยายภาพก่อนแตะ
อักษรที่ขึ้นบนจอไม่ใช่ตัวที่กดภาษาคีย์บอร์ดของ iPhone ไม่ตรงกับภาษาที่ Windows บน VPS ใช้อยู่ตั้งภาษาสองฝั่งให้ตรงกันก่อนกรอกข้อมูล โดยเฉพาะช่องรหัสผ่าน

ถ้าเปิดหน้าจอได้แล้วแต่เจอข้อความใน MT5 ที่ไม่แน่ใจ แคปหน้าจอส่งให้ทีมงานช่วยอ่านได้ ไม่ต้องแนบรหัสผ่าน VPS

ถามบ่อยเรื่อง VPS iPhone

มีแค่ iPad ไม่มี iPhone ใช้ได้เหมือนกันไหม?

ใช้ได้ทุกขั้นเหมือนกัน ทั้งแอปและวิธีตั้งค่าไม่ต่างจาก iPhone ข้อดีคือจอกว้าง อ่านกราฟกับตารางใน MT5 ได้ชัดกว่า แถมต่อ Trackpad หรือเมาส์ช่วยได้

ปิดแอปหรือปิดเครื่อง iPhone ไปแล้ว EA ยังเดินอยู่ไหม?

ยังเดินอยู่ เพราะ EA ไม่ได้อยู่ในมือถือ สิ่งที่หยุดไปมีแค่ภาพที่ส่งมาแสดงบนจอของคุณ ตราบใดที่บน VPS ไม่มีใครกด Sign out หรือปิด MT5 ระบบก็ทำงานตามปกติ

ลง EA ในแอป MT5 บน iPhone ได้หรือเปล่า?

ไม่ได้ เวอร์ชัน iOS ของ MetaTrader 5 ใช้เปิดดูบัญชีและส่งคำสั่งเองด้วยมือ ไม่มีที่ให้วางไฟล์ EA ตัว EA ต้องอยู่บน MT5 เวอร์ชัน Windows ที่เปิดไว้บนคอมหรือ VPS

คำเตือนความเสี่ยง: iPhone ช่วยให้ตามดูระบบได้จากทุกที่ แต่ความเสี่ยงของการซื้อขายยังเท่าเดิม การเทรดที่ใช้ Leverage อาจทำให้เงินในบัญชีลดลงมากหรือหมด EA ไม่มีการรับประกันกำไร และตัวเลขในอดีตไม่ใช่สิ่งยืนยันอนาคต ตั้งรหัสปลดล็อก iPhone ไว้เสมอ อย่าบอกรหัส VPS กับใคร และอ่าน ความเสี่ยงของการใช้ EA ก่อนเริ่ม
