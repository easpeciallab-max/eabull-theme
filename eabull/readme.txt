=== EA BULL · WordPress Theme ===

ธีมเว็บไซต์ EA BULL ผู้ช่วยเทรดอัตโนมัติสำหรับ MetaTrader 5
ดีไซน์ Glass Sky: พื้นฟ้าสว่าง แผงกระจกฝ้า น้ำเงินปีกกับทอง · รองรับมือถือ · ปุ่มติดต่อทุกปุ่มไปที่ LINE

----------------------------------------------------------------
1) อัปเดตธีม
----------------------------------------------------------------
ธีมนี้ติดตั้งผ่าน WP Pusher จาก GitHub (easpeciallab-max/eabull-theme, subdirectory eabull)
อัปเดต: หลังบ้าน > WP Pusher > Themes > Update theme

----------------------------------------------------------------
2) ตั้งค่าเว็บครั้งแรก
----------------------------------------------------------------
หลังบ้าน > ลักษณะ (Appearance) > EA BULL Setup > ตั้งค่าเว็บทั้งหมด

ระบบจะ
- สร้างเพจที่ยังไม่มี พร้อมผูกเทมเพลต (แพ็กเกจ คู่มือ ทดสอบ ความเสี่ยง เอกสาร /go)
- ตั้งหน้าแรกและหน้าบทความ
- สร้างเมนูหลักและเมนูท้ายเว็บ
- นำเข้าบทความเริ่มต้น 12 เรื่องเป็นฉบับร่าง พร้อมรูปปกและข้อมูล Yoast

เพจกฎหมาย (นโยบายความเป็นส่วนตัว ข้อกำหนด คำขอลบข้อมูล) มีช่อง [เจ้าของเว็บ: ...]
ต้องกรอกชื่อผู้ให้บริการ ที่อยู่ อีเมล และระยะเวลาให้ครบก่อนเผยแพร่

----------------------------------------------------------------
3) ตั้งค่าที่ต้องทำก่อนเปิดใช้จริง
----------------------------------------------------------------
ลักษณะ > ปรับแต่ง (Customize) > "EA BULL · ตั้งค่าหน้าเว็บ"

1. "1) ช่องทางติดต่อ" ใส่ลิงก์ LINE OA และ OpenChat
   ปุ่มติดต่อทุกปุ่มจะใช้ลิงก์นี้ · ถ้าเว้นว่าง ปุ่มจะพาไปหน้า /go/ แทน
2. ข้อมูลโบรกเกอร์ (ชื่อ ชื่อเซิร์ฟเวอร์) ใช้ในคู่มือเปิดบัญชีและล็อกอิน
3. คุกกี้และสถิติ: ใส่ GA4 Measurement ID และ Meta Pixel ID
   สคริปต์จะโหลดหลังผู้ใช้กดยินยอมเท่านั้น
4. แพ็กเกจ: โหมดเริ่มต้นคือ "สอบถามทาง LINE" (ไม่แสดงราคา)
   ถ้าจะแสดงราคา ให้กรอกราคาและสิ่งที่ได้รับจริงของแต่ละแพ็กเกจก่อน
5. ผลทดสอบ Backtest / Forward Test: กรอกเฉพาะข้อมูลจริงที่มีแหล่งที่มา
   ช่องที่ยังขึ้นต้นด้วย "ระบุ" จะถูกซ่อนอัตโนมัติ

----------------------------------------------------------------
4) แก้เนื้อหา
----------------------------------------------------------------
- ข้อความสั้น หัวข้อ ปุ่ม รูป ทุกส่วนของหน้าแรก หน้าย่อย คู่มือ /go และคุกกี้:
  ลักษณะ > ปรับแต่ง (แต่ละ section มีสวิตช์แสดง/ซ่อน)
- เนื้อหายาวของเพจและบทความ: แก้ในหน้าแก้ไขเพจหรือโพสต์ตามปกติ
- รูปประกอบคู่มือ: ช่องรูปของแต่ละขั้นอยู่ในหมวดคู่มือ (ผู้ดูแลเห็นกรอบเส้นประเมื่อยังไม่มีรูป)
- ห้ามเปิดเพจที่ใช้เทมเพลตของธีมด้วย Elementor เพราะจะทับการแสดงผล

----------------------------------------------------------------
5) หลักเนื้อหาของเว็บ
----------------------------------------------------------------
- ไม่แสดงตัวเลขผลเทรดที่ไม่มีแหล่งที่มา และไม่ใส่รีวิวที่ไม่ใช่ของจริง
- คำเตือนความเสี่ยงต้องคงไว้ครบทุกหน้า
- กล่าวถึงโบรกเกอร์พันธมิตรเมื่อไหร่ ต้องบอกว่าเราได้รับค่าตอบแทน
- ภาพที่มีตัวเลข ต้องมีคำบรรยายว่าเป็นภาพประกอบ ไม่ใช่ผลการเทรดจริง
